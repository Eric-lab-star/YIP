# DS18B20 온도센서

어항 물이 너무 차가워지면 알려 주는 장치, 베란다 온도를 기록하는 장치를 만들려면
온도를 **숫자로** 읽을 수 있어야 해요.
오늘의 주인공 **DS18B20**은 긴 전선 끝에 금속 캡이 달린 온도센서로,
**방수형이라 물속 온도까지** 잴 수 있는 믿음직한 부품입니다.
그리고 선 **한 가닥**으로 대화하는 **1-Wire** 통신도 함께 배워요.

<Callout type="goal">

**이번 수업을 마치면**

1. DS18B20이 온도를 숫자로 알려 주는 디지털 센서임을 설명할 수 있어요.
2. 1-Wire 통신의 특징을 I2C와 비교해서 말할 수 있어요.
3. 1-Wire를 설정하고 온도 값을 읽는 과정을 이해할 수 있어요.

</Callout>

## 1. 온도를 숫자로 말해 주는 센서

<SectionClip src={clipBase + "/ep01.mp4"} title="53화 — 온도를 숫자로 말하는 센서" />

CDS와 MQ-2를 떠올려 보세요. 저항이 변하는 아날로그 센서라서,
라즈베리파이로는 기준보다 높은지 낮은지만 알 수 있었어요.

DS18B20은 다릅니다. **센서 안에 작은 변환 회로가 들어 있어서**,
온도를 직접 재고 **"지금 24.3도야"라는 숫자**로 답해 주는 **디지털 센서**예요.
ADC가 없는 라즈베리파이에게 딱 맞는 똑똑한 친구죠.

- 측정 범위는 영하 55도부터 영상 125도까지로 넉넉해요.
- 방수형은 금속 캡 부분을 물에 담가 수온을 잴 수 있어요.
- MPU6050처럼, 아날로그의 한계를 **센서 쪽에서 디지털로 바꿔서** 해결한 경우예요.

## 2. 1-Wire: 선 한 가닥으로 나누는 대화

<SectionClip src={clipBase + "/ep02.mp4"} title="54화 — 선 한 가닥의 대화" />

지난 시간의 I2C는 SDA와 SCL **두 가닥**으로 대화했어요.
DS18B20이 쓰는 **1-Wire(원와이어)**는 이름 그대로 **데이터 선이 한 가닥**뿐입니다.

| 비교 | I2C | 1-Wire |
| --- | --- | --- |
| 데이터 선 | 2가닥(SDA, SCL) | 1가닥 |
| 장치 구분 | 주소(예: 0x68) | 센서마다 새겨진 고유 번호 |
| 라즈베리파이 기본 핀 | GPIO2, GPIO3 | GPIO4 |

1-Wire에서도 여러 센서를 **같은 선 하나에** 함께 연결할 수 있어요.
공장에서 센서마다 **세상에 하나뿐인 고유 번호**를 새겨 두었기 때문에,
어항용과 실내용 DS18B20 두 개를 한 선에 달아도 누가 보낸 값인지 구분됩니다.

<Callout type="note">

**풀업 저항 하나가 필요해요.**

1-Wire의 데이터 선은 평소 전압을 잡아 줄 **4.7k옴 풀업 저항**을
데이터 선과 3.3V 사이에 하나 연결해야 해요.
버튼 수업에서 배운 풀업과 같은 개념인데, 이번에는 내장 풀업 대신
**바깥에 실제 저항**을 다는 것이 안정적이라 회로도에 포함되어 있습니다.

| 센서 선 | 연결하는 곳 |
| --- | --- |
| 빨강(VCC) | 3.3V |
| 검정(GND) | GND |
| 노랑(데이터) | GPIO4 + 4.7k옴 저항으로 3.3V와 연결 |

선 색은 제품마다 다를 수 있으니 수업 회로도와 제품 설명을 확인하세요.

</Callout>

## 3. 설정하고 읽어 보기

<SectionClip src={clipBase + "/ep03.mp4"} title="55화 — 폴더 속의 온도" />

I2C처럼 1-Wire도 설정에서 켜 줘야 해요.
**기본 설정 → Raspberry Pi Configuration → Interfaces**에서 **1-Wire를 사용함**으로 바꾸고 재부팅합니다.

재부팅하면 재미있는 일이 일어나요.
운영체제가 센서를 찾아서 **파일처럼** 보여 줍니다.
`/sys/bus/w1/devices/` 폴더 아래에 `28-`로 시작하는 폴더가 생기는데, 그 이름이 바로 센서의 고유 번호예요.
그 안의 파일을 읽으면 온도가 나옵니다. **센서 읽기가 파일 읽기가 되는 거예요.**

파이썬에서는 이 과정을 w1thermsensor 라이브러리가 깔끔하게 대신해 줍니다.

```python
# 실습에서 설치할 w1thermsensor 라이브러리를 사용한 예시예요.
from w1thermsensor import W1ThermSensor
from time import sleep

sensor = W1ThermSensor()

while True:
    temp = sensor.get_temperature()
    print(f"현재 온도: {temp:.1f}도")
    sleep(1)
```

실행한 뒤 금속 캡을 손으로 쥐어 보세요. 체온 때문에 숫자가 천천히 올라갑니다.
얼음물에 담그면 내려가고요. **온도가 변하는 데는 시간이 걸린다**는 것도 함께 관찰하세요.
금속 캡이 온도에 적응할 때까지 몇 초에서 수십 초가 걸리는 것이 정상이에요.

<Callout type="tip">

**센서가 안 보일 때**

1. 설정에서 1-Wire를 켜고 **재부팅**했는지 확인해요.
2. 4.7k옴 풀업 저항이 데이터 선과 3.3V 사이에 있는지 확인해요. 가장 흔한 원인이에요.
3. 데이터 선이 GPIO4(물리 핀 7)에 꽂혀 있는지 확인해요.
4. `/sys/bus/w1/devices/`에 28-로 시작하는 폴더가 있는지 봐요. 없으면 배선, 있으면 코드 문제로 갈라낼 수 있어요.

</Callout>

## 스스로 확인해 보기

<details>
<summary>1. CDS나 MQ-2와 달리 DS18B20은 라즈베리파이에서 값을 숫자로 읽을 수 있어요. 왜인가요?</summary>

DS18B20은 센서 안에 변환 회로가 있어서 온도를 직접 숫자로 바꿔 보내는 디지털 센서이기 때문이에요.
아날로그 값을 그대로 내보내는 센서와 달리 ADC가 따로 필요 없습니다.

</details>

<details>
<summary>2. 같은 선 하나에 DS18B20 두 개를 연결하면 값이 섞이지 않을까요?</summary>

섞이지 않아요. 센서마다 공장에서 새긴 고유 번호가 있어서,
어느 센서가 보낸 온도인지 번호로 구분할 수 있습니다.

</details>

<details>
<summary>3. 1-Wire 회로에서 4.7k옴 저항은 무슨 역할을 하나요?</summary>

데이터 선의 평소 전압을 3.3V로 잡아 주는 풀업 저항이에요.
이 저항이 없으면 신호가 불안정해져서 센서를 찾지 못하는 경우가 많습니다.

</details>
