# DS18B20 온도센서 실습

오늘은 센서가 말해 주는 온도를 두 가지 방법으로 읽어 봅니다.
먼저 폴더 속 파일을 직접 열어 보고, 그다음 파이썬 프로그램으로 온도 변화를 지켜봐요.

<Callout type="goal">

**이번 실습을 마치면**

1. 풀업 저항을 넣은 DS18B20 회로를 만들고 1-Wire를 켤 수 있어요.
2. 터미널에서 센서의 고유 번호를 찾고 온도 파일을 열어 볼 수 있어요.
3. 파이썬으로 온도를 읽으며 금속 캡이 얼마나 빨리 반응하는지 잴 수 있어요.

</Callout>

<Callout type="important">

**배선 전 약속**

- 배선을 바꿀 때는 **먼저 전원을 완전히 분리**해요.
- GPIO 신호 핀은 **3.3V**까지만 다뤄요. 센서의 VCC와 풀업 저항은 5V가 아니라 **3.3V(물리 핀 1)**에 연결해요.
- 선 색은 제품마다 다를 수 있어요. 빨강, 검정, 노랑이 아니라면 제품 설명을 먼저 확인해요.
- 물에는 **금속 캡만** 담가요. 라즈베리파이와 브레드보드는 물에서 멀리 둬요.

</Callout>

- [ ] 브레드보드

- [ ] 찬물을 담은 컵 (선택)

코드의 따옴표 안에 있는 한글이 입력되지 않으면 영어로 바꿔도 돼요.

<MissionCard number={1} title="회로 만들고 1-Wire 켜기" time="15분">

**회로의 길:** 데이터 선은 GPIO4(물리 핀 7)로 가고, 같은 줄이 4.7k옴 저항을 지나 3.3V와도 이어져요.

1. 라즈베리파이의 전원을 끄고 어댑터를 뽑아요.
2. 아래 표대로 하나씩 꽂아요. 센서 선 끝이 잘 안 꽂히면 선생님께 보여 주세요.

| 부품 | 한쪽 | 다른 쪽 |
| --- | --- | --- |
| 센서 빨강 (VCC) | 브레드보드 a5 | |
| 센서 노랑 (데이터) | 브레드보드 a10 | |
| 센서 검정 (GND) | 브레드보드 a15 | |
| 4.7k옴 저항 | c5 | c10 |
| 점퍼선 1 | 물리 핀 1 (3.3V) | 브레드보드 b5 |
| 점퍼선 2 | 물리 핀 7 (GPIO4) | 브레드보드 b10 |
| 점퍼선 3 | 물리 핀 9 (GND) | 브레드보드 b15 |

3. 확인이 끝나면 전원을 연결해요.
4. 라즈베리 메뉴의 **기본 설정**에서 **Raspberry Pi Configuration**(새 버전은 **Control Centre**)을 열고, **Interfaces**에서 **1-Wire**를 켠 뒤 다시 시작해요.

**성공 확인:** 다시 시작한 뒤 설정 화면을 열어도 1-Wire가 켜져 있고, 센서가 뜨거워지지 않아요. 센서가 뜨거우면 바로 전원을 뽑고 선을 확인해요.

</MissionCard>

<MissionCard number={2} title="폴더 속에서 온도 찾기" time="10분">

운영체제는 센서를 파일처럼 보여 줘요. 터미널에 입력해요.

```bash
ls /sys/bus/w1/devices/
```

`28-`로 시작하는 이름이 보이면 그것이 내 센서의 고유 번호예요. 공책에 적고 짝의 번호와 비교해 봐요.

이제 온도가 적힌 파일을 열어요. `28-*`는 `28-`로 시작하는 폴더를 뜻해요.

```bash
cat /sys/bus/w1/devices/28-*/w1_slave
```

두 줄이 나오고, 첫 줄 끝에는 `YES`, 둘째 줄 끝에는 `t=` 뒤에 숫자가 있어요. 이 숫자를 1000으로 나누면 섭씨온도예요.

**성공 확인:** `t=` 뒤의 숫자를 도 단위로 바꿔 적었고, 교실 온도와 비슷해요. 금속 캡을 손으로 쥐고 몇십 초 뒤에 같은 명령을 다시 실행하면 숫자가 커져요. 위쪽 화살표 키를 누르면 명령을 다시 입력하지 않아도 돼요.

</MissionCard>

<MissionCard number={3} title="파이썬으로 온도 변화 재기" time="20분">

w1thermsensor 라이브러리를 설치해요. 지난 시간에 만든 가상 환경을 그대로 써요.

```bash
python3 -m venv --system-site-packages ~/sensor-env
source ~/sensor-env/bin/activate
pip install w1thermsensor
```

첫 줄은 가상 환경이 없을 때 새로 만들어 주고, 이미 있으면 그대로 둬요.

<Callout type="note">

**수업 전에 선생님이 준비해 두면 좋아요**

설치는 인터넷 상태에 따라 몇 분씩 걸릴 수 있어요. 위 명령을 미리 실행해 두면 학생은 `source` 줄만 입력하고 바로 시작할 수 있어요.

</Callout>

1. Thonny 편집기에 아래 코드를 입력하고 홈 폴더에 `read_temp.py`로 저장해요.

```python
from w1thermsensor import W1ThermSensor
from time import sleep, time

sensor = W1ThermSensor()
start = time()

for i in range(40):
    temp = round(sensor.get_temperature(), 1)
    seconds = round(time() - start)
    print(f"{seconds}초: {temp}도")
    sleep(1)
```

`time()`은 지금 시각을 초로 알려 줘요. 시작할 때의 값을 빼면 몇 초 지났는지 나와요. 이 프로그램은 40번 재면 스스로 끝나요.

2. 터미널 맨 앞에 `(sensor-env)`가 있는지 확인하고 실행해요. 중간에 멈출 때는 **Ctrl+C**를 눌러요.

```bash
python read_temp.py
```

**성공 확인:** 시작하고 몇 초가 지났는지와 온도가 한 줄씩 나와요. 금속 캡을 건드리지 않으면 숫자가 거의 그대로예요.

이제 금속 캡을 쥐기 전에 **결과를 먼저 예상**해 봐요.

3. 손으로 쥐면 몇 도까지 오를까요? 몇 초 만에 거기까지 갈까요? 예상을 공책에 적어요.
4. 프로그램을 다시 실행하고, 시작하자마자 금속 캡을 손으로 꼭 쥐어요. 화면을 보며 표를 채워요. 딱 맞는 초가 없으면 가장 가까운 줄을 적어요.

| 시간 | 온도 |
| --- | --- |
| 0초 | |
| 10초 | |
| 20초 | |
| 30초 | |
| 60초 | |

5. 다시 실행하고 이번에는 손을 뗀 채로 내려오는 빠르기를 봐요. 찬물이 있다면 금속 캡만 담가 비교해요.

**성공 확인:** 표에서 온도가 한 번에 뛰지 않고 차츰 변해요. 쥐었을 때와 뗐을 때 중 어느 쪽이 더 빠른지 내 표로 말할 수 있어요.

</MissionCard>

## 막혔을 때

| 증상 | 확인할 곳 |
| --- | --- |
| `/sys/bus/w1/devices/` 폴더가 없어요 | 1-Wire를 켜고 다시 시작했는지 확인해요. |
| `28-` 폴더가 없어요 | 전원을 분리하고 4.7k옴 저항이 5번 줄과 10번 줄을 잇는지 확인해요. 가장 흔한 원인이에요. |
| 이름이 `00-`으로 시작해요 | 풀업 저항이 빠졌을 수 있어요. 저항과 3.3V 선을 확인해요. |
| 데이터 선이 맞는지 모르겠어요 | 점퍼선 2가 물리 핀 7번(GPIO4)에 있는지, 센서 선 색이 제품 설명과 같은지 확인해요. |
| 센서가 뜨거워져요 | 바로 전원을 뽑아요. VCC와 GND가 바뀌었을 수 있으니 선생님과 함께 확인해요. |
| `NoSensorFoundError`가 나요 | 코드가 아니라 배선이나 설정 문제예요. `ls` 명령으로 `28-` 폴더부터 확인해요. |
| `No module named 'w1thermsensor'` | 터미널 앞에 `(sensor-env)`가 없어요. `source ~/sensor-env/bin/activate`를 입력하고 다시 실행해요. |
