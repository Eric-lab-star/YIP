# 카메라 연결하기

지금까지 라즈베리파이는 밝기, 가스, 거리, 온도, 기울기를 느꼈어요.
오늘은 가장 풍부한 감각인 **시각**을 달아 줄 차례입니다.
전용 **카메라 모듈**을 연결하면 라즈베리파이로 사진을 찍고 영상을 녹화할 수 있어요.
다음 시간의 사물인식으로 가는 징검다리이기도 합니다.

<Callout type="goal">

**이번 수업을 마치면**

1. 카메라 모듈을 CSI 단자에 안전하게 연결할 수 있어요.
2. 명령어로 사진과 영상을 촬영할 수 있어요.
3. Python 프로그램에서 카메라를 사용할 수 있어요.

</Callout>

## 1. 어디에, 어떻게 꽂을까요?

1차시에서 스치듯 만났던 단자를 기억하나요?
보드 가운데쯤의 길고 납작한 단자, **CSI(카메라 직렬 인터페이스)**가 오늘의 자리예요.
카메라 모듈은 USB가 아니라 **얇은 리본 케이블**로 이 단자에 연결합니다.
CSI는 카메라 전용의 널찍한 길이라 고화질 영상도 빠르게 전달할 수 있어요.

연결 순서는 손끝의 섬세함이 필요해요.

1. **운영체제를 종료하고 전원을 분리해요.** 카메라 연결은 반드시 꺼진 상태에서 합니다.
2. CSI 단자 양끝의 **검은 잠금 클립을 살짝 위로** 당겨 올려요.
3. 리본 케이블을 꽂아요. **금속 접점의 방향**이 중요해요. 수업 안내에 따라 접점이 올바른 쪽을 향하게 합니다.
4. 케이블을 끝까지 넣은 채 **잠금 클립을 다시 눌러** 고정해요.
5. 살짝 당겨 보아 빠지지 않으면 성공이에요.

<Callout type="important">

**리본 케이블과 잠금 클립은 약해요.**

1차시의 당부를 다시 떠올립시다. 리본 케이블은 꺾이면 속의 가는 선이 끊어질 수 있고,
잠금 클립은 과하게 힘을 주면 부러져요. 모든 동작을 **천천히, 부드럽게** 합니다.
그리고 CSI 옆에는 생김새가 거의 같은 **DSI(디스플레이 단자)**가 있어요.
보드에 적힌 글자를 확인하고 **CAMERA라고 표시된 쪽**에 꽂으세요.

</Callout>

## 2. 첫 촬영: 명령어 한 줄

전원을 켜고 터미널에서 한 줄이면 사진이 찍혀요.

```bash
rpicam-still -o photo.jpg
```

몇 초간 미리보기가 뜬 뒤 `photo.jpg` 파일이 생깁니다.
파일 관리자에서 열어 보세요. 라즈베리파이가 본 첫 장면이에요.

영상도 비슷해요. 10초짜리 영상은 이렇게 찍습니다.

```bash
rpicam-vid -t 10000 -o video.mp4
```

`-t 10000`은 10,000밀리초, 곧 10초 동안 녹화하라는 뜻이에요.
촬영이 안 되면 먼저 연결을 의심합니다. 전원을 분리한 뒤 리본 케이블의 방향과 고정 상태를 다시 확인하세요.

## 3. Python으로 찍기: 프로그램과 카메라의 만남

명령어로도 충분히 찍을 수 있는데 왜 Python이 필요할까요?
**조건과 반복**을 붙일 수 있기 때문이에요.
"거리 센서에 물체가 가까워지면 찍어라", "10분마다 한 장씩 찍어라" 같은
**스스로 판단하는 카메라**는 프로그램이 있어야 가능합니다.

Python에서는 **Picamera2** 라이브러리를 사용해요. Raspberry Pi OS에 기본으로 들어 있습니다.

```python
from picamera2 import Picamera2
from time import sleep

camera = Picamera2()
camera.start()
sleep(2)

camera.capture_file("photo.jpg")
camera.stop()
```

- `camera.start()` 뒤에 `sleep(2)`를 두는 이유가 있어요. 카메라가 **밝기에 적응할 시간**을 주는 거예요. 사람 눈이 어두운 곳에서 적응하는 것과 같아요.
- `camera.capture_file(...)`: 사진을 찍어 파일로 저장해요.

여기에 반복문을 더하면 **타임랩스**(일정 간격으로 계속 찍기)가 되고,
15차시의 파일 저장과 합치면 촬영 기록 장부도 만들 수 있어요.
배운 조각들이 자꾸 서로 연결되는 것이 느껴지나요?

<Callout type="tip">

**카메라에는 책임이 따라와요.**

카메라는 다른 센서와 달리 **사람을 찍을 수 있는** 장치예요.
친구를 찍을 때는 반드시 먼저 허락을 받고,
교실 밖이나 다른 사람의 공간을 향하지 않게 해요.
촬영한 사진과 영상을 허락 없이 공유하지 않는 것까지가 오늘 배우는 기술의 일부입니다.

</Callout>

</details>

<details>
<summary>2. CSI와 DSI는 생김새가 비슷해요. 카메라는 어느 쪽에 꽂아야 하나요?</summary>

CAMERA라고 표시된 CSI 단자에 꽂아요.
DSI는 전용 디스플레이를 연결하는 단자라 역할이 달라요. 보드의 표기를 확인합니다.

</details>

<details>
<summary>3. 명령어로도 사진을 찍을 수 있는데 Python으로 찍는 이유는 무엇인가요?</summary>

조건과 반복을 붙일 수 있기 때문이에요.
센서 값에 따라 자동으로 찍거나 일정 간격으로 계속 찍는 것처럼,
스스로 판단하는 촬영은 프로그램으로만 만들 수 있어요.

</details>
