# 카메라 연결하기 실습

오늘은 라즈베리파이에 눈을 달아 줍니다.
리본 케이블을 조심히 연결하고, 명령어로 찍어 본 다음, 스스로 찍고 기록하는 프로그램까지 만들어요.

<Callout type="goal">

**이번 실습을 마치면**

1. 내 보드의 표기를 읽어 카메라 단자를 찾고 리본 케이블을 고정할 수 있어요.
2. 터미널에서 사진 한 장과 10초 영상을 찍어 파일로 열어 볼 수 있어요.
3. Python으로 여러 장을 찍고 촬영 시각을 파일에 남길 수 있어요.

</Callout>

<Callout type="important">

**배선 전 약속**

- 카메라를 꽂거나 뺄 때는 **운영체제를 종료하고 전원을 완전히 분리**해요.
- 리본 케이블은 꺾지 말고, 잠금 클립은 힘주어 당기지 않아요.
- 오늘은 GPIO 핀을 쓰지 않아요. 더 해 보기에서 버튼을 연결한다면 GPIO 신호 핀은 **3.3V**까지만 다루고, 5V 핀에 연결하지 마세요.
- 사람을 찍을 때는 먼저 허락을 받아요.

</Callout>

## 준비물

- [ ] 라즈베리파이와 전원 어댑터 (모니터, 키보드, 마우스 연결)
- [ ] 카메라 모듈
- [ ] 내 보드에 맞는 리본 케이블 (라즈베리파이 5와 Zero는 단자가 작아서 케이블이 달라요)
- [ ] 카메라 방향을 보여 주는 선생님의 안내 사진이나 모듈 설명서

코드의 따옴표 안에 있는 한글이 입력되지 않으면 영어로 바꿔도 돼요.

<MissionCard number={1} title="카메라 연결하기" time="15분">

1. 운영체제를 종료하고 어댑터를 뽑아요.
2. 보드에 적힌 글자를 읽어 카메라 단자를 찾아요. 단자의 위치는 보드 모델마다 다르니 위치로 찾지 말고 표기로 찾아요.

| 보드 | 카메라를 꽂는 곳 |
| --- | --- |
| 라즈베리파이 4 Model B | `CAMERA`라고 적힌 단자. 생김새가 비슷한 디스플레이 단자가 따로 있어요. |
| 라즈베리파이 5 | `CAM/DISP 0` 또는 `CAM/DISP 1`이라고 적힌 단자 |
| 그 밖의 보드 | 보드 표기와 공식 문서를 확인해요. |

3. 단자의 잠금 클립을 살짝 들어 올려요.
4. 선생님의 안내 사진이나 설명서를 보고 **금속 접점의 방향**을 맞춘 뒤 리본 케이블을 끝까지 넣어요. 방향은 보드와 모듈에 따라 다를 수 있으니 짐작으로 꽂지 않아요.
5. 케이블을 넣은 채 잠금 클립을 다시 눌러 고정하고, 살짝 당겨 빠지지 않는지 봐요.
6. 카메라 쪽 단자의 케이블도 같은 방법으로 확인해요.
7. 전원을 연결하고 바탕화면이 나오면 터미널에서 카메라 목록을 확인해요.

```bash
rpicam-hello --list-cameras
```

**성공 확인:** 터미널에 카메라 이름이 적힌 목록이 나와요. 카메라가 없다는 메시지가 나오면 전원을 분리하고 1번부터 다시 확인해요.

</MissionCard>

<MissionCard number={2} title="명령어로 찍어 보기" time="10분">

1. 사진을 한 장 찍어요. 몇 초 동안 미리보기가 뜬 뒤 파일이 저장돼요.

```bash
rpicam-still -o photo.jpg
```

2. 파일 관리자에서 `photo.jpg`를 열어 봐요.

이제 실행하기 전에 **결과를 먼저 예상**해 봐요.
`-t`는 시간을 정하는 옵션이고, 숫자만 적으면 밀리초 단위예요.
아래 명령은 앞의 명령보다 미리보기가 길까요, 짧을까요? 공책에 적어요.

```bash
rpicam-still -t 2000 -o quick.jpg
```

3. 실행해서 예상과 비교해요.
4. 10초짜리 영상을 찍어요. 라즈베리파이 4 이하의 보드에서는 `--codec libav`를 함께 적어야 재생기가 알아보는 진짜 MP4 파일이 만들어져요.

```bash
rpicam-vid -t 10s --codec libav -o video.mp4
```

<Callout type="note">

파일 이름 끝을 `.mp4`로 적는다고 내용까지 MP4가 되는 것은 아니에요.
공식 문서에 따르면 형식은 확장자가 아니라 `--codec` 옵션이 정합니다.
라즈베리파이 5는 `rpicam-vid -t 10s -o video.mp4`만 적어도 MP4로 저장돼요.

</Callout>

5. 파일 관리자에서 `video.mp4`를 열어 재생해요.

**성공 확인:** `photo.jpg`, `quick.jpg`, `video.mp4`가 모두 열려요. `-t 2000`을 적은 쪽의 미리보기가 약 2초로 더 짧았던 까닭을 말할 수 있어요.

</MissionCard>

<MissionCard number={3} title="Python으로 찍어 보기" time="10분">

1. Thonny에서 아래 코드를 `camera_test.py`로 저장하고 **Run**을 눌러요. 화면에 미리보기는 뜨지 않아요.

```python
from picamera2 import Picamera2
from time import sleep

camera = Picamera2()
camera.start()
sleep(2)

camera.capture_file("wait.jpg")
camera.stop()
```

2. 파일 관리자에서 `wait.jpg`를 열어 봐요.
3. `sleep(2)`는 카메라가 밝기에 적응할 시간을 줘요. 이 줄을 지우고 파일 이름을 `no_wait.jpg`로 바꾸면 사진이 어떻게 달라질지 **먼저 예상**해 공책에 적어요.
4. 실행한 뒤 두 사진을 나란히 비교해요. 차이가 작을 수도 있으니 밝기와 색을 잘 살펴봐요.

**성공 확인:** `wait.jpg`와 `no_wait.jpg`가 모두 만들어졌고, 어떤 차이가 보였는지 또는 왜 차이가 작았는지 공책에 적었어요.

</MissionCard>

<MissionCard number={4} title="촬영 기록 장부 만들기" time="10분">

반복문과 15차시의 파일 저장을 합쳐요. 3초마다 한 장씩, 다섯 장을 찍고 시각을 장부에 남깁니다.

1. 아래 코드를 `timelapse.py`로 저장해요.

```python
from picamera2 import Picamera2
from datetime import datetime
from time import sleep

camera = Picamera2()
camera.start()
sleep(2)

for i in range(5):
    now = datetime.now().strftime("%H%M%S")
    name = "shot_" + now + ".jpg"
    camera.capture_file(name)

    with open("camera_log.csv", "a") as file:
        file.write(now + "," + name + "\n")

    print(name, "저장했어요")
    sleep(3)

camera.stop()
```

2. 실행하기 전에 사진이 몇 장 생기고, 다시 한 번 실행하면 `camera_log.csv`가 몇 줄이 될지 예상해 봐요.
3. 두 번 실행해요. 찍는 동안 카메라 앞의 물건을 조금씩 옮겨 봐요.
4. 파일 관리자에서 사진과 `camera_log.csv`를 열어 봐요.

**성공 확인:** 사진 파일이 10장 생겼고, `camera_log.csv`에는 지워진 줄 없이 10줄이 쌓였어요. 사진을 차례로 넘기면 물건이 움직여요.

</MissionCard>

## 막혔을 때

| 증상 | 확인할 곳 |
| --- | --- |
| 카메라가 없다는 메시지가 나와요 | 전원을 분리하고 단자 표기, 금속 접점 방향, 양쪽 잠금 클립을 확인해요. |
| 방향과 고정이 맞는데도 목록이 비어 있어요 | 공식 모듈이 아니면 설정이 더 필요할 수 있어요. 선생님께 모듈 이름을 알려요. |
| `rpicam-still`을 찾을 수 없다고 나와요 | 운영체제 버전에 따라 명령 이름이 다를 수 있어요. 선생님과 설치 상태를 확인해요. |
| 카메라를 쓸 수 없다거나 사용 중이라는 오류가 나요 | 카메라를 쓰는 다른 프로그램이 돌고 있어요. Thonny의 Stop을 누르고 터미널 명령이 끝났는지 확인해요. |
| 사진이 온통 뿌옇거나 초점이 안 맞아요 | 렌즈에 보호 필름이 붙어 있는지 확인해요. |
| 사진이 거꾸로 찍혀요 | 카메라를 놓은 방향을 바꾸면 돼요. 고장이 아니에요. |
| `video.mp4`가 열리지 않아요 | 명령에 `--codec libav`를 넣었는지 확인해요. |
| `ModuleNotFoundError: No module named 'picamera2'` | Thonny가 쓰는 Python을 확인하고 선생님께 알려요. `sudo apt install python3-picamera2`가 공식 설치 방법이에요. |
