# LED 제어하기 실습

오늘은 내가 쓴 코드로 진짜 불빛을 켜 봅니다.
회로를 만들고, 쉘에서 한 줄씩 켜 본 다음, 깜빡이는 프로그램까지 완성해요.

<Callout type="goal">

**이번 실습을 마치면**

1. 저항과 LED를 직렬로 연결한 회로를 만들 수 있어요.
2. 쉘에서 `led.on()`과 `led.off()`로 LED를 켜고 끌 수 있어요.
3. 켜지는 시간과 꺼지는 시간을 내가 정해 LED를 깜빡이게 할 수 있어요.

</Callout>

<Callout type="important">

**배선 전 약속**

- 배선을 바꿀 때는 **먼저 전원을 완전히 분리**해요.
- GPIO 신호 핀은 **3.3V**까지만 다뤄요. 5V 핀에 연결하지 마세요.
- 전원을 넣기 전에 친구나 선생님과 배선을 한 번 더 확인해요.

</Callout>

## 준비물

- [ ] 라즈베리파이와 전원 어댑터 (모니터, 키보드, 마우스 연결)
- [ ] 브레드보드
- [ ] LED 1개
- [ ] 330옴 저항 1개
- [ ] 암-수 점퍼선 2개

<MissionCard number={1} title="LED 회로 만들기" time="15분">

**회로의 길:** GPIO17(물리 핀 11) → 저항 → LED 긴 다리 → LED 짧은 다리 → GND(물리 핀 9)

1. 라즈베리파이의 전원을 끄고 어댑터를 뽑아요.
2. 아래 표대로 하나씩 꽂아요. 브레드보드의 번호는 예시이니, 같은 줄끼리 이어지기만 하면 다른 줄을 써도 괜찮아요.

| 부품 | 한쪽 | 다른 쪽 |
| --- | --- | --- |
| 점퍼선 1 | 물리 핀 11 (GPIO17) | 브레드보드 a10 |
| 330옴 저항 | c10 | c15 |
| LED | 긴 다리 d15 | 짧은 다리 d16 |
| 점퍼선 2 | 브레드보드 a16 | 물리 핀 9 (GND) |

3. 회로의 길을 손가락으로 따라가며 끊어진 곳이 없는지 확인해요.
4. 확인이 끝나면 전원을 연결하고 바탕화면이 나올 때까지 기다려요.

**성공 확인:** 전원을 넣었을 때 LED는 아직 꺼져 있고, 연기나 타는 냄새가 나지 않아요. 이상하면 바로 전원을 뽑고 선생님을 불러요.

</MissionCard>

<MissionCard number={2} title="쉘에서 한 줄씩 켜 보기" time="10분">

Thonny 아래쪽의 **쉘**에 한 줄씩 입력하고 Enter를 눌러요.

```python
from gpiozero import LED
led = LED(17)
led.on()
```

세 번째 줄을 입력하는 순간 LED가 켜져요. 이제 꺼 봅니다.

```python
led.off()
```

**성공 확인:** `led.on()`과 `led.off()`를 입력할 때마다 LED가 바로 반응해요.

<Callout type="note">

쉘에서는 `led`라는 이름이 남아 있어서 LED가 켜진 상태로 유지돼요.
**Stop** 버튼을 누르면 쉘이 새로 시작되면서 `led`도 사라져요. 이때 LED는 꺼질 수도 있고, 켜진 채 남을 수도 있어요. 고장이 아니에요.
다시 쓰려면 `from gpiozero import LED`와 `led = LED(17)`부터 입력해야 해요. 프로그램이 `LED(17)`을 다시 만들면 LED는 꺼진 상태에서 시작해요.

</Callout>

</MissionCard>

<MissionCard number={3} title="깜빡이는 프로그램 만들기" time="15분">

1. Thonny의 쉘에서 쓰던 `led`를 정리하기 위해 **Stop** 버튼을 한 번 눌러요.
2. 편집기에 아래 코드를 입력하고 `blink.py`로 저장해요.

```python
from gpiozero import LED
from time import sleep

led = LED(17)

while True:
    led.on()
    sleep(1)
    led.off()
    sleep(1)
```

3. **Run** 버튼으로 실행해요. 멈출 때는 **Stop** 버튼을 눌러요.

**성공 확인:** LED가 1초 켜지고 1초 꺼지기를 반복해요.

이제 코드를 바꾸기 전에 **결과를 먼저 예상**해 봐요.

4. 첫 번째 `sleep(1)`을 `sleep(0.2)`로 바꾸면 LED가 어떻게 달라질까요? 예상을 공책에 적어요.
5. 실행해서 예상과 비교해요.

**성공 확인:** LED가 짧게 켜졌다가 1초 동안 꺼지기를 반복해요. 그렇게 보이는 이유를 코드의 어느 줄 때문인지 말할 수 있어요.

</MissionCard>

## 막혔을 때

| 증상 | 확인할 곳 |
| --- | --- |
| LED가 전혀 켜지지 않아요 | 전원을 분리하고 LED 방향을 확인해요. 긴 다리가 저항 쪽이어야 해요. |
| 방향이 맞는데도 켜지지 않아요 | 점퍼선이 물리 핀 11번과 9번에 있는지, 부품이 같은 줄에 꽂혔는지 확인해요. |
| `NameError: name 'led' is not defined` | `led = LED(17)`을 먼저 입력했는지 확인해요. Stop을 누르면 다시 입력해야 해요. |
| `GPIO busy`처럼 핀을 쓸 수 없다는 오류가 나요 | 이전 프로그램이 핀을 쓰고 있어요. Stop을 누르고 다시 실행해요. |
| `IndentationError` 오류가 나요 | `while True:` 아래 네 줄의 들여쓰기가 똑같은지 확인해요. |

## 더 해 보기

1. **두 번 깜빡이기:** 짧게 두 번 깜빡이고 2초 쉬기를 반복하게 바꿔 보세요.
2. **횟수 정하기:** `while True:` 대신 `for i in range(5):`를 써서 다섯 번만 깜빡이고 끝나게 해 보세요.
3. **핀 바꾸기:** 전원을 분리하고 점퍼선을 GPIO27(물리 핀 13)로 옮긴 뒤, 코드도 함께 바꿔 다시 켜 보세요.
