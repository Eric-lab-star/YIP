# MPU6050 센서

스마트폰을 옆으로 눕히면 화면이 따라 돕니다.
게임기를 기울이면 자동차가 방향을 틀죠.
기계가 자신의 기울기와 움직임을 느낄 수 있기 때문인데,
그 느낌을 담당하는 부품이 오늘의 주인공 **MPU6050**이에요.
그리고 이 센서를 통해 **I2C**라는 새로운 대화 방법도 함께 배웁니다.

<Callout type="goal">

**이번 수업을 마치면**

1. 가속도 센서와 자이로 센서가 각각 무엇을 재는지 설명할 수 있어요.
2. I2C 통신이 무엇이고 왜 필요한지 말할 수 있어요.
3. MPU6050을 연결해 기울기 값을 읽는 과정을 이해할 수 있어요.

</Callout>

## 1. 한 칩에 두 가지 감각

MPU6050 안에는 서로 다른 감각 두 개가 함께 들어 있어요.

| 감각 | 재는 것 | 알 수 있는 것 |
| --- | --- | --- |
| 가속도 센서 | 속도가 변하는 정도와 중력 | 기울기, 흔들림, 떨어짐 |
| 자이로 센서 | 회전하는 빠르기 | 어느 방향으로 얼마나 빨리 도는지 |

**가속도 센서**의 재미있는 점은 가만히 있어도 **중력**을 느낀다는 거예요.
중력은 항상 땅을 향하니까, 센서가 느끼는 중력의 방향을 보면
지금 보드가 **얼마나 기울어 있는지** 알 수 있습니다.
스마트폰 화면이 도는 것이 바로 이 원리예요.

**자이로 센서**는 회전을 느껴요. 가만히 있으면 0에 가깝다가, 빙글 돌리면 값이 커집니다.
두 감각은 서로의 약점을 보완하는 짝꿍이라 드론이나 게임기에는 거의 항상 함께 들어가요.

각 감각은 **X, Y, Z 세 방향**을 따로 재요.
그래서 MPU6050을 "6축 센서"라고 부릅니다. 가속도 3축 + 자이로 3축이에요.

## 2. 값이 많으면 핀이 모자라요 — I2C의 등장

여기서 문제가 하나 생깁니다.
여섯 가지 값이 쉬지 않고 변하는데, 지금까지처럼 핀 하나에 신호 하나씩 받는 방식이라면
핀이 몇 개나 필요할까요? 값 하나는 켜짐/꺼짐이 아니라 큰 숫자라서, 사실 그 방식으로는 어림도 없어요.

그래서 MPU6050은 **I2C(아이투씨)**라는 통신 방식을 사용합니다.
신호를 하나씩 보내는 대신, **정해진 규칙에 따라 숫자 데이터를 통째로 주고받는 대화**를 하는 거예요.
놀랍게도 선은 단 두 가닥이면 충분합니다.

- **SDA**: 데이터가 오가는 길
- **SCL**: 대화의 박자를 맞추는 시계 신호

<Callout type="analogy">

**깃발 신호와 전화 통화의 차이예요.**

지금까지의 GPIO 입출력은 깃발을 올리고 내리는 신호였어요. 간단하지만 전할 수 있는 내용이 적죠.
I2C는 전화 통화예요. "X축 가속도 값 알려 줘" 하고 물으면 "16384야" 하고 숫자로 답해 줍니다.
그리고 한 전화선에 여러 명이 **주소**로 구분되어 연결될 수 있어요.
MPU6050의 주소는 보통 **0x68**이에요. 같은 두 가닥 선에 다른 I2C 센서를 더 연결해도
주소가 다르면 서로 헷갈리지 않습니다.

</Callout>

라즈베리파이에는 I2C 전용 자리가 준비되어 있어요.
**SDA는 GPIO2(물리 핀 3), SCL은 GPIO3(물리 핀 5)**입니다.

| MPU6050 핀 | 연결하는 곳 |
| --- | --- |
| VCC | 3.3V(물리 핀 1) |
| GND | GND |
| SDA | GPIO2(물리 핀 3) |
| SCL | GPIO3(물리 핀 5) |

## 3. 사용 준비와 확인

I2C는 설정에서 켜 줘야 사용할 수 있어요.
라즈베리 메뉴의 **기본 설정 → Raspberry Pi Configuration → Interfaces**에서 **I2C를 사용함**으로 바꿉니다.

연결과 설정이 끝났는지 터미널에서 확인할 수 있어요.

```bash
i2cdetect -y 1
```

표 안에 **68**이 보이면 라즈베리파이가 MPU6050을 찾았다는 뜻이에요.
이 확인 한 줄이 실습에서 배선 문제를 잡는 가장 강력한 도구가 됩니다.

파이썬에서는 MPU6050용 라이브러리를 설치해 사용해요.
라이브러리가 I2C 대화를 대신해 주어서, 우리는 결과 숫자만 받으면 됩니다.

```python
# 실습에서 설치할 mpu6050 라이브러리를 사용한 예시예요.
from mpu6050 import mpu6050

sensor = mpu6050(0x68)

data = sensor.get_accel_data()
print(data["x"], data["y"], data["z"])
```

보드를 평평하게 두면 Z 방향 값에 중력이 나타나고,
보드를 기울이면 중력이 X나 Y 방향으로 옮겨 가는 것을 볼 수 있어요.
숫자가 기울기를 따라 변하는 것을 확인하는 것이 실습의 핵심입니다.

<Callout type="tip">

**i2cdetect에 아무것도 안 보일 때**

1. 설정에서 I2C를 켰는지 확인하고, 켰다면 재부팅했는지 확인해요.
2. SDA와 SCL이 서로 바뀌지 않았는지 확인해요. 가장 흔한 실수예요.
3. VCC는 **3.3V**에 연결했는지 확인해요.
4. 점퍼선을 다른 것으로 바꿔 봐요. 선 불량도 생각보다 잦습니다.

</Callout>

## 스스로 확인해 보기

<details>
<summary>1. 가속도 센서는 가만히 있어도 기울기를 알 수 있어요. 어떻게 가능한가요?</summary>

가속도 센서는 항상 땅을 향하는 중력을 느끼기 때문이에요.
센서가 느끼는 중력의 방향이 바뀌면 보드가 기울었다는 뜻이라, 그걸로 기울기를 계산합니다.

</details>

<details>
<summary>2. I2C 통신이 지금까지의 GPIO 입출력과 다른 점은 무엇인가요?</summary>

GPIO 입출력은 켜짐/꺼짐 신호 하나를 다루지만,
I2C는 두 가닥 선(SDA, SCL)으로 숫자 데이터를 통째로 주고받는 대화 방식이에요.
여러 장치가 주소로 구분되어 같은 선을 함께 쓸 수 있습니다.

</details>

<details>
<summary>3. MPU6050을 연결했는지 프로그램 없이 확인하는 방법은 무엇인가요?</summary>

터미널에서 i2cdetect -y 1을 실행해요.
표에 68이 나타나면 라즈베리파이가 센서를 찾은 것입니다.

</details>
