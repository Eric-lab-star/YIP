# 데이터 저장하기 실습

오늘은 흘러가던 온도를 파일에 붙잡아 둡니다.
쓰기 모드와 추가 모드를 눈으로 비교하고, 껐다 켜도 기록이 이어지는 온도 기록 장치를 완성해요.

<Callout type="goal">

**이번 실습을 마치면**

1. w 모드와 a 모드로 같은 파일을 열어 보고 결과가 어떻게 다른지 보여 줄 수 있어요.
2. 시각과 온도를 CSV로 쌓고, 머리글은 한 번만 적는 프로그램을 만들 수 있어요.
3. 쌓인 기록의 개수를 세어 내 예상과 비교할 수 있어요.

</Callout>

<Callout type="important">

**배선 전 약속**

- 지난 시간의 DS18B20 회로를 다시 만들어요. 배선을 바꿀 때는 **먼저 전원을 완전히 분리**해요.
- GPIO 신호 핀은 **3.3V**까지만 다뤄요. 센서의 VCC와 풀업 저항은 5V가 아니라 **3.3V(물리 핀 1)**에 연결해요.
- 기록 중에 어댑터를 그냥 뽑지 않아요. 프로그램을 멈추고 안전하게 종료한 다음 뽑아요.

</Callout>

## 준비물

- [ ] 라즈베리파이와 전원 어댑터 (모니터, 키보드, 마우스 연결, 인터넷 연결)
- [ ] 브레드보드
- [ ] 방수형 DS18B20 온도센서 1개
- [ ] 4.7k옴 저항 1개
- [ ] 암-수 점퍼선 3개

코드의 따옴표 안에 있는 한글이 입력되지 않으면 영어로 바꿔도 돼요.

<MissionCard number={1} title="w와 a 비교하기" time="10분">

이번 미션은 센서 없이 Thonny만으로 해요.

1. 아래 코드를 `write_test.py`로 저장해요.

```python
file = open("record.txt", "w")
file.write("첫째 줄\n")
file.close()
```

2. **Run**을 세 번 눌러요. 그다음 record.txt를 Thonny에서 열어 줄 수를 세어요.

이제 코드를 바꾸기 전에 **결과를 먼저 예상**해 봐요.

3. Thonny 위쪽의 `write_test.py` 탭으로 돌아와요. record.txt 탭에서 Run을 누르면 글 파일을 프로그램으로 실행하게 돼요. `"w"`를 `"a"`로 바꾸고 세 번 더 실행하면 record.txt는 몇 줄이 될까요? 예상을 공책에 적어요.
4. 실행하고 파일을 다시 열어 비교해요.
5. `write_test.py` 탭에서 다시 `"w"`로 되돌려 한 번 실행하면 몇 줄이 될까요? 예상한 뒤 확인해요.

<FileModeSim />

**성공 확인:** w로 세 번 실행하면 1줄, a로 세 번 더 실행하면 4줄, 다시 w로 한 번 실행하면 1줄이에요. 기록 프로그램에 a를 쓰는 이유를 말할 수 있어요.

</MissionCard>

<MissionCard number={2} title="온도 기록 장치 완성하기" time="20분">

1. 라즈베리파이의 전원을 끄고 어댑터를 뽑은 뒤, 지난 시간의 회로를 다시 만들어요.

| 부품 | 한쪽 | 다른 쪽 |
| --- | --- | --- |
| 센서 빨강 (VCC) | 브레드보드 a5 | |
| 센서 노랑 (데이터) | 브레드보드 a10 | |
| 센서 검정 (GND) | 브레드보드 a15 | |
| 4.7k옴 저항 | c5 | c10 |
| 점퍼선 1 | 물리 핀 1 (3.3V) | 브레드보드 b5 |
| 점퍼선 2 | 물리 핀 7 (GPIO4) | 브레드보드 b10 |
| 점퍼선 3 | 물리 핀 9 (GND) | 브레드보드 b15 |

2. 전원을 연결한 뒤 터미널을 열고 가상 환경을 켜요. 다른 라즈베리파이를 쓴다면 1-Wire를 켜고, 지난 시간처럼 가상 환경을 만들고 `pip install w1thermsensor`도 실행해요.

```bash
source ~/sensor-env/bin/activate
```

3. Thonny 편집기에 아래 코드를 입력하고 홈 폴더에 `temp_log.py`로 저장해요.

```python
from w1thermsensor import W1ThermSensor
from datetime import datetime
from time import sleep
import os

FILE_NAME = "temperature.csv"

sensor = W1ThermSensor()

# 파일이 없거나 비어 있을 때만 머리글을 적어요.
if not os.path.exists(FILE_NAME) or os.path.getsize(FILE_NAME) == 0:
    with open(FILE_NAME, "a") as file:
        file.write("시각,온도\n")

while True:
    temp = round(sensor.get_temperature(), 1)
    now = datetime.now().strftime("%H:%M:%S")

    with open(FILE_NAME, "a") as file:
        file.write(f"{now},{temp}\n")

    print(f"{now} 기록 완료")
    sleep(10)
```

4. `(sensor-env)`가 붙은 터미널에서 실행해요. 약 1분 뒤 **Ctrl+C**로 멈춰요.

```bash
python temp_log.py
```

5. temperature.csv를 열어 내용을 봐요.

**성공 확인:** 첫 줄은 `시각,온도`이고, 그 아래에 시각과 온도가 쉼표로 나뉘어 약 10초 간격으로 쌓여 있어요.

<Callout type="note">

머리글을 `while` 안에 넣으면 기록마다 머리글이 끼어들어요.
그래서 반복문이 시작되기 전에, 그것도 파일이 비어 있을 때만 한 번 적어요.
덕분에 프로그램을 끄고 다시 켜도 머리글은 늘어나지 않아요.

</Callout>

</MissionCard>

<MissionCard number={3} title="다시 켜고 기록 세어 보기" time="15분">

프로그램을 다시 실행하기 전에 **결과를 먼저 예상**해 봐요.

1. `python temp_log.py`를 다시 실행해서 약 1분 더 기록하면 머리글은 몇 개가 될까요? 기록은 모두 몇 줄쯤 될까요? 예상을 공책에 적어요.
2. 실행하고 약 1분 뒤 Ctrl+C로 멈춰요. 그동안 금속 캡을 손으로 쥐고 있으면 온도 변화도 함께 남아요.
3. 아래 코드를 `count_log.py`로 저장해요.

```python
with open("temperature.csv") as file:
    lines = file.readlines()

print("머리글:", lines[0].strip())
print("기록 수:", len(lines) - 1)
print("첫 기록:", lines[1].strip())
print("마지막 기록:", lines[-1].strip())
```

4. `python count_log.py`로 실행해서 예상과 비교해요.
5. temperature.csv에서 `시각,온도`가 있는 줄이 맨 위 한 줄뿐인지 눈으로 확인해요.

**성공 확인:** 두 번 실행했는데도 머리글은 한 줄이고, 첫 번째 실행의 기록 뒤에 두 번째 실행의 기록이 이어져 있어요. 기록 수가 약 12개로 내 예상과 비슷해요.

</MissionCard>

## 막혔을 때

| 증상 | 확인할 곳 |
| --- | --- |
| record.txt가 안 보여요 | 실행한 코드 파일과 같은 폴더를 찾아봐요. 코드를 먼저 저장해야 해요. |
| 모든 기록이 한 줄에 붙어 있어요 | `write` 안의 글 끝에 `\n`이 있는지 확인해요. |
| 마지막 기록 한 줄만 남아요 | 기록하는 `open`이 `"a"`인지 확인해요. `"w"`면 열 때마다 지워져요. |
| 맨 위에 머리글이 없어요 | 머리글 없이 만들어진 파일이 이미 있었어요. 그 파일의 이름을 바꿔 두고 다시 실행해요. |
| 머리글이 기록 사이에 끼어 있어요 | 머리글을 적는 `if`가 `while` 위에 있는지, 들여쓰기가 맞는지 확인해요. |
| `NoSensorFoundError`가 나요 | 터미널에서 `ls /sys/bus/w1/devices/`로 `28-` 폴더를 찾아봐요. 없으면 배선과 1-Wire 설정을 확인해요. |
| `No module named 'w1thermsensor'` | 터미널 앞에 `(sensor-env)`가 없어요. 가상 환경을 켜고 다시 실행해요. |
| `FileNotFoundError`가 나요 | temp_log.py를 실행한 폴더와 같은 폴더에서 count_log.py를 실행해요. |
| 시각이 실제 시각과 달라요 | 라즈베리파이가 인터넷에 연결되어 있는지 확인해요. 시계가 맞지 않을 수 있어요. |
| 표 프로그램에서 한글이 깨져요 | 파일은 괜찮아요. 구글 시트에 올리거나, 여는 프로그램에서 인코딩을 UTF-8로 골라요. |

## 더 해 보기

1. **날짜도 남기기:** `"%H:%M:%S"`를 `"%Y-%m-%d %H:%M:%S"`로 바꿔, 날짜가 바뀌어도 구분되게 해 보세요. 새 파일 이름으로 시작하는 것이 좋아요.
2. **가장 높은 온도:** count_log.py에서 각 줄을 쉼표로 나누고 온도만 모아 `max()`로 가장 높은 값을 찾아보세요.
3. **기록 간격 정하기:** 교실 온도를 하루 동안 잰다면 10초와 10분 중 어느 쪽이 좋을지, 하루에 몇 줄이 쌓이는지 계산해 보세요.
