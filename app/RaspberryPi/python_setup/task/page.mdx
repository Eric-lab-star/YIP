# 파이썬 설정하기 실습

오늘은 Thonny를 열고 내가 쓴 코드를 라즈베리파이에게 실행시켜 봅니다.
쉘에서 시험하고, 파일로 저장하고, 일부러 오류를 내서 고치는 것까지 해 봐요.

<Callout type="goal">

**이번 실습을 마치면**

1. 쉘에서 코드를 실행하고 `import gpiozero`로 준비 상태를 점검할 수 있어요.
2. 세 줄짜리 프로그램을 `hello.py`로 저장하고 다시 열어 실행할 수 있어요.
3. 오류 메시지에서 줄 번호를 찾아 틀린 곳을 고칠 수 있어요.

</Callout>

## 준비물

- [ ] 라즈베리파이와 전원 어댑터 (모니터, 키보드, 마우스 연결)
- [ ] 운영체제가 설치된 microSD 카드
- [ ] 공책과 필기구

<MissionCard number={1} title="쉘에서 바로 실행하기" time="10분">

1. 라즈베리파이를 켜고 라즈베리 아이콘 메뉴의 **개발(Programming) → Thonny**를 열어요.
2. 위쪽 편집기와 아래쪽 쉘을 손가락으로 구분해 봐요.
3. 쉘에 아래 줄을 입력하고 Enter를 눌러요.

```python
print("Hello, Raspberry Pi!")
```

4. 다음 줄을 입력하기 전에 **결과를 먼저 예상**해 공책에 적어요. `8`이 나올까요, 다른 것이 나올까요?

```python
print("3 + 5")
```

5. 실행해서 예상과 비교해요.
6. 앞으로 쓸 도구가 준비되어 있는지 점검해요.

```python
import gpiozero
```

**성공 확인:** 쉘에 `Hello, Raspberry Pi!`와 `3 + 5`가 나타났어요. `import gpiozero`는 아무 글자도 나오지 않고 다음 입력을 기다려요. 오류가 없으면 준비가 끝난 거예요.

<Callout type="note">

코드의 글자는 영어로 적었어요. 설치 환경에 따라 라즈베리파이에서 한글 입력이 되지 않을 수 있기 때문이에요.
한글이 입력된다면 따옴표 안을 한글로 바꿔도 좋아요.

</Callout>

</MissionCard>

<MissionCard number={2} title="파일로 저장하고 다시 열기" time="15분">

1. 편집기에 아래 세 줄을 입력해요. 두 번째 줄의 이름은 내 영어 이름으로 바꿔요.

```python
print("Hello, Raspberry Pi!")
print("My name is Hana.")
print("I am learning Python.")
```

2. 저장 버튼을 누르고 `hello.py`로 저장해요. 저장 창에서 어느 폴더에 저장되는지 공책에 적어요.
3. 초록색 **Run** 버튼으로 실행해요. 결과는 아래쪽 쉘에 나타나요.
4. Thonny를 닫기 전에 **결과를 먼저 예상**해 봐요. 다시 열면 쉘에 입력한 줄과 `hello.py` 중 무엇을 다시 쓸 수 있을까요?
5. Thonny를 닫았다가 다시 열어요. `hello.py`가 열려 있지 않다면 **Load** 버튼으로 찾아서 열어요.
6. **Run**으로 다시 실행해요.

**성공 확인:** 다시 연 `hello.py`를 실행했을 때 세 줄이 순서대로 쉘에 나타나요.

</MissionCard>

<MissionCard number={3} title="오류를 만들고 고치기" time="15분">

오류는 틀린 곳을 알려 주는 안내문이에요. 일부러 만들어서 읽는 연습을 해요.

1. `hello.py`의 두 번째 줄에서 **닫는 따옴표**를 지워요. 몇 번째 줄에서 오류가 난다고 나올지 **먼저 예상**해 공책에 적어요.
2. 저장하고 **Run**으로 실행해요.
3. 쉘의 메시지에서 세 가지를 찾아 공책에 적어요.

| 찾을 것 | 어디를 볼까요? |
| --- | --- |
| 오류 이름 | `SyntaxError`처럼 콜론 앞에 있는 낱말 |
| 줄 번호 | `line` 뒤의 숫자 |
| 고칠 곳 | 그 줄에서 짝이 맞지 않는 따옴표나 괄호 |

4. 따옴표를 되돌리고 다시 실행해요.
5. 이번에는 두 번째 줄 끝의 **닫는 괄호** `)`를 지우고 실행해요. 메시지를 읽고 고쳐요.

**성공 확인:** 두 번의 오류 모두 메시지를 읽고 스스로 고쳐서, 세 줄이 다시 정상으로 나타나요. 첫 번째 오류의 메시지는 `line 2`를 가리켜요. 괄호 오류는 Python 버전에 따라 줄 번호나 문장이 조금 다를 수 있으니, 가리킨 줄과 그 근처 줄을 함께 살펴봐요.

</MissionCard>

## 막혔을 때

| 증상 | 확인할 곳 |
| --- | --- |
| 메뉴에서 Thonny를 찾지 못하겠어요 | 라즈베리 아이콘 메뉴의 개발(Programming) 항목을 확인해요. 메뉴가 영어일 수 있어요. |
| `NameError: name 'pront' is not defined` | 철자를 확인해요. `Print`처럼 대문자로 써도 같은 오류가 나요. 모두 소문자로 써요. |
| `IndentationError` 오류가 나요 | 줄 맨 앞에 빈칸이 들어갔는지 확인하고 지워요. |
| `ModuleNotFoundError: No module named 'gpiozero'` | 철자를 확인해요. 철자가 맞으면 선생님께 Thonny 화면을 보여 드려요. |
| 한글이 입력되지 않거나 네모로 보여요 | 한글 입력기나 글꼴이 없는 환경일 수 있어요. 영어로 입력하고 계속해요. |
| 고쳤는데 같은 오류가 나요 | 저장을 했는지, 지금 실행한 탭이 `hello.py`가 맞는지 확인해요. |
| 저장한 파일을 찾지 못하겠어요 | 공책에 적은 폴더를 Load 창에서 열어 확인해요. |
