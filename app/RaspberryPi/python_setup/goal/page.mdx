# 파이썬 설정하기

라즈베리파이가 켜졌으니 이제 **명령을 내리는 방법**을 배울 차례예요.
우리는 **Python(파이썬)**이라는 프로그래밍 언어로 라즈베리파이에게 일을 시킬 거예요.
좋은 소식이 하나 있어요. Raspberry Pi OS에는 Python이 **이미 설치되어 있습니다.**
설치가 아니라, 어디에 있고 어떻게 쓰는지 알아보는 것이 이번 시간의 목표예요.

<Callout type="goal">

**이번 수업을 마치면**

1. Thonny 편집기를 열고 쉘과 편집기 영역을 구분할 수 있어요.
2. 첫 Python 프로그램을 작성하고 실행할 수 있어요.
3. 작성한 프로그램을 파일로 저장하고 다시 열 수 있어요.

</Callout>

## 1. Python은 어떤 언어인가요?

<SectionClip src={clipBase + "/ep01.mp4"} title="20화 — 파이썬이라는 언어" />

Python은 사람이 읽기 쉬운 문법으로 유명한 프로그래밍 언어예요.
라즈베리파이라는 이름의 Pi가 원래 Python에서 왔다고 할 만큼, 라즈베리파이와 잘 어울리는 짝꿍입니다.

앞으로 우리는 Python으로 LED를 켜고, 센서 값을 읽고, 웹서버까지 만들 거예요.
그 모든 일의 시작은 오늘 작성하는 **한 줄짜리 프로그램**입니다.

## 2. Thonny: 우리가 사용할 Python 편집기

<SectionClip src={clipBase + "/ep02.mp4"} title="21화 — 우리의 작업실, Thonny" />

라즈베리 아이콘 메뉴에서 **개발(Programming) → Thonny**를 찾아 실행하세요.
Thonny(토니)는 초보자를 위해 만들어진 Python 편집기로, Raspberry Pi OS에 기본으로 들어 있어요.

Thonny 화면은 크게 두 부분으로 나뉩니다.

| 영역 | 위치 | 하는 일 |
| --- | --- | --- |
| 편집기 | 위쪽 | 프로그램을 작성하고 파일로 저장하는 곳 |
| 쉘(Shell) | 아래쪽 | 한 줄씩 바로 실행하고 결과를 보는 곳 |

<Callout type="analogy">

**쉘은 연습장, 편집기는 공책이에요.**

쉘에 입력한 내용은 바로 실행되지만 저장되지 않아요. 계산을 빠르게 확인하는 연습장이죠.
편집기에 쓴 내용은 파일로 저장할 수 있어서, 다음에 또 실행할 수 있는 공책입니다.
짧은 실험은 쉘에서, 완성할 프로그램은 편집기에서 작성해요.

</Callout>

## 3. 첫 프로그램: 화면에 인사하기

<SectionClip src={clipBase + "/ep03.mp4"} title="22화 — 첫 인사, 프린트" />

쉘에 아래 한 줄을 입력하고 Enter를 눌러 보세요.

```python
print("안녕, 라즈베리파이!")
```

쉘에 **안녕, 라즈베리파이!**가 나타나면 성공이에요.
`print()`는 괄호 안의 내용을 화면에 보여 주는 Python의 기본 기능입니다.
따옴표로 감싼 부분이 그대로 출력된다는 것을 확인하세요.

이번에는 같은 내용을 **편집기**에 작성하고, 저장한 뒤 실행해 봅시다.

1. 편집기에 `print("안녕, 라즈베리파이!")`를 입력합니다.
2. 저장 버튼을 누르고 `hello.py`라는 이름으로 저장합니다.
3. 초록색 **실행 버튼**을 누르면 쉘에 결과가 나타납니다.

파일 이름 끝의 **.py**는 Python 프로그램 파일이라는 표시예요.
저장한 파일은 microSD 카드에 기록되므로, 라즈베리파이를 껐다 켜도 다시 열 수 있습니다.

## 4. 오류 메시지와 친해져요

<SectionClip src={clipBase + "/ep04.mp4"} title="23화 — 빨간 글씨는 친구" />

일부러 따옴표 하나를 빼고 실행해 보세요.

```python
print("안녕, 라즈베리파이!)
```

빨간 글씨로 **SyntaxError**라는 메시지가 나타납니다.
오류 메시지는 혼내는 것이 아니라, **어디가 틀렸는지 알려 주는 안내문**이에요.
앞으로 오류를 만나면 당황하지 말고 다음 순서로 읽어 보세요.

1. 오류 이름을 확인해요. SyntaxError는 문법이 틀렸다는 뜻이에요.
2. 몇 번째 줄인지 확인해요. 메시지에 줄 번호가 함께 나와요.
3. 그 줄에서 따옴표, 괄호, 철자가 짝이 맞는지 살펴봐요.

<Callout type="tip">

**gpiozero도 이미 준비되어 있어요.**

앞으로 LED와 센서를 다룰 때 **gpiozero**라는 Python 라이브러리를 사용합니다.
라이브러리는 자주 쓰는 기능을 미리 만들어 모아 둔 도구 상자예요.
gpiozero도 Raspberry Pi OS에 기본으로 들어 있어서 따로 설치할 필요가 없습니다.
쉘에 `import gpiozero`를 입력했을 때 아무 오류가 없다면 준비 완료예요.

</Callout>

## 스스로 확인해 보기

<details>
<summary>1. Thonny의 쉘과 편집기는 어떻게 다른가요?</summary>

쉘은 한 줄씩 바로 실행해서 결과를 확인하는 곳이고 내용이 저장되지 않아요.
편집기는 프로그램을 작성해서 .py 파일로 저장하는 곳이라 다음에 다시 열어 실행할 수 있습니다.

</details>

<details>
<summary>2. 라즈베리파이에서 Python을 쓰려면 먼저 설치해야 하나요?</summary>

아니요. Raspberry Pi OS에는 Python과 Thonny, gpiozero가 기본으로 들어 있어요.
설치 없이 Thonny를 열어 바로 사용할 수 있습니다.

</details>

<details>
<summary>3. 실행했더니 SyntaxError가 나왔어요. 가장 먼저 무엇을 확인할까요?</summary>

오류 메시지에 나온 줄 번호를 찾아가서, 따옴표와 괄호의 짝, 철자가 맞는지 확인합니다.
오류 메시지는 틀린 위치를 알려 주는 안내문이에요.

</details>
