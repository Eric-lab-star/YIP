# 블루투스LE 스마트 조명제어 실습

오늘은 내 라즈베리파이가 스마트 조명이 됩니다.
서랍장을 프로그램으로 만들고, 스마트폰에서 서랍에 숫자를 써넣어 LED를 켜 봐요.

<Callout type="goal">

**이번 실습을 마치면**

1. 내 이름으로 광고하는 BLE 조명 프로그램을 실행할 수 있어요.
2. 스마트폰 앱에서 라즈베리파이를 찾아 연결하고 서비스와 특성을 찾아낼 수 있어요.
3. 전원 특성에 값을 써서 LED를 켜고 끄고, 값을 읽어 상태를 확인할 수 있어요.

</Callout>

<Callout type="important">

**배선 전 약속**

- 배선을 바꿀 때는 **먼저 전원을 완전히 분리**해요.
- GPIO 신호 핀은 **3.3V**까지만 다뤄요. 5V 핀에 연결하지 마세요.
- 오늘의 회로는 6차시와 같아요. 저항을 빠뜨리지 않았는지 전원을 넣기 전에 친구와 확인해요.

</Callout>

<MissionCard number={1} title="LED 회로와 라이브러리 준비하기" time="15분">

1. 라즈베리파이의 전원을 끄고 어댑터를 뽑아요.
2. 아래 표대로 하나씩 꽂아요.

| 부품 | 한쪽 | 다른 쪽 |
| --- | --- | --- |
| 점퍼선 1 | 물리 핀 11 (GPIO17) | 브레드보드 a10 |
| 330옴 저항 | c10 | c15 |
| LED | 긴 다리 d15 | 짧은 다리 d16 |
| 점퍼선 2 | 브레드보드 a16 | 물리 핀 9 (GND) |

3. 전원을 연결하고, 메뉴 막대의 블루투스 아이콘으로 블루투스가 켜져 있는지 확인해요.
4. 터미널을 열고 BLE 라이브러리 bluezero를 가상 환경에 설치해요. 첫 줄은 라이브러리가 쓰는 시스템 부품을, 둘째 줄은 가상 환경을 준비해요. 가상 환경이 이미 있으면 그대로 쓰게 돼요.

```bash
sudo apt install python3-dbus python3-gi
python3 -m venv --system-site-packages ~/sensor-env
source ~/sensor-env/bin/activate
pip install bluezero
```

**성공 확인:** `pip install`이 오류 없이 끝나고, 터미널 맨 앞에 `(sensor-env)`가 보여요.

<Callout type="note">

**수업 전에 선생님이 준비해 두면 좋아요**

설치는 인터넷 상태에 따라 몇 분씩 걸릴 수 있어요. 위 명령을 미리 실행해 두면 학생은 `source` 줄만 입력하고 바로 시작할 수 있어요.

</Callout>

<MissionCard number={2} title="스마트 조명 프로그램 실행하기" time="15분">

교실에는 라즈베리파이가 여러 대라서 이름이 같으면 내 것을 찾을 수 없어요. 그래서 이름 끝에 내 번호를 넣어요.

1. Thonny 편집기에 아래 코드를 입력하고, `LIGHT_NAME`의 `01`을 내 자리 번호로 바꿔요. 이름은 지금처럼 영어와 숫자로 짧게 써요. 홈 폴더에 `ble_light.py`로 저장해요.

```python
from gpiozero import LED
from bluezero import adapter, peripheral

LIGHT_NAME = "LIGHT01"
LIGHT_SERVICE = "12341000-1234-1234-1234-123456789abc"
POWER_CHAR = "12341001-1234-1234-1234-123456789abc"

led = LED(17)


def read_power():
    # 폰이 서랍을 읽으면 지금 LED 상태를 알려 줘요.
    if led.is_lit:
        return [1]
    return [0]


def write_power(value, options):
    # 폰이 서랍에 쓰면 그 값이 value[0]에 들어와요.
    print("받은 값:", value[0])
    if value[0] == 1:
        led.on()
    else:
        led.off()


address = adapter.list_adapters()[0]

light = peripheral.Peripheral(address, local_name=LIGHT_NAME)
light.add_service(srv_id=1, uuid=LIGHT_SERVICE, primary=True)
light.add_characteristic(
    srv_id=1,
    chr_id=1,
    uuid=POWER_CHAR,
    value=[0],
    notifying=False,
    flags=["read", "write"],
    read_callback=read_power,
    write_callback=write_power,
)

print(LIGHT_NAME, "광고를 시작해요. 멈추려면 Ctrl+C")
light.publish()
```

코드와 학습하기의 서랍장을 짝지어 봐요.

| 코드 | 학습하기의 말 |
| --- | --- |
| `add_service` | 조명 서비스라는 서랍장 |
| `add_characteristic` | 전원 상태라는 서랍 |
| `write_power` | 서랍에 값이 들어오면 할 일 |
| `publish` | 광고를 내보내고 폰을 기다리기 |

`publish()`는 끝나지 않고 계속 기다려요. 프로그램이 끝나면 핀이 정리되어 LED도 꺼지는데, 여기서 기다려 주기 때문에 조명이 계속 동작해요.

2. `(sensor-env)`가 붙은 터미널에서 실행해요.

```bash
python ble_light.py
```

3. 스마트폰의 블루투스를 켜고 nRF Connect 앱을 열어요. 앱이 권한을 물으면 허용해요.
4. 앱에서 주변 기기를 검색해(Scan) 내 이름을 찾고 연결(Connect)해요. 스마트폰의 블루투스 설정 화면이 아니라 **앱 안에서** 찾아요.

**성공 확인:** 앱 목록에 내 이름이 보이고, 연결한 뒤 서비스 목록에 `12341000`으로 시작하는 서비스가 보여요. 그 안에 `12341001`로 시작하는 특성이 있어요.

</MissionCard>

<MissionCard number={3} title="폰으로 서랍을 쓰고 읽기" time="15분">

앱의 화면은 폰과 버전에 따라 조금 달라요. `12341001` 특성 옆의 **쓰기(Write)**와 **읽기(Read)** 버튼을 찾아요. 보통 위쪽 화살표가 쓰기, 아래쪽 화살표가 읽기예요.

1. 쓰기를 눌러요. 값의 형식은 글자(Text)가 아니라 **바이트 또는 숫자**로 고르고, `01`을 입력해 보내요.
2. 터미널의 `받은 값:`과 LED를 봐요.
3. 읽기를 눌러 앱에 나오는 값이 `01`인지 확인해요.
4. 값을 `00`으로 써서 LED를 꺼요.

**성공 확인:** `01`을 쓰면 LED가 켜지고 `00`을 쓰면 꺼져요. 터미널에 받은 값이 그대로 찍혀요.

이제 보내기 전에 **결과를 먼저 예상**해 봐요.

5. LED가 켜진 상태에서 `02`를 쓰면 어떻게 될까요? 코드의 `if`를 보고 예상을 공책에 적어요.
6. 보내서 예상과 비교해요. 그다음 읽기를 눌러 값이 무엇으로 나오는지도 확인해요.

<BleWriteSim />

**성공 확인:** `02`는 1이 아니라서 `else`로 가고 LED가 꺼져요. 읽기 값은 `read_power`가 LED 상태를 보고 답하므로 `00`이에요.

</MissionCard>

## 막혔을 때

| 증상 | 확인할 곳 |
| --- | --- |
| 앱에 내 이름이 안 보여요 | 터미널에 `광고를 시작해요`가 떴고 오류가 없는지 확인해요. 블루투스 설정 화면이 아니라 앱에서 찾아야 해요. |
| 이름 없이 주소만 보이는 기기가 많아요 | 앱의 검색을 다시 시작하고, 내 라즈베리파이 가까이에서 찾아요. |
| 친구 폰에서만 보이고 내 폰에서는 안 보여요 | 다른 폰이 이미 연결되어 있는지 확인해요. 연결을 끊고 다시 검색해요. |
| `01`을 보냈는데 LED가 켜지지 않아요 | 터미널의 `받은 값:`을 봐요. 49처럼 나오면 글자로 보낸 거예요. 형식을 바이트나 숫자로 바꿔요. |
| 받은 값은 1인데 LED가 켜지지 않아요 | 전원을 분리하고 LED 방향과 물리 핀 11번, 9번을 확인해요. |
| `No module named 'bluezero'` | 터미널 앞에 `(sensor-env)`가 없어요. 가상 환경을 켜고 다시 실행해요. |
| `No module named 'dbus'` 또는 `'gi'` | 미션 1의 `sudo apt install` 줄을 실행했는지, 가상 환경에 `--system-site-packages`를 넣었는지 확인해요. |
| `pip install bluezero`에서 설치 오류가 나요 | 오류 내용을 선생님께 보여 주세요. OS 버전에 따라 라이브러리가 맞지 않을 수 있어요. |
| 광고나 블루투스 관련 오류로 멈춰요 | 앞서 실행한 프로그램이 다른 터미널에 남아 있는지 확인해요. 메뉴 막대의 블루투스가 켜져 있는지도 봐요. |
| `GPIO busy`처럼 핀을 쓸 수 없다는 오류가 나요 | 이전 프로그램이 핀을 쓰고 있어요. Ctrl+C나 Thonny의 Stop으로 멈춘 뒤 다시 실행해요. |
