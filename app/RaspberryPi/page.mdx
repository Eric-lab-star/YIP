# 라즈베리파이 살펴보기

작은 초록색 보드 위에 컴퓨터 한 대가 들어 있어요.
**라즈베리파이(Raspberry Pi)**는 연산처리장치, 메모리, 여러 연결 단자를 하나의 기판에 모은 **싱글 보드 컴퓨터**입니다.

우리가 사용할 보드는 **Raspberry Pi 4 Model B, 메모리 1GB 모델**입니다.
운영체제를 설치하고 키보드와 모니터를 연결하면 일반 컴퓨터처럼 사용할 수 있어요.
Python으로 프로그램을 만들고, 센서나 LED를 연결해 주변 장치를 제어할 수도 있습니다.

글을 아래로 읽어 보세요. 옆의 모형이 움직이며 지금 소개하는 부품을 가까이 보여줍니다.
작은 화면에서는 모형이 글 위에 나타납니다.

<section id="processor" data-pi-section="processor">

## 연산처리장치

보드 가운데에서 왼쪽으로 조금 치우친 **은색 정사각형 칩**을 찾아보세요.
이 칩은 **Broadcom BCM2711**이라는 SoC입니다.
SoC는 CPU를 비롯한 여러 기능을 하나의 칩에 모았다는 뜻이에요.

그 안의 **CPU(중앙처리장치)**는 프로그램의 명령을 해석하고 실행합니다.
계산을 하거나, 두 값을 비교하거나, 다음에 실행할 일을 판단하지요.
Python에서 `3 + 5`를 계산할 때도 CPU가 일을 합니다.

이 보드의 CPU에는 **Cortex-A72 코어가 4개** 들어 있습니다.
코어는 명령을 처리하는 일꾼이라고 생각하면 돼요.
여러 일을 나누어 처리할 수 있지만, 모든 프로그램이 자동으로 네 배 빨라지는 것은 아닙니다.

<Callout type="analogy">

컴퓨터를 요리하는 주방에 비유하면 **CPU는 조리법을 읽고 요리하는 요리사**예요.
실행할 순서를 따라 계산하고 판단하는 역할을 합니다.

</Callout>

칩 위에 방열판이나 냉각팬이 붙어 있다면 실제 칩이 가려져 있을 수 있어요.
전원을 켜고 오래 사용한 칩은 뜨거울 수 있으니 손으로 만지지 말고 눈으로 위치를 확인하세요.

</section>

<section id="memory" data-pi-section="memory">

## 메모리

연산처리장치 오른쪽의 **검은색 직사각형 칩**은 메모리입니다.
우리 보드에는 **1GB 용량의 LPDDR4 RAM**이 들어 있어요.

**RAM**은 실행 중인 프로그램과 작업에 필요한 데이터를 잠시 올려 두는 공간입니다.
Python에서 만든 변수의 값, 열어 둔 프로그램의 데이터 등이 이 공간을 사용합니다.

주방에 비유하면 메모리는 **요리 재료를 펼쳐 놓는 작업대**예요.
작업대가 넓으면 여러 재료를 한꺼번에 놓을 수 있듯, 메모리가 넉넉하면 여러 프로그램을 함께 실행하기 수월합니다.
1GB 모델에서는 쓰지 않는 프로그램과 브라우저 탭을 닫아 두는 습관이 도움이 됩니다.

<Callout type="important">

**메모리 1GB는 파일 저장 공간이 1GB라는 뜻이 아닙니다.**
RAM의 내용은 전원이 꺼지면 사라집니다.
운영체제와 저장한 Python 파일은 주로 **microSD 카드**에 남아요.
작업을 마치면 파일을 저장하세요.

</Callout>

</section>

<section id="ports" data-pi-section="ports">

## 포트와 단자

보드 가장자리에는 다른 장치와 연결하는 여러 입구가 있습니다.
이 입구를 **포트** 또는 **단자**라고 불러요.
모양과 역할이 다르므로 케이블을 꽂기 전에 어떤 단자인지 확인해야 합니다.

모형이 돌아가며 보여주는 쪽에는 USB 포트와 유선 네트워크 단자가 모여 있습니다.

- **USB 2.0 포트 2개:** 안쪽이 검은색입니다. 키보드나 마우스 같은 주변 장치를 연결해요.
- **USB 3.0 포트 2개:** 안쪽이 파란색입니다. USB 저장 장치처럼 많은 데이터를 주고받는 장치에 활용할 수 있어요.
- **이더넷 포트:** 네트워크 케이블을 연결하는 넓은 단자입니다. 공유기와 연결해 유선 네트워크를 사용해요.

다른 가장자리도 살펴볼까요?
얇은 리본 케이블을 끼우는 **카메라(CSI) 단자와 디스플레이(DSI) 단자**,
이어폰 모양의 플러그를 꽂는 **3.5mm 오디오·영상 단자**도 있습니다.
**microSD 카드 슬롯은 보드 뒷면**에 있어요.

<Callout type="tip">

단자의 이름을 전부 외우기보다 **연결하려는 장치에 맞는 입구를 찾는 것**부터 연습하세요.
케이블이 잘 들어가지 않으면 힘으로 밀지 말고 모양과 방향을 다시 확인합니다.

</Callout>

</section>

<section id="gpio" data-pi-section="gpio">

## 40 GPIO 헤더핀

보드의 긴 가장자리를 따라 금속 핀이 두 줄로 서 있습니다.
**한 줄에 20개씩, 모두 40개**로 구성된 GPIO 헤더예요.

**GPIO**는 General Purpose Input/Output, 즉 **범용 입출력**을 뜻합니다.
입력은 버튼이나 센서의 신호를 읽는 것이고, 출력은 LED 같은 장치에 신호를 보내는 것입니다.
Python 프로그램이 현실의 장치와 소통하는 통로라고 생각하면 돼요.

단, **40개가 모두 같은 신호 핀은 아닙니다.**
전원을 공급하는 **3.3V·5V 핀**, 전기 회로의 기준이 되는 **GND(접지) 핀**, 신호를 주고받는 **GPIO 핀**이 섞여 있어요.

핀에는 두 가지 번호가 쓰입니다.
**물리 핀 번호**는 헤더에서의 자리이고, **GPIO 번호**는 신호의 이름이에요.
예를 들어 **물리 핀 11번은 GPIO17**입니다. 회로를 연결할 때는 교재가 어떤 번호를 쓰는지 꼭 확인하세요.

<Callout type="important">

**GPIO 신호는 3.3V 기준입니다. 신호 핀에 5V를 직접 넣으면 보드가 손상될 수 있어요.**
연결을 바꿀 때는 보드를 종료하고 전원을 분리합니다.
LED에는 전류를 제한하는 저항을 사용하고, 모터는 GPIO에 직접 연결하지 않습니다.

</Callout>

</section>

<section id="hdmi" data-pi-section="hdmi">

## 마이크로 HDMI

전원 단자 옆에 나란히 있는 작은 단자 두 개가 **마이크로 HDMI(micro-HDMI)**입니다.
라즈베리파이의 화면과 소리를 모니터나 TV로 보내는 출력 단자예요.

일반 HDMI보다 크기가 작으므로 **micro-HDMI–HDMI 케이블**이나 알맞은 변환 어댑터가 필요합니다.
작은 쪽은 라즈베리파이에, 큰 쪽은 모니터의 HDMI 입력에 연결합니다.

두 단자는 **HDMI0**과 **HDMI1**입니다.
**USB-C 전원 단자에 더 가까운 쪽이 HDMI0**이에요.
모니터를 한 대 연결하는 첫 실습에서는 HDMI0을 사용하세요.

<Callout type="tip">

화면이 나오지 않으면 모니터의 입력이 연결한 **HDMI 입력**으로 선택되어 있는지 확인하세요.
USB-C 전원 단자에 모니터를 연결해도 화면은 나오지 않습니다.

</Callout>

</section>

<section id="power" data-pi-section="power">

## USB-C 전원 단자

마이크로 HDMI 옆, 보드 모서리 가까이에 있는 타원형 입구가 **USB-C 전원 단자**입니다.
우리 실습에서는 이 단자로 보드에 전기를 공급합니다.

라즈베리파이 4는 **5V·3A급의 안정적인 전원**이 필요합니다.
라즈베리파이 4용 공식 USB-C 전원 공급 장치처럼 규격에 맞는 제품을 사용하세요.
USB-C 모양이 같아도 모든 충전기와 케이블이 필요한 전력을 안정적으로 공급하는 것은 아닙니다.

전원이 부족하면 주변 장치가 제대로 동작하지 않거나 보드가 다시 시작될 수 있어요.
처음 준비할 때는 필요한 케이블과 장치를 연결한 뒤 **전원을 마지막에 연결**합니다.

<Callout type="important">

사용을 마칠 때는 **파일 저장 → 운영체제 종료 → 종료 확인 → 전원 분리** 순서를 지켜요.
파일을 쓰는 중에 전원을 갑자기 끊으면 microSD 카드의 데이터가 손상될 수 있습니다.

</Callout>

이제 보드에서 연산처리장치, 메모리, USB 포트, GPIO 헤더, 마이크로 HDMI, 전원 단자를 찾아보세요.
각 부품의 이름과 역할을 설명할 수 있다면 다음 실습을 시작할 준비가 된 거예요.
