# 주변기기 연결하기 실습

오늘은 지난 시간에 만든 카드로 라즈베리파이를 처음 켜 봅니다.
순서대로 연결하고, 켜진 모습을 점검하고, 안전하게 끄는 것까지 해 봐요.

<Callout type="goal">

**이번 실습을 마치면**

1. 전원을 마지막에 두고 장치 네 가지를 차례로 연결해 부팅할 수 있어요.
2. 메뉴, Wi-Fi, 시계, 입력 장치를 점검해 부팅 결과를 판단할 수 있어요.
3. 메뉴에서 종료하고 불이 멈춘 것을 확인한 뒤 전원을 분리할 수 있어요.

</Callout>

<Callout type="important">

**연결 전 약속**

- 전원 케이블은 **항상 마지막**에 연결해요. 꽂는 순간 바로 켜져요.
- 카드나 케이블을 바꿀 때는 **먼저 전원을 분리**해요.
- 단자가 잘 들어가지 않으면 억지로 밀지 말고 방향을 다시 확인해요.

</Callout>

## 준비물

- [ ] 라즈베리파이 4 Model B 보드
- [ ] 지난 시간에 만든 microSD 카드
- [ ] USB 키보드와 마우스
- [ ] 모니터와 micro-HDMI–HDMI 케이블
- [ ] 5V·3A급 USB-C 전원 어댑터
- [ ] 사용자 이름과 비밀번호를 적은 공책

<MissionCard number={1} title="순서대로 연결하기" time="10분">

전원은 아직 꽂지 않아요. 아래 표의 순서대로 하나씩 연결해요.

| 순서 | 할 일 | 연결하는 곳 | 확인할 점 |
| --- | --- | --- | --- |
| 1 | microSD 카드 꽂기 | 보드 뒷면 슬롯 | 금속 단자가 보드 쪽을 향해요 |
| 2 | 키보드와 마우스 연결 | USB-A 포트 | 검은색 포트를 권장해요 |
| 3 | 모니터 연결 | HDMI0 (USB-C에 가까운 쪽) | 모니터를 켜고 맞는 HDMI 입력을 골라요 |
| 4 | 전원 어댑터 준비 | 아직 꽂지 않아요 | 미션 2에서 꽂아요 |

**성공 확인:** 짝이 손가락으로 연결을 따라가며 확인했어요. 카드, 키보드, 마우스, 모니터가 연결되어 있고 USB-C 전원 단자만 비어 있어요.

</MissionCard>

<MissionCard number={2} title="첫 부팅과 점검" time="20분">

전원을 꽂기 전에 **결과를 먼저 예상**해 봐요.

1. 전원을 꽂으면 보드의 불과 모니터에 어떤 일이 어떤 순서로 일어날지 공책에 적어요.
2. 전원 어댑터를 USB-C 단자에 연결하고, 보드의 불과 화면을 함께 지켜봐요.
3. 첫 부팅은 몇 분까지 걸릴 수 있어요. 화면이 잠깐 꺼졌다 다시 켜져도 전원을 뽑지 말고 기다려요.
4. 미리 설정을 건너뛴 카드라면 환영 마법사가 나와요. 화면을 따라 나라, 사용자, Wi-Fi를 입력해요. 소프트웨어 업데이트 단계는 오래 걸릴 수 있으니 선생님 안내를 따라요. 업데이트 중에는 전원을 뽑지 않아요.
5. 바탕화면이 나오면 아래를 하나씩 점검해 공책에 적어요.

| 점검할 것 | 방법 | 결과 |
| --- | --- | --- |
| 라즈베리 아이콘 | 클릭해서 프로그램 메뉴가 열리는지 봐요 | 공책에 적어요 |
| Wi-Fi 아이콘 | 메뉴 막대에서 연결 상태를 봐요 | 공책에 적어요 |
| 시계 | 현재 시각과 맞는지 봐요 | 공책에 적어요 |
| 마우스 | 포인터가 움직이는지 봐요 | 공책에 적어요 |
| 키보드 | 웹 브라우저를 열어 주소창에 글자를 쳐 봐요 | 공책에 적어요 |

6. 처음의 예상과 실제로 일어난 일을 비교해요.

**성공 확인:** 바탕화면이 나타났고 점검표 다섯 칸이 채워졌어요. 보드의 빨간 불과 초록 불이 언제 켜졌는지 내 말로 말할 수 있어요.

</MissionCard>

<MissionCard number={3} title="안전하게 종료하기" time="10분">

종료를 누르기 전에 **먼저 예상**해 봐요. 화면과 보드의 불 중 어느 쪽이 먼저 멈출까요?

1. 열어 둔 파일이 있으면 저장해요.
2. 왼쪽 위 라즈베리 아이콘 메뉴에서 **종료(Shutdown)**를 골라요. 다시 묻는 창이 나오면 종료를 한 번 더 골라요.
3. 화면이 꺼지고 보드의 초록 불이 깜빡임을 멈출 때까지 기다려요.
4. 그다음에 전원 케이블을 분리해요.

**성공 확인:** 화면이 꺼지고 초록 불이 멈춘 것을 본 뒤에 전원을 뽑았어요. 빨간 불은 전원을 뽑을 때까지 켜져 있을 수 있어요.

</MissionCard>

## 막혔을 때

| 증상 | 확인할 곳 |
| --- | --- |
| 화면이 전혀 나오지 않아요 | 모니터가 켜져 있는지, 맞는 HDMI 입력을 골랐는지 확인해요. |
| 입력이 맞는데도 화면이 안 나와요 | 전원을 분리하고 케이블을 끝까지 꽂아요. 화면이 안 나오면 HDMI0 포트로 옮겨 봐요. |
| 글자만 있는 진단 화면이 나오고 바탕화면으로 가지 않아요 | 전원을 분리하고 카드가 끝까지 들어갔는지 확인해요. 그래도 같으면 카드를 선생님께 보여 드려요. |
| 초록 불이 같은 규칙으로 계속 깜빡이고 부팅이 안 돼요 | 깜빡이는 횟수를 세어 선생님께 알려요. 횟수가 원인을 알려 주는 신호예요. |
| 번개 모양이나 전원 부족 안내가 보여요 | 전원이 부족하다는 신호예요. 수업용 5V·3A급 어댑터로 바꿔요. |
| 키보드나 마우스가 반응하지 않아요 | 전원을 분리하고 다른 USB-A 포트에 꽂은 뒤 다시 켜요. |
| Wi-Fi가 연결되지 않아요 | Wi-Fi 아이콘을 눌러 수업용 네트워크를 고르고 비밀번호를 입력해요. |
| 비밀번호를 잊었어요 | 공책을 확인하고, 없으면 선생님께 알려요. |

## 더 해 보기

1. **부팅 시간 재기:** 전원을 꽂은 순간부터 바탕화면이 나올 때까지 시간을 재고, 첫 부팅과 두 번째 부팅을 비교해 보세요.
2. **눈 감고 말하기:** 연결 순서와 종료 순서를 보지 않고 짝에게 말해 보세요.
3. **메뉴 둘러보기:** 라즈베리 아이콘 메뉴에서 다음 시간에 쓸 Thonny가 어디 있는지 찾아보세요.
