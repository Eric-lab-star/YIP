# 주변기기 연결하기

운영체제가 담긴 microSD 카드가 준비되었으니, 이제 라즈베리파이를 진짜 컴퓨터로 깨울 차례예요.
1차시에서 배운 단자들의 위치를 떠올리면서, 장치를 **올바른 순서**로 연결해 봅시다.
순서가 중요한 이유는 단 하나, **전원은 항상 마지막**이기 때문이에요.

<Callout type="goal">

**이번 수업을 마치면**

1. 주변기기를 올바른 순서로 연결하고 첫 부팅을 할 수 있어요.
2. 부팅이 잘 되었는지 화면으로 확인할 수 있어요.
3. 라즈베리파이를 안전하게 종료하고 정리할 수 있어요.

</Callout>

## 1. 연결 순서 한눈에 보기

<SectionClip src={clipBase + "/ep01.mp4"} title="16화 — 순서가 중요해" />

| 순서 | 할 일 | 연결하는 곳 |
| --- | --- | --- |
| 1 | microSD 카드 꽂기 | 보드 뒷면 슬롯 |
| 2 | 키보드·마우스 연결 | USB-A 포트 |
| 3 | 모니터 연결 | micro-HDMI(HDMI0) |
| 4 | 전원 연결 | USB-C 전원 단자 |

<Callout type="important">

**전원 케이블은 반드시 마지막에 연결해요.**

라즈베리파이에는 전원 버튼이 없어서, 전원 케이블을 꽂는 순간 바로 켜집니다.
다른 장치를 먼저 연결해 두어야 켜지는 순간부터 화면과 키보드를 쓸 수 있고,
전원이 들어온 상태에서 장치를 꽂다가 보드에 무리를 주는 일도 피할 수 있어요.

</Callout>

## 2. 하나씩 연결해 봅시다

<SectionClip src={clipBase + "/ep02.mp4"} title="17화 — 하나씩, 차근차근" />

### microSD 카드: 방향을 확인하고 끝까지

보드 뒷면의 슬롯에 카드의 **금속 단자가 보드 쪽을 향하도록** 넣습니다.
라즈베리파이 4의 슬롯은 밀어 넣는 방식이라, 딸깍 소리 없이 부드럽게 끝까지 들어가면 된 거예요.
잘 들어가지 않는다면 방향이 반대일 수 있으니 억지로 밀지 마세요.

### 키보드와 마우스: 아무 USB-A 포트나 괜찮아요

키보드와 마우스는 네 개의 USB-A 포트 어디에 꽂아도 동작합니다.
1차시에서 배운 대로 검은색은 USB 2.0, 파란색은 USB 3.0인데,
키보드와 마우스는 주고받는 데이터가 적어서 **검은색 포트**에 꽂는 것을 권장해요.
파란색 포트는 나중에 USB 저장 장치처럼 빠른 속도가 필요한 장치를 위해 남겨 둡니다.

### 모니터: HDMI0에 연결해요

micro-HDMI–HDMI 케이블의 작은 쪽을 라즈베리파이에, 큰 쪽을 모니터에 연결합니다.
두 단자 중 **USB-C 전원 단자에 가까운 쪽이 HDMI0**이라는 것, 기억하고 있나요?
모니터 한 대로 시작할 때는 HDMI0을 사용하고,
연결 후 모니터에서 해당 HDMI 입력을 선택해야 화면이 나옵니다.

### 전원: 연결하는 순간 켜져요

마지막으로 5V·3A급 전원 공급 장치를 USB-C 단자에 연결합니다.
보드의 빨간 불이 들어오고, 잠시 후 모니터에 라즈베리 로고가 지나가면서 부팅이 시작돼요.
처음에는 1분 정도 걸릴 수 있으니 차분히 기다립니다.

## 3. 부팅이 잘 되었는지 확인해요

<SectionClip src={clipBase + "/ep03.mp4"} title="18화 — 잘 켜졌는지 확인하기" />

부팅이 끝나면 **바탕화면**이 나타납니다.
화면 위쪽의 메뉴 막대에서 다음을 확인해 보세요.

- **라즈베리 아이콘**: 프로그램 메뉴예요. 클릭하면 설치된 프로그램들이 보입니다.
- **Wi-Fi 아이콘**: 2차시의 미리 설정에서 Wi-Fi를 넣었다면 연결된 상태로 표시돼요.
- **시계**: 인터넷에 연결되어 있으면 현재 시각이 맞게 표시됩니다.

마우스가 움직이고 키보드 입력이 되는지도 확인합니다.
여기까지 되었다면 여러분의 라즈베리파이는 완전한 컴퓨터로 동작하고 있는 거예요.

<Callout type="note">

**화면이 안 나와요. 어디부터 볼까요?**

1. 모니터가 켜져 있고, **올바른 HDMI 입력**을 선택했는지 확인해요.
2. 케이블이 **HDMI0**에 꽂혀 있는지 확인해요.
3. microSD 카드가 끝까지 들어갔는지 확인해요. 운영체제가 없으면 화면이 나오지 않아요.
4. 화면 구석에 **번개 모양**이 보이면 전원이 부족하다는 신호예요. 수업용 정품 전원 장치를 사용하세요.

확인할 때는 전원을 분리한 뒤 다시 연결 순서대로 진행합니다.

</Callout>

## 4. 안전하게 종료하기

<SectionClip src={clipBase + "/ep04.mp4"} title="19화 — 헤어질 때도 예의 있게" />

사용을 마칠 때 전원을 바로 뽑으면 저장 중이던 데이터가 손상될 수 있어요.
1차시에서 배운 종료 순서를 실제로 해 봅시다.

1. 작업하던 **파일을 저장**합니다.
2. 라즈베리 아이콘 메뉴에서 **종료(Shutdown)**를 선택합니다.
3. 화면이 꺼지고 보드의 초록 불이 멈출 때까지 **몇 초 기다립니다**.
4. 마지막으로 **전원 케이블을 분리**합니다.

microSD 카드는 평소에는 꽂아 둔 채로 사용하고, 빼야 할 때도 반드시 종료 후 전원을 분리한 다음에 뺍니다.

## 스스로 확인해 보기

<details>
<summary>1. 전원 케이블을 가장 마지막에 연결하는 이유는 무엇인가요?</summary>

라즈베리파이는 전원 버튼이 없어서 전원을 꽂는 순간 바로 켜지기 때문이에요.
다른 장치를 먼저 연결해 두어야 켜지자마자 화면과 키보드를 쓸 수 있습니다.

</details>

<details>
<summary>2. 전원을 연결했는데 화면 구석에 번개 모양이 나타났어요. 무슨 뜻일까요?</summary>

전원 공급이 부족하다는 경고입니다.
5V·3A를 안정적으로 공급하는 전원 장치로 바꿔야 해요.
전원이 부족하면 장치가 오동작하거나 보드가 다시 시작될 수 있습니다.

</details>

<details>
<summary>3. 수업이 끝났어요. 라즈베리파이를 정리하는 올바른 순서는 무엇인가요?</summary>

파일 저장 → 메뉴에서 종료 선택 → 종료가 끝날 때까지 대기 → 전원 케이블 분리 순서입니다.
전원을 바로 뽑으면 microSD 카드의 데이터가 손상될 수 있어요.

</details>
