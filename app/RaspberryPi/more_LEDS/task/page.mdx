# LED 여러개 제어하기 실습

오늘은 LED를 세 개로 늘려 브레드보드 위에 작은 신호등을 세웁니다.
회로를 만들고, 하나씩 시험한 다음, 순서와 시간을 내가 정한 신호등을 완성해요.

<Callout type="goal">

**이번 실습을 마치면**

1. LED 세 개를 저항과 함께 꽂고 GND를 레일 하나로 모을 수 있어요.
2. 쉘에서 LED를 하나씩 켜 보며 배선이 맞는지 직접 가려낼 수 있어요.
3. 불의 순서와 켜지는 시간을 정해 내 신호등 프로그램을 돌릴 수 있어요.

</Callout>

<Callout type="important">

**배선 전 약속**

- 배선을 바꿀 때는 **먼저 전원을 완전히 분리**해요.
- GPIO 신호 핀은 **3.3V**까지만 다뤄요. 오늘 회로에는 5V 핀을 쓰지 않아요.
- 저항은 LED마다 하나씩 꽂아요. 하나를 나눠 쓰지 않아요.
- 전원을 넣기 전에 친구나 선생님과 배선을 한 번 더 확인해요.

</Callout>

## 준비물

- [ ] 라즈베리파이와 전원 어댑터 (모니터, 키보드, 마우스 연결)
- [ ] 브레드보드
- [ ] LED 3개 (빨강, 노랑, 초록)
- [ ] 330옴 저항 3개
- [ ] 암-수 점퍼선 4개
- [ ] 수-수 점퍼선 3개

<MissionCard number={1} title="LED 세 개 회로 만들기" time="15분">

**회로의 길:** GPIO 핀 → 저항 → LED 긴 다리 → LED 짧은 다리 → 파란 레일(-) → GND(물리 핀 9)

세 LED는 신호 핀과 저항을 따로 쓰고, 돌아가는 길인 GND만 레일 하나에 모아요.

1. 라즈베리파이의 전원을 끄고 어댑터를 뽑아요.
2. 아래 표대로 하나씩 꽂아요. 브레드보드의 번호는 예시이니, 같은 줄끼리 이어지기만 하면 다른 줄을 써도 괜찮아요.

| 부품 | 한쪽 | 다른 쪽 |
| --- | --- | --- |
| 암-수 점퍼선 1 | 물리 핀 9 (GND) | 파란 레일(-) |
| 암-수 점퍼선 2 | 물리 핀 11 (GPIO17) | a5 |
| 330옴 저항 1 | c5 | c10 |
| 빨강 LED | 긴 다리 d10 | 짧은 다리 d11 |
| 수-수 점퍼선 1 | a11 | 파란 레일(-) |
| 암-수 점퍼선 3 | 물리 핀 13 (GPIO27) | a13 |
| 330옴 저항 2 | c13 | c18 |
| 노랑 LED | 긴 다리 d18 | 짧은 다리 d19 |
| 수-수 점퍼선 2 | a19 | 파란 레일(-) |
| 암-수 점퍼선 4 | 물리 핀 15 (GPIO22) | a21 |
| 330옴 저항 3 | c21 | c26 |
| 초록 LED | 긴 다리 d26 | 짧은 다리 d27 |
| 수-수 점퍼선 3 | a27 | 파란 레일(-) |

3. 빨강, 노랑, 초록의 회로의 길을 차례로 손가락으로 따라가요. 세 길이 GND 레일에 닿기 전에 서로 만나는 곳이 없어야 해요.
4. 확인이 끝나면 전원을 연결하고 바탕화면이 나올 때까지 기다려요.

**성공 확인:** 전원을 넣었을 때 LED 세 개가 모두 꺼져 있고, 연기나 타는 냄새가 나지 않아요. 이상하면 바로 전원을 뽑고 선생님을 불러요.

</MissionCard>

<MissionCard number={2} title="쉘에서 하나씩 시험하기" time="5분">

프로그램을 만들기 전에 배선부터 확인해요. Thonny의 **쉘**에 한 줄씩 입력해요.

```python
from gpiozero import LED
red = LED(17)
yellow = LED(27)
green = LED(22)
red.on()
```

이제 `yellow.on()`과 `green.on()`을 차례로 입력하고, `red.off()`처럼 하나씩 꺼 봐요.

<Callout type="note">

쉘에서 시험할 때도 `red = LED(17)`처럼 **변수에 담아** 둬요.
`LED(27).on()`처럼 변수 없이 쓰면 그 LED를 가리키는 이름이 남지 않아서 불이 켜진 채로 유지되지 않아요.

</Callout>

**성공 확인:** 입력한 이름과 같은 색의 LED가 켜지고 꺼져요. 다른 색이 켜지거나 하나만 안 켜지면 다음 미션으로 넘어가기 전에 그 줄의 배선을 고쳐요.

</MissionCard>

<MissionCard number={3} title="리스트와 반복문으로 차례로 켜기" time="10분">

1. 쉘에서 쓰던 변수를 정리하기 위해 **Stop** 버튼을 한 번 눌러요.
2. 편집기에 아래 코드를 입력하고 `chase.py`로 저장한 뒤 **Run**으로 실행해요.

```python
from gpiozero import LED
from time import sleep

leds = [LED(17), LED(27), LED(22)]

for led in leds:
    led.on()
    sleep(1)
    led.off()
```

**성공 확인:** 빨강, 노랑, 초록이 1초씩 차례로 켜졌다 꺼지고 프로그램이 끝나요.

이제 코드를 바꾸기 전에 **결과를 먼저 예상**해 봐요. 반복문을 켜는 일과 끄는 일로 나누었어요.

3. 아래 프로그램을 실행하면 불이 어떤 모습으로 움직일까요? 세 개가 동시에 켜지는 순간이 있을까요? 예상을 공책에 적어요.
4. `light_wave.py`로 저장하고 실행해서 예상과 비교해요.

```python
from gpiozero import LED
from time import sleep

leds = [LED(17), LED(27), LED(22)]

for led in leds:
    led.on()
    sleep(0.5)

for led in leds:
    led.off()
    sleep(0.5)
```

**성공 확인:** 불이 하나씩 늘어나 셋 다 켜진 뒤, 빨강부터 하나씩 꺼져요. 왜 그렇게 되는지 두 `for` 문으로 설명할 수 있어요.

</MissionCard>

<MissionCard number={4} title="내 신호등 설계하기" time="10분">

진짜 신호등은 초록 → 노랑 → 빨강 순서로 바뀌고, 불마다 켜져 있는 시간이 달라요.
이번에는 색마다 시간이 달라서 변수 세 개로 지휘해요.

1. 아래 코드를 입력하고 `traffic.py`로 저장해요.

```python
from gpiozero import LED
from time import sleep

red = LED(17)
yellow = LED(27)
green = LED(22)

while True:
    green.on()
    sleep(4)
    green.off()

    yellow.on()
    sleep(1)
    yellow.off()

    red.on()
    sleep(3)
    red.off()
```

2. 실행해서 순서와 시간을 눈으로 확인해요. 멈출 때는 **Stop** 버튼을 눌러요.
3. 공책에 내 신호등 규칙을 적어요. 색마다 몇 초 켤지 정하고, 그렇게 정한 이유도 한 줄 적어요.
4. `sleep`의 숫자를 내 규칙대로 바꾸고 다시 실행해요.

**성공 확인:** 초록 → 노랑 → 빨강이 내가 적은 시간대로 반복돼요. 짝이 초시계로 재서 내 규칙과 맞는지 확인해 줘요.

</MissionCard>

## 막혔을 때

| 증상 | 확인할 곳 |
| --- | --- |
| 세 LED가 모두 켜지지 않아요 | 함께 쓰는 길을 먼저 봐요. 물리 핀 9번 점퍼선이 파란 레일에 꽂혀 있는지, 레일이 중간에 끊어진 보드는 아닌지 확인해요. |
| 하나만 켜지지 않아요 | **Stop**을 누른 뒤 쉘에서 `from gpiozero import LED`, `test = LED(27)`, `test.on()`을 차례로 입력해 그 LED만 켜 봐요. 그래도 안 켜지면 전원을 분리하고 그 LED의 방향과 그 줄의 배선을 확인해요. |
| 다른 색이 켜져요 | 점퍼선이 다른 핀에 꽂혔거나 코드의 핀 번호가 바뀐 거예요. 빨강 17, 노랑 27, 초록 22를 확인해요. |
| 쉘에서 켰는데 불이 남아 있지 않아요 | `LED(27).on()`처럼 변수 없이 쓰지 않았는지 확인해요. |
| `GPIO busy`처럼 핀을 쓸 수 없다는 오류가 나요 | 앞에서 쓰던 변수가 핀을 잡고 있어요. Stop을 누르고 다시 실행해요. |
| `IndentationError` 오류가 나요 | `while True:`나 `for` 아래 줄의 들여쓰기가 똑같은지 확인해요. |

## 더 해 보기

1. **깜빡이는 노랑:** 노랑이 켜져 있는 동안 세 번 깜빡이다가 빨강으로 넘어가게 바꿔 보세요.
2. **왕복 달리기:** `order = [red, yellow, green, yellow]`처럼 리스트를 만들어 불이 왔다 갔다 하게 해 보세요. 같은 LED를 리스트에 두 번 넣어도 괜찮아요.
