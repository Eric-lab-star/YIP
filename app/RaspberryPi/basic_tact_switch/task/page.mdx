# 기초 택트 스위치 실습

오늘은 라즈베리파이가 처음으로 바깥의 신호를 듣습니다.
버튼의 상태를 화면에 찍어 본 다음, 버튼으로 LED를 움직이는 프로그램까지 만들어요.

<Callout type="goal">

**이번 실습을 마치면**

1. 택트 스위치를 가운데 홈에 걸쳐 꽂고 GPIO27과 GND에 연결할 수 있어요.
2. 버튼을 누를 때와 뗄 때 `is_pressed` 값이 바뀌는 것을 화면으로 확인할 수 있어요.
3. 버튼 입력으로 LED를 켜고, 조건을 고쳐 다르게 동작하게 만들 수 있어요.

</Callout>

<Callout type="important">

**배선 전 약속**

- 배선을 바꿀 때는 **먼저 전원을 완전히 분리**해요.
- GPIO 신호 핀은 **3.3V**까지만 다뤄요. 오늘 회로는 GPIO 핀과 GND만 쓰니 5V 핀에는 아무것도 꽂지 않아요.
- 버튼이 연결된 GPIO27을 `LED(27)`처럼 출력으로 쓰지 않아요. 버튼은 입력 핀에만 연결해요.
- 전원을 넣기 전에 친구나 선생님과 배선을 한 번 더 확인해요.

</Callout>

## 준비물

- [ ] 라즈베리파이와 전원 어댑터 (모니터, 키보드, 마우스 연결)
- [ ] 브레드보드
- [ ] 택트 스위치 1개
- [ ] LED 1개
- [ ] 330옴 저항 1개
- [ ] 암-수 점퍼선 3개
- [ ] 수-수 점퍼선 2개

<MissionCard number={1} title="버튼과 LED 회로 만들기" time="15분">

**버튼의 길:** GPIO27(물리 핀 13) → 택트 스위치 → 파란 레일(-) → GND(물리 핀 9)

**LED의 길:** GPIO17(물리 핀 11) → 저항 → LED 긴 다리 → LED 짧은 다리 → 파란 레일(-) → GND(물리 핀 9)

버튼 회로에는 저항이 없어요. gpiozero의 Button이 내장 풀업을 켜 주기 때문이에요.

1. 라즈베리파이의 전원을 끄고 어댑터를 뽑아요.
2. 택트 스위치를 가운데 홈에 걸쳐 꽂아요. 다리가 e10, e12, f10, f12에 들어가요.
3. 나머지를 아래 표대로 꽂아요.

| 부품 | 한쪽 | 다른 쪽 |
| --- | --- | --- |
| 암-수 점퍼선 1 | 물리 핀 9 (GND) | 파란 레일(-) |
| 암-수 점퍼선 2 | 물리 핀 13 (GPIO27) | j10 |
| 수-수 점퍼선 1 | a12 | 파란 레일(-) |
| 암-수 점퍼선 3 | 물리 핀 11 (GPIO17) | a18 |
| 330옴 저항 | c18 | c23 |
| LED | 긴 다리 d23 | 짧은 다리 d24 |
| 수-수 점퍼선 2 | a24 | 파란 레일(-) |

<Callout type="note">

j10은 스위치의 f10 다리와, a12는 스위치의 e12 다리와 같은 묶음이에요.
이 둘은 스위치에서 **대각선으로 마주 보는 다리**예요. 대각선 두 다리는 서로 다른 짝이라서, 스위치를 어느 쪽으로 돌려 꽂아도 누를 때만 이어져요.
스위치 다리가 10번과 12번 줄에 맞지 않으면, 실제로 꽂힌 줄에 맞춰 점퍼선을 옮겨요. 대각선이라는 것만 지키면 돼요.

</Callout>

4. 두 길을 손가락으로 따라가며 끊어진 곳이 없는지 확인해요.
5. 확인이 끝나면 전원을 연결하고 바탕화면이 나올 때까지 기다려요.

**성공 확인:** 전원을 넣었을 때 LED는 꺼져 있고, 연기나 타는 냄새가 나지 않아요. 이상하면 바로 전원을 뽑고 선생님을 불러요.

</MissionCard>

<MissionCard number={2} title="버튼의 상태 읽어 보기" time="10분">

먼저 **결과를 예상**해 봐요. 버튼을 누르지 않을 때와 누르고 있을 때 화면에 무엇이 나올까요? 예상을 공책에 적어요.

1. 아래 코드를 입력하고 `read_button.py`로 저장해요.

```python
from gpiozero import Button
from time import sleep

button = Button(27)

while True:
    print(button.is_pressed)
    sleep(0.5)
```

2. **Run**으로 실행하고 쉘을 보면서 버튼을 눌렀다 떼 봐요. 멈출 때는 **Stop** 버튼을 눌러요.

**성공 확인:** 누르지 않으면 `False`, 누르고 있는 동안에는 `True`가 찍혀요.

이번에는 값을 계속 묻지 않고 눌릴 때까지 기다려요.

3. 아래 코드를 `wait_button.py`로 저장하고 실행해요. 몇 초 기다렸다가 버튼을 눌러요. 한글이 입력되지 않으면 따옴표 안을 영어로 바꿔도 돼요.

```python
from gpiozero import Button

button = Button(27)

print("버튼을 눌러 보세요")
button.wait_for_press()
print("버튼이 눌렸어요!")
```

**성공 확인:** 첫 번째 문장이 나온 뒤 프로그램이 멈춰 있다가, 버튼을 누르는 순간 두 번째 문장이 나와요.

</MissionCard>

<MissionCard number={3} title="버튼으로 LED 움직이기" time="15분">

1. 아래 코드를 입력하고 `button_led.py`로 저장해요.

```python
from gpiozero import Button, LED

button = Button(27)
led = LED(17)

while True:
    if button.is_pressed:
        led.on()
    else:
        led.off()
```

2. 실행해요. 멈출 때는 **Stop** 버튼을 눌러요.

**성공 확인:** 버튼을 누르는 동안에만 LED가 켜지고, 손을 떼면 꺼져요.

이제 코드를 바꾸기 전에 **결과를 먼저 예상**해 봐요.

3. `else:`와 `led.off()` 두 줄을 지우면 LED가 어떻게 달라질까요? 버튼을 처음 누르기 전, 누른 뒤, 손을 뗀 뒤로 나눠 공책에 적어요.
4. 지우고 실행해서 예상과 비교해요.

```python
from gpiozero import Button, LED

button = Button(27)
led = LED(17)

while True:
    if button.is_pressed:
        led.on()
```

**성공 확인:** 처음에는 꺼져 있다가 한 번 누르면 켜지고, 손을 떼도 계속 켜져 있어요. 끄는 코드가 사라졌기 때문이라고 설명할 수 있어요.

</MissionCard>

## 막혔을 때

| 증상 | 확인할 곳 |
| --- | --- |
| 눌러도 계속 `False`예요 | 전원을 분리하고 스위치 다리가 끝까지 꽂혔는지, 점퍼선이 물리 핀 13번과 파란 레일에 있는지 확인해요. |
| 누르지 않았는데 계속 `True`예요 | 두 점퍼선이 스위치의 같은 짝에 연결됐을 수 있어요. 대각선으로 마주 보는 다리에 연결했는지 확인해요. |
| 버튼은 읽히는데 LED가 켜지지 않아요 | LED 방향과 물리 핀 11번을 확인해요. 긴 다리가 저항 쪽이어야 해요. |
| 코드의 번호가 헷갈려요 | 코드에는 GPIO 번호를 써요. `Button(27)`이고, 물리 핀은 13번이에요. |
| `GPIO busy`처럼 핀을 쓸 수 없다는 오류가 나요 | 이전 프로그램이 핀을 쓰고 있어요. Stop을 누르고 다시 실행해요. |
| `IndentationError` 오류가 나요 | `while True:`와 `if`, `else` 아래 줄의 들여쓰기를 확인해요. |
