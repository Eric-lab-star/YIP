# 기초 택트 스위치

지금까지 라즈베리파이는 LED에게 명령을 **내보내기만** 했어요.
이번에는 방향을 바꿔서, 바깥 세계의 신호를 **받아들이는** 입력을 배웁니다.
입력의 가장 좋은 첫 연습 상대가 바로 **택트 스위치**, 딸깍 소리가 나는 작은 버튼이에요.

<Callout type="goal">

**이번 수업을 마치면**

1. 택트 스위치의 네 다리가 어떻게 연결되어 있는지 설명할 수 있어요.
2. GPIO 입력으로 버튼이 눌렸는지 읽는 원리를 이해할 수 있어요.
3. gpiozero의 Button으로 버튼 입력에 반응하는 프로그램을 만들 수 있어요.

</Callout>

## 1. 스위치: 길을 끊었다 이었다 하는 문지기

**스위치**는 회로의 길을 잇거나 끊는 부품이에요.
**택트 스위치**는 누르는 동안에만 길이 이어지고, 손을 떼면 다시 끊어지는 방식입니다.
"딸깍" 하는 촉감(tact)이 있어서 이런 이름이 붙었어요.

그런데 택트 스위치를 들여다보면 다리가 **네 개**라서 고개를 갸웃하게 됩니다.
길을 잇고 끊는 데는 두 개면 충분할 텐데 말이죠.
비밀은 이렇습니다. **네 다리는 두 개씩 이미 짝으로 연결되어 있어요.**

- 스위치 몸통을 기준으로 **같은 쪽에 있는 두 다리는 늘 이어져 있는 한 짝**이에요.
- 버튼을 누르면 **반대쪽 짝과 연결**됩니다.

그래서 연결할 때는 서로 **반대쪽 짝에서 하나씩** 다리를 골라야 해요.
같은 짝의 두 다리를 쓰면 버튼을 누르지 않아도 늘 연결된 상태가 됩니다.
다리가 많은 이유는 브레드보드에 단단히 고정하기 위해서이기도 해요.
택트 스위치는 가운데 홈에 걸쳐 꽂으면 짝이 자연스럽게 양쪽으로 나뉘어 실수를 줄일 수 있습니다.

## 2. 입력: 핀의 전압을 읽는 일

LED 때는 프로그램이 핀의 전압을 **바꿨어요**(출력).
버튼은 반대로, 핀의 전압이 지금 높은지 낮은지를 프로그램이 **읽어요**(입력).

우리가 만들 회로의 생각은 이렇습니다.

**GPIO27(물리 핀 13) ← 택트 스위치 → GND**

버튼이 눌리면 GPIO27이 GND와 이어져 전압이 **낮음(0V)**이 되고,
눌리지 않았을 때는 **높음(3.3V)**을 유지해요.
프로그램은 이 전압의 변화를 읽어서 "아, 지금 버튼이 눌렸구나"를 알아차립니다.

<Callout type="note">

**누르지 않았을 때의 전압은 누가 정해 줄까요?**

버튼이 안 눌린 동안 핀이 어디에도 연결되어 있지 않으면,
핀의 전압은 높지도 낮지도 않은 **붕 뜬 상태**가 되어 값이 제멋대로 흔들려요.
그래서 평소에 핀을 3.3V 쪽으로 살짝 당겨 두는 **풀업 저항**이라는 장치가 필요합니다.
다행히 라즈베리파이에는 핀마다 내장 풀업 저항이 들어 있고,
gpiozero의 Button은 **이 내장 풀업을 자동으로 켜 줍니다.**
덕분에 우리는 스위치와 점퍼선만으로 회로를 만들 수 있어요.

</Callout>

## 3. gpiozero의 Button

```python
from gpiozero import Button

button = Button(27)

button.wait_for_press()
print("버튼이 눌렸어요!")
```

- `button = Button(27)`: GPIO27에 연결된 버튼이라고 알려 줘요. 내장 풀업도 이때 켜집니다.
- `button.wait_for_press()`: 버튼이 눌릴 때까지 프로그램이 여기서 **기다려요**.
- 버튼이 눌리면 다음 줄로 넘어가 메시지가 출력됩니다.

### 입력과 출력을 연결하면: 버튼으로 LED 켜기

입력(버튼)과 출력(LED)을 한 프로그램에 모으면, 1차시에서 예고했던
**버튼의 신호 입력 → 프로그램의 판단 → LED를 켜는 신호 출력** 흐름이 완성됩니다.

```python
from gpiozero import Button, LED

button = Button(27)
led = LED(17)

while True:
    if button.is_pressed:
        led.on()
    else:
        led.off()
```

`button.is_pressed`는 버튼이 지금 눌려 있으면 참이 되는 값이에요.
실행하면 **누르는 동안에만** LED가 켜집니다.
전등 스위치 같지만, 중간에 프로그램이 끼어 있다는 점이 달라요.
프로그램의 판단을 바꾸면 "두 번 누르면 켜지는 등"도, "누르면 3초 뒤 꺼지는 등"도 만들 수 있습니다.

<Callout type="tip">

**버튼이 반응하지 않을 때**

1. 스위치 다리의 짝을 확인해요. **반대쪽 짝에서 하나씩** 연결했나요?
2. 핀 자리를 확인해요. GPIO27은 물리 핀 13번이에요. GND는 가까운 14번을 쓰면 편해요.
3. `Button(27)`의 숫자를 확인해요.
4. 눌렀는데 계속 눌림으로 나온다면 같은 짝의 두 다리에 연결했을 가능성이 커요.

</Callout>

## 스스로 확인해 보기

<details>
<summary>1. 택트 스위치의 다리 네 개 중 아무거나 두 개를 쓰면 안 되는 이유는 무엇인가요?</summary>

네 다리는 두 개씩 이미 연결된 짝이기 때문이에요.
같은 짝의 두 다리를 쓰면 버튼을 누르지 않아도 항상 연결된 상태가 됩니다.
반대쪽 짝에서 하나씩 골라 연결해야 해요.

</details>

<details>
<summary>2. 출력과 입력은 무엇이 다른가요?</summary>

출력은 프로그램이 핀의 전압을 바꿔 바깥으로 신호를 보내는 것이고(LED 켜기),
입력은 바깥에서 만들어진 핀의 전압 변화를 프로그램이 읽는 것이에요(버튼 읽기).

</details>

<details>
<summary>3. 풀업 저항은 어떤 문제를 해결해 주나요?</summary>

버튼이 눌리지 않은 동안 핀이 붕 떠서 값이 흔들리는 문제를 해결해요.
평소 전압을 3.3V로 잡아 두었다가, 버튼이 눌리면 0V로 떨어지게 해서
눌림과 안 눌림을 확실하게 구분할 수 있게 합니다.
gpiozero의 Button은 내장 풀업을 자동으로 켜 줘요.

</details>
