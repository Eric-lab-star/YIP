# 최종프로젝트 실습

오늘은 새로운 부품을 배우지 않아요. 지금까지 직접 만들어 본 조각에서 골라 내 작품을 만듭니다.
완성품보다 **오늘 끝까지 동작하는 가장 작은 버전** 하나를 목표로 해요.

<Callout type="goal">

**이번 실습을 마치면**

1. 내가 만들어 본 조각 중에서 골라 입력, 판단, 출력을 한 장의 계획으로 적을 수 있어요.
2. 조각을 하나씩 더하며 확인해서 동작하는 작품을 내 손으로 완성할 수 있어요.
3. 점검표로 내 작품을 스스로 평가하고 친구에게 1분 동안 설명할 수 있어요.

</Callout>

<Callout type="important">

**배선 전 약속**

- 배선을 바꿀 때는 프로그램을 멈추고, **운영체제를 종료한 뒤 전원을 완전히 분리**해요.
- GPIO 신호 핀은 **3.3V**까지만 다뤄요. HC-SR04의 Echo는 약 5V이니 **반드시 전압 분배를 거쳐** GPIO24에 연결해요.
- 센서 모듈의 전원 핀은 해당 차시의 실습대로 연결해요. 모듈의 DO 신호를 GPIO에 잇기 전에 선생님께 확인받아요.
- 부품을 하나 더할 때마다 전원을 넣기 전에 친구나 선생님과 배선을 확인해요.
- 사람을 찍거나 녹음할 때는 먼저 허락을 받아요.

</Callout>

- [ ] 지난 차시 실습에서 만든 프로그램 파일

<MissionCard number={1} title="조각 고르기" time="5분">

아래 표에서 **이미 동작시켜 본 조각**을 고르세요. 입력 하나, 판단 하나, 출력 하나면 충분해요.

| 조각 | 자리 | 연결 | 다시 볼 곳 |
| --- | --- | --- | --- |
| 택트 스위치 | 입력 | GPIO27 (물리 핀 13) | [기초 택트 스위치](/RaspberryPi/basic_tact_switch/task) |
| CDS 모듈 | 입력 | DO를 GPIO22 (물리 핀 15) | [CDS 센서](/RaspberryPi/what_is_CDS/task) |
| MQ-2 모듈 | 입력 | DO를 GPIO22 (물리 핀 15) | [MQ-2가스감지센서](/RaspberryPi/MQ-2_sensor/task) |
| HC-SR04 | 입력 | Trig를 GPIO23 (물리 핀 16), Echo를 전압 분배 거쳐 GPIO24 (물리 핀 18) | [초음파센서](/RaspberryPi/ultra_sonic_sensor/task) |
| MPU6050 | 입력 | I2C, GPIO2 (물리 핀 3)와 GPIO3 (물리 핀 5) | [MPU6050 센서](/RaspberryPi/MPU6050_sensor/task) |
| DS18B20 | 입력 | GPIO4 (물리 핀 7)와 4.7k옴 풀업 | [DS18B20 온도센서](/RaspberryPi/DS18B02_sensor/task) |
| 카메라 | 입력 | 카메라 단자 | [카메라 연결하기](/RaspberryPi/camera_controll/task) |
| 마이크 | 입력 | USB 포트 | [녹음기](/RaspberryPi/audio_recorder/task) |
| 웹 요청 | 입력 | Wi-Fi | [웹으로 LED 제어하기](/RaspberryPi/led_controll_over_web/task) |
| BLE | 입력 | 내장 블루투스 | [블루투스LE 스마트 조명제어](/RaspberryPi/BLE/task) |
| 조건문과 반복문 | 판단 | 코드 | 지난 차시의 프로그램 |
| 사물인식 모델 | 판단 | 코드와 모델 파일 | [사물인식](/RaspberryPi/object_detection/task) |
| LED | 출력 | GPIO17 (물리 핀 11) | [LED 제어하기](/RaspberryPi/LED_controll/task) |
| 3색 LED | 출력 | GPIO17, 27, 22 (물리 핀 11, 13, 15) | [LED 여러개 제어하기](/RaspberryPi/more_LEDS/task) |
| 파일 저장 | 출력 | 코드 | [데이터 저장하기](/RaspberryPi/save_data/task) |
| 웹페이지 | 출력 | Wi-Fi | [웹서버 만들기](/RaspberryPi/web_server/task) |

고르기가 어려우면 이 조합에서 출발해요.

- **스마트 가로등:** CDS + 초음파 + LED
- **온도 기록장:** DS18B20 + 파일 저장 + 웹페이지
- **문 지킴이:** 초음파 + 카메라 사진 저장 + LED
- **움직임 알림 상자:** MPU6050 + 3색 LED
- **원격 조명 리모컨:** 웹 요청 + LED 여러 개

<Callout type="note">

**핀이 겹치는지 확인해요.** 한 GPIO에는 부품 하나만 연결해요.
예를 들어 3색 LED는 GPIO27과 GPIO22를 쓰니 버튼이나 CDS 모듈과 겹쳐요.
겹치면 한쪽을 빈 GPIO로 옮기고, 코드의 번호도 함께 바꿔요.
빈 GPIO로는 GPIO5(물리 핀 29), GPIO6(물리 핀 31)을 쓸 수 있어요.

</Callout>

<MissionCard number={2} title="한 장 계획 쓰기" time="10분">

아래 표를 공책에 옮겨 내 작품으로 채워요. 왼쪽 칸의 스마트 가로등은 예시예요.

| 항목 | 스마트 가로등 예시 | 내 작품 |
| --- | --- | --- |
| 해결할 문제 | 사람이 없을 때도 복도 불이 켜져 있어요 | |
| 입력 | CDS로 어두움을, 초음파로 사람을 읽어요 | |
| 판단 | 어둡고 50cm 안에 물체가 있을 때 | |
| 출력 | LED를 켜요 | |
| 가장 작은 버전 | CDS 값을 화면에 찍어요 | |
| 더할 순서 | 초음파 값 찍기 → LED 켜기 → 조건 합치기 | |
| 쓰는 핀 | GPIO22, 23, 24, 17 | |

계획을 다 쓰면 **입력이 어떻게 변할 때 출력이 어떻게 달라져야 하는지** 한 문장으로 적어요. 만든 뒤 시험할 기준이 돼요.

**성공 확인:** 표의 모든 칸이 채워져 있고, 옆 친구가 내 계획만 읽고 작품이 하는 일을 말할 수 있어요.

</MissionCard>

<MissionCard number={3} title="한 조각씩 만들기" time="20분">

조각을 하나 더할 때마다 값을 화면에서 확인하고 다음으로 넘어가요. 긴 코드를 한 번에 돌리면 어디서 막혔는지 찾기 어려워요.

1. **가장 작은 버전**부터 만들어요. 필요한 배선은 위 표의 해당 차시 실습대로 꽂아요. MPU6050, DS18B20, BLE, 사물인식을 쓰는 작품은 Thonny의 Run이 아니라 해당 차시처럼 가상 환경을 켠 터미널에서 실행해요.
2. 값을 화면에 찍어 동작을 확인해요. 스마트 가로등이라면 CDS 값부터 봐요.

```python
from gpiozero import DigitalInputDevice
from time import sleep

cds = DigitalInputDevice(22)

while True:
    print(cds.value)
    sleep(0.5)
```

3. 값을 보고 **내 모듈이 어두울 때 어떤 값을 내는지** 적어요. 모듈의 다이얼 설정에 따라 다를 수 있으니, 손으로 가리고 직접 확인해요.
4. 다음 조각을 더하기 전에 **결과를 먼저 예상**해 적어요. 예를 들어 초음파 센서에 손을 가까이 대면 숫자가 어떻게 변할까요?
5. 조각을 하나씩 더해 내 작품을 완성해요. 스마트 가로등을 끝까지 합치면 이런 모습이에요.

```python
from gpiozero import DigitalInputDevice, DistanceSensor, LED
from time import sleep

cds = DigitalInputDevice(22)
sensor = DistanceSensor(echo=24, trigger=23)
led = LED(17)

while True:
    print("어두움:", cds.value, "거리:", sensor.distance)

    if cds.value and sensor.distance < 0.5:
        led.on()
    else:
        led.off()

    sleep(0.2)
```

작품이 계속 동작해야 한다면 `while True:`처럼 프로그램이 끝나지 않게 만들어요. 프로그램이 끝나면 더는 입력을 읽고 판단할 수 없어요. 터미널에서 실행한 프로그램은 끝날 때 핀을 정리해서 LED가 꺼져요. Thonny의 Run으로 실행했다면 프로그램이 끝나도 LED가 켜진 채 남을 수 있어요.

시간이 부족하면 욕심내지 말고 지금까지 동작하는 버전을 지켜요. 파일을 고치기 전에 `작품_1.py`, `작품_2.py`처럼 이름을 나눠 저장해 두면 언제든 돌아갈 수 있어요.

**성공 확인:** 미션 2에 적은 문장대로 입력을 바꾸었을 때 출력이 달라져요. 예를 들어 어둡게 하고 손을 대면 LED가 켜지고, 손을 치우면 꺼져요.

</MissionCard>

<MissionCard number={4} title="스스로 점검하고 설명하기" time="10분">

1. 아래 점검표로 내 작품을 평가해요. 항목마다 0점에서 2점을 공책에 적어요.

| 항목 | 2점 | 1점 | 0점 |
| --- | --- | --- | --- |
| 동작 | 계획한 대로 여러 번 동작해요 | 가끔 되거나 일부만 돼요 | 아직 동작하지 않아요 |
| 입력, 판단, 출력 | 세 자리가 모두 분명해요 | 한 자리가 코드에서 잘 안 보여요 | 말로 나누기 어려워요 |
| 안전한 배선 | 전원 분리와 3.3V 약속을 모두 지켰어요 | 친구가 고쳐 줘서 지켰어요 | 확인받지 못했어요 |
| 한 조각씩 확인 | 조각마다 값을 찍어 확인했어요 | 일부만 확인했어요 | 한 번에 다 연결했어요 |
| 내 설명 | 코드의 각 부분을 내 말로 설명해요 | 일부만 설명할 수 있어요 | 아직 설명하기 어려워요 |

2. 점수가 낮은 항목 하나를 골라 다음에 어떻게 고칠지 한 문장으로 적어요.
3. 친구에게 1분 동안 설명해요. 네 가지를 담아요.
   - 왜 만들었나요?
   - 입력, 판단, 출력으로 어떻게 동작하나요?
   - 어디서 막혔고 어떻게 풀었나요?
   - 시간이 더 있다면 무엇을 더하고 싶나요?

**성공 확인:** 점검표의 다섯 항목에 모두 점수를 적었고, 고칠 점 한 문장이 있으며, 친구 앞에서 작품을 동작시키며 설명했어요.

</MissionCard>

## 막혔을 때

원인을 찾는 순서로는 **배선 → 핀 번호 → 코드**를 제안해요. 정해진 규칙은 아니에요. 오류 메시지가 코드를 가리키면 코드부터 봐도 좋아요. 가장 중요한 것은 **방금 더한 조각**부터 살피는 거예요.

| 증상 | 확인할 곳 |
| --- | --- |
| 방금 더한 부품이 동작하지 않아요 | 그 부품만 남긴 짧은 프로그램으로 따로 시험해요. 해당 차시의 실습 페이지를 봐요. |
| 값이 전혀 변하지 않아요 | 전원을 분리하고 배선을 본 뒤, 코드의 GPIO 번호와 실제로 꽂은 핀이 같은지 비교해요. |
| `GPIO busy`처럼 핀을 쓸 수 없다는 오류가 나요 | 이전 프로그램이 돌고 있거나 코드에서 같은 핀을 두 번 썼어요. Stop을 누르고 핀 번호를 확인해요. |
| `IndentationError` 오류가 나요 | 코드를 합치면서 들여쓰기가 어긋났어요. `if`와 `while` 아래 줄의 칸을 맞춰요. |
| 조건이 맞는데도 LED가 안 켜져요 | `print`로 조건에 쓰는 값을 찍어 봐요. 내 모듈의 값이 예상과 반대일 수 있어요. |
| 초음파 거리가 1m에서 멈춰요 | `DistanceSensor`의 기본 최대 거리가 1m예요. 더 멀리 재려면 `max_distance`를 정해요. |
| 터미널에서 실행한 프로그램이 끝나면 LED가 꺼져요 | 프로그램이 끝날 때 핀이 정리돼요. 반복문으로 계속 돌아가게 해요. |
| Thonny에서 프로그램이 끝났거나 Stop을 눌렀는데 LED가 켜져 있어요 | Thonny가 멈출 때는 핀을 정리하지 않을 수 있어요. 고장이 아니에요. `LED(17)`이 든 프로그램을 다시 실행하면 꺼져요. |
| `No module named 'mpu6050'`처럼 라이브러리를 못 찾아요 | 가상 환경의 라이브러리는 Thonny에서 보이지 않아요. 터미널에서 `source ~/sensor-env/bin/activate`를 입력하고 `python 파일이름.py`로 실행해요. 사물인식은 `~/ai-env`예요. 멈출 때는 Ctrl+C를 눌러요. |
| 시간이 모자라요 | 가장 작은 버전까지만 완성해도 괜찮아요. 남은 조각은 "더하고 싶은 것"으로 발표해요. |
