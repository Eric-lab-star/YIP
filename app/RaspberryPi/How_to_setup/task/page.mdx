# 환경설정하기 실습

오늘은 내 microSD 카드를 라즈베리파이가 깨어날 수 있는 카드로 만듭니다.
작업은 평소에 쓰는 컴퓨터에서 하고, 다음 시간에 이 카드로 첫 부팅을 해요.

<Callout type="goal">

**이번 실습을 마치면**

1. 내 카드를 저장소 목록에서 정확히 골라낼 수 있어요.
2. 사용자, Wi-Fi, 시간대를 미리 설정해 카드를 만들 수 있어요.
3. 쓰기와 검사가 끝난 것을 확인하고 카드를 안전하게 꺼낼 수 있어요.

</Callout>

<Callout type="important">

**쓰기 전 약속**

- 쓰기를 시작하면 고른 저장소의 내용이 **모두 지워져요.** 필요한 파일은 미리 옮겨 둬요.
- 저장소를 고를 때는 **용량과 이름**을 다시 확인해요. 쓰기 버튼을 누르기 전에 짝이나 선생님에게 확인을 받아요.
- 쓰는 도중에는 카드를 **뽑지 않아요.**

</Callout>

## 준비물

- [ ] 인터넷에 연결된 컴퓨터
- [ ] microSD 카드 (공식 안내는 데스크톱용 Raspberry Pi OS에 32GB 이상을 권장해요)
- [ ] 카드 리더 (컴퓨터에 슬롯이 있으면 필요 없어요)
- [ ] 선생님이 알려 주신 Wi-Fi 이름과 비밀번호
- [ ] 공책과 필기구

<MissionCard number={1} title="카드와 Imager 준비하기" time="10분">

1. 카드 겉면의 용량을 공책에 적어요.
2. 카드에 필요한 파일이 있었다면 다른 곳으로 옮겨요. 없다면 그대로 넘어가요.
3. [공식 다운로드 페이지](https://www.raspberrypi.com/software/)에서 Raspberry Pi Imager를 받아 설치해요. 선생님이 미리 설치해 두셨다면 건너뛰어요.
4. 카드를 카드 리더에 넣어 컴퓨터에 연결해요. 쓰지 않는 USB 저장 장치는 뽑아 두면 헷갈리지 않아요.
5. Imager를 실행해요.

**성공 확인:** Imager 첫 화면이 열렸고, 공책에 카드 용량이 적혀 있어요. 컴퓨터에 연결된 저장 장치는 내 카드뿐이에요.

</MissionCard>

<MissionCard number={2} title="세 가지 선택과 미리 설정" time="10분">

화면을 따라 차례로 고르고 **다음(Next)**으로 넘어가요. Imager 버전에 따라 화면 모양과 글자가 조금 다를 수 있어요.

| 차례 | 고르는 것 | 우리 수업의 선택 |
| --- | --- | --- |
| 1 | 기기(Device) | Raspberry Pi 4 |
| 2 | 운영체제(OS) | 권장으로 표시된 Raspberry Pi OS. 이름에 Lite가 붙은 것은 화면 없이 쓰는 버전이니 고르지 않아요. |
| 3 | 저장소(Storage) | 공책에 적은 용량과 맞는 내 카드 |

이어서 미리 설정(Customisation) 화면이 나오면 아래처럼 넣어요. 표에 없는 화면(원격 접속 등)은 바꾸지 말고 넘어가요.

| 항목 | 넣을 값 | 주의할 점 |
| --- | --- | --- |
| 기기 이름(Hostname) | 선생님이 정해 주신 이름 | 칸에 이미 이름이 있고 따로 안내가 없으면 그대로 둬요 |
| 지역 | 서울(Seoul), 시간대 Asia/Seoul | 키보드는 선생님 안내를 따라요 |
| 사용자 이름 | 영어 소문자로 시작하는 짧은 이름 | 대문자와 한글은 쓸 수 없어요 |
| 비밀번호 | 내가 기억할 수 있는 값 | 공책에 적되 친구에게 보여 주지 않아요 |
| Wi-Fi | 선생님이 알려 주신 이름과 비밀번호 | 대소문자까지 똑같이 입력해요 |

**성공 확인:** 쓰기를 시작하기 직전 화면에서 기기, 운영체제, 저장소, 설정을 짝이 함께 확인했어요. 공책에 사용자 이름과 비밀번호가 적혀 있어요.

</MissionCard>

<MissionCard number={3} title="쓰기와 검사 지켜보기" time="20분">

쓰기를 누르기 전에 **결과를 먼저 예상**해 봐요.

1. 쓰기가 끝날 때까지 몇 분이 걸릴지 공책에 적어요. 시작하는 시각도 함께 적어요.
2. 쓰기를 시작해요. 카드의 내용을 지운다는 확인 창이 나오면 저장소를 한 번 더 확인하고 진행해요. 컴퓨터가 관리자 권한을 물으면 선생님을 불러요.
3. 진행 표시를 지켜봐요. 기록이 끝나면 제대로 기록됐는지 검사하는 단계가 이어져요.
4. 완료 화면이 나오면 끝난 시각을 적고 예상과 비교해요. 시간은 인터넷과 카드 속도에 따라 달라져요.
5. 완료 화면을 닫은 뒤 컴퓨터에서 카드를 안전하게 꺼내고 리더에서 분리해요.
6. 금속 단자를 만지지 않게 카드를 보관하고, 이름을 적어 선생님께 드려요.

**성공 확인:** Imager에 완료 표시가 나타난 뒤에 카드를 분리했어요. 공책에 예상 시간과 실제 시간이 함께 적혀 있어요.

<Callout type="note">

쓰기가 끝난 뒤 컴퓨터가 카드를 포맷하라고 물을 수 있어요.
컴퓨터가 읽지 못하는 영역이 있어서 그럴 뿐이니 **취소**를 눌러요. 포맷하면 방금 만든 카드가 지워져요.

</Callout>

</MissionCard>

## 막혔을 때

| 증상 | 확인할 곳 |
| --- | --- |
| 저장소 목록에 카드가 보이지 않아요 | 카드가 리더에 끝까지 들어갔는지, 리더가 컴퓨터에 잘 꽂혔는지 확인하고 다시 연결해요. |
| 목록에 저장 장치가 여러 개 보여요 | 내 카드가 아닌 장치를 뽑고 다시 확인해요. 모르면 고르지 말고 선생님을 불러요. |
| 쓰기 도중 오류가 나요 | 어댑터에 넣어 쓴다면 잠금 스위치를 확인하고 다시 써요. 반복되면 다른 카드나 리더로 바꿔 봐요. |
| 사용자 이름이 입력되지 않아요 | 영어 소문자로 시작했는지, 빈칸이나 한글이 없는지 확인해요. |
| 수업이 끝나는데 쓰기가 끝나지 않았어요 | 카드를 뽑지 말고 선생님께 알려요. 도중에 뽑은 카드는 처음부터 다시 써야 해요. |

## 더 해 보기

1. **순서 설명하기:** 카드를 만드는 과정을 다섯 단계로 나눠 공책에 쓰고, 왜 그 순서인지 짝에게 설명해 보세요.
2. **건너뛰면 어떻게 될까:** 미리 설정을 건너뛰면 첫 부팅에서 무엇을 입력해야 할지 학습하기에서 찾아 적어 보세요.
3. **비교하기:** Imager의 운영체제 목록에서 Raspberry Pi OS 항목들의 설명을 읽고 무엇이 다른지 적어 보세요.
