# MQ-2가스감지센서 실습

오늘은 눈에 보이지 않는 가스에 반응하는 LED 경보기를 만듭니다.
가장 먼저 선생님과 전압부터 확인하고, 내 모듈의 값을 관찰한 다음 그 값에 맞춰 프로그램을 써요.

<Callout type="goal">

**이번 실습을 마치면**

1. 선생님이 DO 전압을 확인한 뒤에만 GPIO22에 연결하는 순서를 지킬 수 있어요.
2. `gas.value`를 찍어 내 모듈이 감지할 때 0을 내는지 1을 내는지 직접 알아낼 수 있어요.
3. 관찰한 값에 맞는 조건을 골라 LED 경보 프로그램을 완성할 수 있어요.

</Callout>

<Callout type="important">

**배선 전 약속**

- 배선을 바꿀 때는 **먼저 전원을 완전히 분리**해요.
- GPIO 신호 핀은 **3.3V**까지만 다뤄요. 5V 핀에는 모듈의 VCC만 연결해요.
- 모듈은 5V로 동작하고, 모듈에 따라 DO로 5V에 가까운 전압이 나올 수 있어요. 이런 전압이 GPIO 핀에 들어가면 라즈베리파이가 망가질 수 있어요.
- 그래서 **선생님이 멀티미터로 DO가 3.3V 이하인 것을 확인하기 전에는 DO를 GPIO22에 연결하지 않아요.**
- 모듈마다 핀 순서가 달라요. **모듈에 적힌 글자**를 보고 연결해요. AO는 연결하지 않아요.
- 전원을 넣기 전에 친구나 선생님과 배선을 한 번 더 확인해요.

</Callout>

<Callout type="important">

**가스 시험 약속**

- 가스 시험은 **선생님이 직접, 환기되는 곳에서, 아주 짧게** 해요. 학생끼리 하지 않아요.
- 불꽃이나 점화원 근처에서 절대 시험하지 않아요. 라이터는 점화하지 않아요.
- 센서는 쓰는 동안 뜨거워지니 망사를 만지지 않아요.
- 오늘 만드는 경보기는 **진짜 안전 장치가 아니에요.** 집이나 교실의 가스 감시에 쓰면 안 돼요.

</Callout>

- [ ] 멀티미터 (선생님이 사용)

<MissionCard number={1} title="DO를 빼고 연결해 전압 확인하기" time="15분">

이번 미션에서 DO는 **어디에도 연결하지 않아요.**

1. 라즈베리파이의 전원을 끄고 어댑터를 뽑아요.
2. 모듈의 핀 옆에 적힌 글자를 읽고 VCC, GND, DO의 자리를 찾아요.
3. 아래 표대로 꽂아요. 짝수 번호 핀은 보드 가장자리 쪽 줄에 있어요. 그 줄에서 USB 포트의 반대쪽 끝부터 세어 첫 번째가 물리 핀 2번, 세 번째가 물리 핀 6번이에요.

| 부품 | 한쪽 | 다른 쪽 |
| --- | --- | --- |
| 암-암 점퍼선 1 | 모듈 VCC | 물리 핀 2 (5V) |
| 암-암 점퍼선 2 | 모듈 GND | 물리 핀 6 (GND) |
| 없음 | 모듈 DO | **아직 연결하지 않음** |
| 없음 | 모듈 AO | 연결하지 않음 |

4. LED는 6차시와 같은 회로로 브레드보드에 꾸며요.

| 부품 | 한쪽 | 다른 쪽 |
| --- | --- | --- |
| 암-수 점퍼선 1 | 물리 핀 11 (GPIO17) | 브레드보드 a10 |
| 330옴 저항 | c10 | c15 |
| LED | 긴 다리 d15 | 짧은 다리 d16 |
| 암-수 점퍼선 2 | 브레드보드 a16 | 물리 핀 9 (GND) |

5. 선생님께 배선을 확인받고 전원을 연결해요.
6. 센서가 달궈지도록 몇 분 이상 예열해요. 이때 값이 흔들리는 것은 고장이 아니에요.
7. **선생님이** 멀티미터로 모듈의 DO와 GND 사이 전압을 재요. 기준 나사를 돌려 DO의 두 상태를 모두 만들어 각각 재고, 더 높은 전압을 기록해요.

| 측정 결과 | 다음 행동 |
| --- | --- |
| 두 상태 모두 3.3V 이하 | 미션 2로 넘어가요. |
| 한 상태라도 3.3V를 넘음 | **여기서 멈춰요.** 이 모듈의 DO는 GPIO에 연결하지 않고, 선생님의 안내를 따라요. |

**성공 확인:** 공책에 선생님이 잰 DO 전압이 적혀 있고, 3.3V 이하라는 확인을 받았어요. DO 선은 아직 꽂혀 있지 않아요.

</MissionCard>

<MissionCard number={2} title="gas.value 관찰하기" time="10분">

미션 1에서 선생님의 확인을 받은 모듈만 이 미션을 진행해요.

1. 전원을 끄고 어댑터를 뽑아요.
2. 세 번째 점퍼선을 꽂아요.

| 부품 | 한쪽 | 다른 쪽 |
| --- | --- | --- |
| 암-암 점퍼선 3 | 모듈 DO | 물리 핀 15 (GPIO22) |

3. 전원을 연결하고 다시 몇 분 동안 예열해요.
4. **결과를 먼저 예상**해요. 지금 교실 공기에서 값은 0일까요, 1일까요? 공책에 적어요.
5. 아래 코드를 `read_gas.py`로 저장하고 실행해요.

```python
from gpiozero import DigitalInputDevice
from time import sleep

gas = DigitalInputDevice(22)

while True:
    print(gas.value)
    sleep(0.5)
```

6. 쉘을 보면서 기준 나사를 천천히 돌려 숫자가 바뀌는 곳을 찾아요. 숫자가 0과 1 두 가지로 나오는 것을 확인해요.
7. 나사를 조금 되돌려, 숫자가 바뀌기 바로 전 위치에 두고 값이 안정될 때까지 기다려요. 이때의 숫자를 **평소 값**으로 공책에 적어요. 프로그램은 멈추지 않아요.

**성공 확인:** 쉘에서 0과 1을 모두 보았고, 공책에 평소 값이 적혀 있어요.

</MissionCard>

<MissionCard number={3} title="선생님과 가스 시험하기" time="7분">

어떤 값이 가스를 감지한 상태인지는 **모듈에 따라 달라요.** 학습하기의 예제와 반대인 모듈도 있어서 직접 확인해야 해요.

1. `read_gas.py`를 계속 실행해 둔 채로 창문을 열어 환기해요.
2. 주변에 불꽃이나 점화원이 없는지 확인해요.
3. **결과를 먼저 예상**해요. 가스가 닿으면 숫자가 어떻게 바뀔까요?
4. **선생님이** 라이터를 점화하지 않고 센서 근처에서 가스를 아주 짧게 내보내요. 학생은 한 걸음 떨어져서 쉘을 봐요.
5. 숫자가 바뀌면 그 값을 **감지 값**으로 공책에 적어요.
6. 값이 평소대로 돌아올 때까지 기다려요. 시간이 걸릴 수 있으니 환기를 계속해요.

반응이 없어도 가스를 더 오래 내보내지 않아요. 선생님이 기준 나사를 다시 맞춘 뒤 다시 할지 정해요.

**성공 확인:** 공책에 평소 값과 감지 값이 서로 다른 숫자로 적혀 있어요.

</MissionCard>

<MissionCard number={4} title="내 모듈에 맞는 경보 프로그램" time="8분">

1. **Stop**을 누르고 아래 코드를 입력해 `gas_alarm.py`로 저장해요.
2. `detected = 1`의 숫자를 미션 3에서 적은 **감지 값**으로 바꿔요. 이 숫자가 내 모듈에 맞는 조건을 정해요.

```python
from gpiozero import DigitalInputDevice, LED

gas = DigitalInputDevice(22)
alarm_led = LED(17)

detected = 1

while True:
    if gas.value == detected:
        alarm_led.on()
    else:
        alarm_led.off()
```

`==`는 양쪽 값이 같은지 묻는 기호예요. 학습하기의 `if gas.value:`는 감지할 때 1이 되는 모듈에서만 맞아요.

3. 실행하고 공기가 깨끗해진 상태에서 LED가 꺼져 있는지 봐요.
4. 가스를 다시 쓰지 않고 기준 나사를 살짝 돌려 값을 바꿔 봐요. LED가 함께 바뀌는지 확인하고 나사를 되돌려요.
5. **Stop** 버튼으로 멈춰요.

**성공 확인:** 평소에는 LED가 꺼져 있고, 값이 감지 값으로 바뀌면 LED가 켜져요. 내 모듈의 `detected`가 왜 그 숫자인지 설명할 수 있어요.

</MissionCard>

## 막혔을 때

| 증상 | 확인할 곳 |
| --- | --- |
| DO 전압이 3.3V를 넘어요 | 더 진행하지 않아요. DO를 GPIO에 연결하지 말고 선생님의 안내를 따라요. |
| 켜자마자 값이 왔다 갔다 해요 | 예열 중일 수 있어요. 몇 분 더 기다린 뒤 다시 봐요. |
| 나사를 돌려도 값이 그대로예요 | 전원을 분리하고 VCC, GND, DO 연결을 모듈의 글자와 비교해요. 그다음 나사를 끝까지 억지로 돌리지 말고 선생님께 물어봐요. |
| 가스 시험에서 값이 바뀌지 않아요 | 가스를 더 내보내지 말고 선생님께 말해요. 기준 나사의 위치를 다시 맞춰야 할 수 있어요. |
| 평소에 LED가 켜지고 감지할 때 꺼져요 | `detected`의 숫자가 공책의 감지 값과 같은지 확인해요. |
| 값은 바뀌는데 LED가 켜지지 않아요 | LED 방향과 물리 핀 11번, 9번을 확인해요. |
| `GPIO busy`처럼 핀을 쓸 수 없다는 오류가 나요 | 이전 프로그램이 핀을 쓰고 있어요. Stop을 누르고 다시 실행해요. |

## 더 해 보기

추가 활동에서는 가스를 쓰지 않아요. 값은 기준 나사로 바꿔서 시험해요.

1. **깜빡이는 경보:** 감지 값이면 LED가 0.2초 간격으로 깜빡이게 바꿔 보세요.
2. **화면 알림:** 값을 읽을 때마다 쉘에 `평소`나 `감지`가 찍히게 해 보세요. `sleep(0.5)`을 넣어 화면이 너무 빠르게 지나가지 않게 해요.
3. **안전등 추가:** 전원을 분리하고 LED 하나를 GPIO27(물리 핀 13)에 저항과 함께 더 연결해, 평소에는 그 LED가 켜지게 해 보세요.
