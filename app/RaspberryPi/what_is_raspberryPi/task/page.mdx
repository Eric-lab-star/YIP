# 라즈베리파이의 구성요소 실습

오늘은 진짜 보드를 손에 들고 부품을 하나씩 찾아봅니다.
전원은 연결하지 않고, 눈으로 찾고 친구에게 설명하면서 보드와 친해져요.

<Callout type="goal">

**이번 실습을 마치면**

1. 보드에서 주요 부품과 단자를 손가락으로 가리키며 이름을 말할 수 있어요.
2. 키보드, 모니터, 전원 케이블을 꽂을 자리를 실물과 비교해 찾을 수 있어요.
3. 파일을 실행하고 저장할 때 일하는 부품을 순서대로 친구에게 설명할 수 있어요.

</Callout>

<Callout type="important">

**관찰 전 약속**

- 오늘은 **전원을 연결하지 않아요.** 보드에 어댑터가 꽂혀 있다면 먼저 선생님께 알려요.
- 보드는 **가장자리**를 잡아요. 칩과 금속 핀은 손으로 만지지 않아요.
- 방열판이나 케이스가 붙어 있으면 떼지 말고 그대로 관찰해요.

</Callout>

## 준비물

- [ ] 라즈베리파이 4 Model B 보드
- [ ] USB 키보드와 마우스
- [ ] micro-HDMI–HDMI 케이블
- [ ] USB-C 전원 어댑터 (꽂지 않고 모양만 비교)
- [ ] 공책과 필기구

<MissionCard number={1} title="보드에서 부품 찾기" time="15분">

1. 보드에 적힌 모델 이름을 찾아 공책에 적어요. 모델이 다르면 위치도 다를 수 있으니 선생님께 알려요.
2. 표를 따라 찾기 전에, **결과를 먼저 예상**해 봐요. 네 개의 USB-A 포트와 USB-C 단자는 같은 가장자리에 있을까요? 예상을 공책에 적어요.
3. 아래 표의 부품을 하나씩 찾아 손가락으로 가리키고, 짝에게 확인을 받아요.

| 찾을 것 | 힌트 | 맡은 일 |
| --- | --- | --- |
| BCM2711 칩 | 은색 정사각형 칩, 방열판에 가려졌을 수 있어요 | CPU와 GPU가 들어 있어요 |
| RAM 칩 | 보드에 붙은 검은색 메모리 칩 | 실행 중인 내용을 잠시 보관해요 |
| microSD 슬롯 | 보드 **뒷면**의 작은 슬롯 | 운영체제와 파일이 든 카드를 꽂아요 |
| USB-A 포트 4개 | 위아래로 쌓인 직사각형 입구, 검은색과 파란색 | 키보드, 마우스, 저장 장치를 꽂아요 |
| 이더넷 포트 | USB 포트 옆의 폭이 넓은 사각형 입구 | 유선 네트워크를 연결해요 |
| micro-HDMI 2개 | 작고 납작한 단자 두 개 | 화면과 소리를 내보내요 |
| USB-C 전원 단자 | 모서리 가까이의 둥근 타원형 단자 | 보드에 전기를 공급해요 |
| GPIO 헤더 | 긴 가장자리의 금속 핀 두 줄 | 바깥 장치와 신호를 주고받아요 |
| 카메라·디스플레이 단자 | 얇은 플라스틱 슬롯, 근처에 적힌 글자를 읽어 봐요 | 리본 케이블을 연결해요 |
| 3.5mm 단자 | 둥근 입구 | 이어폰이나 스피커를 연결해요 |

4. GPIO 헤더의 핀을 만지지 말고 눈으로 세어 봐요. 한 줄에 몇 개이고 모두 몇 개인가요?
5. 예상과 실제 위치를 비교해요.

**성공 확인:** 짝이 표에서 아무 부품이나 말했을 때 3초 안에 보드에서 가리킬 수 있어요. GPIO 핀이 한 줄에 20개, 모두 40개인 것도 직접 세어 확인했어요.

</MissionCard>

<MissionCard number={2} title="장치의 자리 찾기" time="10분">

준비한 장치를 하나씩 들고 꽂을 자리를 찾아요. **오늘은 꽂지 말고** 단자 옆에 대어 모양만 비교해요.

| 장치 | 꽂을 단자 이름 | 왜 그 자리인가요? |
| --- | --- | --- |
| 키보드 | 공책에 적어요 | 공책에 적어요 |
| 마우스 | 공책에 적어요 | 공책에 적어요 |
| 모니터 케이블의 작은 쪽 | 공책에 적어요 | 공책에 적어요 |
| 전원 어댑터 | 공책에 적어요 | 공책에 적어요 |

1. 표를 공책에 옮겨 그리고 채워요.
2. micro-HDMI 두 개 중 **USB-C에 더 가까운 쪽**을 찾아요. 이 단자가 HDMI0이에요.
3. 파란색 USB 포트와 검은색 USB 포트가 어떻게 다른지 짝에게 말해 봐요.

**성공 확인:** 키보드와 마우스는 USB-A, 모니터는 micro-HDMI, 전원은 USB-C로 표가 채워졌고, 보드에서 HDMI0을 가리킬 수 있어요.

</MissionCard>

<MissionCard number={3} title="부품들의 협력 설명하기" time="15분">

Python 파일을 열어 실행하고 저장하는 과정을 부품 이름으로 따라가 봐요.

1. 먼저 **결과를 예상**해 봐요. 파일을 고치고 저장하지 않은 채 전원이 꺼졌어요. 고친 내용은 어떻게 될까요? 그렇게 생각한 이유를 RAM과 microSD라는 낱말을 넣어 공책에 적어요.
2. 아래 단계를 순서대로 읽으면서, 각 단계에서 일하는 부품을 보드에서 가리켜요.

| 단계 | 일어나는 일 | 일하는 부품 |
| --- | --- | --- |
| 1 | 보드에 전기가 들어와요 | USB-C 전원 단자 |
| 2 | 운영체제가 시작돼요 | microSD 카드 |
| 3 | 파일을 열어요 | USB 키보드와 마우스 |
| 4 | 내용이 올라오고 명령을 처리해요 | RAM, CPU |
| 5 | 결과가 화면에 나타나요 | micro-HDMI에 연결된 모니터 |
| 6 | 파일이 기록돼요 | microSD 카드 |

3. 표를 가리고 짝에게 처음부터 설명해 봐요. 막히면 역할을 바꿔요.
4. 처음의 예상을 다시 읽고, 고칠 곳이 있으면 고쳐요.

**성공 확인:** 저장하지 않은 내용은 RAM에만 있어서 사라지고, 저장한 파일은 microSD 카드에 남는다고 내 말로 설명할 수 있어요. 표를 보지 않고 여섯 단계를 말할 수 있어요.

</MissionCard>

## 막혔을 때

| 증상 | 확인할 곳 |
| --- | --- |
| 은색 칩이 보이지 않아요 | 방열판이나 케이스에 가려졌을 수 있어요. 떼지 말고 위치만 확인해요. |
| 표와 단자 위치나 개수가 달라요 | 보드에 적힌 모델 이름을 확인해요. 이 표는 Raspberry Pi 4 Model B 기준이에요. |
| 카메라 단자와 디스플레이 단자가 헷갈려요 | 슬롯 근처에 적힌 글자를 읽어 봐요. 생김새가 비슷해서 글자로 구분해요. |
| USB-C와 micro-HDMI가 헷갈려요 | 어댑터와 케이블의 끝을 단자 옆에 대어 모양을 비교해요. 꽂지는 않아요. |
| RAM과 microSD의 차이를 설명하기 어려워요 | 학습하기의 책상과 책장 비유를 다시 읽어 봐요. |

## 더 해 보기

1. **물리 핀 찾기:** 보드에서 USB 포트의 반대쪽 끝, 보드 안쪽 줄의 첫 핀이 물리 핀 1번이에요. 그 줄을 따라 번호가 홀수로 늘어나요. 눈으로 세어 물리 핀 11번(GPIO17)을 찾아보세요.
2. **입력과 출력 나누기:** 버튼, LED, 온도 센서, 모터를 라즈베리파이 기준의 입력과 출력으로 나눠 보세요.
3. **단자 지도 그리기:** 보드를 위에서 본 모습을 그리고, 오늘 찾은 단자의 이름을 적어 보세요.
