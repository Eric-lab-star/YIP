# CDS 센서 실습

오늘은 빛을 입력으로 받아 어두워지면 스스로 켜지는 가로등을 만듭니다.
내 모듈이 어두울 때 어떤 값을 내는지 먼저 확인하고, 그 값에 맞춰 프로그램을 완성해요.

<Callout type="goal">

**이번 실습을 마치면**

1. CDS 모듈의 VCC, GND, DO를 라즈베리파이에 연결할 수 있어요.
2. 값을 화면에 찍어 내 모듈이 어두울 때 0을 내는지 1을 내는지 직접 알아낼 수 있어요.
3. 기준 나사를 돌려 내가 원하는 밝기에서 켜지는 가로등을 맞출 수 있어요.

</Callout>

<Callout type="important">

**배선 전 약속**

- 배선을 바꿀 때는 **먼저 전원을 완전히 분리**해요.
- GPIO 신호 핀은 **3.3V**까지만 다뤄요. CDS 모듈의 VCC는 **3.3V(물리 핀 1)** 에 연결하고, 5V 핀에는 꽂지 않아요.
- 모듈마다 핀 순서가 달라요. 표의 순서가 아니라 **모듈에 적힌 글자**를 보고 연결해요.
- AO 핀이 있어도 연결하지 않아요. 오늘은 DO만 써요.
- 전원을 넣기 전에 친구나 선생님과 배선을 한 번 더 확인해요.

</Callout>

## 준비물

- [ ] 라즈베리파이와 전원 어댑터 (모니터, 키보드, 마우스 연결)
- [ ] 브레드보드
- [ ] CDS 센서 모듈 (DO 핀과 기준 조절 나사가 있는 것)
- [ ] LED 1개
- [ ] 330옴 저항 1개
- [ ] 암-수 점퍼선 2개
- [ ] 암-암 점퍼선 3개
- [ ] 손전등이나 휴대폰 불빛
- [ ] 기준 나사에 맞는 작은 드라이버

<MissionCard number={1} title="CDS 모듈과 LED 연결하기" time="12분">

**입력의 길:** CDS 모듈 DO → GPIO22(물리 핀 15)

**출력의 길:** GPIO17(물리 핀 11) → 저항 → LED 긴 다리 → LED 짧은 다리 → GND(물리 핀 9)

1. 라즈베리파이의 전원을 끄고 어댑터를 뽑아요.
2. 모듈의 핀 옆에 적힌 글자를 읽고 VCC, GND, DO의 자리를 찾아요.
3. 모듈은 암-암 점퍼선으로 라즈베리파이에 바로 연결해요. 모듈의 핀이 점퍼선에 맞지 않으면 선생님께 물어봐요. 홀수 번호 핀은 보드 안쪽 줄, 짝수 번호 핀은 보드 가장자리 쪽 줄에 있어요. 물리 핀 14번은 가장자리 쪽 줄에서 USB 포트의 반대쪽 끝부터 세어 일곱 번째 핀이에요.

| 부품 | 한쪽 | 다른 쪽 |
| --- | --- | --- |
| 암-암 점퍼선 1 | 모듈 VCC | 물리 핀 1 (3.3V) |
| 암-암 점퍼선 2 | 모듈 GND | 물리 핀 14 (GND) |
| 암-암 점퍼선 3 | 모듈 DO | 물리 핀 15 (GPIO22) |

4. LED는 6차시와 같은 회로로 브레드보드에 꾸며요.

| 부품 | 한쪽 | 다른 쪽 |
| --- | --- | --- |
| 암-수 점퍼선 1 | 물리 핀 11 (GPIO17) | 브레드보드 a10 |
| 330옴 저항 | c10 | c15 |
| LED | 긴 다리 d15 | 짧은 다리 d16 |
| 암-수 점퍼선 2 | 브레드보드 a16 | 물리 핀 9 (GND) |

5. 물리 핀 1번과 2번을 헷갈리지 않았는지 다시 확인해요. 2번은 5V예요.
6. 확인이 끝나면 전원을 연결하고 바탕화면이 나올 때까지 기다려요.

**성공 확인:** 전원을 넣었을 때 LED는 꺼져 있고, 연기나 타는 냄새가 나지 않아요. 이상하면 바로 전원을 뽑고 선생님을 불러요.

</MissionCard>

<MissionCard number={2} title="내 모듈의 값 알아내기" time="10분">

어두울 때 DO가 1이 되는지 0이 되는지는 **모듈에 따라 달라요.** 학습하기의 예제와 반대인 모듈도 있으니 직접 확인해요.

1. 실행하기 전에 **결과를 먼저 예상**해요. 손으로 센서를 가리면 숫자가 어떻게 될까요? 공책에 적어요.
2. 아래 코드를 `read_cds.py`로 저장하고 실행해요.

```python
from gpiozero import DigitalInputDevice
from time import sleep

cds = DigitalInputDevice(22)

while True:
    print(cds.value)
    sleep(0.5)
```

3. 쉘을 보면서 손바닥으로 센서를 덮었다가 떼 봐요.
4. 숫자가 바뀌지 않으면 작은 드라이버로 기준 나사를 조금씩 돌려요. 힘을 주지 말고 천천히 돌리다가, 손으로 덮을 때와 뗄 때 숫자가 달라지는 곳에서 멈춰요.
5. 공책에 **밝을 때 값**과 **어두울 때 값**을 적고, **Stop**으로 멈춰요.

**성공 확인:** 덮을 때와 뗄 때 숫자가 서로 다르게 찍히고, 공책에 내 모듈의 어두울 때 값이 적혀 있어요.

</MissionCard>

<MissionCard number={3} title="어두워지면 켜지는 가로등" time="10분">

버튼 대신 센서가 입력이 되었을 뿐, 입력 → 판단 → 출력의 흐름은 같아요.

1. 아래 코드를 입력하고 `street_lamp.py`로 저장해요.
2. `dark = 1`의 숫자를 미션 2에서 적은 **어두울 때 값**으로 바꿔요.

```python
from gpiozero import DigitalInputDevice, LED

cds = DigitalInputDevice(22)
lamp = LED(17)

dark = 1

while True:
    if cds.value == dark:
        lamp.on()
    else:
        lamp.off()
```

`==`는 양쪽 값이 같은지 묻는 기호예요. `=` 하나는 변수에 값을 넣을 때 써요.

3. 실행하고 손바닥으로 센서를 덮었다가 떼 봐요. 멈출 때는 **Stop** 버튼을 눌러요.

**성공 확인:** 센서를 덮으면 LED가 켜지고, 손을 떼면 꺼져요. 반대로 움직이면 `dark`의 숫자를 다시 확인해요.

</MissionCard>

<MissionCard number={4} title="가로등이 켜지는 밝기 맞추기" time="8분">

교실에서는 꺼져 있고, 손으로 덮으면 켜지도록 기준을 맞춰 봐요.

1. `street_lamp.py`를 실행해 둔 채 기준 나사를 아주 조금 돌려요. 전선은 건드리지 않아요.
2. 교실 불빛에서 꺼져 있고 손바닥으로 덮을 때만 켜지는 곳을 찾아요.
3. **결과를 먼저 예상**해요. 손바닥을 센서 위로 천천히 가져가면 어디쯤에서 켜질까요? 손전등을 비추면 어떻게 될까요?
4. 손바닥을 천천히 내려 보고, 손으로 센서를 둥글게 감싸 어둡게 한 뒤 손가락 틈으로 손전등을 비춰 보며 예상과 비교해요.

**성공 확인:** 교실 불빛에서는 꺼져 있고, 손바닥으로 가리면 켜지고, 감싼 손 틈으로 손전등을 비추면 다시 꺼져요. 나사가 코드 대신 무엇을 바꾸는지 친구에게 설명할 수 있어요.

</MissionCard>

## 막혔을 때

| 증상 | 확인할 곳 |
| --- | --- |
| 값이 0이나 1 하나로만 나와요 | 기준 나사를 천천히 돌려 봐요. 그래도 그대로면 전원을 분리하고 VCC, GND, DO 연결을 모듈의 글자와 비교해요. |
| 교실이 밝은데 LED가 켜져요 | 기준 나사를 돌려 어두움의 기준을 맞춰요. `dark`의 숫자도 다시 확인해요. |
| 밝을 때 켜지고 어두울 때 꺼져요 | `dark`의 숫자가 미션 2의 어두울 때 값과 같은지 확인해요. |
| 경계에서 LED가 깜빡거려요 | 밝기가 기준 근처라서 그래요. 나사를 조금 더 돌려 기준을 옮기거나 더 어둡게 가려요. |
| 값은 바뀌는데 LED가 켜지지 않아요 | LED 방향과 물리 핀 11번, 9번을 확인해요. |
| `GPIO busy`처럼 핀을 쓸 수 없다는 오류가 나요 | 이전 프로그램이 핀을 쓰고 있어요. Stop을 누르고 다시 실행해요. |

## 더 해 보기

1. **낮에 켜지는 등:** `lamp.on()`과 `lamp.off()`를 맞바꾸기 전에 어떻게 될지 예상하고 확인해 보세요.
2. **조심스러운 가로등:** 어두워졌을 때 2초 기다렸다가 다시 확인해서, 여전히 어두울 때만 켜지게 해 보세요. 손이 잠깐 지나가는 그림자에는 켜지지 않아야 해요.
3. **깜빡이는 표지판:** 어두운 동안 LED가 켜지는 대신 0.5초 간격으로 깜빡이게 바꿔 보세요.
