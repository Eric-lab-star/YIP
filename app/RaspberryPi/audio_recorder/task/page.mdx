# 녹음기 실습

오늘은 내 목소리를 숫자로 저장했다가 다시 소리로 꺼내 봅니다.
파일 크기를 미리 계산해 맞혀 본 다음, 버튼을 누르면 녹음되는 음성 메모기까지 만들어요.

<Callout type="goal">

**이번 실습을 마치면**

1. 마이크와 소리 출력 장치가 내 라즈베리파이에서 동작하는지 직접 점검할 수 있어요.
2. 녹음 설정을 보고 파일 크기를 먼저 계산한 뒤 실제 크기와 비교할 수 있어요.
3. 버튼을 누르면 시각이 붙은 파일로 녹음되는 음성 메모기를 만들 수 있어요.

</Callout>

<Callout type="important">

**배선 전 약속**

- 미션 4의 버튼을 꽂기 전에 **운영체제를 종료하고 전원을 완전히 분리**해요.
- GPIO 신호 핀은 **3.3V**까지만 다뤄요. 오늘 쓰는 GPIO27에 5V 핀을 연결하지 마세요.
- 전원을 넣기 전에 친구나 선생님과 배선을 한 번 더 확인해요.
- 다른 사람의 목소리를 녹음할 때는 먼저 허락을 받아요.

</Callout>

## 준비물

- [ ] 라즈베리파이와 전원 어댑터 (모니터, 키보드, 마우스 연결)
- [ ] USB 마이크, 또는 마이크가 달린 USB 웹캠
- [ ] 소리를 들을 장치 하나 (아래 표에서 골라요)
- [ ] 브레드보드
- [ ] 택트 스위치 1개
- [ ] 암-수 점퍼선 2개

소리를 들으려면 스피커가 있는 쪽으로 소리를 보내야 해요. 내 자리에 있는 것을 하나 골라요.

| 소리를 들을 장치 | 필요한 것 | 확인할 것 |
| --- | --- | --- |
| HDMI 모니터 | 스피커가 들어 있는 모니터 | 스피커가 없는 모니터도 많아요. 모니터 설명서나 메뉴를 확인해요. |
| 3.5mm 이어폰 | 보드의 3.5mm 단자 | 라즈베리파이 4 Model B에는 있고 라즈베리파이 5에는 없어요. 내 보드를 봐요. |
| USB 스피커나 USB 이어폰 | 남는 USB 포트 | 꽂은 뒤 출력 목록에 이름이 나오는지 확인해요. |

코드의 따옴표 안에 있는 한글이 입력되지 않으면 영어로 바꿔도 돼요.

<MissionCard number={1} title="귀와 입 점검하기" time="10분">

1. USB 마이크를 USB-A 포트에 꽂아요. USB는 켜 둔 채 꽂아도 괜찮아요.
2. 터미널에서 녹음 장치 목록을 확인해요.

```bash
arecord -l
```

3. `card` 줄에 꽂은 마이크의 이름이 보이는지 찾고, 그 줄의 `card` 번호와 `device` 번호를 공책에 적어요.
4. 소리가 나갈 곳을 정해요. 바탕화면 오른쪽 위의 볼륨 아이콘을 **마우스 오른쪽 버튼**으로 눌러 내가 고른 장치를 선택해요. 따로 고르지 않으면 소리는 HDMI 쪽으로 먼저 나가요.
5. 시험음을 들어 봐요. 소리가 크게 날 수 있으니 이어폰은 귀에서 조금 떼어 둬요. 왼쪽과 오른쪽을 번갈아 소리 낸 뒤 끝나요.

```bash
speaker-test -t sine -f 440 -c 2 -l 1
```

**성공 확인:** `arecord -l` 목록에 내 마이크가 보이고, 내가 고른 장치에서 "삐" 소리가 들려요.

</MissionCard>

<MissionCard number={2} title="내 목소리 녹음하기" time="10분">

1. 터미널에서 5초 동안 녹음해요. 명령을 실행하자마자 마이크에 대고 말해요.

```bash
arecord -d 5 -r 44100 -f S16_LE recording.wav
```

2. 녹음이 끝나면 들어 봐요.

```bash
aplay recording.wav
```

3. 입과 마이크의 거리를 바꿔 가며 다시 녹음해 보고, 언제 가장 또렷한지 찾아봐요.

**성공 확인:** 내가 고른 장치에서 내 목소리가 들리고, 끝까지 5초 동안 재생돼요.

</MissionCard>

<MissionCard number={3} title="파일 크기 맞혀 보기" time="10분">

`-f S16_LE`는 잰 값 하나를 16비트로 적는다는 뜻이에요. 8비트가 1바이트이니 값 하나는 2바이트이고, 따로 정하지 않으면 한 줄기(모노)로 녹음돼요.

**1초에 재는 횟수 × 2바이트 × 녹음 초**를 쓰면 크기를 먼저 계산할 수 있어요.

1. 앞에서 만든 `recording.wav`의 크기를 공책에 계산해요. `44100 × 2 × 5`예요.
2. 아래 명령으로 만들 `phone.wav`의 크기도 **먼저 계산**하고, 소리가 어떻게 들릴지 예상해 적어요.

```bash
arecord -d 5 -r 8000 -f S16_LE phone.wav
```

3. 녹음한 뒤 실제 크기를 확인해요. 날짜 바로 앞의 숫자가 바이트 단위의 크기예요.

```bash
ls -l recording.wav phone.wav
```

4. 두 파일을 번갈아 들어 봐요.

```bash
aplay phone.wav
aplay recording.wav
```

**성공 확인:** 실제 크기가 계산한 441,000바이트와 80,000바이트보다 파일 정보만큼 조금 더 크게 나와요. `phone.wav`가 더 작은 대신 전화기처럼 답답하게 들리는 까닭을 말할 수 있어요.

</MissionCard>

<MissionCard number={4} title="버튼 음성 메모기 만들기" time="15분">

**회로의 길:** GPIO27(물리 핀 13) → 택트 스위치 → GND(물리 핀 14)

1. 운영체제를 종료하고 어댑터를 뽑은 뒤 아래 표대로 꽂아요.

| 부품 | 한쪽 | 다른 쪽 |
| --- | --- | --- |
| 택트 스위치 | 가운데 홈에 걸쳐 다리를 e10, e12, f10, f12에 꽂아요 | 다리 간격이 달라 안 맞으면 줄 번호를 바꿔요 |
| 점퍼선 1 | 물리 핀 13 (GPIO27) | 브레드보드 a10 |
| 점퍼선 2 | 브레드보드 j12 | 물리 핀 14 (GND) |

점퍼선 두 개는 스위치의 **대각선 다리**로 이어져요. 대각선 다리는 반대쪽 짝이라 스위치를 어느 방향으로 꽂아도 괜찮아요.

2. 전원을 연결하고 Thonny에서 아래 코드를 `memo.py`로 저장한 뒤 **Run**을 눌러요.

```python
from gpiozero import Button
from datetime import datetime
import os

button = Button(27)

while True:
    print("버튼을 누르면 5초 동안 녹음해요.")
    button.wait_for_press()

    now = datetime.now().strftime("%H%M%S")
    name = "memo_" + now + ".wav"

    print("녹음 시작!")
    os.system("arecord -d 5 -r 44100 -f S16_LE " + name)
    print(name, "저장했어요")
```

`os.system`은 터미널에 입력할 명령을 Python이 대신 실행해 줘요.

3. 버튼을 두 번 눌러 메모를 두 개 남겨요.
4. **Stop**을 누르고 파일 관리자에서 `memo_`로 시작하는 파일을 찾아요.
5. 녹음이 끝나자마자 재생까지 하려면 어느 줄을 어디에 더해야 할지 **먼저 예상**해 적은 뒤, `os.system("aplay " + name)`을 넣어 확인해요.

**성공 확인:** 버튼을 누를 때마다 시각이 다른 파일이 생기고, `aplay`로 재생하면 내 목소리가 들려요. 재생 줄을 더하면 녹음 직후 바로 들려요.

</MissionCard>

## 막혔을 때

| 증상 | 확인할 곳 |
| --- | --- |
| `arecord -l` 목록에 마이크가 없어요 | USB를 다시 꽂거나 다른 포트에 꽂고 다시 확인해요. |
| `arecord`가 장치를 찾지 못하거나 다른 마이크를 써요 | 공책의 번호로 장치를 직접 정해요. `card 2, device 0`이라면 `arecord -D plughw:2,0 -d 5 -r 44100 -f S16_LE recording.wav`처럼 적어요. |
| 소리가 전혀 안 들려요 | 볼륨 아이콘에서 고른 출력 장치와 음량, 모니터에 스피커가 있는지 확인해요. |
| 터미널에서 출력 장치를 바꾸고 싶어요 | `wpctl status`의 `Sinks`에서 번호를 찾아 `wpctl set-default 번호`를 입력해요. 별표가 옮겨 가면 돼요. |
| 소리는 들리는데 내 목소리가 너무 작아요 | 마이크와 입의 거리를 줄이고, 설정에서 입력 볼륨을 확인해요. |
| 녹음 파일에 아무 소리도 없어요 | 마이크에 전원 스위치가 있다면 켜져 있는지 확인하고, 다른 마이크가 대신 쓰이고 있지 않은지 `arecord -l`을 다시 봐요. |
| 버튼을 눌러도 반응이 없어요 | 전원을 분리하고 물리 핀 13번, 14번과 스위치가 가운데 홈을 걸쳤는지 확인해요. |
| 누르지 않았는데 녹음이 시작돼요 | 같은 짝의 두 다리에 연결했을 수 있어요. 전원을 분리하고 대각선 다리로 옮겨요. |
