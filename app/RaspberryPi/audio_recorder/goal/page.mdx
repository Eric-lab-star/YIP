# 녹음기

라즈베리파이는 이제 보고(카메라), 느끼고(센서), 말할 줄(스피커) 알아요.
오늘은 **듣는 능력**을 더해 녹음기를 만듭니다.
그 과정에서 눈에 보이지 않는 소리가 어떻게 **숫자가 되어 파일에 담기는지**,
디지털 세계의 중요한 비밀 하나를 배우게 돼요.

<Callout type="goal">

**이번 수업을 마치면**

1. 라즈베리파이에서 녹음하려면 왜 USB 마이크가 필요한지 설명할 수 있어요.
2. 샘플링이 무엇인지 말할 수 있어요.
3. 명령어로 소리를 녹음하고 재생할 수 있어요.

</Callout>

## 1. 귀는 따로 달아야 해요

먼저 확인할 것이 있어요. 1차시에서 배운 단자들을 떠올려 보세요.
3.5mm 둥근 단자는 소리를 **내보내는** 출력 전용이었죠.
라즈베리파이에는 **마이크 입력 단자가 없습니다.**

그래서 귀는 따로 달아 줍니다. 가장 간단한 방법이 **USB 마이크**예요.
USB-A 포트에 꽂기만 하면 운영체제가 알아서 인식합니다.
마이크가 달린 USB 웹캠도 같은 방법으로 쓸 수 있어요.

연결을 확인하는 명령이 있어요.

```bash
arecord -l
```

목록에 꽂은 마이크가 보이면 준비 완료예요.
`arecord`는 녹음, `aplay`는 재생을 맡는 Raspberry Pi OS의 기본 도구입니다.

## 2. 소리가 숫자가 되는 비밀: 샘플링

소리의 정체는 공기의 **떨림(진동)**이에요.
마이크는 이 떨림을 전기 신호로 바꾸는데, 이 신호는 연속적으로 변하는 **아날로그**예요.
어디서 많이 듣던 이야기죠? CDS 수업에서 배운 그 문제가 다시 나타났어요.
컴퓨터는 연속적인 값을 그대로 저장할 수 없습니다.

해결책은 **아주 빠르게, 아주 많이 재는 것**이에요.
1초에 수만 번씩 신호의 높이를 재서, 그 **숫자들의 목록**으로 저장합니다.
이것을 **샘플링(표본화)**이라고 해요.

<Callout type="analogy">

**영화 필름을 떠올려 보세요.**

영화는 사실 1초에 24장씩 찍은 사진의 연속이에요. 빠르게 넘기면 움직임으로 보이죠.
소리도 같아요. 1초에 44,100번 높이를 재서 늘어놓으면,
이어 들었을 때 원래 소리처럼 들립니다.
이 "1초에 몇 번 재는가"를 **샘플링 레이트**라고 해요.
음악 CD가 44,100번, 전화 통화가 8,000번 정도예요.
많이 잴수록 원래 소리에 가깝지만 파일은 커집니다.

</Callout>

이렇게 잰 숫자들을 가공 없이 그대로 담는 파일 형식이 **WAV**예요.
음질이 좋은 대신 파일이 크죠. 평소 듣는 MP3는 사람 귀에 덜 들리는 부분을
덜어내 크기를 줄인 **압축** 형식이에요.

## 3. 녹음하고 들어 보기

5초 동안 녹음해 봅시다.

```bash
arecord -d 5 -r 44100 -f S16_LE recording.wav
```

- `-d 5`: 5초 동안 녹음해요.
- `-r 44100`: 샘플링 레이트, 1초에 44,100번 잰다는 뜻이에요.
- `-f S16_LE`: 높이 하나하나를 얼마나 정밀한 숫자로 적을지 정하는 형식이에요. CD와 같은 16비트를 썼어요.

마이크에 대고 말한 뒤, 재생해 보세요.

```bash
aplay recording.wav
```

스피커나 이어폰에서 내 목소리가 나오면 성공이에요.
내 목소리가 **44,100분의 1초 단위의 숫자들**이 되었다가 다시 소리로 돌아온 거예요.

### Python과 연결하면

실습에서는 Python에서 녹음 명령을 실행하고 파일 이름에 시각을 붙여 봅니다.
그러면 배운 것들이 또 연결돼요.
**버튼을 누르면 녹음이 시작되는 음성 메모기**(8차시 + 오늘),
**소리 파일 목록을 보여 주는 웹페이지**(17차시 + 오늘)처럼요.

<Callout type="tip">

**녹음이 안 되거나 소리가 이상할 때**

- `arecord -l` 목록에 마이크가 없으면 USB를 다시 꽂고 확인해요.
- 녹음은 되는데 소리가 너무 작으면 마이크와 입의 거리를 줄여 보고, 설정의 입력 볼륨을 확인해요.
- 재생이 안 들리면 출력 장치(HDMI 모니터, 3.5mm 이어폰) 선택을 확인해요. 출력과 입력은 서로 다른 장치라는 것을 기억하세요.
- 카메라와 마찬가지로, **다른 사람의 목소리를 녹음할 때는 반드시 먼저 허락**을 받아요.

</Callout>
