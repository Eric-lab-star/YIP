# 웹서버 만들기

우리는 매일 수십 번씩 웹사이트에 접속하지만,
주소를 입력한 순간 **무슨 일이 벌어지는지**는 잘 생각하지 않아요.
오늘은 그 비밀을 파헤치고, 한 걸음 더 나아가
**라즈베리파이를 직접 웹사이트의 주인으로** 만들어 봅니다.
같은 Wi-Fi에 있는 스마트폰으로 내 라즈베리파이에 접속하는 날이에요.

<Callout type="goal">

**이번 수업을 마치면**

1. 클라이언트와 서버, 요청과 응답의 관계를 설명할 수 있어요.
2. Flask로 간단한 웹서버를 만들고 실행할 수 있어요.
3. IP 주소를 확인하고 같은 네트워크의 다른 기기에서 접속할 수 있어요.

</Callout>

## 1. 웹의 규칙: 요청하면 응답한다

웹의 세계에는 두 가지 역할이 있어요.

- **클라이언트**: 보여 달라고 **요청**하는 쪽. 브라우저가 대표예요.
- **서버**: 요청을 받아 내용을 **응답**하는 쪽. 웹사이트의 주인이에요.

<Callout type="analogy">

**식당을 떠올리면 정확해요.**

손님(클라이언트)이 메뉴판의 이름(주소)으로 주문(요청)하면,
주방(서버)이 음식(웹페이지)을 만들어 내어 줘요(응답).
주문이 없는데 음식이 먼저 나오는 일은 없죠.
웹도 똑같아요. **서버는 항상 요청을 기다렸다가 응답합니다.**

</Callout>

브라우저에 주소를 입력하는 것이 곧 주문이에요.
지금까지 우리는 늘 손님이었지만, 오늘부터는 주방을 차립니다.
그리고 서버는 대단한 컴퓨터만 하는 일이 아니에요. **라즈베리파이도 훌륭한 서버가 될 수 있습니다.**

## 2. Flask: 파이썬으로 차리는 작은 주방

**Flask(플라스크)**는 Python으로 웹서버를 만드는 라이브러리예요.
놀랍게도 몇 줄이면 서버가 완성됩니다.

```python
from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "안녕하세요! 라즈베리파이 서버입니다."

app.run(host="0.0.0.0", port=8080)
```

처음 보는 모양이 몇 개 있지만, 식당에 비유하면 읽을 수 있어요.

- `app = Flask(__name__)`: 식당을 하나 차려요.
- `@app.route("/")`: **메뉴판 등록**이에요. "/" 라는 주소로 주문이 오면 바로 아래 함수가 담당한다는 표시예요.
- `def home(): return ...`: 주문이 왔을 때 내어 줄 내용이에요.
- `app.run(host="0.0.0.0", port=8080)`: 식당 문을 열어요. `0.0.0.0`은 **다른 기기의 접속도 받겠다**는 뜻이에요.

실행한 뒤 라즈베리파이의 브라우저에서 `http://localhost:8080`에 접속해 보세요.
인사말이 보이면 여러분의 첫 웹서버가 영업을 시작한 거예요.
**localhost**는 "지금 이 컴퓨터 자신"을 가리키는 특별한 이름입니다.

### 주소를 늘려 봐요

`@app.route`를 여러 개 두면 메뉴가 늘어나요.

```python
@app.route("/hello")
def hello():
    return "반가워요!"

@app.route("/time")
def now():
    from datetime import datetime
    return datetime.now().strftime("%H시 %M분 %S초")
```

`/time`에 접속할 때마다 현재 시각이 나와요.
**응답을 프로그램이 그때그때 만든다**는 것, 이것이 서버의 진짜 힘이에요.

## 3. 다른 기기에서 접속하기: IP 주소

localhost는 자기 자신만 가리키니, 스마트폰에서 접속하려면
라즈베리파이의 **네트워크 주소**가 필요해요.
공유기는 연결된 기기마다 **IP 주소**라는 번호를 붙여 줘요. 네트워크 세계의 집 주소인 셈이죠.

라즈베리파이의 IP 주소는 터미널에서 확인할 수 있어요.

```bash
hostname -I
```

`192.168.0.15`처럼 생긴 번호가 나와요.
이제 **같은 Wi-Fi에 연결된** 스마트폰 브라우저에서 `http://192.168.0.15:8080`으로 접속해 보세요.
내 손안의 폰에 라즈베리파이가 만든 페이지가 뜹니다.

<Callout type="note">

**접속이 안 될 때 확인할 것**

- 스마트폰이 라즈베리파이와 **같은 Wi-Fi**에 있나요? 다른 네트워크나 모바일 데이터로는 이 주소에 닿지 않아요.
- 주소 끝에 **:8080**을 붙였나요? 포트는 한 건물의 여러 출입구 같은 것이라, 서버가 연 출입구 번호를 정확히 적어야 해요.
- Flask 프로그램이 **실행 중**인가요? 서버가 꺼져 있으면 응답할 수 없어요.
- IP 주소는 공유기 사정에 따라 바뀔 수 있어요. 어제의 주소가 오늘도 같다고 믿지 말고 다시 확인하세요.

</Callout>

## 스스로 확인해 보기

<details>
<summary>1. 클라이언트와 서버는 각각 무슨 역할을 하나요?</summary>

클라이언트는 내용을 보여 달라고 요청하는 쪽(브라우저),
서버는 요청을 받아 내용을 만들어 응답하는 쪽이에요.
서버는 항상 요청을 기다렸다가 응답합니다.

</details>

<details>
<summary>2. app.run의 host="0.0.0.0"은 무슨 뜻인가요?</summary>

자기 자신뿐 아니라 같은 네트워크의 다른 기기에서 오는 접속도 받겠다는 뜻이에요.
이 설정이 있어야 스마트폰에서 라즈베리파이 서버에 접속할 수 있습니다.

</details>

<details>
<summary>3. 스마트폰에서 라즈베리파이 서버에 접속하려면 무엇을 알아야 하나요?</summary>

라즈베리파이의 IP 주소와 서버가 사용하는 포트 번호예요.
hostname -I로 IP를 확인하고, 같은 Wi-Fi에서 http://IP주소:포트 형식으로 접속합니다.

</details>
