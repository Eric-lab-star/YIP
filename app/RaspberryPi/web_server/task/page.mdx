# 웹서버 만들기 실습

오늘은 손님 자리에서 일어나 주방을 차려 봅니다.
내 라즈베리파이에 서버를 열고, 내 손의 스마트폰으로 주문을 넣어 봐요.

<Callout type="goal">

**이번 실습을 마치면**

1. Flask 서버를 실행하고 브라우저에 내가 쓴 인사말을 띄울 수 있어요.
2. 주소를 늘려서 접속할 때마다 현재 시각을 새로 만들어 보여 줄 수 있어요.
3. 다른 기기에서 내 서버에 접속하고, 그 요청이 쉘에 찍히는 것을 찾아낼 수 있어요.

</Callout>

## 준비물

- [ ] 라즈베리파이와 전원 어댑터 (모니터, 키보드, 마우스 연결)
- [ ] 라즈베리파이의 Wi-Fi 연결
- [ ] 같은 Wi-Fi에 연결할 수 있는 스마트폰, 또는 친구의 컴퓨터

<MissionCard number={1} title="첫 서버 열기" time="15분">

**먼저 Flask가 있는지 확인해요.** 터미널을 열고 아래 줄을 입력해요.

```bash
python3 -c "import flask"
```

아무 글자도 나오지 않으면 준비된 거예요.
`ModuleNotFoundError`가 나오면 선생님께 알린 뒤 아래 명령으로 설치해요. 인터넷 연결이 필요해요.

```bash
sudo apt install python3-flask
```

이제 서버를 만듭니다.

1. Thonny 편집기에 아래 코드를 입력하고, 인사말을 내 말로 바꿔요.
2. `server.py`로 저장하고 **Run**을 눌러요.

```python
from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "안녕하세요! 라즈베리파이 서버입니다."

app.run(host="0.0.0.0", port=8080)
```

3. 쉘에 `Running on`으로 시작하는 줄이 나오는지 봐요. `WARNING`으로 시작하는 줄은 연습용 서버라는 안내이니 그대로 두어도 괜찮아요.
4. 라즈베리파이의 브라우저를 열고 주소창에 `http://localhost:8080`을 입력해요.

서버는 요청을 기다리는 프로그램이라서 스스로 끝나지 않아요. Run을 누른 뒤 멈춰 있는 것처럼 보이면 잘 돌아가고 있는 거예요.

**성공 확인:** 브라우저에 내가 쓴 인사말이 보이고, 접속할 때마다 쉘에 `"GET / HTTP/1.1" 200`이 들어간 줄이 하나씩 늘어나요.

</MissionCard>

<MissionCard number={2} title="메뉴를 늘려 보기" time="15분">

서버는 실행하는 동안 코드를 다시 읽지 않아요. 코드를 고친 뒤에는 **Stop을 누르고 다시 Run**을 해야 바뀐 내용이 적용돼요.

1. **Stop**을 누르고 `server.py`를 아래처럼 고쳐 저장한 뒤 다시 **Run**을 눌러요.

```python
from flask import Flask
from datetime import datetime

app = Flask(__name__)

@app.route("/")
def home():
    return "안녕하세요! 라즈베리파이 서버입니다."

@app.route("/hello")
def hello():
    return "반가워요!"

@app.route("/time")
def now():
    return datetime.now().strftime("%H시 %M분 %S초")

app.run(host="0.0.0.0", port=8080)
```

2. `http://localhost:8080/hello`에 접속해 답이 바뀌는지 확인해요.

이번에는 접속하기 전에 **결과를 먼저 예상**해 봐요. 두 가지를 공책에 적어요.

- `/time`을 열어 두고 10초 뒤에 새로 고침을 하면 화면의 시각은 어떻게 될까요?
- 코드에 없는 `/snack`에 접속하면 어떻게 될까요?

3. 차례로 해 보고 예상과 비교해요.

**성공 확인:** `/time`은 새로 고침할 때마다 시각이 바뀌고, `/snack`에서는 `Not Found`가 나오며 쉘의 그 줄에 `404`가 찍혀요. 왜 그런지 코드의 어느 부분 때문인지 말할 수 있어요.

</MissionCard>

<MissionCard number={3} title="스마트폰에서 접속하기" time="15분">

`localhost`는 지금 이 기기 자신을 가리켜요. 폰에서 `localhost`를 입력하면 폰 자신을 찾게 되니, 라즈베리파이의 IP 주소가 필요해요.

1. 서버는 켜 둔 채로 터미널을 열고 IP 주소를 확인해요.

```bash
hostname -I
```

2. `192.168.0.15`처럼 점으로 나뉜 숫자를 찾아 공책에 적어요. 번호가 여러 개 나오면 쉘의 `Running on http://` 줄에서 `127.0.0.1`이 아닌 주소를 써요.
3. 스마트폰을 라즈베리파이와 **같은 Wi-Fi**에 연결해요. 모바일 데이터로는 이 주소에 닿지 않아요.
4. 폰 브라우저 주소창에 `http://내IP주소:8080`을 입력해요. 앞의 `http://`와 뒤의 `:8080`까지 모두 적어요.
5. 폰에서 `/time`도 열어 봐요.

<Callout type="note">

학교나 기관의 Wi-Fi는 보안 때문에 기기끼리의 접속을 막아 두기도 해요.
설정을 모두 확인했는데도 안 되면 선생님께 알려요. 네트워크 문제이니 코드는 고치지 않아도 돼요.

</Callout>

**성공 확인:** 폰 화면에 내 인사말과 현재 시각이 나오고, 쉘의 새 줄 맨 앞에 `127.0.0.1`이 아닌 폰의 주소가 찍혀요.

</MissionCard>

## 막혔을 때

| 증상 | 확인할 곳 |
| --- | --- |
| `ModuleNotFoundError: No module named 'flask'` | 미션 1의 설치 명령을 실행했는지 확인해요. |
| `Address already in use` 오류가 나요 | 앞서 켠 서버가 아직 돌고 있어요. Stop을 누르고 다시 실행해요. |
| 브라우저에 연결할 수 없다고 나와요 | Thonny에서 서버가 실행 중인지, 주소 끝에 `:8080`을 붙였는지 확인해요. |
| 라즈베리파이에서는 되는데 폰에서는 안 돼요 | 같은 Wi-Fi인지, `localhost`가 아니라 IP 주소를 적었는지, 코드에 `host="0.0.0.0"`이 있는지 확인해요. |
| 어제 쓰던 주소로 접속이 안 돼요 | IP 주소는 바뀔 수 있어요. `hostname -I`로 다시 확인해요. |
| 고친 내용이 브라우저에 안 나와요 | 저장한 뒤 Stop과 Run을 다시 눌렀는지 확인해요. |
| 만든 주소인데 `Not Found`가 나와요 | `@app.route`의 주소와 입력한 주소의 철자, 대소문자가 같은지 비교해요. |
| 쉘에 `/favicon.ico`와 `404`가 찍혀요 | 브라우저가 탭 아이콘을 찾으며 보낸 요청이에요. 고장이 아니에요. |
