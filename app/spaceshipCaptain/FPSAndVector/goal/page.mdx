  - **델타타임(dt)** 을 곱하면 왜 컴퓨터마다 같은 속도가 되는지 설명할 수 있다.

## 1단계 · Vector2 — 화살표 하나로 묶기 (8분)

벡터는 **화살표**라고 생각하면 된다냥.
보물 지도의 "오른쪽으로 5걸음, 위로 3걸음" 처럼
x와 y 두 숫자로 **방향과 거리를 한 번에** 나타낸다냥.

```python
pygame.Vector2(5, 3)   # 오른쪽 5, 아래 3
```

<Callout type="important">
  파이게임에서 y는 **아래쪽이 커진다냥.**
  화면 맨 위가 y=0 이고, 아래로 갈수록 숫자가 커진다냥.
  수학 시간에 배운 좌표와 반대라서 처음엔 헷갈린다냥.
</Callout>

벡터가 좋은 이유는 **더하기가 된다는 것**이다냥.

<CompareBubble
  left={{
    label: 'x, y를 따로 관리하면',
    color: 'ink',
    items: [
      'pos_x = 640 / pos_y = 360',

    ],

/>

<Callout type="analogy">
  x와 y를 따로 드는 건 **양손에 짐을 하나씩 들고 가는 것**이고,
  벡터는 **가방 하나에 담아 드는 것**이다냥.
  가방째로 옮기면 안에 든 게 몇 개든 한 번에 옮겨진다냥.
</Callout>

## 2단계 · FPS는 플립북이다냥 (7분)

FPS는 **1초에 화면을 몇 번 그리는가** 다냥.

<Callout type="analogy">
  빠르게 넘기는 만화책, **플립북**을 떠올려보자냥.

  - 1초에 60장 넘기면 → 아주 부드럽다냥
  - 1초에 10장만 넘기면 → 뚝뚝 끊긴다냥

  게임 화면도 똑같다냥. 이 "1초에 몇 장" 이 FPS다냥.
</Callout>

파이게임에서는 시계를 하나 만들어서 속도를 제한한다냥.

```python
clock = pygame.time.Clock()   # 게임 시작 전에 한 번 만든다냥

# 게임 루프 안에서
clock.tick(60)                # 초당 60번을 넘지 않게 붙잡아준다냥
```

## 3단계 · 진짜 문제 — 컴퓨터마다 속도가 다르다냥 (10분)

여기가 오늘의 핵심이다냥.

지금 우리 코드는 **한 프레임에 speed 만큼** 움직인다냥.
그런데 프레임 수가 컴퓨터마다 다르다냥.

```
빠른 컴퓨터: 1초에 200프레임 → 200번 이동 → 슝!
느린 컴퓨터: 1초에  30프레임 →  30번 이동 → 느릿...
```

같은 코드인데 결과가 다르다냥. 이건 게임으로선 큰 문제다냥.

### 해결책: 델타타임(dt)

**"한 프레임에 얼마"** 대신 **"1초에 얼마"** 로 생각을 바꾸는 것이다냥.

```python
dt = clock.tick(60) / 1000     # 지난 프레임에서 지금까지 걸린 시간(초)
player_rect.center += speed * dt
```

`clock.tick()` 은 **지난 프레임과 지금 사이에 걸린 시간을 밀리초로 돌려준다냥.**
1000으로 나누면 초 단위가 된다냥.

<StepCard step="빠른 컴퓨터" title="1초에 200프레임이면">

한 프레임에 걸린 시간 `dt` 는 약 **0.005초** 다냥.
`speed * 0.005` 씩 200번 → 합치면 `speed * 1` 이다냥.

</StepCard>

<StepCard step="느린 컴퓨터" title="1초에 30프레임이면">

한 프레임에 걸린 시간 `dt` 는 약 **0.033초** 다냥.
`speed * 0.033` 씩 30번 → 합치면 역시 `speed * 1` 이다냥.

</StepCard>

<Callout type="important">
  **어느 컴퓨터든 1초가 지나면 딱 `speed` 만큼 이동한다냥.**
  그래서 `speed` 의 의미가 "한 프레임에 몇 픽셀" 에서
  **"1초에 몇 픽셀"** 로 바뀐다냥.
  그래서 실습에서 `speed` 숫자를 훨씬 크게 키우게 된다냥.
</Callout>

## 4단계 · 왜 tick()과 dt를 같이 쓰냥? (3분)

`clock.tick(60)` 은 두 가지 일을 **동시에** 한다냥.

1. 프레임이 60을 넘지 않게 **붙잡아준다냥** (컴퓨터가 헛돌지 않게)
2. 지난 프레임에서 걸린 **시간을 돌려준다냥** (dt를 만들 재료)

그래서 이 한 줄로 두 문제를 다 해결한다냥.

```python
dt = clock.tick(60) / 1000
```
