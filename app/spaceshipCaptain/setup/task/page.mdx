<MissionCard number={1} title="uv 설치하기" time="10분">

내 컴퓨터에 맞는 줄을 **한 줄만** 골라서 터미널에 붙여넣자냥.

```bash
# macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows (PowerShell)
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

설치가 끝났는지 확인해보자냥.

```bash
uv --version
```

버전 번호가 나오면 성공이다냥.

<Callout type="important">
  `uv를 찾을 수 없습니다` 같은 말이 나오면 **터미널을 완전히 닫았다가 다시 열어보자냥.**
  설치한 도구를 컴퓨터가 알아보려면 터미널을 새로 켜야 할 때가 있다냥.
</Callout>

</MissionCard>

<MissionCard number={2} title="프로젝트 만들고 pygame-ce 설치하기" time="5분">

우주선 게임을 담을 작업실을 만들자냥.

```bash
uv init space_shooter
cd space_shooter
```

이러면 이런 파일들이 생긴다냥.

```
space_shooter/
├── main.py            ← 시작점 파이썬 파일
├── pyproject.toml     ← 프로젝트 정보와 설치한 도구 목록
├── .python-version    ← 파이썬 버전
└── .gitignore
```

이제 파이게임을 주문하자냥.

```bash
uv add pygame-ce
```

설치가 끝나면 `pyproject.toml` 을 열어보자냥. 이런 줄이 **자동으로** 생겨 있을 거다냥.

```toml
[project]
dependencies = [
    "pygame-ce>=2.5.3",
]
```

> **확인해보자냥**
> - `space_shooter` 폴더 안에 들어와 있냥? (`cd space_shooter` 했는지 확인)
> - `pyproject.toml` 에 `pygame-ce` 가 적혀 있냥?

</MissionCard>

<MissionCard number={3} title="main.py 뼈대 채우기" time="10분">

`main.py` 를 열고 아래 코드를 **빈칸을 채워가며** 직접 써보자냥.
학습 목표에서 배운 네 뼈대(준비 · 창 · 반복 · 종료) 순서 그대로다냥.

<StepCard step="1" title="준비 — 도구 가져오고 켜기">

```python
import pygame

pygame.____()   # 파이게임의 모든 기능을 켜는 명령이다냥
```

> 힌트: 오븐을 예열하는 그 명령이다냥.

</StepCard>

<StepCard step="2" title="창 — 도화지 만들기">

```python
WINDOW_WIDTH, WINDOW_HEIGHT = 1280, 720
display_surface = pygame.display.________((WINDOW_WIDTH, WINDOW_HEIGHT))
```

> 힌트: `창의 모드를 정한다`는 뜻의 이름이다냥. 괄호가 두 겹인 것에 주의하자냥 — 가로와 세로를 **한 쌍**으로 묶어서 넘긴다냥.

</StepCard>

<StepCard step="3" title="반복 — 게임 루프 만들기">

```python
def main():
    running = True
    while ________:
        pass
    pygame.quit()
```

> 힌트: "게임을 계속 돌릴까?" 스위치 변수를 그대로 쓰면 된다냥.

</StepCard>

<StepCard step="4" title="이벤트 — 민원 접수함 비우기">

`pass` 자리를 이걸로 바꾸자냥.

```python
        for event in pygame.event.get():
            if event.type == pygame.____:
                running = False
```

> 힌트: 창의 X 버튼을 눌렀을 때 생기는 사건 이름이다냥. 전부 대문자다냥.

</StepCard>

</MissionCard>

<MissionCard number={4} title="실행해서 창 띄우기" time="5분">

맨 아래에 이 두 줄을 더하자냥. 이 파일을 직접 실행했을 때만 `main()` 을 부르라는 뜻이다냥.

```python
if __name__ == "__main__":
    main()
```

그리고 실행하자냥.

```bash
uv run main.py
```

**검은 창이 뜨고, X 버튼을 누르면 닫히면 성공이다냥!**

<Callout type="tip">
  창이 떴는데 마우스로 만지면 "응답 없음"이 된다냥?
  그건 미션 3의 4단계, **이벤트를 꺼내는 `for` 문이 빠졌을 때** 나타나는 증상이다냥.
</Callout>

</MissionCard>

## 완성 코드

빈칸을 다 채우면 이런 모습이다냥. 막혔을 때만 열어보자냥.

```python
import pygame

pygame.init()
WINDOW_WIDTH, WINDOW_HEIGHT = 1280, 720
display_surface = pygame.display.set_mode((WINDOW_WIDTH, WINDOW_HEIGHT))


def main():
    running = True
    while running:
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                running = False
    pygame.quit()


if __name__ == "__main__":
    main()
```
