<MissionCard number={1} title="game_over 상태 만들기" time="12분">

먼저 `main()` 에 상태 변수를 하나 두자냥. 그리고 배경도 변수에 담자냥.

```python
def main():
    running = True
    game_over = ______
    bg = Background()          # 변수에 담는다냥
    player = Player()
```

> 힌트: 게임을 시작할 때는 아직 안 끝난 상태다냥.

이제 게임 루프의 뒷부분을 **두 갈래로** 나누자냥.

```python
        pygame.sprite.groupcollide(
            meteor_sprite_group, missile_sprite_group, True, True
        )

        if not game_over:
            if pygame.sprite.spritecollide(player, meteor_sprite_group, False):
                game_over = ______
            all_sprite_group.update(dt)
            all_sprite_group.draw(display_surface)
        else:
            player.kill()
            meteor_sprite_group.empty()
            display_surface.blit(bg.image)

        pygame.display.flip()
```

> 힌트: 부딪혔으면 게임이 끝난 상태가 된다냥.

<Callout type="important">
  전에는 `running = False` 였다냥. 이제는 **창을 닫지 않는다냥.**
  창은 계속 살아 있고 **보여주는 화면만** 바뀐다냥.
</Callout>

**운석에 부딪히면 우주선과 운석이 사라지고 배경만 남으면 성공이다냥.**
아직 글자는 없다냥.

<Callout type="tip">
  `bg` 를 변수에 담은 이유가 여기 있다냥.
  게임 오버일 때는 그룹을 안 쓰고 **배경만 직접 `blit`** 해야 하니
  배경 객체를 손에 들고 있어야 한다냥.
</Callout>

</MissionCard>

<MissionCard number={2} title="HUD 클래스로 글자 띄우기" time="15분">

`entity/hud.py` 를 만들자냥. 먼저 **글자가 나오는지부터** 확인하자냥.

```python
import pygame
from settings import all_sprite_group, WINDOW_WIDTH, WINDOW_HEIGHT


class Hud(pygame.sprite.Sprite):
    font = pygame.font.Font(size=100)

    def __init__(self):
        super().__init__(all_sprite_group)
        self.image: pygame.Surface = Hud.font.______("Game Over", True, "white")
        self.rect = self.image.get_frect(
            center=(WINDOW_WIDTH / 2, WINDOW_HEIGHT / 2)
        )

    def update(self, dt: float):
        pass
```

> 힌트: 글자를 **그림(Surface)으로 굽는** 함수다냥.

`main.py` 에서 하나 만들자냥.

```python
from entity.hud import Hud

    bg = Background()
    player = Player()
    hud = Hud()
```

**화면 한가운데에 "Game Over" 가 계속 보이면 성공이다냥.**
지금은 항상 보이는 게 정상이다냥 — 다음 미션에서 고친다냥.

<Callout type="important">
  `pygame.font.Font(...)` 도 **클래스 변수**라 `import` 하는 순간 실행된다냥.
  10강에서 배운 그 함정이다냥.
  `settings.py` 에서 `pygame.init()` 을 이미 했으니 괜찮다냥!
</Callout>

지금은 글자가 항상 보인다냥. **필요할 때만** 그리도록 바꾸자냥.

`hud.py` 의 `__init__` 에서 글자를 비우고,

```python
    def __init__(self, msg=""):
```

**직접 그리는 메서드**를 추가하자냥. `display_surface` 를 가져와야 한다냥.

```python
from settings import all_sprite_group, display_surface, WINDOW_WIDTH, WINDOW_HEIGHT

    def draw(self, msg: str):
        self.image = Hud.font.render(msg, True, "white")
        self.rect = self.image.get_frect(
            center=(WINDOW_WIDTH / 2, WINDOW_HEIGHT / 2)
        )
        display_surface.______(self.image, self.rect)
```

> 힌트: 2강에서 배운, Surface를 화면에 붙이는 함수다냥.

그리고 `main.py` 의 게임 오버 갈래에서 부르자냥.

```python
        else:
```

> 힌트

> - 두 번째 빈칸: 다시 플레이 상태로 돌아간다냥.

**게임 오버 화면에서 R을 누르면 처음부터 다시 시작되면 성공이다냥!**

## 완성 코드

<ToggleCodeBlock
  header="entity/hud.py"
  code={`import pygame
from os.path import join
from settings import (
    all_sprite_group,
    display_surface,
    WINDOW_HEIGHT,
    WINDOW_WIDTH,
)


class Hud(pygame.sprite.Sprite):
    font_path: str = join("images", "Galmuri9.ttf")
    font = pygame.font.Font(font_path, size=100)

    def __init__(self, msg: str = ""):
        super().__init__(all_sprite_group)
        self.image: pygame.Surface = Hud.font.render(msg, True, "white")
        self.rect: pygame.FRect = self.image.get_frect(
            center=(WINDOW_WIDTH / 2, WINDOW_HEIGHT / 2)
        )

    def draw(self, msg: str):
        self.image = Hud.font.render(msg, True, "white")
        self.rect = self.image.get_frect(
            center=(WINDOW_WIDTH / 2, WINDOW_HEIGHT / 2)
        )
        display_surface.blit(self.image, self.rect)

    def update(self, dt: float):
        pass
`}
/>

<ToggleCodeBlock
  header="main.py"
  code={`import pygame
from settings import (
    display_surface,
    all_sprite_group,
    meteor_sprite_group,
    missile_sprite_group,
)
from entity.bg import Background
from entity.meteor import Meteor
from entity.player import Player
from entity.hud import Hud

clock = pygame.time.Clock()


def main():
    running = True
    game_over = False

    bg = Background()
    player = Player()
    hud = Hud()

    meteor_event = pygame.event.custom_type()
    pygame.time.set_timer(meteor_event, 400)

    while running:
        dt = clock.tick(60) / 1000
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                running = False
            if event.type == meteor_event:
                Meteor.spawn(3)
            if event.type == pygame.KEYDOWN and event.key == pygame.K_r:
                if game_over:
                    all_sprite_group.add(bg)
                    player.reset()
                    hud.kill()
                    game_over = False

        pygame.sprite.groupcollide(
            meteor_sprite_group, missile_sprite_group, True, True
        )

        if not game_over:
            if pygame.sprite.spritecollide(player, meteor_sprite_group, False):
                game_over = True
            all_sprite_group.update(dt)
            all_sprite_group.draw(display_surface)
        else:
            all_sprite_group.empty()
            meteor_sprite_group.empty()
            missile_sprite_group.empty()
            display_surface.blit(bg.image)
            hud.draw("Game Over")

        pygame.display.flip()
    pygame.quit()


if __name__ == "__main__":
    main()
`}
/>

## 더 만들어보고 싶다면

게임이 완성됐다냥! 여기서 더 나아가고 싶다면 이런 것들을 해보자냥.

<Callout type="tip">
  - **점수**를 세어보자냥. 운석을 맞출 때마다 `score += 1` 하고 `hud.draw(f"점수: {score}")` 로 보여준다냥.
  - **목숨**을 만들어보자냥. 부딪히면 바로 게임 오버 대신 목숨을 하나 줄인다냥.
  - **난이도**를 올려보자냥. 시간이 지날수록 `set_timer` 간격을 줄인다냥.
  - **소리**를 넣어보자냥. `pygame.mixer` 를 찾아보자냥.
  - 게임 오버 화면에 **최고 점수**를 보여줘도 좋다냥.
</Callout>
