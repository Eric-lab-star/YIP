## 1단계 · pygame.display는 TV 본체다냥 (5분)

TV 본체라고 생각하면 된다냥. 켜고, 이름표 붙이고, 화면을 새로 뿌린다냥.

<StepCard step="2" title="set_caption() — 창 제목을 붙인다">

## 2단계 · flip()이 없으면 왜 아무것도 안 보이냥? (7분)

파이게임은 화면을 **두 장** 쓴다냥. 이걸 더블 버퍼링이라고 한다냥.

<Callout type="analogy">
  화가가 캔버스 두 개를 놓고 작업한다고 생각하면 된다냥.

  - **뒷면 캔버스**: 지금 열심히 그리는 중인 그림
  - **앞면 캔버스**: 관객이 보고 있는 그림

  `flip()` 은 다 그린 뒷면 캔버스를 **앞으로 뒤집어 보여주는** 동작이다냥.
  이걸 안 하면 아무리 그려도 관객은 계속 옛날 그림만 본다냥.
</Callout>

```python
while running:
    for event in pygame.event.get():
        ...
    display_surface.fill((0, 0, 0))   # 뒷면에 배경을 칠하고
    pygame.display.flip()             # 앞으로 뒤집어 보여준다냥
```

<Callout type="important">
  `fill()` 도 매 프레임 불러야 한다냥.
  안 그리면 **이전 프레임의 그림이 그대로 남아** 우주선이 움직일 때
  지나간 자리가 줄줄이 남는다냥. 매 프레임 도화지를 새로 덧칠하는 셈이다냥.
</Callout>

## 3단계 · 도화지는 두 종류다냥 (8분)

여기가 오늘의 핵심이다냥. 이름이 둘 다 surface라서 헷갈리기 쉽다냥.

<CompareBubble

      '여기에 붙인 것만 눈에 보인다',

    label: 'Surface (그림 조각)',

      'pygame.Surface((가로, 세로))로 만든다',
      '몇 개든 만들 수 있다',
      '그 자체로는 화면에 안 보인다',
      'blit()으로 무대에 붙여야 보인다',

```python
surf = pygame.Surface((100, 150))       # 100x150짜리 그림 조각을 만들고
surf.fill("orange")                     # 주황색으로 칠한 뒤
display_surface.blit(surf, (100, 100))  # 무대의 (100,100) 위치에 붙인다냥
```

<Callout type="analogy">
  `display_surface` 가 **교실 게시판**이라면,
  `Surface` 는 손에 든 **색종이 조각**이다냥.
  색종이는 아무리 예쁘게 칠해도 게시판에 붙이기 전엔 아무도 못 본다냥.
  그 붙이는 동작이 `blit()` 이다냥.
</Callout>

앞으로 우주선도, 운석도, 미사일도 전부 이 방식이다냥.
**각자 자기 Surface를 갖고, 매 프레임 무대에 blit 된다냥.**

## 4단계 · 색을 정하는 두 가지 방법 (3분)

```python
display_surface.fill((250, 250, 0))   # RGB 숫자로
surf.fill("orange")                   # 색 이름 문자열로
```

`(R, G, B)` 는 빨강·초록·파랑을 각각 0~255로 섞는 방식이다냥.
`(0,0,0)` 은 검정, `(255,255,255)` 는 흰색이다냥.

## 매 프레임의 순서

이 순서가 앞으로 계속 반복된다냥. 통째로 외워두면 편하다냥.

```
① 이벤트 확인    for event in pygame.event.get()
② 배경 지우기    display_surface.fill(...)
③ 그림 붙이기    display_surface.blit(...)
④ 화면에 내보내기 pygame.display.flip()
```
