## 1단계 · 미사일의 일생 (7분)

<StepCard step="태어남" title="스페이스바를 누른 순간, 우주선 코앞에서">

미사일은 우주선의 **위쪽 끝**에서 나와야 자연스럽다냥.
3강에서 배운 **기준점**을 여기서 쓴다냥.

```python
Missile(group, pygame.Vector2(self.rect.midtop))
```

우주선의 `midtop`(위쪽 변 가운데)에서 태어나게 한다냥.

</StepCard>

<StepCard step="살아감" title="매 프레임 위로">

```python
def update(self, dt):
    self.rect.centery -= dt * Missile.speed
```

위로 가야 하니 `y` 를 **뺀다냥**(파이게임의 y는 아래가 커진다냥).
`dt` 를 곱하는 것도 잊지 말자냥.

</StepCard>

<StepCard step="사라짐" title="화면 위로 벗어나면">

```python
if self.rect.bottom < 0:
    self.kill()
```

미사일의 **아래쪽 변**이 화면 맨 위(`y=0`)보다 위로 올라갔다는 건
완전히 화면 밖으로 나갔다는 뜻이다냥.

</StepCard>

## 2단계 · kill() — 왜 꼭 필요하냥? (8분)

<Callout type="important">
  `kill()` 은 그 스프라이트를 **자기가 속한 모든 그룹에서 빼내는** 메서드다냥.
  그룹에서 빠지면 `update` 도 `draw` 도 더 이상 안 불린다냥.
  즉 **존재하지 않는 것처럼 된다냥.**
</Callout>

이걸 안 하면 어떻게 되냥?

  명함첩에서 빠지면 아무도 그 사람을 부르지 않는다냥.
</Callout>

## 4단계 · 쿨다운 — 연사 막기 (10분)

`get_just_pressed()` 를 써도 문제가 남는다냥.
**스페이스바를 빠르게 연타하면** 미사일이 우수수 나간다냥.
게임 밸런스가 무너진다냥.

그래서 **쿨다운**을 둔다냥.

<Callout type="analogy">
  쿨다운은 **엘리베이터 버튼**과 같다냥.
  아무리 빨리 여러 번 눌러도 일정 시간이 지나야 다시 반응한다냥.
</Callout>

```python
missile_cooldown = 200      # 0.2초 (밀리초 단위)
missile_timer = 0           # 마지막으로 쏜 시각

def handleMissile(self):
    current_time = pygame.time.get_ticks()
    if current_time - Player.missile_timer > Player.missile_cooldown:
        self.spawn_missile()
```

<StepCard step="get_ticks()" title="게임이 시작된 뒤 흐른 시간">

`pygame.time.get_ticks()` 는 게임이 시작된 순간부터 **지금까지 몇 밀리초 지났는지**를 돌려준다냥.
스톱워치라고 생각하면 된다냥.

</StepCard>

<StepCard step="현재 - 마지막 > 쿨다운" title="충분히 기다렸나?">

`지금 시각 - 마지막으로 쏜 시각` 이 **얼마나 지났는지**다냥.
이게 쿨다운보다 크면 "이제 쏴도 된다" 는 뜻이다냥.

</StepCard>

<Callout type="tip">
  `dt` 를 쓰지 않고 밀리초를 쓰는 이유가 있다냥.
  쿨다운은 **"몇 초에 한 번"** 이라는 절대 시간이라서
  프레임과 상관없이 시계로 재는 게 더 간단하다냥.
</Callout>

## 5단계 · 우주선이 그룹을 들고 있어야 하는 이유 (5분)

미사일을 만드는 건 **우주선**이다냥. 그런데 미사일도 그룹에 들어가야 그려진다냥.

```python
class Player(pygame.sprite.Sprite):
    def __init__(self, group):
        super().__init__(group)
        ...
        self.group = group        # 그룹을 기억해둔다냥

    def spawn_missile(self):
        Missile(self.group, ...)  # 같은 그룹에 넣는다냥
```

<Callout type="important">
  `super().__init__(group)` 은 **우주선 자신**만 그룹에 넣어준다냥.
  나중에 미사일을 만들 때 그 그룹을 다시 써야 하니
  `self.group = group` 으로 **따로 기억해둬야 한다냥.**
</Callout>
