<MissionCard number={2} title="랜덤으로 떨어지게 하기" time="12분">

이제 운석마다 다르게 만들자냥. 파일 맨 위에 `random` 을 가져오자냥.

```python
from os.path import join
import ______
import pygame
from settings import WINDOW_WIDTH, WINDOW_HEIGHT
```

`__init__` 을 이렇게 바꾸자냥.

```python
    def __init__(self, group: pygame.sprite.Group):
        super().__init__(group)
        self.image = pygame.image.load(Meteor.path).convert_alpha()
        self.rect: pygame.FRect = self.image.get_frect(
            center=(random.randint(0, WINDOW_WIDTH), random.randint(____, ____))
        )
        self.speed: float = random.randint(300, 500)
        self.direction: pygame.Vector2 = pygame.Vector2(random.randint(-1, 1), 1)
```

> 힌트: y는 **화면 위쪽 바깥**에서 시작해야 한다냥. 화면 맨 위가 0이니 그보다 작은 값이다냥.

그리고 `update` 를 채우자냥.

```python
    def update(self, dt: float):
        self.rect.center += self.direction * dt * self.speed
        if self.rect.____ > WINDOW_HEIGHT:
            self.kill()
```

> 힌트: 운석의 **위쪽 변**이 화면 바닥보다 아래로 갔는지 본다냥.

**운석이 위에서 비스듬히 떨어지면 성공이다냥.** 한 개뿐이라 금방 사라진다냥.

<Callout type="tip">
  실행할 때마다 운석이 **다른 자리에서 다른 속도로** 떨어지는지 확인하자냥.
  매번 똑같다면 `random` 을 쓰지 않은 것이다냥.
</Callout>

</MissionCard>

<MissionCard number={3} title="spawn 클래스 메서드 만들기" time="10분">

운석 열 개를 만들려고 `Meteor(group)` 을 열 번 쓸 순 없다냥.
**공장**을 만들자냥.

```python
    @__________
    def spawn(cls, group: pygame.sprite.Group, n: int):
        if n <= 0:
            raise ValueError("n must be greater than 0")
        for _ in range(n):
            Meteor(group)
```

> 힌트: 객체 없이 클래스 자체에서 바로 부를 수 있게 해주는 표시다냥.

`main.py` 에서 열 개를 한 번에 만들자냥.

```python
    Meteor.spawn(all_sprite_group, 10)
```

**운석 여러 개가 우르르 떨어지면 성공이다냥!**

<Callout type="tip">
  `raise ValueError(...)` 는 **잘못된 값이 들어오면 알려주는** 코드다냥.
  `Meteor.spawn(group, 0)` 처럼 부르면 조용히 아무것도 안 하는 것보다
  **에러로 알려주는 게 낫다냥.** 나중에 버그를 훨씬 빨리 찾는다냥.
</Callout>

</MissionCard>

<MissionCard number={4} title="타이머로 계속 나오게 하기" time="12분">

지금은 10개가 떨어지고 끝이다냥. **계속 나오게** 하자냥.

`main()` 안, `while` 문 **위**에 두 줄을 추가하자냥.

```python
    meteor_event = pygame.event.____________()
    pygame.time.__________(meteor_event, 400)
```

> 힌트
> - 첫 번째 빈칸: 새로운 종류의 이벤트를 만드는 함수다냥.
> - 두 번째 빈칸: 타이머(알람)를 맞추는 함수다냥.

그리고 이벤트 확인 부분에 한 갈래를 추가하자냥.

```python
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                running = False
            if event.type == ____________:
                Meteor.spawn(all_sprite_group, 3)
```

> 힌트: 방금 만든 이벤트 변수 이름이다냥.

**0.4초마다 운석 3개가 계속 쏟아지면 성공이다냥!**

<Callout type="tip">
  `400` 을 `100` 으로 바꿔보자냥. 운석이 미친 듯이 쏟아진다냥.
  `2000` 으로 바꾸면 한참 기다려야 한다냥.
  **게임 난이도를 조절하는 숫자**다냥. 자기가 좋아하는 값을 찾아보자냥!
</Callout>

</MissionCard>

<MissionCard number={5} title="최적화 — 이미지를 한 번만 불러오기" time="15분">

지금은 운석이 하나 생길 때마다 디스크에서 그림 파일을 다시 읽는다냥.
**한 번만 읽어서 모두가 공유**하게 바꾸자냥.

### 5-1. settings.py를 먼저 고친다냥

**순서가 중요하다냥.** 이걸 먼저 안 하면 다음 단계에서 오류가 난다냥.

```python
# settings.py
import pygame

WINDOW_WIDTH, WINDOW_HEIGHT = 1280, 720

pygame.init()
display_surface: pygame.Surface = pygame.display.set_mode(
    (WINDOW_WIDTH, WINDOW_HEIGHT)
)
pygame.display.set_caption("space shooter")
```

`main.py` 에서는 이제 화면을 가져다 쓰기만 한다냥.

```python
import pygame
from settings import display_surface
from entity.bg import Background
from entity.player import Player
from entity.meteor import Meteor

clock = pygame.time.Clock()
```

`main.py` 에 있던 `pygame.init()`, `set_mode`, `set_caption` 은 **지우자냥.**

### 5-2. 이미지를 클래스 변수로 올린다냥

```python
class Meteor(pygame.sprite.Sprite):
    path: str = join("images", "meteor.png")
    ______: pygame.Surface = pygame.image.load(path).convert_alpha()

    def __init__(self, group: pygame.sprite.Group):
        super().__init__(group)
        self.image = Meteor.______
```

> 힌트: 두 빈칸은 같은 이름이다냥. Surface를 담아둘 클래스 변수 이름을 자유롭게 정해도 되는데, 보통 `surf` 라고 쓴다냥.

### 5-3. 미사일에도 똑같이 적용한다냥

`missile.py` 도 완전히 같은 방식으로 바꾸자냥. **스스로 해보자냥.**

<Callout type="important">
  순서를 안 지키면 이런 오류가 난다냥.

  ```
  pygame.error: cannot convert without video display
  ```

  `convert_alpha()` 는 **화면이 먼저 있어야** 쓸 수 있는데,
  클래스 변수는 `import` 하는 순간 실행되기 때문이다냥.
  5-1을 먼저 했는지 확인하자냥!
</Callout>

**화면은 하나도 안 바뀌어야 한다냥.** 운석을 많이 만들어도 덜 버벅이면 성공이다냥.

</MissionCard>

pygame.init()
display_surface: pygame.Surface = pygame.display.set_mode(
    (WINDOW_WIDTH, WINDOW_HEIGHT)

`}
/>

<ToggleCodeBlock
  header="entity/meteor.py"
  code={`from os.path import join
import random
import pygame
from settings import WINDOW_HEIGHT, WINDOW_WIDTH


class Meteor(pygame.sprite.Sprite):
    path: str = join("images", "meteor.png")
    surf: pygame.Surface = pygame.image.load(path).convert_alpha()

    def __init__(self, group: pygame.sprite.Group):
        super().__init__(group)
        self.image = Meteor.surf
        self.rect: pygame.FRect = self.image.get_frect(
            center=(random.randint(0, WINDOW_WIDTH), random.randint(-100, 0))
        )
        self.speed: float = random.randint(300, 500)
        self.direction: pygame.Vector2 = pygame.Vector2(random.randint(-1, 1), 1)

    @classmethod
    def spawn(cls, group: pygame.sprite.Group, n: int):
        if n <= 0:
            raise ValueError("n must be greater than 0")
        for _ in range(n):
            Meteor(group)

    def update(self, dt: float):
        self.rect.center += self.direction * dt * self.speed
        if self.rect.top > WINDOW_HEIGHT:
            self.kill()
`}
/>

<ToggleCodeBlock
  header="entity/missile.py"
  code={`import pygame
from os.path import join


class Missile(pygame.sprite.Sprite):
    path: str = join("images", "missile.png")
    surf: pygame.Surface = pygame.image.load(path).convert_alpha()
    speed: float = 200

    def __init__(self, group: pygame.sprite.Group, pos: pygame.Vector2):
        super().__init__(group)
        self.image = Missile.surf
        self.rect: pygame.FRect = self.image.get_frect(midbottom=pos)

    def update(self, dt: float):
        self.rect.centery -= dt * Missile.speed
        if self.rect.bottom < 0:
            self.kill()
`}
/>

<ToggleCodeBlock
  header="main.py"
  code={`import pygame
from settings import display_surface
from entity.bg import Background
from entity.player import Player
from entity.meteor import Meteor

clock = pygame.time.Clock()


def main():
    running = True
    all_sprite_group = pygame.sprite.Group()

    Background(all_sprite_group)
    Player(all_sprite_group)

    meteor_event = pygame.event.custom_type()
    pygame.time.set_timer(meteor_event, 400)

    while running:
        dt = clock.tick(60) / 1000
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                running = False
            if event.type == meteor_event:
                Meteor.spawn(all_sprite_group, 3)

        all_sprite_group.update(dt)
        all_sprite_group.draw(display_surface)

        pygame.display.flip()
    pygame.quit()


if __name__ == "__main__":
    main()
`}
/>

## 오늘 한 일

<Callout type="goal">
  - `random` 으로 운석마다 다른 위치·속도·방향을 줬다.
  - `@classmethod` 로 운석을 한 번에 여러 개 만드는 공장을 만들었다.
  - **커스텀 이벤트 + 타이머**로 운석이 계속 쏟아지게 했다.
  - 이미지를 **클래스 변수로 한 번만** 불러오도록 최적화했다.
  - `settings.py` 로 화면 생성을 옮겨 import 순서를 맞췄다.
</Callout>

이제 쏠 수도 있고 맞출 것도 있다냥.
