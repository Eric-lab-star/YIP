  그리고 그림을 화면 정중앙에 놓거나 벽에 튕기게 하려면
  **위치를 다루는 방법**이 필요하다냥. 그게 오늘의 주인공 `Frect` 다냥.

## 오늘의 학습 목표

<Callout type="goal">
  - 이미지 파일을 불러오는 세 단계(**경로 → 불러오기 → 투명 처리**)를 설명할 수 있다.
  - `Frect` 가 무엇이고 왜 `get_rect` 가 아니라 `get_frect` 를 쓰는지 말할 수 있다.
  - 기준점(`center`, `topleft`, `midbottom` …)이 무엇을 뜻하는지 설명할 수 있다.

## 1단계 · 이미지를 불러오는 세 단계 (7분)

<StepCard step="1" title="경로 만들기 — join()">

```python
from os.path import join

player_path = join("images", "player.png")
```

`join` 은 폴더 이름과 파일 이름을 이어서 **경로**를 만들어준다냥.
왜 그냥 `"images/player.png"` 라고 안 쓰냥?
윈도우는 `\`, 맥은 `/` 로 폴더를 구분하기 때문이다냥.
`join` 이 컴퓨터에 맞는 기호를 알아서 넣어준다냥.

</StepCard>

<StepCard step="2" title="불러오기 — pygame.image.load()">

```python
player_surf = pygame.image.load(player_path)
```

파일을 읽어서 **Surface** 로 만들어준다냥.
지난 시간에 배운 그 그림 조각이다냥. 그러니 `blit` 으로 붙이면 된다냥.

</StepCard>

<StepCard step="3" title="투명 처리 — convert_alpha()">

```python
player_surf = pygame.image.load(player_path).convert_alpha()
```

우주선 그림의 **배경이 투명한 부분**을 제대로 처리해준다냥.
이걸 빠뜨리면 우주선 주위에 네모난 상자가 보인다냥.
덤으로 그리는 속도도 빨라진다냥.

</StepCard>

<Callout type="important">
  `convert_alpha()` 는 `pygame.display.set_mode()` **뒤에** 호출해야 한다냥.
  화면이 아직 없는데 "화면에 맞게 변환"할 수는 없기 때문이다냥.
</Callout>

## 2단계 · Frect — 위치를 다루는 사각형 (10분)

우주선을 화면 **정중앙**에 놓고 싶다냥. `blit(player_surf, (?, ?))` 의 물음표에 뭘 넣어야 하냥?

<Callout type="analogy">
  직접 계산하면 이렇게 된다냥.

  ```
  x = 화면가로/2 - 이미지가로/2
  y = 화면세로/2 - 이미지세로/2
  ```

  이미지 크기가 바뀌면 다시 계산, 화면 크기가 바뀌어도 다시 계산이다냥.
  귀찮다냥!
</Callout>

그래서 파이게임은 이미지를 감싸는 **투명한 사각형**을 하나 준다냥.
그게 `Frect` 다냥.

```python
player_rect = player_surf.get_frect(center=(WINDOW_WIDTH / 2, WINDOW_HEIGHT / 2))
```

"이 사각형의 **중심**을 화면 한가운데에 맞춰줘" 라고만 하면
파이게임이 알아서 왼쪽 위 좌표를 계산해준다냥.

<Callout type="analogy">
  기준점은 **종이를 벽에 붙일 때 어느 부분을 맞출지** 정하는 것과 같다냥.

  - `center` — 종이 한가운데를 맞춘다냥
  - `topleft` — 왼쪽 위 모서리를 맞춘다냥
  - `midbottom` — 아래쪽 변의 가운데를 맞춘다냥
</Callout>

자주 쓰는 기준점이다냥.

- `center` — 중심
- `topleft`, `topright`, `bottomleft`, `bottomright` — 네 모서리
- `midtop`, `midbottom`, `midleft`, `midright` — 각 변의 가운데

## 4단계 · 벽에 튕기게 만드는 원리 (8분)

우주선을 좌우로 왔다 갔다 하게 만들려면 두 가지가 필요하다냥.

<StepCard step="1" title="방향과 속력을 나눠서 갖는다">

```python
direction = 1     # 1이면 오른쪽, -1이면 왼쪽
speed = 0.5       # 한 프레임에 얼마나 갈지
```

매 프레임 `speed * direction` 만큼 위치를 더한다냥.
`direction` 이 `-1` 이 되면 자연스럽게 반대로 간다냥.

</StepCard>

<StepCard step="2" title="벽에 닿았는지 확인한다">

```python
if player_rect.right >= WINDOW_WIDTH or player_rect.left <= 0:
    direction *= -1
```

`Frect` 는 `right`, `left`, `top`, `bottom` 으로
**사각형의 각 변이 지금 어디 있는지** 알려준다냥.
오른쪽 변이 화면 끝을 넘었으면 방향을 뒤집는다냥.

</StepCard>

<Callout type="important">
  `direction *= -1` 은 "부호를 뒤집어라" 는 뜻이다냥.
  1이면 -1이 되고, -1이면 1이 된다냥. 튕기는 동작을 한 줄로 표현한 것이다냥.
</Callout>
