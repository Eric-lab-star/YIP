### 핵심 비유 — "글에 어울리는 표지 그리기"

잡지나 블로그 글에는 내용을 한눈에 보여주는 **대표 사진(표지)**이 있지냥. 오늘 우리가 하는 일은, 우리가 쓴 글의 분위기를 **AI 화가에게 설명해서**, 그 글에 딱 어울리는 표지 그림을 그려달라고 부탁하는 거다냥.

<Callout type="analogy">
  **글(작가) + 그림(화가) = 한 팀!**

  - **작가**는 주제를 받아 글을 쓴다냥.
  - **화가**는 그 글의 분위기를 듣고 어울리는 표지를 그린다냥.

  둘이 한 팀이 되어 **완성된 한 편의 블로그 글**을 만드는 거다냥!
</Callout>

### 이미지 프롬프트도 결국 "좋은 프롬프트"

<StepCard step="핵심" title="좋은 이미지 프롬프트의 원리는 똑같다냥!">

이미지 프롬프트라고 특별한 게 아니다냥. 우리가 글 프롬프트에서 배운 원리가 그대로 적용된다냥.

| 원리 | 예시 |
|---|---|
| **구체적 묘사** | "카페"보다 "원목 테이블과 작은 화분이 있는 아늑한 홈카페" |
| **분위기** | "따뜻한", "차분한", "활기찬" 같은 느낌 단어 |
| **스타일** | "수채화 느낌", "사진처럼 사실적인", "귀여운 일러스트" |

게다가 **글의 주제에서 이미지 키워드를 뽑아내는 과정** 자체를 AI에게 시킬 수도 있다냥! 즉, AI에게 "이 글의 대표 이미지를 묘사하는 영어 문장을 만들어줘"라고 부탁하는 거다냥.

</StepCard>

### 기본 코드 예시 — 주제에서 이미지 묘사 뽑아내기

먼저 주제로부터 **영어 이미지 묘사문**을 만든다냥. 지금까지 써온 것과 똑같은 `generate_content`다냥.

```python
from google import genai

client = genai.Client(api_key="여기에 본인의 제미나이 API 키 입력")

topic = "초보자를 위한 홈카페 만들기"

image_desc_prompt = f"""
'{topic}'이라는 블로그 글의 대표 이미지를 만들려고 해.
이미지 생성 AI에게 전달할 영어 묘사문을 한 문장으로 만들어줘.
따뜻하고 아늑한 분위기를 담아줘.
"""
image_description = client.models.generate_content(model="gemini-3.5-flash", contents=image_desc_prompt).text
print("이미지 묘사:", image_description)
```

이렇게 하면 AI가 주제를 보고 **"warm and cozy home cafe with wooden table and small plants..."** 같은 영어 묘사문을 만들어준다냥. 이 묘사문을 이번엔 **진짜로 그림을 그려주는 모델**에게 그대로 넘겨줄 거다냥!

### 기본 코드 예시 — 진짜로 이미지 그리기

<Callout type="note">
  이미지를 그리는 모델은 지금까지 쓰던 `gemini-3.5-flash`와 다르다냥. **이미지
  생성 전용 모델**(`gemini-3.1-flash-lite-image`, 별명 "나노 바나나 2 라이트")을 쓰고,
  `response_modalities`라는 설정으로 "글자(TEXT) 말고 그림(IMAGE)도 같이
  줘"라고 알려줘야 한다냥. 나머지는 똑같이 `client.models.generate_content()`다냥!
</Callout>

```python
from google.genai import types

image_response = client.models.generate_content(
    model="gemini-3.1-flash-lite-image",
    contents=image_description,
    config=types.GenerateContentConfig(
        response_modalities=["TEXT", "IMAGE"],
    ),
)

# 응답 안에서 이미지 조각을 찾아 파일로 저장한다
for part in image_response.parts:
    if image := part.as_image():
        image.save("cover.jpg")
        print("표지 이미지를 저장했습니다: cover.jpg")
```

`response.parts`를 하나씩 살펴보면서, `part.as_image()`로 그림 조각을 꺼내 `.save()`로 저장하면 끝이다냥! 이렇게 만든 `cover.jpg`를 Streamlit의 `st.image()`에 넘기면 화면에 진짜 표지 그림이 뿅 하고 나타난다냥.

## 3단계 · 글과 그림을 한 화면에 (3분)

<NyangSpeech>
  이제 마지막 그림을 그려보자냥. 글 생성 기능과 이미지 생성 기능을
  **하나의 Streamlit 화면**에서 합치는 거다냥. 주제 하나만 입력하면 →
  완성된 블로그 글 + 어울리는 표지 이미지가 화면에 짠! 하고 나오는 거지냥!
</NyangSpeech>

### 핵심 비유 — "글과 그림을 함께 내놓는 출판사"

<Callout type="analogy">
  오늘 만들 앱은 작은 **출판사**와 같다냥.

  - **주제(원고 의뢰)**가 들어오면 →
  - **작가(글 생성 AI)**가 글을 쓰고 →
  - **화가(이미지 생성 AI)**가 표지를 그려서 →
  - 한 편의 완성된 글을 **독자(사용자)**에게 내놓는 거다냥.

  여러 AI 기능을 **한 화면에서 협업**하게 만드는 게 오늘의 핵심이다냥!
</Callout>

<Callout type="note">
  오늘 만든 앱에서 AI는 한 가지 일만 하는 게 아니라냥. **글 구조 만들기, 본문 쓰기,
  이미지 묘사 만들기, 진짜 이미지 그리기**처럼 여러 일을 동시에 해낸다냥. 이렇게
  여러 AI 기능을 묶어 하나의 앱으로 만드는 걸 **멀티 기능 통합**이라고 부른다냥!
</Callout>

<Callout type="tip">
  **결제가 안 된 계정이라면?** 걱정 말라냥! 실습 코드는 이미지 생성이 실패해도
  앱이 멈추지 않도록 만들 거다냥 — 표지 이미지만 못 나오고, **글 생성 기능은
  평소처럼 잘 작동한다냥.** 오늘의 핵심은 "AI 기능 여러 개를 한 화면에 조합하는
  방법"을 배우는 거지, 모두가 반드시 그림을 봐야 하는 건 아니라냥.
</Callout>
