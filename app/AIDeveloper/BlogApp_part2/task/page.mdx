<MissionCard number={1} title="진짜 표지 이미지 만들기 " time="10~13분">

먼저 주제를 받아서, 그 글에 어울리는 **대표 이미지 묘사문**을 AI에게 만들게 하고, 그 묘사문으로 **진짜 표지 이미지**까지 그려보자냥! 아래 템플릿에서 **빈칸(`____`)을 직접 채워보자냥.**

```python
from google import genai
from google.genai import types

client = genai.Client(api_key="여기에 본인의 제미나이 API 키 입력")

topic = "초보자를 위한 홈카페 만들기"

# 1) 주제에서 이미지 묘사를 뽑아내는 프롬프트를 직접 작성해보세요
image_desc_prompt = f"""
'{topic}'이라는 블로그 글의 대표 이미지를 만들려고 해.
이미지 생성 AI에게 전달할 영어 묘사문을 한 문장으로 만들어줘.
{____} 분위기를 담아줘.
"""
image_description = client.models.generate_content(model="gemini-3.5-flash", contents=image_desc_prompt).text
print("이미지 묘사:", image_description)

# 2) 이미지 묘사문을 진짜 그림으로 바꾸기 (그대로 복사!)
# gemini-3.5-flash는 글자만 만들 수 있어서, 그림을 그리는 전용 모델을 따로 쓴다
image_response = client.models.generate_content(
    model="gemini-3.1-flash-lite-image",
    contents=image_description,
    config=types.GenerateContentConfig(
        response_modalities=["TEXT", "IMAGE"],
    ),
)

for part in image_response.parts:
    if image := part.as_image():
        image.save("cover.jpg")
        print("표지 이미지를 저장했습니다: cover.jpg")
```

> **확인해보자냥 (빈칸 힌트)**
> - `{____}` 자리에는 글의 **분위기**를 나타내는 단어를 넣으면 된다냥. 예를 들어 "따뜻하고 아늑한", "차분하고 깔끔한" 같은 느낌 단어다냥!
> - 실행한 폴더에 `cover.jpg` 파일이 새로 생겼냥? 직접 열어서 확인해보자냥!

<Callout type="tip">
  **`part.as_image()`는 뭐하는 애냥?**

  `image_response.parts`에는 AI가 만든 결과 조각들이 여러 개 들어있을 수 있다냥
  (글자 조각, 그림 조각 등). `part.as_image()`는 "이 조각이 그림이면 꺼내주고,
  아니면 아무것도 안 준다"는 뜻이다냥. 그림 조각을 찾으면 `.save("cover.jpg")`로
  파일에 저장하면 끝이다냥!
</Callout>

**직접 해보기**
`topic`을 `"가을에 떠나기 좋은 국내 여행지"`, `"집에서 하는 간단한 홈트레이닝"` 등으로 바꿔가며 어떤 이미지가 나오는지 비교해보자냥!

<Callout type="important">
  **이미지가 안 나온다면?** 결제(billing)가 활성화되지 않은 API 키라면
  `image_response.parts`에 그림 조각이 없거나, 에러가 날 수 있다냥. 그럴 땐
  당황하지 말고 선생님께 손을 들어 확인받거나, 글 생성 기능(미션 2)에 먼저
  집중해도 괜찮다냥!
</Callout>

</MissionCard>

<MissionCard number={2} title="Streamlit 앱으로 통합하기 " time="12~15분">

이제 글 생성과 이미지 묘사 생성을 **하나의 Streamlit 화면**에 합쳐보자냥! 주제를 입력하고 말투를 고른 뒤 버튼을 누르면 → 완성된 블로그 글 + 추천 이미지 묘사가 화면에 나타나도록 만드는 거다냥.

<Callout type="note">
  **어? 11차시엔 구조부터 → 본문 순서로 두 단계로 나눠 만들지 않았냥?**

  맞다냥! 11차시에서는 "설계도(구조) 먼저 → 본문 나중"으로 **두 번**에 나눠
  요청하는 방법을 배웠다냥. 오늘 앱에서는 화면을 간단하게 만들기 위해 **한
  번의 요청**으로 합쳐서 쓴다냥 — 프롬프트의 **형식** 지시(제목·소제목 3개·본문·
  마무리)만 잘 갖추면, 한 번에 요청해도 충분히 짜임새 있는 글이 나온다냥.
  더 길고 정교한 글을 원한다면, 11차시처럼 구조를 먼저 받고 소제목마다 따로
  본문을 요청하는 방식으로 직접 바꿔봐도 좋다냥!
</Callout>

아래 템플릿에서 **빈칸(`____`)을 직접 채워보자냥.**

```python
import streamlit as st
from google import genai
from google.genai import types

client = genai.Client(api_key="여기에 본인의 제미나이 API 키 입력")

st.title("네이버 블로그 자동 작성 도우미")

topic = st.text_input("블로그 주제를 입력하세요")
tone = st.selectbox("말투를 골라주세요", ["친근한", "전문적인", "유머러스한"])

if st.button("블로그 글 생성하기"):
    # 글 생성 프롬프트를 직접 작성해보세요 (11차시 내용 활용)
    post_prompt = f"""
    너는 {tone} 말투의 블로거야.
    '{topic}' 주제로 제목, 소제목 3개와 각 본문, 마무리를 갖춘 블로그 글을 써줘.
    """
    with st.spinner("글을 쓰는 중..."):
        post = client.models.generate_content(model="gemini-3.5-flash", contents=post_prompt).text

    st.write("### 생성된 블로그 글")
    st.write(post)

    # 표지 이미지 묘사 프롬프트 작성
    image_desc_prompt = ____  # 이미지 묘사 프롬프트 작성
    image_description = client.models.generate_content(model="gemini-3.5-flash", contents=image_desc_prompt).text

    # 진짜 표지 이미지 생성 — 결제가 안 되어 있어도 앱이 멈추지 않도록
    # try/except로 감싼다 (그대로 복사!)
    st.write("### 표지 이미지")
    with st.spinner("표지 이미지를 그리는 중..."):
        try:
            image_response = client.models.generate_content(
                model="gemini-3.1-flash-lite-image",
                contents=image_description,
                config=types.GenerateContentConfig(response_modalities=["TEXT", "IMAGE"]),
            )
            saved = False
            for part in image_response.parts:
                if image := part.as_image():
                    image.save("cover.jpg")
                    st.image("cover.jpg", caption="AI가 그린 표지 이미지")
                    saved = True
            if not saved:
                st.info("이번엔 이미지를 만들지 못했어요. 다시 시도해보세요!")
        except Exception:
            st.warning("표지 이미지를 그리지 못했습니다. (이미지 생성은 결제가 활성화된 API 키가 필요해요)")
```

> **확인해보자냥 (빈칸 힌트)**
> - `image_desc_prompt = ____` 자리에는 미션 1에서 만든 **이미지 묘사 프롬프트**를 넣으면 된다냥! `f"""..."""` 문자열 안에 `{topic}`을 활용하는 게 핵심이다냥.
> - 예를 들면 `image_desc_prompt = f"'{topic}' 글에 어울리는 대표 이미지를 영어 한 문장으로 묘사해줘."` 처럼 작성하면 된다냥.

<Callout type="tip">
  **`try` / `except`는 왜 감싸는 거냥?**

  이미지 생성은 결제가 안 되어 있으면 **에러가 날 수 있다냥.** `try` 안의
  코드를 실행하다가 에러가 나면, 앱 전체가 멈추는 대신 `except` 안의 코드가
  대신 실행된다냥. 그래서 이미지가 실패해도 **글 생성 결과는 안전하게 화면에
  남아있는다냥!** 이렇게 실패할 수도 있는 부분을 미리 감싸두는 습관은 진짜
  서비스를 만들 때도 아주 중요하다냥.
</Callout>

**직접 해보기**
같은 주제로 말투(`친근한`, `전문적인`, `유머러스한`)만 바꿔가며 버튼을 눌러보자냥. 글의 느낌과 표지 그림이 어떻게 달라지는지 비교하면 정말 재미있다냥!

</MissionCard>
