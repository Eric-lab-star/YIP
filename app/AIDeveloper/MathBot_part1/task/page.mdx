<MissionCard number={1} title="BotFather로 봇 만들고 토큰 받기 " time="8~10분">

가장 먼저, 내 봇을 만들고 **열쇠(토큰)**를 발급받아야 한다냥. 텔레그램 앱에서 아래 순서대로 따라 해보자냥!

<StepCard step="순서" title="봇 생성 5단계">

1. 텔레그램 앱에서 검색창에 **`BotFather`**를 검색한다냥. (파란 체크 표시가 있는 공식 계정이라냥!)
2. BotFather와 대화를 시작하고, **`/newbot`**이라고 메시지를 보낸다냥.
3. 봇의 **이름(name)**을 정해서 보낸다냥. (화면에 보일 이름이라냥)
4. 봇의 **사용자명(username)**을 정한다냥. 반드시 **`bot`으로 끝나야** 한다냥! (예: `my_math_bot`)
5. BotFather가 축하 메시지와 함께 **긴 토큰**을 보내준다냥. 이걸 잘 복사해두자냥!

</StepCard>

> **확인해보자냥**
> - BotFather가 보내준 토큰을 받았냥? (`123456789:ABC...` 같은 긴 문자열이라냥)
> - 토큰을 메모장 등에 안전하게 복사해두었냥?

<Callout type="important">
  **토큰은 비밀번호다냥!**

  이 토큰은 내 봇을 여는 **열쇠**라서, 친구에게 보여주거나 인터넷에 올리면 안 된다냥. 만약 실수로 노출됐다면, BotFather에서 `/revoke`로 토큰을 새로 발급받을 수 있다냥!

  그래서 다음 미션에서는 토큰을 **코드 안에 적지 않고** 따로 숨기는 방법을 배울 거다냥.
</Callout>

```bash
pip install python-telegram-bot python-dotenv
```

<Callout type="important">
  **가상환경 주의냥**

  `.venv` 같은 가상환경을 쓴다면, 터미널 줄 맨 앞에 `(.venv)`가 보이는 상태에서
  설치해야 한다냥. 설치는 됐다는데 코드에서 `ModuleNotFoundError`가 뜬다면
  **설치한 파이썬과 실행한 파이썬이 다른 것**이라냥. 그럴 땐 `pip` 대신
  `python -m pip install ...`로 하면 확실하다냥! (자세한 건 3차시 실습에 있다냥)
</Callout>

- `python-telegram-bot` — 텔레그램 봇을 만드는 도구라냥
- `python-dotenv` — **토큰을 코드 밖에 숨겨두고 꺼내 쓰는** 도구라냥

### 토큰을 숨길 `.env` 파일 만들기

<StepCard step="순서" title="비밀 서랍 만들기 3단계">

1. 봇 코드(`.py`)를 저장할 폴더에, **`.env`** 라는 이름의 새 파일을 만든다냥. (이름 앞에 **점(`.`)**이 꼭 붙어야 한다냥!)
2. 그 안에 아래 한 줄만 적는다냥. `=` 앞뒤에 **띄어쓰기를 넣지 말자냥.**

   ```text
   TELEGRAM_TOKEN=여기에 BotFather에서 받은 토큰 붙여넣기
   ```

3. 저장한다냥. 이제 토큰은 **코드가 아니라 `.env` 안**에 있다냥!

</StepCard>

> **확인해보자냥**
> - 설치가 에러 없이 끝났냥?
> - `.env` 파일이 **`.py` 파일과 같은 폴더**에 있냥? (다른 폴더에 있으면 못 찾는다냥!)
> - 설치 중 빨간 에러가 났다면, 손을 들고 코딩냥에게 알려주자냥!

<Callout type="analogy">
  **`.env`는 "비밀 서랍"이라냥**

  코드는 친구에게 보여주거나 인터넷에 올릴 일이 많다냥. 그런데 토큰을 코드 안에 적어두면, 코드를 보여주는 순간 **열쇠까지 같이 넘겨주는 셈**이라냥.

  `.env`는 그 열쇠만 따로 담아두는 **비밀 서랍**이라냥. 코드는 "서랍에서 열쇠 꺼내와" 라고만 말하고, 서랍 자체는 절대 남에게 주지 않는 거다냥!
</Callout>

</MissionCard>

<MissionCard number={3} title="메아리 봇 만들고 실행하기 " time="12~15분">

이제 핵심이다냥! 사용자가 보낸 메시지를 **그대로 따라 답장**하는 메아리 봇을 만들어볼 거다냥.

아래 템플릿에서 **빈칸(`____`)을 직접 채워보자냥.** 토큰은 이미 `.env`에 넣어뒀으니, 코드에는 **토큰을 적지 않는다냥!**

```python
import os

from dotenv import load_dotenv
from telegram import Update
from telegram.ext import Application, MessageHandler, CommandHandler, filters, ContextTypes

load_dotenv()                                # .env 파일에서 비밀 값을 읽어온다냥
TELEGRAM_TOKEN = os.environ["TELEGRAM_TOKEN"]  # 비밀 서랍에서 토큰을 꺼낸다냥

# /start 명령어에 응답하는 함수
async def start(update: Update, context: ContextTypes.DEFAULT_TYPE):
    message = update.effective_message
    if message is None:
        return
    await message.reply_text("안녕하세요! 메시지를 보내면 따라 말해드릴게요.")

# 일반 메시지에 응답하는 함수
async def echo(update: Update, context: ContextTypes.DEFAULT_TYPE):
    message = update.effective_message
    if message is None or message.text is None:
        return

    user_text = message.text
    # 받은 메시지를 그대로 답장하도록 작성해보세요
    await message.reply_text(____)

# 봇 실행
app = Application.builder().token(TELEGRAM_TOKEN).build()
app.add_handler(CommandHandler("start", start))
app.add_handler(MessageHandler(filters.TEXT & ~filters.COMMAND, echo))

print("봇이 실행 중입니다...")
app.run_polling()
```

> **확인해보자냥 (빈칸 힌트)**
> - `reply_text(____)`의 빈칸에는 무엇이 들어가야 할까냥? (사용자가 보낸 메시지를 담아둔 **변수 이름**이다냥! 윗줄을 잘 보자냥 )

**직접 해보기**
코드를 저장하고 실행한 다음, **내 텔레그램에서 직접 내 봇을 검색**해보자냥! (미션 1에서 정한 username으로 찾으면 된다냥) 그리고 아무 말이나 보내보자냥. 봇이 그대로 따라 말하냥?

<Callout type="important">
  **`KeyError: 'TELEGRAM_TOKEN'` 이라고 뜨냥?**

  비밀 서랍을 못 찾았다는 뜻이다냥! 아래 세 가지를 확인해보자냥.

  - `.env` 파일이 `.py` 파일과 **같은 폴더**에 있냥?
  - 파일 이름이 `env.txt`나 `.env.txt`가 아니라 정확히 **`.env`**냥?
  - `.env` 안의 이름이 코드와 똑같이 **`TELEGRAM_TOKEN`**이냥? (대소문자도 똑같아야 한다냥!)
</Callout>

## 코드 뜯어보기 — 궁금했던 두 가지

<NyangSpeech mood="TEACH">
  빈칸은 채웠는데, 코드에 처음 보는 게 두 개 있었을 거다냥.
  `effective_message`랑 `filters` 말이다냥! 하나씩 뜯어보자냥.
</NyangSpeech>

### 1. 왜 `update.message`가 아니라 `update.effective_message`냥?

텔레그램이 보내주는 `update`는 **모든 종류의 사건을 한 상자에 담아서** 온다냥. 새 메시지, **수정된 메시지**, 채널에 올린 글… 이번 사건과 관계없는 칸은 전부 **비어 있다냥(`None`)**.

| 사용자가 한 일 | `update.message` | 내용이 실제로 들어 있는 곳 |
| --- | --- | --- |
| 새 메시지 보내기 | 들어 있음 | `update.message` |
| 보낸 메시지를 **수정** | 비어 있음 | `update.edited_message` |
| 채널에 글 올리기 | 비어 있음 | `update.channel_post` |

`update.message`만 쓰면 **수정된 메시지를 조용히 놓친다냥.** `update.effective_message`는 "이번 사건에서 실제로 내용이 들어 있는 칸"을 알아서 골라주니까 더 안전하다냥!

<Callout type="tip">
  **에디터에 노란 줄이 그어졌다냥?**

  `"text" is not a known attribute of "None"` 같은 경고를 봤다면, 그건 에디터(pyright 같은 검사기)가 **"그 칸이 비어 있을 수도 있잖냥?"** 하고 알려주는 거라냥.

  그래서 우리는 이렇게 먼저 막아준 거다냥.

  ```python
  if message is None:
      return
  ```

  이 줄을 지나온 뒤부터는 **비어 있지 않은 게 확실**하니까, 검사기도 더 이상 경고하지 않는다냥!
</Callout>

### 2. `filters.TEXT & ~filters.COMMAND` 는 무슨 뜻이냥?

`MessageHandler`는 원래 **모든 메시지**를 다 받는다냥. 첫 번째 자리에 넣은 게 **"이 중에서 무엇만 받을지 거르는 체"**라냥.

<StepCard step="문법" title="&, ~ 는 계산이 아니라 조건 조립이라냥">

| 기호 | 읽는 법 | 뜻 |
| --- | --- | --- |
| `A & B` | A **그리고** B | 둘 다 맞아야 통과 |
| `A \| B` | A **또는** B | 하나만 맞아도 통과 |
| `~A` | A**가 아님** | 뒤집는다 |

- `filters.TEXT` → **글자**로 된 메시지 (사진·스티커·음성은 탈락이라냥)
- `filters.COMMAND` → **`/`로 시작하는 명령어** (`/start` 같은 것)
- `~`가 `&`보다 먼저 붙으니까 → `filters.TEXT & (~filters.COMMAND)`

합치면 **"글자인데, 명령어는 아닌 것"**이라냥!

</StepCard>

| 사용자가 보낸 것 | 통과하냥? | 왜냥 |
| --- | --- | --- |
| `안녕` | 통과 | 글자이고 명령어가 아니라냥 |
| `/start` | 탈락 | 명령어라냥 |
| 사진 | 탈락 | 글자가 아니라냥 |
| `내일 /start 할게` | 통과 | `/`가 맨 앞이 아니라 명령어가 아니라냥 |

<Callout type="note">
  **`~filters.COMMAND`가 없으면 어떻게 되냥?**

  `/start`도 사실은 **글자**라냥! 그래서 이걸 빼면 메아리 봇이 `/start`까지 그대로 따라 말하게 된다냥. `/start`는 `start` 함수가 맡기로 했으니, 여기서는 확실하게 빼주는 거다냥.
</Callout>

---

<Callout type="tip">
  **봇을 멈추고 싶을 땐?**

  `app.run_polling()`은 봇을 **계속 켜둔 상태**로 둔다냥. 그래서 코드가 멈추지 않고 계속 메시지를 기다린다냥. 봇을 멈추려면 **셀 중단** 또는 터미널에서 **`Ctrl+C`**를 눌러야 한다냥!
</Callout>
