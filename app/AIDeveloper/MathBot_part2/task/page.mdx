<MissionCard number={2} title="사진 속 문제 인식하기 " time="10~12분">

이미지를 제미나이에 전달해서, **"무슨 문제인지" 글자로 읽어보게** 만들어볼 거다냥.

<Callout type="important">
  **먼저 `.env`에 제미나이 키를 넣자냥**

  13차시에서 봇 토큰을 **`.env`라는 비밀 서랍**에 숨기는 법을 배웠지냥? 제미나이 API 키도 **똑같이 소중한 열쇠**라서, 코드에 직접 적으면 안 된다냥.

  오늘 쓸 `.py` 파일과 같은 폴더에 `.env`를 만들고 한 줄 적어두자냥. (`=` 앞뒤에 띄어쓰기 금지라냥!)

  ```text
  GEMINI_API_KEY=여기에 제미나이 API 키 붙여넣기
  ```
</Callout>

아래 템플릿에서 **빈칸(`____`)을 직접 채워보자냥.**

```python
import os

from dotenv import load_dotenv
from google import genai
import PIL.Image

load_dotenv()                                                # .env에서 비밀 값을 읽어온다냥
client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])  # 서랍에서 키 꺼내기

# 수학 문제 사진 불러오기
image = PIL.Image.open("math_problem.jpg")

# 이미지와 함께 보낼 지시문을 직접 작성해보세요
read_prompt = ____  # 예: "이 사진 속에 있는 수학 문제를 글자로 그대로 읽어줘."

response = client.models.generate_content(model="gemini-3.5-flash", contents=[read_prompt, image])
print("인식된 문제:", response.text)
```

> **확인해보자냥 (빈칸 힌트)**
> - `read_prompt = ____` 자리에는 AI에게 **사진을 어떻게 읽어달라**고 부탁하는 문장을 넣으면 된다냥.
> - 가장 쉽게는 `read_prompt = "이 사진 속에 있는 수학 문제를 글자로 그대로 읽어줘."` 처럼 따옴표로 감싼 문장을 넣으면 된다냥!

**직접 해보기**
실행해서, AI가 사진 속 문제를 글자로 잘 읽어내는지 확인해보자냥. 또렷한 사진과 흐릿한 사진을 **둘 다** 넣어보고 결과가 어떻게 다른지 비교해보자냥!

<Callout type="tip">
  **`KeyError: 'GEMINI_API_KEY'` 라고 뜨냥?**

  비밀 서랍을 못 찾았다는 뜻이라냥. `.env`가 `.py`와 **같은 폴더**에 있는지, 파일 이름이 정확히 **`.env`**인지, 안에 적은 이름이 **`GEMINI_API_KEY`**로 코드와 똑같은지 확인해보자냥!
</Callout>

<MissionCard number={3} title="단계별 풀이 생성하기 " time="10~13분">

이번엔 사진 속 문제를 **단계별로 풀어주는** 프롬프트를 완성해볼 거다냥. 답만 툭 던지는 게 아니라, **풀이 과정 → 정답** 순서로 차근차근 설명하게 만드는 게 핵심이다냥!

아래 템플릿에서 **빈칸(`{____}`)을 직접 채워보자냥.**

```python
# 풀이용 프롬프트를 직접 완성해보세요
solve_prompt = """
너는 친절한 수학 선생님이야.
이 사진 속 수학 문제를 풀어줘. 단,
1) 먼저 문제가 무엇을 묻는지 설명하고,
2) {____} (단계별 풀이 과정을 어떻게 보여줄지 지시)
3) 마지막에 '정답: '으로 정답을 명확히 알려줘.
중학생도 이해할 수 있게 쉽게 설명해줘.
"""

response = client.models.generate_content(model="gemini-3.5-flash", contents=[solve_prompt, image])
print(response.text)
```

> **확인해보자냥 (빈칸 힌트)**
> - `{____}` 자리에는 AI가 **풀이 과정을 어떻게 보여줄지** 지시하는 문장을 넣으면 된다냥.
> - 예를 들어 `풀이 과정을 한 단계씩 순서대로 자세히 보여주고,` 처럼 적으면 좋다냥!

### ‍ 핵심 비유 — "풀이 과정을 꼭 보여주는 선생님"

<StepCard step="비유" title="왜 단계별 풀이를 부탁할까냥?">

좋은 수학 선생님은 **답만** 알려주지 않고, "왜 이렇게 푸는지" 과정을 차근차근 보여준다냥.

AI에게도 **"정답만 말하지 말고, 단계별로 풀이를 보여줘"**라고 부탁하는 게 중요하다냥. 그래야 우리가 답을 **외우는** 게 아니라 **푸는 방법**을 배울 수 있으니까냥!

프롬프트에 **"단계별로"**, **"쉽게 설명"**이라는 조건을 넣는 이유가 바로 이것이다냥

</StepCard>

**직접 해보기**
간단한 사칙연산부터 방정식까지, **여러 난이도**의 문제 사진으로 테스트해보자냥. 풀이가 단계별로 잘 나오냥?

<Callout type="important">
  **AI 풀이를 그대로 믿지 말자냥**

  AI가 가끔 **계산 실수**를 할 수 있다냥. AI가 내준 풀이를 받으면, 그대로 믿지 말고 **"이게 정말 맞나?"** 하고 직접 검토하는 습관을 들이자냥. 이건 다음 윤리 수업과도 연결되는 정말 중요한 태도다냥!
</Callout>

<MissionCard number={4} title="풀이를 브라우저 화면에 띄우기 " time="10~12분">

지금까지 풀이는 **터미널에 `print`로만** 나왔다냥. 나 혼자 보기엔 괜찮지만, 친구에게 "이거 써봐" 하고 건네주기엔 좀 아쉽지냥?

3차시에서 배운 **Streamlit**을 꺼낼 차례다냥! 사진을 올리면 → 화면에 사진이 뜨고 → 버튼을 누르면 → 풀이가 브라우저에 나타나는 앱을 만들어보자냥.

<Callout type="analogy">
  **`print`는 나만 보는 연습장, 화면은 모두가 보는 칠판이다냥**

  터미널에 찍힌 풀이는 **코드를 실행한 사람만** 볼 수 있다냥. 연습장에 적은 답 같은 거지냥.

  Streamlit으로 브라우저에 띄우면, 그건 **칠판에 크게 적은 풀이**가 된다냥. 파이썬을 모르는 친구도 사진만 올리면 풀이를 볼 수 있게 되는 거다냥!
</Callout>

새 파일 **`math_app.py`**를 만들고, 아래 템플릿에서 **빈칸(`____`)을 직접 채워보자냥.**

```python
import os

import streamlit as st
from dotenv import load_dotenv
from google import genai
import PIL.Image

load_dotenv()
client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

st.title("사진으로 푸는 수학 봇")
st.write("수학 문제 사진을 올리면 AI가 단계별로 풀어준다냥!")

uploaded = st.file_uploader("수학 문제 사진을 올려주세요", type=["jpg", "jpeg", "png"])

if uploaded:
    image = PIL.Image.open(uploaded)          # 올린 파일을 그대로 열 수 있다냥
    st.image(image, caption="올린 문제 사진")

    if st.button("풀이 보기"):
        # 미션 3에서 완성한 풀이 프롬프트를 그대로 가져와보세요
        solve_prompt = ____

        with st.spinner("AI가 문제를 푸는 중..."):
            response = client.models.generate_content(
                model="gemini-3.5-flash",
                contents=[solve_prompt, image],
            )

        st.write("### AI가 만든 풀이")
        st.write(response.text)
        st.warning("AI도 계산 실수를 할 수 있어요. 풀이를 꼭 직접 검토해보세요!")
```

터미널에서 아래 명령어로 실행하자냥.

```bash
streamlit run math_app.py
```

> **확인해보자냥 (빈칸 힌트)**
> - `solve_prompt = ____` 자리에는 **미션 3에서 완성한 그 프롬프트**를 그대로 넣으면 된다냥! 새로 만들 필요 없다냥.
> - `solve_prompt = """너는 친절한 수학 선생님이야. ... """` 처럼 따옴표 세 개로 감싼 여러 줄 문자열을 그대로 붙여넣자냥.

> **확인해보자냥 (화면 점검)**
> - 웹 브라우저가 자동으로 열렸냥?
> - 사진을 올리면 화면에 **사진이 바로** 보이냥?
> - **풀이 보기** 버튼을 누르면 잠깐 빙글빙글 돌다가 풀이가 나타나냥?

<StepCard step="구조" title="이 코드가 하는 일을 한 줄씩 보자냥">

| 코드 | 하는 일 |
|---|---|
| `st.title` / `st.write` | 화면에 제목과 안내 문구를 띄운다 |
| `st.file_uploader` | 사용자가 **사진을 올릴 상자**를 만든다 |
| `PIL.Image.open(uploaded)` | 올린 파일을 **미션 2와 똑같은 이미지**로 연다 |
| `st.image` | 올린 사진을 화면에 보여준다 |
| `st.button` | 눌렀을 때만 AI를 부르게 한다 (돈과 시간을 아낀다냥!) |
| `st.spinner` | 기다리는 동안 "작업 중"을 표시한다 |
| `st.write(response.text)` | 제미나이의 답변을 화면에 출력한다 |

미션 2·3과 **AI를 부르는 부분은 하나도 안 바뀌었다냥.** `print` 자리에 `st.write`가 들어가고, 파일 이름을 코드에 적는 대신 `st.file_uploader`로 받게 된 것뿐이다냥!

</StepCard>

<Callout type="important">
  **화면이 안 뜨면 여기부터 확인하자냥**

  - 실행 명령어가 `streamlit run math_app.py`가 맞냥? `python math_app.py`로 실행하면 화면이 **안 뜬다냥!** (3차시에서 배운 그거다냥)
  - `.env` 파일이 `math_app.py`와 **같은 폴더**에 있냥? 없으면 `KeyError: 'GEMINI_API_KEY'`가 뜬다냥.
  - `ModuleNotFoundError: No module named 'streamlit'`이 뜨면 `pip install streamlit`을 안 한 거다냥.
</Callout>

<Callout type="tip">
  **버튼을 누를 때만 AI를 부르는 이유가 있다냥**

  Streamlit은 화면에서 뭔가 바뀔 때마다 코드를 **처음부터 다시** 실행한다냥. 그래서 `if st.button(...)` 안에 넣지 않으면, 사진을 올리자마자 AI가 불려가고 화면을 조금만 건드려도 또 불려간다냥.

  API 호출은 **공짜가 아니다냥.** "버튼을 눌렀을 때만 실행"은 앱을 만들 때 아주 중요한 습관이다냥!
</Callout>

**직접 해보기**
미션 1에서 준비한 사진들을 하나씩 올려보자냥. 이번엔 **파일 이름을 코드에 적지 않아도** 되니까, 여러 장을 훨씬 빠르게 시험해볼 수 있다냥. 옆 친구에게 브라우저를 넘겨주고 직접 사진을 올려보게 해보자냥 — 그게 바로 **앱을 만든다는 것**이다냥!

</MissionCard>
