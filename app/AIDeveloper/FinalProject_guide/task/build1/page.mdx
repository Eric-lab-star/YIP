# 제작 1 — 대표 메뉴 만들고 진열대에 올리기

## 제작에 들어가기 전 · 막히면 볼 참고 영상

<NyangSpeech mood="TEACH">
  이제부터는 진짜로 코드를 쓰는 구간이다냥. 손이 안 움직일 때는 남이 만드는 걸
  한 번 보고 오는 게 제일 빠르다냥. 우리가 쓰는 것과 **같은 도구**를 다루는
  영상 두 개를 골라뒀다냥!
</NyangSpeech>

<StepCard step="참고" title="우리 강의와 같은 도구를 쓰는 영상">

| 언제 보면 좋냥? | 영상 |
|---|---|
| 제미나이 API 키가 없거나, 키부터 다시 받고 싶을 때 (2차시 복습) | [무료로 제미나이(Gemini) API KEY 발급받고 파이썬으로 사용해보기](https://www.youtube.com/watch?v=SRJeTcyU79M) — RGB코딩 |
| Streamlit 화면 만들기가 손에 안 익을 때 (3차시 복습) | [Streamlit으로 빠르게 웹앱 생성하기 — 설치·환경설정·실습파일](https://www.youtube.com/watch?v=Gr5Vuo7TCaE) — 테디노트 |

</StepCard>

<Callout type="important">
  **영상은 참고 자료이지 정답이 아니다냥.** 세 가지만 기억하자냥!

  - 영상마다 **쓰는 버전이 다르다냥.** 코드가 우리 수업과 다르면 우리 수업 쪽이 기준이다냥.
  - **그대로 따라 치기만 하면 남는 게 없다냥.** 한 번 보고, 영상을 끄고, 내 앱에 맞게 다시 써보자냥.
  - 영상은 **언제든 사라질 수 있다냥.** 링크가 죽어 있으면 선생님께 알려주면 된다냥.
</Callout>

<Callout type="tip">
  **영상보다 더 빠른 방법이 있다냥.** 지금 막힌 에러 메시지를 그대로 복사해서
  AI에게 붙여넣고 이렇게 물어보라냥 — "이 에러가 무슨 뜻이야? 초보자도 알아듣게
  설명해줘." 미션 1·2에서 AI와 기획했던 것처럼, **디버깅에서도 AI는 좋은 짝**이다냥!
</Callout>

<MissionCard number={3} title="대표 메뉴부터! 핵심 기능 구현 (25차시)" time="25~30분">

가게를 열 때 모든 메뉴를 동시에 만들기보다, **대표 메뉴 하나**를 먼저 완성하는 게 좋다냥. 오늘은 기획서의 **핵심 기능 1개**를 `.ipynb`에서 먼저 만들어보자냥.

- 프롬프트 작성, API 호출 등 가장 중요한 기능부터 구현한다냥.
- `.ipynb`의 장점을 살려, **작은 단위(셀)로 자주 실행**하며 확인한다냥.
- 막히면 지난 차시 코드를 **참고 템플릿**으로 가져다 써도 좋다냥!

> **이번 미션의 목표**
> - 핵심 기능 1개가 `.ipynb`에서 동작하냥?
> - 짝에게 시연해보고, 다음에 만들 기능을 메모했냥?

</MissionCard>

<MissionCard number={4} title="진열대에 올리기 — UI 연결 또는 기능 확장 (26차시)" time="25~30분">

맛있는 메뉴(핵심 기능)를 만들었다면, 이제 손님이 볼 수 있는 **진열대(화면)**에 올릴 차례다냥. 내 진도에 맞게 둘 중 하나를 골라 진행하면 된다냥!

  **두 갈래 길 — 내 상황에 맞게 고르자냥**

  - **기능 확장 그룹** — 기획서의 **두 번째 기능** 구현을 시작한다냥.
