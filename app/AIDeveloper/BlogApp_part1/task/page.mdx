<MissionCard number={2} title="블로그 구조 생성하기 " time="10~12분">

이제 AI에게 **글의 설계도(제목 + 소제목 3개)**를 만들어달라고 해보자냥! 아래 템플릿에서 **빈칸(`____`)을 직접 채워보자냥.**

```python
from google import genai

client = genai.Client(api_key="여기에 본인의 제미나이 API 키 입력")

topic = "초보자를 위한 홈카페 만들기"

# 역할/형식을 지정한 프롬프트를 직접 완성해보세요
structure_prompt = f"""
너는 ____ 말투의 블로거야.
'{topic}'이라는 주제로 네이버 블로그 글을 쓰려고 해.
다음 형식으로 글의 구조만 먼저 만들어줘:

제목: (눈길을 끄는 제목 1개)
소제목1: 
소제목2: 
소제목3: 
"""

structure = client.models.generate_content(model="gemini-3.5-flash", contents=structure_prompt).text
print(structure)
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 **말투**를 넣으면 된다냥. `친근한`, `전문적인`, `유머러스한` 중에서 골라보자냥!
> - `____`를 **지우고 그 자리에 단어만** 쓰면 된다냥. 중괄호 `{ }`를 씌우면 안 된다냥 — f-string 안에서 `{ }`는 "여기에 변수 값을 넣어라"는 뜻이라, `{친근한}`처럼 쓰면 `NameError`가 난다냥!
> - 실행하면 제목 1개와 소제목 3개가 나오냥? AI가 앞뒤로 인사말을 붙이거나 `**제목:**`처럼 굵게 표시할 수도 있는데, 그건 정상이다냥. 소제목 3개만 눈으로 찾아서 다음 미션에 복사해 쓰면 된다냥!

**직접 해보기**
`topic` 을 본인이 쓰고 싶은 주제(예: `제주도 2박 3일 여행`, `자취생 5분 요리`)로 바꿔보자냥. 말투도 바꿔가며 결과가 어떻게 달라지는지 살펴보자냥!

</MissionCard>

<MissionCard number={3} title="본문 채우기 " time="10~13분">

설계도가 완성됐으니, 이제 **각 소제목마다 본문**을 채워서 한 편의 글로 합쳐볼 거다냥!

### 그 전에 · 미션 2의 결과를 미션 3이 쓸 수 있는 모양으로 바꾸자냥

미션 2가 우리에게 준 건 **글자 덩어리 하나**다냥. `structure` 변수 안에 제목도, 소제목 3개도, 인사말도 전부 뒤섞여서 **한 덩어리 문자열**로 들어있다냥.

그런데 미션 3의 반복문은 소제목을 **하나씩 따로** 꺼내 써야 한다냥. 그러려면 **리스트**가 필요하다냥. 이 둘 사이에 다리를 놓는 게 지금 할 일이다냥!

<Callout type="analogy">
  **덩어리 → 낱개로 나누기**

  미션 2의 결과는 장바구니에 **한꺼번에 담긴 장 본 것**과 같다냥. 미션 3은 그걸
  **하나씩 꺼내서** 요리하는 단계라냥. 그러니 먼저 **꺼내기 좋게 정리**해줘야
  하는 거다냥!
</Callout>

**1단계 — 미션 2를 실행하고, 출력에서 소제목 줄만 찾자냥**

`print(structure)` 결과는 대략 이런 모양이다냥:

```text
안녕! 요청하신 홈카페 글 구조를 짜봤어. 확인해 봐!

***

**제목:** [홈카페 입문] 초보자를 위한 초간단 감성 홈카페 만들기 꿀팁

**소제목1:** 장비 욕심은 넣어두세요! 초보자 맞춤 가성비 필수템 3가지
**소제목2:** 우리 집 거실이 카페로? 쉽게 하는 감성 인테리어 한 스푼
**소제목3:** 1분 만에 뚝딱! 카페 갈 필요 없는 시그니처 레시피
```

앞뒤로 인사말이 붙고 `***`, `**` 같은 장식이 섞여 나올 수 있다냥. 이모지가 들어갈 때도 있다냥. 놀라지 말자냥 — **우리가 쓸 건 소제목 3줄뿐**이다냥!

**2단계 — 이름표(`**소제목1:**`)를 떼어내자냥**

`**소제목1:**` 은 "여기가 소제목이야"라고 알려주는 **이름표**일 뿐, 소제목 자체가 아니다냥. 우리가 쓸 건 **이름표 뒤에 오는 실제 문장**이다냥.

| 그대로 복사하면 | 이름표를 떼면 |
|---|---|
| `**소제목1:** 장비 욕심은 넣어두세요!` | `장비 욕심은 넣어두세요!` |

**3단계 — 따옴표로 감싸서 `subtitles` 리스트에 넣자냥**

```python
subtitles = [
    "장비 욕심은 넣어두세요! 초보자 맞춤 가성비 필수템 3가지",
    "우리 집 거실이 카페로? 쉽게 하는 감성 인테리어 한 스푼",
    "1분 만에 뚝딱! 카페 갈 필요 없는 시그니처 레시피",
]
```

문장 하나가 `"..."` 하나가 되고, 쉼표로 구분한다냥. 이제 반복문이 이걸 하나씩 꺼내 쓸 수 있다냥!

<Callout type="important">
  **이름표를 왜 꼭 떼야 하냥?**

  `subtitle` 은 **두 군데**에서 쓰인다냥. 하나는 본문을 부탁하는 프롬프트고,
  다른 하나는 아래 줄이다냥:

  ```python
  full_post += f"## {subtitle}\n{body}\n\n"
  ```

  즉 `subtitle` 이 **완성된 블로그 글의 소제목으로 그대로 찍힌다**는 뜻이다냥!
  이름표를 안 떼면 완성된 글에 `## **소제목1:** 장비 욕심은...` 이라고 나온다냥.
  (프롬프트 쪽은 이름표가 붙어 있어도 AI가 알아서 잘 써주긴 한다냥 — 문제는
  **최종 결과물에 이름표가 그대로 남는다**는 거다냥!)
</Callout>

<Callout type="tip">
  **소제목 자동 추출은 아직 어렵다냥!**

  AI가 만든 구조에서 소제목만 **코드로** 쏙쏙 뽑아내려면, 줄을 나누고
  `소제목` 이라는 글자를 찾고 `:` 뒤만 잘라내는 작업이 필요하다냥. 게다가
  AI가 매번 조금씩 다른 모양으로 답해서 생각보다 까다롭다냥.

  그래서 오늘은 **눈으로 보고 손으로 복사하는 방식**으로 간다냥. 이게 절대
  부끄러운 게 아니라냥 — 진짜 개발자도 처음엔 손으로 해보고, 규칙이 눈에
  익은 다음에 자동화한다냥. 자동화는 나중에 배운다냥!
</Callout>

이제 아래 템플릿에서 **빈칸(`____`)을 채우고**, `subtitles` 에는 방금 정리한 소제목 3개를 넣어보자냥.

```python
# 주의! 이 코드는 미션 2 코드 "아래에 이어서" 써야 한다냥.
# (client 와 topic 을 미션 2에서 만들어뒀기 때문이다냥)

# 위에서 만든 소제목들을 리스트로 정리 (직접 입력하거나 파싱)
subtitles = [
    "소제목1 내용을 여기에",
    "소제목2 내용을 여기에",
    "소제목3 내용을 여기에",
]

full_post = f"[주제: {topic}]\n\n"

for subtitle in subtitles:
    # 각 소제목에 맞는 본문 생성 프롬프트를 직접 작성해보세요
    body_prompt = f"""
    '{topic}' 블로그 글의 '{subtitle}' 부분 본문을 써줘.
    ____ 분량으로, 친근한 말투로 작성해줘.
    """
    body = client.models.generate_content(model="gemini-3.5-flash", contents=body_prompt).text
    full_post += f"## {subtitle}\n{body}\n\n"

print(full_post)
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 **본문 분량**을 넣으면 된다냥. `3문장`, `200자` 처럼 구체적으로 적어보자냥!
> - 여기서도 중괄호 `{ }`를 씌우면 안 된다냥! `{3문장}`처럼 쓰면 `NameError`가 난다냥. `{topic}`과 `{subtitle}`은 **진짜 변수**라서 중괄호가 있는 거다냥 — 그 둘은 그대로 두자냥!
> - 반복문이 소제목 3개를 하나씩 AI에게 건네주며 본문을 받아온다냥. 전체 글이 잘 합쳐졌냥?
> - `NameError: name 'client' is not defined` 가 뜨면, 미션 2 코드 아래에 이어서 쓰지 않은 거다냥!

### 핵심 비유 · 목차를 먼저 짜고 챕터를 쓰는 작가

<Callout type="analogy">
  좋은 작가는 책을 쓸 때 먼저 **목차(소제목)**를 정하고, 그다음 각 **챕터(본문)**를
  하나씩 써내려간다냥.

  우리 앱도 똑같이 일한다냥! 먼저 AI에게 목차를 만들게 하고(미션 2), 그 목차를 하나씩
  다시 AI에게 건네주며 "이 챕터 본문 써줘"라고 부탁하는 거다냥(미션 3). 이렇게 일을
  나누면 각 부분에 더 집중해서 좋은 글을 쓸 수 있다냥!
</Callout>
