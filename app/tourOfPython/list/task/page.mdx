<StepCard step="확인" title="7번이 헷갈렸다면">

`b = a` 는 리스트를 복사하는 게 아니라 **같은 가방에 이름표를 하나 더
붙이는 것**이다냥. 그래서 `b`에 넣으면 `a`에도 들어간다냥. 진짜
복사가 필요하면 `b = a.copy()` 를 쓰면 된다냥!

</StepCard>

<MissionCard number={2} title="손으로 다뤄보기" time="10~12분">

빈칸(`____`)을 채워서 코드를 완성해보자냥.

```python
cart = ["빵", "우유", "계란", "치즈"]

print(cart[____])        # 우유 만 출력하기
print(cart[____])        # 마지막 요소인 치즈 출력하기
cart.____("사과")         # 맨 뒤에 사과 추가하기
cart.____(1, "버터")      # 1번 자리에 버터 끼워넣기
cart.____("계란")         # 계란 지우기
print(len(cart))
```

> **확인해보자냥 (빈칸 힌트)**
> - 우유는 앞에서 두 번째다냥. 번호는 0부터 센다냥. (`1`)
> - 마지막은 음수 번호가 편하다냥. (`-1`)
> - 맨 뒤 추가는 `append`, 자리 지정은 `insert`, 값으로 지우기는 `remove` 다냥.
> - 마지막 길이가 5로 나오냥?

</MissionCard>

<MissionCard number={3} title="정렬하고 최댓값 찾기" time="8~10분">

숫자 리스트를 정리해보자냥.

```python
scores = [88, 95, 70, 100, 64]

scores.____()                 # 작은 값부터 정렬
print(scores)

print(____(scores))           # 가장 높은 점수
print(____(scores))           # 가장 낮은 점수
print(sum(scores) / ____(scores))   # 평균
```

> **확인해보자냥 (빈칸 힌트)**
> - 정렬은 `sort`, 최댓값은 `max`, 최솟값은 `min` 이다냥.
> - 평균은 전부 더한 값을 **개수**로 나눈다냥. 개수는 `len` 이다냥.
> - 평균이 83.4 로 나오냥?

</MissionCard>

<MissionCard number={4} title="합격자 명단 만들기" time="10~12분">

리스트와 반복문을 합쳐서, 실제로 쓸 법한 프로그램을 만들어보자냥.

```python
students = ["가온", "나래", "다온", "라온"]
scores = [88, 55, 92, 70]

합격자 = []
for i in range(len(students)):
    if scores[i] >= ____:
        합격자.____(students[i])

print("합격자:", 합격자)
```

> **확인해보자냥 (빈칸 힌트)**
> - 기준 점수는 70점으로 해보자냥.
> - 합격자 리스트에 이름을 덧붙이려면 `append` 다냥.
> - `['가온', '다온', '라온']` 이 나오냥?

</MissionCard>
