<MissionCard number={1} title="물어보고 대답 받기" time="6~8분">

빈칸(`____`)을 채워서 완성해보자냥.

```python
name = ____("이름이 뭐예요? ")
print(name + "님, 반갑습니다!")
```

> **확인해보자냥 (빈칸 힌트)**
> - 사용자에게 물어보는 함수 이름을 넣으면 된다냥.
> - 실행하면 프로그램이 **멈춰서 기다리냥?** 그게 정상이다냥. 답을 입력하고 엔터를 눌러보자냥.

</MissionCard>

---

<MissionCard number={2} title="함정 확인하기" time="8~10분">

오늘의 핵심 함정을 **직접 눈으로** 확인해보자냥.

```python
age = input("나이가 몇이에요? ")
print(type(age))       # 무엇이 나오냥?
print(age + 1)         # 어떤 오류가 나냥?
```

> **확인해보자냥**
> - 분명 숫자를 입력했는데 `<class 'str'>` 이 나오냥?
> - `age + 1` 에서 나는 오류 메시지를 **소리내어 읽어보자냥.**
> - `age + "1"` 로 바꾸면 어떻게 되냥? 계산이 아니라 이어붙여지냥?

<StepCard step="핵심" title="한 줄 요약">

`input()` 은 무엇을 입력하든 **문자열**을 준다냥. 그래서 숫자로
쓰려면 반드시 바꿔줘야 한다냥!

</StepCard>

</MissionCard>

<MissionCard number={3} title="형 바꿔서 계산하기" time="8~10분">

이제 함정을 피해보자냥.

```python
age = ____(input("나이가 몇이에요? "))
print(type(age))
print("내년에는", age + 1, "살이네요!")
```

> **확인해보자냥 (빈칸 힌트)**
> - 문자열을 정수로 바꾸는 함수다냥.
> - 이번엔 `<class 'int'>` 가 나오냥?
> - 15를 입력하면 "내년에는 16 살이네요!" 가 나오냥?
> - 이제 **"hello" 를 입력해보자냥.** 프로그램이 어떻게 되냥?

</MissionCard>

<MissionCard number={4} title="try..except 로 프로그램 지키기" time="10~12분">

방금 "hello" 를 넣었을 때 프로그램이 그냥 죽었지냥? 막아보자냥.

```python
____:
    age = int(input("나이가 몇이에요? "))
    print("내년에는", age + 1, "살이네요!")
____ ValueError:
    print("숫자를 입력하세요")
```

> **확인해보자냥 (빈칸 힌트)**
> - 오류가 날 수 있는 코드를 감싸는 블록과, 오류가 났을 때 실행할 블록이다냥.
> - 15를 넣으면 정상 동작하냥?
> - "hello" 를 넣으면 이번엔 **죽지 않고** 안내 문구가 나오냥?

</MissionCard>
