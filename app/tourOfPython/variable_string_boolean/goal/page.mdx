## 1단계 · 변수 만들기 (8분)

```python
a = 2
b = 3
c = a + b
print(c)   # 5
```

<Callout type="important">
  **코드는 위에서 아래로 실행된다냥.** 이게 결과에 아주 큰 영향을
  준다냥!

  ```python
  a = 2
  b = 3
  c = a + b   # 여기서 c 는 5로 정해진다
  a = 3       # a 를 바꿔도
  print(c)    # c 는 그대로 5
  ```

  `a = 3` 을 `c = a + b` **위로** 옮기면 결과가 6으로 바뀐다냥.
  직접 해보자냥!
</Callout>

## 2단계 · 변수 이름 짓는 규칙 (7분)

```python
my age = 30    # 불가능 — 공백이 있으면 안 됨
my_age = 30    # 가능 — 공백 대신 밑줄
10_age = 20    # 불가능 — 숫자가 앞에 오면 안 됨
age_10 = 10    # 가능 — 숫자가 뒤는 괜찮음
@age_10 = 10   # 불가능 — 특수문자는 안 됨
```

<StepCard step="핵심" title="변수 이름 규칙">

| 규칙 | 예시 |
|---|---|
| 공백 대신 밑줄 `_` | `my_age` |
| 숫자로 시작하면 안 됨 | `age_10` 은 가능 |
| 특수문자 안 됨 | `@`, `#` 등 |

</StepCard>

<Callout type="note">
  밑줄로 단어를 잇는 방식을 **snake_case** 라고 한다냥. 뱀처럼
  낮게 이어진 모양이라서 그렇게 부른다냥. `myAge` 라고 써도 오류는
  안 나지만, 파이썬 개발자들끼리의 **약속**이라 지켜주면 좋다냥!
</Callout>

## 3단계 · 문자열 — 따옴표가 핵심 (9분)

```python
food = apple    # 오류!
```

<NyangSpeech>
  이렇게 쓰면 `NameError: name 'apple' is not defined` 라는 오류가
  난다냥. 파이썬이 `apple` 을 **변수 이름**으로 착각한 거다냥!
</NyangSpeech>

![NameError 오류 메시지](https://r2.kimkyungsub.com/NameError.png)

```python
food = "apple"   # 따옴표로 감싸면 문자열
print(food)
```

<Callout type="tip">
  **오류 메시지는 개발자를 도와주는 도구다냥.** 오류가 났다고 실력이
  없는 게 아니다냥! 메시지를 읽어보면 "apple이 정의되지 않았다"고
  친절하게 알려주고 있다냥.
</Callout>

## 4단계 · 불리언 — 참과 거짓 (6분)

```python
dead = False
dead = false     # 오류! 첫 글자는 대문자다냥
dead = "False"   # 오류는 아니지만 문자열이다냥!
```

<Callout type="important">
  불리언은 **참(True) 혹은 거짓(False)** 두 가지뿐인 값이다냥.
  게임에서 죽었는지 살았는지 같은 상태를 표현할 때 쓴다냥.

  주의할 점 두 가지다냥 — **첫 글자는 반드시 대문자**, 그리고
  **따옴표로 감싸면 문자열이 되어버린다냥!**
</Callout>
