<MissionCard number={2} title="input 과 int 로 계산기 만들기" time="8~10분">

빈칸(`____`)을 채워서 두 숫자를 더하는 계산기를 만들어보자냥.

```python
a = ____(input("첫 번째 숫자: "))
b = ____(input("두 번째 숫자: "))

print(a + b)
```

> **확인해보자냥 (빈칸 힌트)**
> - `input()` 은 언제나 **문자열**을 준다냥. 숫자로 더하려면 무엇으로 감싸야 하냥?
> - 빈칸을 지우고 그냥 실행해보자냥. 12와 3을 넣으면 15가 아니라 `123` 이 나온다냥!
> - 소수점까지 계산하고 싶으면 `int` 대신 무엇을 쓰면 되냥?

</MissionCard>

<MissionCard number={3} title="len, max, min 써보기" time="8~10분">

미리 만들어진 도구로 리스트를 살펴보자냥.

```python
numbers = [4, 8, 2, 9, 5]

print(____(numbers))     # 가장 작은 값
print(____(numbers))     # 가장 큰 값
print(____(numbers))     # 값이 몇 개인지

이름 = input("이름을 입력하세요: ")
print(____(이름))        # 이름이 몇 글자인지
```

> **확인해보자냥 (빈칸 힌트)**
> - 가장 작은 값은 `min`, 가장 큰 값은 `max`, 개수와 길이는 둘 다 `len` 이다냥.
> - 차례대로 2, 9, 5 가 나오냥?
> - `len` 은 리스트의 **개수**도, 문자열의 **글자 수**도 알려준다냥!

</MissionCard>

<MissionCard number={4} title="random 으로 주사위 만들기" time="10~12분">

이제 표준 라이브러리를 가져와서 진짜 주사위를 만들어보자냥.

```python
____ random

def roll():
    return random.____(1, 6)

print(roll())
print(roll())
print(roll())
```

> **확인해보자냥 (빈칸 힌트)**
> - 라이브러리를 가져오는 키워드는 `import` 다냥.
> - 정해진 범위에서 정수를 뽑아주는 함수는 `randint` 다냥.
> - `randint(1, 6)` 은 1과 6을 **둘 다 포함한다냥.** `range` 와 다르니 헷갈리지 말자냥!
> - 실행할 때마다 숫자가 달라지냥? 달라지지 않으면 뭔가 잘못된 거다냥.

</MissionCard>
