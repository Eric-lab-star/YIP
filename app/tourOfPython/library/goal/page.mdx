## 1단계 · input — 키보드로 입력받기 (8분)

지금까지 계속 써 온 `input` 이 대표적인 내장함수다냥. 공식 문서를
읽어보면 `input(prompt, /)` 라고 나와 있다냥. 여기서 `prompt` 는
**입력 안내 문구**가 들어가는 자리다냥.

```python
name = input("what is your name ")
```

"what is your name " 이라는 문구를 먼저 보여줘서, 무엇을 입력해야
하는지 알려주고 있다냥.

<StepCard step="핵심" title="input 에 대해 꼭 기억할 세 가지">

| 번호 | 기억할 것 |
|---|---|
| 1 | 괄호 안의 글자는 **안내 문구**일 뿐, 입력값이 아니다 |
| 2 | 엔터를 눌러도 **줄바꿈 기호는 저장되지 않는다** |
| 3 | 저장되는 값은 **언제나 문자열**이다 |

</StepCard>

<Callout type="important">
  3번이 가장 중요하다냥! 나이를 입력받아도 그건 숫자가 아니라
  글자 "12" 다냥. 그래서 계산을 하려면 반드시 형을 바꿔줘야 한다냥.
</Callout>

## 2단계 · int, float — 형 바꾸기 (6분)

```python
age = int("12")
pi = float("3.14")
```

`int` 는 문자열 "12"를 정수 12로, `float` 은 문자열 "3.14"를 실수
3.14로 바꿔준다냥.

## 3단계 · len — 길이 재기 (5분)

```python
len("hello")
```

`len` 을 쓰면 문자열의 **길이**를 알 수 있다냥. "hello" 는 다섯
글자니까 5가 나온다냥. 리스트에 쓰면 담긴 값의 **개수**를 알려준다냥.

---

## 4단계 · range — 숫자 범위 만들기 (6분)

```python
for i in range(5):
    print(i)
```

`range` 는 `for` 반복문에서 **범위를 만들어주는** 역할을 한다냥.
`range(5)` 는 0, 1, 2, 3, 4 를 뜻하고 **5는 포함하지 않는다냥.**

<Callout type="tip">
  지난 시간 반복문에서 이미 만난 친구다냥! 끝 숫자를 포함하지
  않는다는 규칙만 기억하면 된다냥.
</Callout>

---

## 5단계 · max, min — 가장 큰 값, 가장 작은 값 (5분)

```python
big = max(3, 10, 7)
small = min(5, 2, 9)
print(big)    # 10
print(small)  # 2
```

`max` 는 가장 큰 값을, `min` 은 가장 작은 값을 찾아준다냥. 값을
여러 개 나열해도 되고, 리스트를 통째로 넣어도 된다냥.

## 6단계 · 표준 라이브러리 가져오기 (10분)

<NyangSpeech>
  표준 라이브러리도 파이썬을 설치할 때 함께 깔린다냥. 그런데
  내장함수와 다른 점이 하나 있다냥. 종류가 **너무너무 많아서**
  필요한 것만 골라서 꺼내 쓰도록 되어 있다냥. 도서관에서 읽고
  싶은 책만 뽑아오는 것과 똑같다냥!
</NyangSpeech>

[더 많은 표준 라이브러리 구경하기](https://docs.python.org/3/library/index.html)

종류가 너무 많고 다양해서 전부 외우지는 않는다냥. 하지만 **어떻게
꺼내오는지**는 알아둘 필요가 있다냥.

```python
import random

def get_rnd():
    return random.randint(0, 10)

def main():
    a = get_rnd()
    b = get_rnd()
    c = get_rnd()
    d = get_rnd()

    print(a, b, c, d)
```

<StepCard step="핵심" title="라이브러리 쓰는 두 단계">

| 순서 | 하는 일 | 코드 |
|---|---|---|
| 1 | 맨 위에서 가져온다 | `import random` |
| 2 | 이름 뒤에 점을 찍고 함수를 쓴다 | `random.randint(0, 10)` |

</StepCard>

`import` 를 써야 라이브러리를 가져올 수 있다냥. 가져온 다음에는
**라이브러리 이름 뒤에 점(`.`)** 을 붙여서 안에 있는 함수를 쓴다냥.
이 프로그램을 실행할 때마다 출력되는 숫자가 달라지는 걸 볼 수
있다냥!
