<MissionCard number={1} title="배너와 표 뼈대 만들기" time="12~15분">

먼저 앱의 얼굴인 표부터 만들어보자냥. 빈칸(`____`)을 채워보자냥.

```python
# main.py
heading = ["title", "state"]
todos = []
WIDTH = 100
INDEX_ROW_PADDING = 3
PADDING = (WIDTH - INDEX_ROW_PADDING) // ____(heading)   # heading 의 개수

def banner(message=""):
    print("=".center(WIDTH, "="))
    print(f"|{message.center(WIDTH - 2)}|")
    print("=".center(WIDTH, "="))

def header():
    banner("____")            # 위쪽 배너 문구

def footer():
    banner("You are Special")  # 아래쪽 배너 문구

banner("테스트")
```

> **확인해보자냥 (빈칸 힌트)**
> - 리스트의 개수를 세는 함수는 `len` 이다냥.
> - 위쪽 배너 문구는 `To-Do List` 로 해보자냥.
> - 실행하면 등호(`=`) 줄 사이에 문구가 가운데 정렬돼 나오냥?
> - 마지막 `banner("테스트")` 줄은 확인이 끝나면 지우자냥.

> **확인해보자냥 (빈칸 힌트)**
> - 목록이 비었다는 건 개수가 0 이하라는 뜻이다냥. `<=` 다냥.
> - 번호와 값을 함께 꺼내주는 건 `enumerate` 다냥.
> - 딕셔너리에서 상태를 꺼내는 이름표는 `state` 다냥.
> - 리스트 번호는 0부터지만 사람에게 보여줄 땐 1부터다냥. 그래서 `+ 1` 이다냥.
> - 빈 리스트 `[]` 를 넣으면 `No items` 가 나오냥?

<MissionCard number={3} title="추가·삭제·완료 표시 만들기" time="12~15분">

이제 데이터를 바꾸는 함수 네 개를 만들어보자냥.

```python

    return {"title": title, "____": "todo"}   # 처음 상태는 todo

def add_item(todos, item):
    todos.____(item)                          # 맨 뒤에 추가

def delete_item(todos, title):
    return [item for item in todos if item["title"] ____ title]

def mark_item(todos, title):
    for i, item in enumerate(todos):
        if item["title"] ____ title:
            todos[i]["state"] = "done" if item["state"] == "todo" else "todo"
            ____                              # 찾았으면 반복 끝내기
```

> **확인해보자냥 (빈칸 힌트)**
> - 상태를 담는 이름표는 `state` 다냥.
> - 리스트 맨 뒤에 붙이는 메소드는 `append` 다냥.
> - 삭제는 "제목이 **다른** 것만 남긴다"는 뜻이다냥. `!=` 다냥.
> - 찾을 때는 "제목이 **같은가**" 니까 `==` 다냥.
> - 이미 찾았으면 더 볼 필요가 없다냥. `break` 다냥.

<Callout type="tip">
  네 함수 모두 `print` 를 하나도 쓰지 않는다냥! 데이터를 바꾸는 함수는
  화면에 아무것도 찍지 않고, 보여주는 일은 `table` 에게 맡긴다냥.
  이게 역할을 나눈다는 뜻이다냥.
</Callout>

## 전체 코드 확인하기

<NyangSpeech>
  다 만들었으면 아래 완성본과 비교해보자냥. 내 코드와 조금 달라도
  앱이 잘 돌아간다면 그것도 정답이다냥!
</NyangSpeech>

```python
# main.py
import os

heading = ["title", "state"]
todos = []
WIDTH = 100
INDEX_ROW_PADDING = 3
PADDING = (WIDTH - INDEX_ROW_PADDING) // len(heading)

def banner(message=""):
    """
    앱을 실행할 때 나오는 멋있는 배너를 만드는 함수
    """
    print("=".center(WIDTH, "="))
    print(f"|{message.center(WIDTH - 2)}|")
    print("=".center(WIDTH, "="))

def show_list(todos):
    """
    format_item 함수를 이용해서 todo 리스트를 표 형태로 보여주는 함수
    """
    index = "n".center(INDEX_ROW_PADDING)
    title = "title".center(PADDING - 2)
    state = "state".center(PADDING - 1)

    print(f"|{index}|{title}|{state}|")  # table heading
    print("-".center(WIDTH, "-"))

    if len(todos) <= 0:
        print(f"|{'No items'.center(WIDTH - 2)}|")
    else:
        for i, item in enumerate(todos):
            format_item(i, item["title"], item["state"])

def format_item(index, title, state):
    """
    index, title, state를 받아서 표 형태로 보여주는 함수
    """
    n = str(index + 1).center(INDEX_ROW_PADDING)
    t = title[:PADDING - 2].center(PADDING - 2)
    s = state.center(PADDING - 1)
    row = f"|{n}|{t}|{s}|"
    print(row)

def header():
    """
    표의 헤더 부분을 보여주는 함수
    """
    banner("To-Do List")

def body(todos):
    """
    표의 바디 부분을 보여주는 함수
    """
    show_list(todos)

def footer():
    """
    표의 마지막 부분을 보여주는 함수
    """
    banner("You are Special")

def table(todos):
    header()
    body(todos)
    footer()


def clear():
    """
    터미널 화면을 지우는 함수
    """
    os.system("cls" if os.name == "nt" else "clear")

def create_item(title):
    """
    아이템을 생성하는 함수, title을 받아서 state는 "todo"로 초기화해서 딕셔너리 형태로 반환
    """
    return {"title": title, "state": "todo"}

def add_item(todos, item):
    """
    아이템을 리스트에 추가하는 함수
    """
    todos.append(item)

def delete_item(todos, title):
    """
    title과 일치하는 아이템을 제거하고 새로운 리스트를 반환
    """
    return [item for item in todos if item["title"] != title]

def mark_item(todos, title):
    """
    title과 일치하는 아이템의 state를 todo <-> done 으로 토글
    """
    for i, item in enumerate(todos):
        if item["title"] == title:
            todos[i]["state"] = "done" if item["state"] == "todo" else "todo"
            break

def parser(todos, prompt):
    """
    사용자의 입력을 명령어와 제목으로 분리해서 알맞은 함수를 호출하고 todos를 반환
    """
    prompt_list = prompt.strip().split(" ", 1)
    command = prompt_list[0]
    title = prompt_list[1] if len(prompt_list) > 1 else ""

    if command == "show":
        pass
    elif command == "add" and title != "":
        new_item = create_item(title)
        add_item(todos, new_item)
    elif command == "delete" and title != "":
        todos = delete_item(todos, title)
    elif command == "mark" and title != "":
        mark_item(todos, title)
    return todos

def main():
    """
    프로그램의 진입점. 무한 루프를 돌면서 명령어를 입력받아 todo 리스트를 갱신하고
    표 형태로 보여준다. Ctrl+C 로 종료할 때까지 계속 실행된다.
    """
    global todos
    try:
        while True:
            table(todos)
            prompt = input("""
todo commands:
add [todo]   : add new items to list.
delete [todo]: delete item from list.
mark [todo]  : mark item as done.
show         : show todo list items.\n""")
            todos = parser(todos, prompt)
            clear()
    except KeyboardInterrupt:
        print("\rbye".center(WIDTH, " "))

if __name__ == "__main__":
    main()
```
