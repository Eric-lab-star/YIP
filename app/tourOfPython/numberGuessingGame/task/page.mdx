> - 함수는 **만들기만 하면 실행되지 않는다냥.** 마지막 줄에서 `main()` 을 불러줘야 한다냥.

<MissionCard number={2} title="while 로 기회 3번 만들기" time="10~12분">

이제 게임이 반복되게 만들어보자냥. 기회는 3번이다냥.

```python
# main.py
def main():
    print("=====================")
    print("number guessing game")
    print("=====================")
    chances = ____          # 총 기회 수
    attempts = ____         # 지금까지 시도한 횟수
    while attempts ____ chances:
        input("guess my number: ")
        attempts ____ 1     # 시도할 때마다 1 늘리기
    else:
        print("you lose")

main()
```

> **확인해보자냥 (빈칸 힌트)**
> - 기회는 3번, 시도 횟수는 0부터 시작한다냥.
> - "시도 횟수가 기회보다 **작을 동안**" 반복해야 한다냥. `<` 냥, `<=` 냥?
> - 1씩 더하는 건 `+=` 다냥.
> - 아무 값이나 세 번 입력했을 때 `you lose` 가 나오냥?

<StepCard step="실험" title="attempts += 1 을 지워보자냥">

일부러 `attempts += 1` 줄을 지우고 실행해보자냥. 시도 횟수가 계속 0이라
조건이 영원히 참이 되고, 게임이 **끝나지 않는다냥!** 이걸 무한 루프라고
부른다냥. 확인했으면 다시 되돌려놓자냥.

</StepCard>

</MissionCard>

> **확인해보자냥 (빈칸 힌트)**
> - 라이브러리를 가져올 때는 `import` 다냥.
> - 정수 난수를 뽑는 함수는 `randint` 다냥.
> - 예외를 감시하는 블록은 `try`, 잡아내는 블록은 `except` 다냥.
> - `input()` 이 준 문자열을 숫자로 바꾸는 함수는 `int` 다냥.
> - 숫자를 넣지 않고 그냥 엔터를 눌러보자냥. 프로그램이 꺼지지 않고 안내 문구가 나오냥?

<MissionCard number={4} title="isCorrect 함수로 게임 완성하기" time="12~15분">

마지막이다냥! 정답을 판정하는 함수를 만들고, `main` 과 이어붙이면 게임이
완성된다냥.

```python
# main.py
def isCorrect(answer, user_input):
    if user_input ____ answer:
        print(f"{user_input} 보다 작은 수입니다.")
        return ____
    elif user_input ____ answer:
        print(f"{user_input} 보다 큰 수입니다.")
        return ____
    elif user_input ____ answer:
        print("정답입니다.")
        return ____
```

그리고 `main` 의 `while` 안을 이렇게 바꿔주자냥.

```python
        try:
            user_input = int(input("guess my number: "))
            if isCorrect(answer, user_input):
                ____              # 정답이면 반복을 끝내기
            else:
                attempts += 1     # 오답이면 시도 횟수 증가
        except ValueError:
            print("숫자를 입력하세요")
```

> **확인해보자냥 (빈칸 힌트)**
> - 입력값이 정답보다 **크면** 정답은 그보다 작은 수다냥. 부등호 방향을 잘 보자냥.
> - 정답일 때만 `True`, 나머지는 `False` 를 돌려준다냥.
> - 반복을 즉시 끝내는 명령은 `break` 다냥.
> - 정답을 맞혔을 때 `you lose` 가 같이 나오면 안 된다냥. 나온다면 `break` 자리를 다시 보자냥!

</MissionCard>

## 전체 코드 확인하기

<NyangSpeech>
  다 만들었으면 아래 완성본과 비교해보자냥. 내 코드와 다른 부분이 있어도
  게임이 잘 돌아간다면 그것도 정답이다냥!
</NyangSpeech>

```python
# main.py
import random

def isCorrect(answer, user_input):
    """
    사용자가 입력한 답과 정답을 비교하는 함수. 정답일 경우 True를 반환하고
    다른 모든 경우에는 False를 반환한다.
    """
    if user_input > answer:
        print(f"{user_input} 보다 작은 수입니다.")
        return False
    elif user_input < answer:
        print(f"{user_input} 보다 큰 수입니다.")
        return False
    elif user_input == answer:
        print("정답입니다.")
        return True

def main():
    """
    실제 게임 로직이 진행되는 함수
    """
    print("=====================")
    print("number guessing game")
    print("=====================")
    answer = random.randint(1, 11)
    chances = 3
    attempts = 0
    while attempts < chances:  # 루프 종료 조건
        try:  # int에서 발생하는 예외를 처리하기 위한 try 블록
            user_input = int(input("guess my number: "))  # input은 문자열을 반환하므로 int형으로 변경
            if isCorrect(answer, user_input):  # 정답 확인 코드
                break  # 정답이면 반복 중단
            else:
                attempts += 1  # 오답이면 시도 횟수 증가
        except ValueError:  # 예외 발생시 실행되는 블록
            print("숫자를 입력하세요")
    else:
        print("you lose")

main()
```
