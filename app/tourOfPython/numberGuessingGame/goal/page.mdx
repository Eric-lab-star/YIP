  의미는 확실하게 전달된다냥!
</Callout>

## 3단계 · while 로 기회를 세기 (10분)

<NyangSpeech>
  코드가 위에서 아래로 딱 한 번만 실행되면 게임이 될 수 없다냥.
  물어보고, 또 물어보고를 반복해야 한다냥. 그런데 **무한히** 반복되면
  안 되니까 끝나는 조건이 필요하다냥!
</NyangSpeech>

```python
# main.py
def main():
    print("=====================")
    print("number guessing game")
    print("=====================")
    chances = 3
    attempts = 0
    while attempts < chances:  # while 조건
        input("guess my number: ")
        attempts += 1
    else:  # while 조건이 거짓이 되었을 때만 실행됨
        print("you lose")

main()
```

<StepCard step="핵심" title="변수 두 개가 하는 일">

| 변수 | 뜻 |
|---|---|
| `chances` | 총 몇 번의 기회를 줄 것인가 (3) |
| `attempts` | 지금까지 몇 번 시도했는가 (0에서 시작) |

시도할 때마다 `attempts += 1` 로 1씩 늘어난다냥. `attempts` 가 3이
되는 순간 `attempts < chances` 가 거짓이 되어 반복이 끝난다냥.

</StepCard>

<Callout type="important">
  `while` 뒤에 붙은 `else` 는 **반복이 조건 때문에 끝났을 때만**
  실행된다냥. 그래서 기회를 다 쓰면 `print("you lose")` 가 나온다냥.
  나중에 배우겠지만 `break` 로 중간에 빠져나오면 이 `else` 는 실행되지
  않는다냥 — 정답을 맞혔을 때 "you lose" 가 안 나오는 이유다냥!
</Callout>

## 4단계 · 랜덤 숫자 만들기 (8분)

```python
# main.py
import random  # 라이브러리 가져오기

def main():
    print("=====================")
    print("number guessing game")
    print("=====================")
    answer = random.randint(1, 11)  # 난수 생성
    chances = 3
    attempts = 0
    while attempts < chances:
        user_input = int(input("guess my number: "))  # int형으로 바꾸기
        attempts += 1
    else:
        print("you lose")

main()
```

<Callout type="note">
  랜덤 숫자를 만들려면 `import random` 으로 라이브러리를 먼저
  가져온다냥. `random.randint(1, 11)` 은 1에서 10 사이의 숫자를
  하나 뽑아준다냥.

  그리고 `input()` 이 주는 값은 언제나 **문자열**이다냥. 숫자와
  비교하려면 `int()` 로 바꿔줘야 한다냥!
</Callout>

여기까지 만들고 실행한 다음, 숫자를 입력하지 않고 그냥 엔터를 눌러보면
이상한 메시지가 나오면서 프로그램이 꺼져버린다냥. 다음 단계에서 그걸
막아보자냥.

## 5단계 · 예외 처리로 프로그램 지키기 (8분)

<NyangSpeech>
  `int()` 는 문자열을 숫자로 바꿔주는 내장 함수다냥. 그런데
  "안녕" 같은 글자는 숫자로 바꿀 수가 없다냥. 이럴 때 파이썬은
  **예외**를 던지고, 아무도 안 받아주면 프로그램이 그대로 종료된다냥.
</NyangSpeech>

```python
# main.py
import random

def main():
    print("=====================")
    print("number guessing game")
    print("=====================")
    answer = random.randint(1, 11)
    chances = 3
    attempts = 0
    while attempts < chances:
        try:  # 예외를 잡는 블록
            user_input = int(input("guess my number: "))  # 여기서 예외가 날 수 있음
            attempts += 1
        except ValueError:  # ValueError 가 나면 여기가 실행됨
            print("Invalid input. Only numbers are allowed")
    else:
        print("you lose")

main()
```

<Callout type="important">
  예외를 잡아주는 코드가 `try...except` 다냥. `try` 안에서 예외가
  발생하면 코드의 흐름이 곧바로 `except` 로 넘어간다냥. `except`
  안에서 반복을 끝내지 않으면 다시 `while` 의 처음으로 돌아간다냥 —
  덕분에 잘못 입력해도 게임이 꺼지지 않는다냥!
</Callout>

## 6단계 · 정답 확인은 함수에게 맡기기 (10분)

정답을 확인하는 일은 `isCorrect` 라는 **따로 만든 함수**에게 맡길
거다냥. 맞으면 `True`, 틀리면 `False` 를 돌려주는 함수다냥.

```python
# main.py
def main():
    ...
    while attempts < chances:
        try:
            user_input = int(input("guess my number: "))
            if isCorrect(answer, user_input):  # 정답 확인
                break  # 정답이면 반복 중단
            else:
                attempts += 1  # 오답이면 시도 횟수 증가
        except ValueError:
            print("숫자를 입력하세요")
    else:
        print("you lose")
```

<Callout type="tip">
  모든 코드를 한곳에 몰아 쓰면 면발이 엉킨 것처럼 흐름을 알 수 없는
  코드가 된다냥. 이걸 **스파게티 코드**라고 부른다냥. 막는 방법은
  두 가지다냥 — **하나의 함수에는 한 가지 역할만**, 그리고 **길어지면
  함수로 나누기**다냥.

  [스파게티 코드 더 알아보기](https://namu.wiki/w/%EC%8A%A4%ED%8C%8C%EA%B2%8C%ED%8B%B0%20%EC%BD%94%EB%93%9C)
</Callout>

이제 `isCorrect` 함수 안을 채워보자냥. 크다, 작다, 같다 — 세 갈래니까
`if...elif` 가 딱 맞는다냥.

```python
# main.py
def isCorrect(answer, user_input):
    if user_input > answer:
        print(f"{user_input} 보다 작은 수입니다.")
        return False
    elif user_input < answer:
        print(f"{user_input} 보다 큰 수입니다.")
        return False
    elif user_input == answer:
        print("정답입니다.")
        return True
```

<Callout type="note">
  `isCorrect()` 는 `main` 함수 **밖** 어디에 써도 괜찮다냥. 다만
  `main()` 을 호출하는 줄보다는 **위쪽**에 있어야 한다냥 — 파이썬은
  위에서부터 읽기 때문에, 아직 배우지 않은 함수는 부를 수 없다냥!
</Callout>
