## 2단계 · 추가하고 바꾸고 지우기 (8분)

```python
person = {"이름": "Alice"}

person["나이"] = 15        # 없던 키 → 추가
person["이름"] = "Bob"     # 있던 키 → 값이 바뀜
del person["나이"]         # 키로 삭제
person.clear()             # 전부 비우기
```

<Callout type="important">
  같은 문법인데 결과가 다르다냥! **없던 키**에 넣으면 추가되고,
  **있던 키**에 넣으면 값이 덮어써진다냥. 실수로 기존 값을 지우지
  않게 조심하자냥.
</Callout>

## 3단계 · 키, 값, 짝으로 꺼내기 (10분)

<NyangSpeech>
  딕셔너리 전체를 훑고 싶을 때 쓰는 세 친구다냥. 무엇을 꺼내고
  싶은지에 따라 골라 쓰면 된다냥!
</NyangSpeech>

```python
scores = {"수학": 90, "영어": 85}

print(scores.keys())          # dict_keys(['수학', '영어'])
print(scores.values())        # dict_values([90, 85])
print(sum(scores.values()))   # 175

for subject, score in scores.items():
    print(subject, ":", score)
```

<StepCard step="핵심" title="셋 중 무엇을 쓸까">

| 하고 싶은 일 | 쓰는 것 |
|---|---|
| 과목 이름만 모으기 | `keys()` |
| 점수만 모아서 합계 내기 | `values()` |
| 과목과 점수를 함께 출력 | `items()` |

</StepCard>

## 4단계 · 없는 키를 안전하게 (8분)

```python
student = {"name": "Alice"}

print(student["grade"])              # 에러! 없는 키
print(student.get("grade"))          # None    ← 오류 없음
print(student.get("grade", "없음"))   # 없음    ← 기본값
print("name" in student)             # True
```

<Callout type="tip">
  대괄호로 꺼내면 없는 키일 때 프로그램이 멈춘다냥. `get()`은 대신
  `None`이나 정해둔 기본값을 돌려줘서 안전하다냥. 있는지 먼저
  확인하고 싶으면 `in`을 쓰면 된다냥!
</Callout>

`pop()`은 리스트에서와 똑같이 **지우면서 그 값을 돌려준다냥.**

```python
student = {"name": "Alice", "age": 20}
age = student.pop("age")
print(age)      # 20
print(student)  # {'name': 'Alice'}
```
