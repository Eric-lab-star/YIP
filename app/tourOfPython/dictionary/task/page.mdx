<StepCard step="확인" title="4번과 5번을 나란히 보자냥">

같은 "없는 키"인데 4번은 **에러**, 5번은 **0**이 나온다냥. 대괄호
`d["c"]` 는 없으면 멈추고, `d.get("c", 0)` 은 기본값을 돌려준다냥.
이 차이가 딕셔너리에서 가장 자주 만나는 함정이다냥!

</StepCard>

<MissionCard number={2} title="성적표 만들기" time="8~10분">

빈칸(`____`)을 채워서 코드를 완성해보자냥.

```python
scores = {"국어": 90, "영어": 80, "수학": 100}

scores["과학"] = ____          # 과학 85점 추가하기

합계 = sum(scores.____())      # 값만 모아서 더하기
평균 = 합계 / ____(scores)     # 과목 수로 나누기

print("합계:", 합계)
print("평균:", 평균)
```

> **확인해보자냥 (빈칸 힌트)**
> - 값만 모으는 건 `values()` 다냥.
> - 과목이 몇 개인지 세는 건 `len()` 이다냥.
> - 합계 355, 평균 88.75 가 나오냥?

</MissionCard>

<MissionCard number={3} title="편의점 재고 관리" time="10~12분">

`items()` 로 키와 값을 함께 꺼내보자냥.

```python
재고 = {"콜라": 5, "사이다": 0, "물": 12}

for 상품, 개수 in 재고.____():
    if 개수 == 0:
        print(상품, "품절!")
    else:
        print(상품, 개수, "개")

재고["콜라"] = 재고["콜라"] - ____   # 콜라 2개 판매
print(재고)
```

> **확인해보자냥 (빈칸 힌트)**
> - 키와 값을 짝으로 꺼내는 건 `items()` 다냥.
> - 2개를 팔았으니 빼는 값도 2 다냥.
> - "사이다 품절!" 이 나오고, 콜라가 3으로 바뀌냥?

</MissionCard>

<MissionCard number={4} title="단어 빈도 분석기" time="10~12분">

딕셔너리가 가장 빛나는 순간이다냥. 무엇이 몇 번 나왔는지 세어보자냥!

```python
words = ["사과", "바나나", "사과", "딸기", "사과", "바나나"]

세기 = {}
for w in words:
    세기[w] = 세기.____(w, 0) + 1

print(세기)
```

> **확인해보자냥 (빈칸 힌트)**
> - 처음 보는 단어는 아직 키가 없다냥. 그래서 `get(w, 0)` 으로 "없으면 0"부터 시작한다냥.
> - 대괄호로 꺼내면 첫 단어에서 바로 에러가 난다냥. 왜 그런지 생각해보자냥!
> - `{'사과': 3, '바나나': 2, '딸기': 1}` 이 나오냥?

</MissionCard>
