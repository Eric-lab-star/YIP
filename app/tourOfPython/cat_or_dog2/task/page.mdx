```python

    print(____"너에게 알맞는 {size} {color} {animal}는")
```

> **확인해보자냥 (빈칸 힌트)**

> - 출력이 "너에게 알맞는 소형 검정색 고양이는" 으로 나오냥?

<MissionCard number={2} title="동물부터 나누기" time="8~10분">

세 가지 정보 중 먼저 **동물**부터 갈라보자냥.

```python
def suggest(animal, color, size):
    print(f"너에게 알맞는 {size} {color} {animal}는")
    ____ animal == "고양이":
        print("고양이 선택")
    ____ animal == "강아지":
        print("강아지 선택")

suggest("강아지", "흰색", "대형")
```

> **확인해보자냥 (빈칸 힌트)**
> - 첫 갈래는 `if`, 그 다음 갈래는 `elif` 다냥.
> - "강아지 선택" 이 나오냥? `suggest("고양이", ...)` 로 바꾸면 "고양이 선택" 이 나오냥?
> - 문자열을 비교할 때는 등호를 **두 개** 쓴다냥. `=` 하나는 값을 넣는 거다냥!

</MissionCard>


> **확인해보자냥 (빈칸 힌트)**
> - 갈래가 시작될 때마다 첫 조건은 `if`, 다음부터는 `elif` 다냥.
> - 흰색 쪽과 강아지 쪽도 **같은 모양**으로 채워보자냥. 품종은 내가 아는 걸로 써도 된다냥!

<MissionCard number={4} title="전부 연결하고 실행하기" time="8~10분">

마지막으로 `start()` 안에서 `suggest()` 를 불러주고, 프로그램을
실행해보자냥.

```python
def start():
    print("반려견 또는 반려묘를 추천해 드려요.")
    animal = cat_or_dog()
    color = black_or_white()
    size = small_medium_large()
    ____(animal, color, size)

____
```

> **확인해보자냥 (빈칸 힌트)**
> - 모은 값 셋을 그대로 넘겨줄 함수 이름이 들어간다냥.
> - 맨 아랫줄에서 `start()` 를 불러야 프로그램이 돌아간다냥. 아무 일도 안 일어난다면 이걸 빠뜨린 거다냥!
> - "고양이 · 검정색 · 소형" 을 넣으면 봄베이가 나오냥?
> - 여섯 가지 조합을 골고루 넣어서 **전부 다 나오는지** 확인하자냥.

</MissionCard>
