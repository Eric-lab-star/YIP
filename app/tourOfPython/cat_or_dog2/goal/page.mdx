## 1단계 · 지난 시간 코드 이어받기 (5분)

지난 시간 마지막 부분에서 코드를 이어서 작성할 거다냥. 코드가
사라졌거나 기억이 안 난다면 아래 코드를 다시 입력하자냥.

```python
def start():
    print("반려견 또는 반려묘를 추천해 드려요.")
    animal = cat_or_dog()
    color = black_or_white()
    size = small_medium_large()

def cat_or_dog():
    cat_dog = input("고양이가 좋아 강아지가 좋아? \n 고양이 또는 강아지 입력: ").strip()
    if not (cat_dog == "고양이" or cat_dog == "강아지"):
        raise ValueError("오류!!!!!")
    return cat_dog

def black_or_white():
    color = input("검정색과 흰색중 하나를 입력하세요 \n 검정색 또는 흰색 입력: ").strip()
    if not (color == "검정색" or color == "흰색"):
        raise ValueError("오류!!!!!")
    return color

def small_medium_large():
    size = input("원하는 크기가 있어?: \n 소형 또는 중형 또는 대형 입력: ").strip()
    if not (size == "소형" or size == "중형" or size == "대형"):
        raise ValueError("오류!!!!")
    return size
```

<Callout type="note">
  우리의 목표는 고양이나 강아지를 추천해주는 거였다냥. 지금 우리가
  알고 있는 정보는 모두 3가지다냥.

  1. 고양이와 강아지 중 무엇을 원하는지
  2. 흰색과 검정색 중 어느 것을 원하는지
  3. 원하는 크기

  이제 모은 정보로 추천만 해주면 된다냥!
</Callout>

## 2단계 · f-string — 문장에 변수 넣기 (8분)

```python
def suggest(animal, color, size):
    print(f"너에게 알맞는 {size} {color} {animal}는")
```

`print` 안에 처음 보는 코드가 있다냥. 문자열 앞에 **f** 를 붙인
`f"너에게 알맞는 ..."` 말이다냥. 이건 문자열 안에 **변수를 넣을 수
있게** 만들어주는 코드다냥.

<Callout type="important">
  앞에 `f` 를 쓰면 중괄호로 감싼 부분은 글자가 아니라 **변수**로
  인식된다냥. 다시 말해 `{'{animal}'}` 부분은 함수가 실행될 때
  실제 값인 "고양이" 또는 "강아지" 로 바뀐다냥!
</Callout>

## 3단계 · 동물부터 나누기 (8분)

3가지 조건 중 우선 강아지와 고양이 중 무엇을 선택했는지 구별해야
한다냥. `if` 로 `animal` 값을 판별해주자냥.

```python
def suggest(animal, color, size):
    print(f"너에게 알맞는 {size} {color} {animal}는")
    if animal == "고양이":
        print("고양이 선택")
    elif animal == "강아지":
        print("강아지 선택")
```

## 4단계 · 색과 크기까지 중첩하기 (12분)

그 다음은 색을 판단한다냥.

```python
def suggest(animal, color, size):
    print(f"너에게 알맞는 {size} {color} {animal}는")
    if animal == "고양이":
        if color == "검정색":
            ...
        elif color == "흰색":
            ...
    elif animal == "강아지":
        if color == "검정색":
            ...
        elif color == "흰색":
            ...
```

<Callout type="tip">
  흑 또는 백, 고양이 또는 강아지. 단 두 가지 상황이라 `if..else` 를
  써도 문제는 없다냥. 그래도 `elif` 를 쓴 이유는 **의미를 분명하게**
  하고, 나중에 선택지를 늘릴 때 빠르고 편하게 고칠 수 있게 하기
  위해서다냥.
</Callout>

이제 마지막으로 크기를 판별해주면 된다냥.

```python
if color == "검정색":
    if size == "소형":
        print("1. 봄베이")
        print("2. 아메리칸 쇼트헤어")
        print("3. 코니시 렉스")
    elif size == "중형":
        print("1. 버미즈")
        print("2. 오리엔탈 쇼트헤어")
        print("3. 봄베이")
    elif size == "대형":
        print("1. 메인쿤")
        print("2. 브리티시 쇼트헤어")
        print("3. 차우시")
elif color == "흰색":
    if size == "소형":
        print("1. 봄베이")
        print("2. 아메리칸 쇼트헤어")
        print("3. 코니시 렉스")
    elif size == "중형":
        print("1. 버미즈")
        print("2. 오리엔탈 쇼트헤어")
        print("3. 봄베이")
    elif size == "대형":
        print("1. 메인쿤")
        print("2. 브리티시 쇼트헤어")
        print("3. 차우시")
```

크기를 판단하는 조건식을 넣고, 각각 알맞은 고양이 품종을 적어줬다냥.
같은 방식으로 강아지도 만들면 프로그램이 완성된다냥.

<StepCard step="구조" title="세 겹으로 좁혀 들어가는 모양">

```
동물          색            크기
고양이  ┬─ 검정색 ┬─ 소형 → 봄베이 ...
        │         ├─ 중형 → 버미즈 ...
        │         └─ 대형 → 메인쿤 ...
        └─ 흰색   ┬─ 소형 → ...
                  ├─ 중형 → ...
                  └─ 대형 → ...
강아지  ┬─ 검정색 → ...
        └─ 흰색   → ...
```

동물로 한 번, 색으로 한 번, 크기로 한 번. **세 번 좁히면** 딱 하나의
추천 목록에 도착한다냥!

</StepCard>
