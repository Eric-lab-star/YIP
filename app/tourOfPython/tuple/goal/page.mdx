# 튜플 tuple

<NyangSpeech>
  안녕, 나 코딩냥이다냥! 지난 시간에 배운 리스트 기억나냥? 오늘
  배울 튜플은 리스트와 아주 비슷하다냥. 여러 값을 묶어서 담는 것도
  똑같다냥. 딱 하나, **한 번 만들면 값을 바꿀 수 없다**는 점이
  다르다냥!
</NyangSpeech>

## 오늘의 학습 목표

<Callout type="goal">
  - 소괄호로 튜플을 만들고, 리스트와 무엇이 다른지 설명할 수 있다.
  - 번호와 슬라이싱으로 튜플의 값을 읽을 수 있다.
  - 언패킹으로 튜플의 값을 여러 변수에 나눠 담을 수 있다.
</Callout>

```python
student = ("Alice", 15, 95.5)

```

<Callout type="important">
  못 바꾸는 게 왜 좋냥? **바뀌면 안 되는 값**을 담을 때 안전하기
  때문이다냥. 생년월일이나 좌표처럼 도중에 실수로 바뀌면 곤란한
  값은 튜플에 담아두면 파이썬이 대신 지켜준다냥!
</Callout>

## 2단계 · 값 읽기 (7분)

<NyangSpeech>
  읽는 방법은 리스트와 완전히 똑같다냥. 번호는 0부터, 음수는 뒤에서
  부터, 슬라이싱도 그대로 된다냥!
</NyangSpeech>

```python
movie = ("인터스텔라", 2014, "SF")

print(movie[0])    # 인터스텔라   ← 0번부터
print(movie[-1])   # SF          ← 뒤에서 첫 번째
print(movie[0:2])  # ('인터스텔라', 2014)
```

<StepCard step="핵심" title="리스트에서 되는 것 중 튜플에서 되는 것">

| 하는 일 | 리스트 | 튜플 |
|---|---|---|
| 번호로 읽기 | 가능 | 가능 |
| 슬라이싱 | 가능 | 가능 |
| `len()` 세기 | 가능 | 가능 |
| `+`, `*` | 가능 | 가능 |
| **값 바꾸기** | 가능 | **불가능** |
| `append`, `remove` | 가능 | **없음** |

</StepCard>

## 3단계 · 더하기, 곱하기, 길이 (7분)

```python
tuple1 = ("사과", "바나나")
tuple2 = ("딸기", "포도")
print(tuple1 + tuple2)   # ('사과', '바나나', '딸기', '포도')

stamp = ("안녕", "반가워")
print(stamp * 3)         # 내용이 3번 반복

drawer = ("양말", "속옷", "티셔츠", "바지")
print(len(drawer))       # 4
```

<Callout type="tip">
  `+`로 이어붙여도 원래 튜플은 그대로 남고 **새 튜플**이 만들어진다냥.
  튜플은 못 바꾸니까, 바꾸는 대신 새로 만드는 거다냥!
</Callout>

## 4단계 · 언패킹 (8분)

<NyangSpeech>
  튜플의 진짜 매력은 여기다냥. 값을 한 번에 여러 변수로 나눠 담을
  수 있다냥. 이걸 **언패킹**이라고 부른다냥 — 상자를 풀어 정리하는
  느낌이다냥!
</NyangSpeech>

```python
student = ("Alice", 15, 95.5)

name, age, score = student
print(name)   # Alice
print(age)    # 15
print(score)  # 95.5
```

<Callout type="note">
  왼쪽 변수 개수와 튜플의 값 개수가 **똑같아야** 한다냥. 개수가
  다르면 에러가 난다냥!
</Callout>
