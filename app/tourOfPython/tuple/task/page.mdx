<MissionCard number={2} title="읽고 언패킹하기" time="8~10분">

빈칸(`____`)을 채워서 코드를 완성해보자냥.

```python
info = ("김철수", 15, "대전")

print(info[____])        # 대전 만 출력하기
print(len(____))         # 값이 몇 개인지

name, age, city = ____   # 세 변수에 나눠 담기
print(name, age, city)
```

> **확인해보자냥 (빈칸 힌트)**
> - 대전은 맨 뒤다냥. `2` 또는 `-1` 둘 다 된다냥.
> - 개수를 셀 대상은 튜플 자신이다냥.
> - 언패킹은 오른쪽에 튜플을 그대로 놓으면 된다냥.
> - 변수 개수와 값 개수가 다르면 에러가 난다냥. 3개씩 맞냥?

</MissionCard>

<MissionCard number={3} title="좌표 거리 계산기" time="10~12분">

좌표처럼 **바뀌면 안 되는 값**이야말로 튜플이 어울린다냥.

```python
a = (1, 2)
b = (4, 6)

x1, y1 = ____
x2, y2 = ____

거리 = ((x2 - x1) ** 2 + (y2 - y1) ** 2) ** 0.5
print("거리:", 거리)
```

> **확인해보자냥 (빈칸 힌트)**
> - 각각 `a`, `b`를 언패킹하면 된다냥.
> - `** 0.5` 는 제곱근이라는 뜻이다냥.
> - 거리가 5.0 으로 나오냥?

</MissionCard>

<MissionCard number={4} title="카페 주문 영수증" time="10~12분">

튜플을 리스트에 담아서, 주문 내역을 정리해보자냥.

```python
주문 = [("아메리카노", 4000), ("케이크", 6500), ("라떼", 4500)]

총액 = 0
for 이름, 가격 in 주문:
    print(이름, 가격)
    총액 = 총액 + ____

print("총액:", 총액)
```

> **확인해보자냥 (빈칸 힌트)**
> - 반복문이 튜플을 자동으로 언패킹해준다냥. 그래서 `이름`, `가격`을 바로 쓸 수 있다냥!
> - 더할 값은 `가격` 이다냥.
> - 총액이 15000 으로 나오냥?

</MissionCard>
