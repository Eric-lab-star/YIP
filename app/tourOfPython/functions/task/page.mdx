<MissionCard number={2} title="매개변수 없는 함수 만들기" time="8~10분">

가장 기본이 되는 함수 세 개를 손으로 써보자냥.

```python
def say_hello():
    print("안녕하세요.")

def box():
    print("""
┌──────────────────┐
│                  │
│                  │
└──────────────────┘
    """)

def love_me():
    print(" ❤️ " * 10)

say_hello()
box()
love_me()
```

> **확인해보자냥**
> - 세 함수를 다 쓴 뒤, 아래에서 **괄호를 붙여** 하나씩 실행해보자냥.
> - 괄호를 빼고 `say_hello` 라고만 쓰면 어떻게 되냥? 직접 해보자냥!
> - 하트가 10개 나오냥?

</MissionCard>

<MissionCard number={3} title="매개변수가 있는 함수" time="10~12분">

빈칸(`____`)을 채워서 값을 받는 함수를 완성해보자냥.

```python
def add(____, ____):
    print(x + y)

def greet(name):
    print(name + "님, 반갑습니다!")

add(3, 5)          # 8
greet(____)        # 내 이름을 넣어보자냥
```

> **확인해보자냥 (빈칸 힌트)**
> - `add` 안에서 `x` 와 `y` 를 쓰고 있으니, 매개변수 이름도 그렇게 맞춰야 한다냥.
> - `greet` 에 넣는 값은 문자열이니 따옴표를 잊지 말자냥.
> - `add(3)` 처럼 하나만 넣으면 어떻게 되냥? 에러 메시지를 읽어보자냥!

</MissionCard>

<MissionCard number={4} title="return 으로 값 돌려받기" time="10~12분">

`print` 하는 함수와 `return` 하는 함수의 차이를 직접 확인해보자냥.

```python
def add_print(x, y):
    print(x + y)

def add_return(x, y):
    ____ x + y

a = add_print(3, 5)
b = add_return(3, 5)

print("a:", a)
print("b:", b)
```

> **확인해보자냥 (빈칸 힌트)**
> - 값을 돌려주는 명령은 `return` 이다냥.
> - `a` 에는 무엇이 담기냥? `None` 이 나올 텐데 왜 그런지 생각해보자냥!
> - `print` 는 보여주기만 하고 돌려주지 않는다냥. 그래서 담을 값이 없다냥.

</MissionCard>
