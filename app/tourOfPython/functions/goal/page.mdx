## 1단계 · 함수 만들기 (8분)

```python
def game_over():
    print("You are dead. Game over")

game_over()
```

<StepCard step="핵심" title="함수를 만드는 순서">

| 순서 | 하는 일 |
|---|---|
| 1 | `def` 를 쓴다 (define, "정의하다") |
| 2 | 한 칸 띄우고 함수 이름을 쓴다 |
| 3 | `():` 를 쓴다 |
| 4 | 다음 줄에서 **탭을 한 번** 누른다 |
| 5 | 실행될 코드를 쓴다 |

</StepCard>

<Callout type="important">
  함수를 **실행**하려면 이름 뒤에 괄호 `()` 가 반드시 있어야 한다냥.
  `game_over` 라고만 쓰면 실행되지 않는다냥 — 믹서기를 쳐다보기만
  한 셈이다냥!
</Callout>

자주 하는 실수 세 가지다냥.

```python
get_time():          # 1. def 로 시작하지 않음
    print(14)

def say_name()       # 2. 콜론이 없음
    print("rina")

def say_hello():     # 3. 바디에 공백이 없음
print("hello")
```

## 3단계 · 함수의 몸체 (8분)

<NyangSpeech>
  믹서기의 안과 밖은 플라스틱으로 나뉘지냥? 파이썬에서 함수의 안과
  밖은 **공백**으로 나뉜다냥. 파이썬은 공백에 아주 민감한 언어다냥!
</NyangSpeech>

```python
def mixer():
    print("start")   # 공백이 있으니 함수 안

print("end")         # 공백이 없으니 함수 밖
```

<Callout type="tip">
  함수 바디에 아무것도 넣고 싶지 않을 때는 `pass` 를 넣으면 된다냥.
  "지금은 비워둘게" 라고 알려주는 표시다냥 — 비워두면 오류가 나기
  때문이다냥.
</Callout>

## 4단계 · 매개변수와 인수 (9분)

```python
def plus_one(number):   # number = 매개변수 (parameter)
    print(number + 1)

plus_one(5)             # 5 = 인수 (argument)
```

<StepCard step="비교" title="매개변수 vs 인수">

| 용어 | 어디에 있냥 | 무엇이냥 |
|---|---|---|
| 매개변수 parameter | 함수를 **만들 때** 괄호 안 | 값을 받을 빈 자리 |
| 인수 argument | 함수를 **부를 때** 괄호 안 | 실제로 넣는 값 |

</StepCard>

<Callout type="note">
  매개변수 이름은 자유롭게 지어도 된다냥. `number` 대신 `num`, `x`,
  `y` 무엇이든 좋다냥. 믹서기에 "넣는 구멍" 이름을 뭐라고 부르든
  상관없는 것과 같다냥!
</Callout>

## 5단계 · return — 값을 돌려주기 (8분)

```python
def add_two(x):
    return x + 2

결과 = add_two(5)
print(결과)   # 7
```

<Callout type="important">
  `print` 는 화면에 **보여주기만** 하고, `return` 은 값을 **돌려줘서
  다시 쓸 수 있게** 한다냥. 믹서기가 주스를 컵에 담아주는 게
  `return` 이다냥!

  그리고 `return` 은 함수를 **끝내는** 역할도 한다냥. `return` 뒤에
  오는 코드는 실행되지 않는다냥.
</Callout>
