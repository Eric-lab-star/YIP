<MissionCard number={1} title="미성년자 판별하기" time="8~10분">

빈칸(`____`)을 채워서 완성해보자냥.

```python
age = ____(input("나이를 입력하세요: "))

if age ____ 19:
    print("당신은 미성년자입니다.")
____:
    print("당신은 어른입니다.")
```

> **확인해보자냥 (빈칸 힌트)**
> - `input()` 은 언제나 **문자열**을 준다냥. 숫자로 비교하려면 `int()` 로 바꿔야 한다냥.
> - 19세 **미만**이 미성년자다냥. `<` 와 `<=` 중 무엇이 맞냥?
> - 19를 넣었을 때 "어른"이 나오냥? 안 나온다면 부등호를 다시 보자냥!

</MissionCard>

<MissionCard number={2} title="성적 등급 매기기" time="10~12분">

`elif` 로 네 갈래를 나눠보자냥.

```python
score = int(input("점수를 입력하세요: "))

if score >= 90:
    print("A")
____ score >= 80:
    print("B")
____ score >= 70:
    print("C")
____:
    print("D")
```

> **확인해보자냥 (빈칸 힌트)**
> - 중간 갈래는 `elif`, 마지막은 `else` 다냥.
> - 85점을 넣으면 B가 나오냥? 65점은 D가 나오냥?

<StepCard step="실험" title="순서를 일부러 뒤집어보자냥">

`if score >= 70` 을 맨 위로 올리고 95점을 넣어보자냥. **C가 나온다냥!**
위에서부터 검사해서 참을 만나면 끝나기 때문이다냥. 직접 해보고 왜
그런지 설명해보자냥.

</StepCard>

</MissionCard>

<MissionCard number={3} title="두 조건 함께 걸기" time="8~10분">

조건은 하나만 걸 수 있는 게 아니다냥.

```python
temp = int(input("기온을 입력하세요: "))

if temp >= 28:
    print("덥다냥! 반팔을 입자냥")
elif temp >= 15:
    print("선선하다냥")
elif temp >= 5:
    print("쌀쌀하다냥. 겉옷을 챙기자냥")
else:
    print("____")
```

> **확인해보자냥 (빈칸 힌트)**
> - 5도 미만일 때 나올 말을 직접 지어보자냥.
> - 30, 20, 10, 0 을 차례로 넣어서 네 갈래가 모두 나오는지 확인하자냥.

</MissionCard>

<MissionCard number={4} title="자유 주제 — 나만의 판별 프로그램" time="12~15분">

이제 배운 걸 모아서 **직접 기획한 프로그램**을 만들어보자냥!

**통과 조건**

1. `if..elif..else` 조건문을 사용할 것
2. `input()` 으로 사용자에게 값을 받을 것

**주제가 떠오르지 않는다면**

- 단어 맞추기
- 수학 퀴즈
- 아주 간단한 MBTI 검사
- 오늘 저녁 메뉴 추천
- 키와 몸무게로 알려주는 건강 신호등

```python
# 여기에 나만의 프로그램을 만들어보자냥
답 = input("질문을 여기에 쓰자냥: ")

if 답 == "":
    print("")
elif 답 == "":
    print("")
else:
    print("")
```

> **확인해보자냥**
> - 조건을 만족하는 입력과 만족하지 않는 입력을 **둘 다** 넣어보자냥.
> - 어떤 입력을 넣어도 프로그램이 멈추지 않고 뭔가 답하냥?

</MissionCard>
