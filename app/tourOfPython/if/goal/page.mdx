<NyangSpeech>

## 오늘의 학습 목표

<Callout type="goal">
  - `if` 로 조건이 참일 때만 실행되는 코드를 쓸 수 있다.
  - `else` 로 조건이 거짓일 때의 코드를 쓸 수 있다.
  - `elif` 로 여러 갈래를 나누고, 위에서부터 검사된다는 걸 안다.
</Callout>

---

## 1단계 · if — 참일 때만 (8분)

```python
if 조건:
    # 조건이 참일 때 실행될 코드
```

<StepCard step="핵심" title="if 문 쓰는 순서">

| 순서 | 하는 일 |
|---|---|
| 1 | `if` 를 쓴다 |
| 2 | 한 칸 띄우고 조건을 쓴다 |
| 3 | 조건 뒤에 `:` 콜론을 쓴다 |
| 4 | 다음 줄로 이동한다 |
| 5 | **들여쓰기**를 한다 |
| 6 | 참일 때 실행할 코드를 쓴다 |

</StepCard>

<Callout type="important">
  함수에서와 똑같다냥 — **콜론과 들여쓰기**가 핵심이다냥. 들여쓴
  줄까지가 "조건이 참일 때 실행할 코드"고, 들여쓰기를 풀면 조건과
  상관없이 항상 실행되는 코드가 된다냥!
</Callout>

## 2단계 · else — 거짓일 때 (8분)

<NyangSpeech>
  신분증 검사를 한다고 해보자냥. 19세 이상이면 어른, 미만이면
  미성년자다냥. 두 갈래로 나뉘지냥? 이럴 때 `else` 를 쓴다냥!
</NyangSpeech>

```python
if age < 19:
    print("당신은 미성년자입니다.")
else:
    print("당신은 어른입니다.")
```

<Callout type="tip">

</Callout>

## 3단계 · elif — 여러 갈래 (10분)

세상이 늘 두 갈래는 아니다냥. 성적을 A, B, C, D로 나누려면 `elif` 가
필요하다냥.

```python
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
else:
    print("D")
```

<Callout type="important">
  **위에서부터 검사하고, 참을 하나 만나면 거기서 끝난다냥.**

  점수가 95점이면 첫 번째 `if` 가 참이라 "A"를 출력하고, 아래
  `elif` 들은 **아예 보지도 않는다냥**. 그래서 조건을 쓰는 **순서가
  아주 중요하다냥!**
</Callout>

<StepCard step="주의" title="순서를 뒤집으면 어떻게 되냥">

```python
if score >= 70:
    print("C")
elif score >= 90:
    print("A")
```

95점을 넣어도 첫 줄이 이미 참이라 **"C"가 나온다냥.** 좁은 조건부터
넓은 조건 순으로 써야 한다냥!

</StepCard>
