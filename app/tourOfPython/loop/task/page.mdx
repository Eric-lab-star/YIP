<MissionCard number={1} title="while 로 1부터 10까지 세기" time="8~10분">

빈칸(`____`)을 채워서 1부터 10까지 출력해보자냥.

```python
n = ____
while n ____ 10:
    print(n)
    n = n ____ 1
```

> **확인해보자냥 (빈칸 힌트)**
> - 1부터 시작해야 하니까 처음 값은 1이다냥.
> - 10까지 **포함**해야 한다냥. `<` 와 `<=` 중 무엇이 맞냥?
> - 안쪽에서 `n` 을 1씩 늘려주지 않으면 무한루프가 된다냥!
> - 1부터 10까지 열 줄이 나오냥? 0이 나오면 안 된다냥.

</MissionCard>

<MissionCard number={2} title="for 로 같은 일 해보기" time="8~10분">

같은 결과를 `for ... in range()` 로도 만들어보자냥.

```python
for i in range(____, ____):
    print(i)
```

> **확인해보자냥 (빈칸 힌트)**
> - `range` 의 **끝 숫자는 포함되지 않는다냥.** 10을 출력하려면 끝에 뭘 넣어야 하냥?
> - 1번 미션과 출력이 똑같이 나오냥?

<StepCard step="비교" title="언제 while, 언제 for 냥">

몇 번 반복할지 **이미 알고 있으면** `for`, "언제 끝날지 해봐야 아는"
상황이면 `while` 이 편하다냥. 이번 문제는 10번인 걸 아니까 `for` 가
더 짧게 끝난다냥!

</StepCard>

</MissionCard>

<MissionCard number={3} title="1부터 100까지의 합 구하기" time="8~10분">

숫자를 출력만 하지 말고 **더해서 모아보자냥.**

```python
total = ____
for i in range(1, 101):
    total = total ____ i

print(total)
```

> **확인해보자냥 (빈칸 힌트)**
> - 더하기를 시작하기 전 `total` 은 0이어야 한다냥. 1로 두면 답이 1 커진다냥.
> - `total = total + i` 는 `total += i` 로 짧게 쓸 수도 있다냥.
> - 결과가 **5050** 으로 나오냥?

</MissionCard>

<MissionCard number={4} title="break 와 continue 로 흐름 조종하기" time="8~10분">

이번엔 반복을 멈추고, 건너뛰어보자냥.

```python
# (1) 씨앗을 심다가 금을 발견하면 즉시 멈추기
seeds = 10
gold = True

while seeds > 0:
    print("seed")
    seeds = seeds - 1
    if gold:
        ____        # 반복을 통째로 종료

# (2) 1부터 10까지 중 홀수만 출력하기
for i in range(1, 11):
    if i % 2 == ____:
        ____        # 이번 회차만 건너뛰기
    print(i)
```

> **확인해보자냥 (빈칸 힌트)**
> - 통째로 멈추는 건 `break`, 이번 회차만 건너뛰는 건 `continue` 다냥.
> - `i % 2` 는 2로 나눈 나머지다냥. **짝수**일 때 나머지가 몇이냥?
> - (1)에서 "seed"가 딱 한 번만 나오냥?
> - (2)에서 1, 3, 5, 7, 9 가 나오냥?

</MissionCard>

<MissionCard number={5} title="반복문으로 모래시계 그리기" time="10~12분">

아래 코드를 그대로 실행하면 **피라미드** 모양이 나온다냥.

```python
k = 1
while k < 6:
    print(f"{' . ' * k:░>19}", end="")
    print(f"{' . ' * k:░<19}", )
    k += 1
```

이제 이 피라미드를 **뒤집어 붙여서 모래시계 모양**이 나오게 코드를
고쳐보자냥.

> **확인해보자냥 (힌트)**
> - 반복문을 하나 더 붙여서, 두 번째는 `k` 를 **줄여가며** 돌리면 된다냥.
> - `while k > 0:` 과 `k -= 1` 을 떠올려보자냥.
> - 가운데가 뾰족하고 위아래가 넓은 모양이 나오냥?

</MissionCard>
