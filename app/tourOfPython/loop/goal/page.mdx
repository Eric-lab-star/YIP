파이썬에는 여러 종류가 있지만 오늘은 가장 많이 쓰는 두 가지,

## 2단계 · while — 조건이 참인 동안 (10분)

```python
count = 3
while count > 0:
    print(count)
    count = count - 1
if count == 0:
    print(" 🚀 로켓 발사!~~~~~")
```

`while` 다음에는 **조건**을 쓴다냥. 조건이 참이면 안쪽 코드를 실행하고,
다시 조건을 확인하러 올라간다냥. 조건이 거짓이 되면 그때 반복이
끝난다냥.

<StepCard step="핵심" title="위 코드를 한 줄씩 따라가보자냥">

| 회차 | `count` | `count > 0` | 하는 일 |
|---|---|---|---|
| 1 | 3 | 참 | 3 출력 → count를 2로 |
| 2 | 2 | 참 | 2 출력 → count를 1로 |
| 3 | 1 | 참 | 1 출력 → count를 0으로 |
| 4 | 0 | 거짓 | 반복 종료 |

</StepCard>

<Callout type="important">
  안쪽에서 `count` 를 줄여주는 줄이 **가장 중요하다냥.** 그 줄이
  없으면 조건이 영원히 참이라 반복이 절대 끝나지 않는다냥.
  `while` 을 쓸 때는 "이 조건이 언제 거짓이 되냥?" 을 꼭 확인하자냥!
</Callout>

## 3단계 · for ... in — 정해진 범위만큼 (10분)

```python
for i in range(0, 4):
    print(i)
```

두 번째로 배울 반복문은 `for ... in` 이다냥. `range()` 는 숫자의
**범위**를 만들어주는 도구다냥. `for i in range(0, 4)` 를 한국어로
읽으면 "0에서 4 사이의 값을 하나씩 i에 넣으면서" 라는 뜻이다냥.

<StepCard step="주의" title="range 의 끝 숫자는 포함되지 않는다냥">

| 코드 | 만들어지는 숫자 |
|---|---|
| `range(0, 4)` | 0, 1, 2, 3 |
| `range(5)` | 0, 1, 2, 3, 4 |
| `range(1, 11)` | 1, 2, 3, ... 10 |

끝 숫자는 **직전까지만** 간다냥. 리스트 슬라이싱과 같은 규칙이다냥!

</StepCard>

<Callout type="tip">
  횟수를 이미 알고 있으면 `for`, "언제 끝날지는 해봐야 아는" 상황이면
  `while` 이 편하다냥. 당근 256개는 `for`, "물이 떨어질 때까지"는
  `while` 이다냥!
</Callout>

## 4단계 · break — 도중에 멈추기 (8분)

<NyangSpeech>
  당근을 심다가 땅에서 금이 나오면 어떡하냥? 물이 다 떨어지면
  어떡하냥? 반복을 멈추고 다른 일을 해야 한다냥. 그럴 때 쓰는
  게 `break` 다냥!
</NyangSpeech>

```python
seeds = 10
gold = True

while seeds > 0:
    print("seed")
    seeds = seeds - 1
    if gold:
        break  # <--- 종료!
```

원래 "seed"가 10번 나와야 하지만, `gold` 가 참이라 **딱 한 번만**
출력되고 반복이 끝난다냥.

```python
for i in range(0, 3):
    if i == 1:
        break  # <-- 종료
    print(i)
```

`for` 에서도 똑같다냥. `i` 가 1이 되는 순간 반복이 통째로 멈춰서
0만 출력된다냥.

## 5단계 · continue — 이번 회차만 건너뛰기 (8분)

`continue` 는 **반복문의 처음으로 되돌아간다냥.** `break` 는 반복을
아예 끝내지만, `continue` 는 이번 회차만 끝내고 다음 회차로
넘어간다냥.

```python
a = 0
while a < 10:
    a += 1
    if a % 2 == 0:
        continue
    print(a)
```

`a % 2` 는 a를 2로 나눈 **나머지**다냥. 짝수면 0, 홀수면 1이 나온다냥.
그래서 짝수일 때만 `continue` 가 실행되어 `print` 를 건너뛴다냥.
결과는 1, 3, 5, 7, 9 다냥!

```python
for i in range(10):
    i += 1
    if i % 2 == 0:
        continue
    print(i)
```

같은 결과를 `for` 로도 만들 수 있다냥.

## 6단계 · 무한루프 (4분)

```python
while True:
    print("ping")
```

조건 자리에 그냥 `True` 를 넣으면 조건이 **영원히 참**이라 반복이
끝나지 않는다냥. 이런 걸 무한루프라고 부른다냥.

<Callout type="note">
  실수로 만들면 큰일이지만, 일부러 만들 때도 많다냥. 게임은
  "계속 화면을 그리고, 키 입력을 받고"를 끝없이 반복해야 하니까
  무한루프 안에서 돌아간다냥. 멈추고 싶을 땐 안에서 `break` 를
  쓰면 된다냥!
</Callout>
