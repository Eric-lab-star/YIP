## 1단계 · IDE를 쓰면 좋은 점 (7분)

<StepCard step="핵심" title="IDE가 대신 해주는 일 네 가지">

| 기능 | 무엇을 도와주냥 |
|---|---|
| 자동완성 | 앞 글자만 쳐도 나머지를 제안해준다 |
| 오류표시 | 실행하기 전에 잘못된 곳에 밑줄을 그어준다 |
| 색깔구분 | 명령어와 문자열을 다른 색으로 보여준다 |
| 바로실행 | 버튼 하나로 코드를 돌려본다 |

</StepCard>

<Callout type="note">
  메모장에 코드를 써도 파이썬은 돌아간다냥. 하지만 오타 하나를
  찾으려고 눈을 부릅뜨게 된다냥. IDE는 그걸 대신 찾아주는 도구다냥!
</Callout>

## 3단계 · VSCode로 코드 실행하기 (10분)

<NyangSpeech>
  이제 직접 해보자냥. 순서만 지키면 어렵지 않다냥!
</NyangSpeech>

<StepCard step="순서" title="첫 파이썬 파일 실행까지">

| 순서 | 하는 일 |
|---|---|
| 1 | 바탕화면에서 우클릭 → 새 폴더 만들기 |
| 2 | 폴더 이름을 알아보기 쉽게 바꾸기 |
| 3 | VSCode에서 그 폴더 열기 |
| 4 | `.py` 로 끝나는 파일 만들기 |
| 5 | 코드를 쓰고 실행 버튼 누르기 |

</StepCard>

![vscode에서 새 폴더 만들기](https://r2.kimkyungsub.com/vscode/vscode_howto1.png)

<Callout type="important">
  파일 이름은 반드시 **`.py`** 로 끝나야 한다냥. 파이썬에게 "이건
  파이썬 코드야" 라고 알려주는 표시다냥. `hello.txt` 로 만들면
  실행되지 않는다냥!
</Callout>
