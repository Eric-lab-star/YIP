<MissionCard number={1} title="작업 폴더 만들기" time="7~8분">

앞으로 만들 파일들을 담아둘 집을 만들어보자냥.

1. 바탕화면에서 마우스 **우클릭** → 새로 만들기 → 폴더
2. 폴더 이름을 `python_study` 로 바꾸기
3. VSCode를 열고 **파일 → 폴더 열기**로 방금 만든 폴더 선택하기

> **확인해보자냥**
> - VSCode 왼쪽에 `PYTHON_STUDY` 라고 폴더 이름이 보이냥?
> - 폴더 이름에 **띄어쓰기와 한글은 피하자냥.** 나중에 문제가 생길 수 있다냥!

</MissionCard>

---

<MissionCard number={2} title="첫 파이썬 파일 만들기" time="7~8분">

이제 코드를 담을 파일을 만들어보자냥.

1. 왼쪽 폴더 이름 옆의 **새 파일** 아이콘 누르기
2. 파일 이름을 `hello.py` 라고 정확히 입력하기
3. 아래 코드를 **직접 타이핑**해보기 (복사 붙여넣기 금지다냥!)

```python
print("hello world")
```

> **확인해보자냥**
> - 파일 이름 끝이 `.py` 가 맞냥? `.txt` 면 실행되지 않는다냥.
> - `print` 와 `"hello world"` 의 **색깔이 다르게** 보이냥? 그게 IDE의 색깔구분이다냥!

<StepCard step="확인" title="실행하는 방법">

오른쪽 위의 **실행 버튼(▶)** 을 누르거나, 터미널에 `python hello.py`
라고 입력하면 된다냥. 아래쪽 터미널 창에 `hello world` 가 나오면
성공이다냥!

</StepCard>

</MissionCard>

<MissionCard number={3} title="오류를 일부러 만들어보기" time="8~10분">

오류는 무서운 게 아니라 **알려주는 신호**다냥. 일부러 만들어보자냥!

```python
print("hello world"     # 닫는 괄호를 일부러 빼보자냥
```

> **확인해보자냥**
> - 실행하기 **전에** VSCode가 이미 빨간 밑줄을 그어주냥? 그게 오류표시 기능이다냥.
> - 실행하면 어떤 메시지가 나오냥? 영어로 나오지만 겁먹지 말고 읽어보자냥.
> - 괄호를 다시 닫으면 밑줄이 사라지냥?

</MissionCard>

<MissionCard number="도전" title="시간이 남는다면?" time="선택">

빠르게 끝낸 친구들을 위한 보너스 미션이다냥!

- [ ] VSCode 확장 프로그램에서 `Python` 을 검색해서 설치해보기
