<MissionCard number={3} title="잘못된 입력 막기" time="10~12분">

지금은 사용자가 "코끼리" 를 입력해도 그대로 통과된다냥. 지난 시간에

```python

    cat_dog = input("고양이가 좋아 강아지가 좋아?\n 고양이 또는 강아지 입력: ").____()

        ____ ValueError("오류!!!!!")

```

> **확인해보자냥 (빈칸 힌트)**
> - 앞뒤 공백을 지우는 메소드는 `.strip()` 이다냥.
> - 고양이일 때도 참, 강아지일 때도 참 → `or` 로 묶는다냥.
> - 묶은 조건을 뒤집어야 "둘 다 아닐 때" 가 된다냥. `not` 을 어디에 붙이냥?
> - 일부러 에러를 내는 명령어는 `raise` 다냥.
