<MissionCard number={3} title="RGB 색 계산기" time="8~10분">

빛의 3원색을 판별하는 함수다냥. 아래 함수를 **실행시켜서** "green" 이
출력되게 만들어보자냥.

```python
def rgb(r, g, b):
    if r == 1 and g == 1 and b == 1:
        print("white")
    elif r == 1 and g == 0 and b == 0:
        print("red")
    elif r == 0 and g == 1 and b == 0:
        print("green")
    elif r == 0 and g == 0 and b == 1:
        print("blue")
    else:
        print("mixed color")

rgb(____, ____, ____)
```

> **확인해보자냥 (빈칸 힌트)**
> - 초록불만 켜진 상태가 green 이다냥. `r`, `g`, `b` 를 각각 몇으로 둬야 하냥?
> - `rgb(1, 1, 0)` 도 넣어보자냥. 어떤 결과가 나오냥? 왜 그런지 설명해보자냥.
> - `rgb(1, 1, 1)` 은 white 가 나오냥?

<StepCard step="실험" title="and 를 빼면 어떻게 되냥">

`elif r == 1 and g == 0 and b == 0:` 를 `elif r == 1:` 로 바꾸고
`rgb(1, 1, 1)` 을 넣어보자냥. white 대신 무엇이 나오냥? `and` 가
왜 필요한지 눈으로 확인할 수 있다냥!

</StepCard>

</MissionCard>

<MissionCard number={4} title="or 와 not 써보기" time="8~10분">

빈칸(`____`)을 채워서 두 함수를 완성해보자냥.

```python
def rain_or_snow(rain, snow):
    if rain ____ snow:
        print("날씨가 좋지 않습니다.")
    else:
        print("날씨가 좋습니다.")

def not_loggedIn(loggedIn):
    if ____ loggedIn:
        print("please login")

rain_or_snow(False, True)
not_loggedIn(____)
```

> **확인해보자냥 (빈칸 힌트)**
> - 비 **또는** 눈이면 안 좋은 날씨다냥. and 냥 or 냥?
> - `not` 은 값을 뒤집는다냥. 로그인이 **안 된** 상태를 찾아야 한다냥.
> - `not_loggedIn(True)` 를 넣으면 아무것도 안 나온다냥. "please login" 이 나오게 하려면 뭘 넣어야 하냥?
> - `rain_or_snow(False, False)` 도 넣어보자냥. "날씨가 좋습니다." 가 나오냥?

</MissionCard>

<MissionCard number={5} title="놀이기구 탑승 판별기 만들기" time="10~12분">

이제 배운 걸 모아서 **직접** 만들어보자냥!

**통과 조건**

1. 나이가 14세 이상 **이고(and)** 키가 140 이상이면 "놀이기구 탑승 가능"
2. 그 밖에는 "탑승 불가"
3. `input()` 으로 나이와 키를 받을 것

```python
나이 = ____(input("나이를 입력하세요: "))
키 = ____(input("키를 입력하세요: "))

if 나이 >= ____ ____ 키 >= ____:
    print("놀이기구 탑승 가능")
else:
    print("탑승 불가")
```

> **확인해보자냥 (빈칸 힌트)**
> - `input()` 은 언제나 **문자열**을 준다냥. 숫자로 비교하려면 `int()` 로 바꿔야 한다냥.
> - 두 조건을 **모두** 만족해야 하니까 `and` 다냥.
> - 나이 14 · 키 140 을 넣으면 탑승 가능이 나오냥? (경계값을 꼭 확인하자냥!)
> - 나이 20 · 키 130 을 넣으면 탑승 불가가 나오냥?

</MissionCard>
