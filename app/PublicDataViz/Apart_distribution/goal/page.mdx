## 1단계 · 데이터 출처와 기본 통계 확인하기 (8분)

<Callout type="note">
  **이번 프로젝트 데이터 출처**

  - 제공처: 국토교통부 실거래가 공개시스템(rt.molit.go.kr) (예시)
  - 라이선스: 공공누리 제1유형 (출처 표시 시 자유 이용 가능)
  - 이 수업에서는 실제 파일 대신, **같은 구조를 가진 작은 예시 데이터**로 연습한다냥.
</Callout>

```python
import pandas as pd

data = {
    "단지명": ["행복아파트", "은빛아파트", "달빛아파트", "구름아파트", "별빛아파트"],
    "전용면적": [59.9, 84.3, 114.8, 59.9, 84.3],
    "거래금액": [65000, 92000, 128000, 68000, 95000],  # 단위: 만원
}
df = pd.DataFrame(data)

print(df["거래금액"].describe())
```

<Callout type="important">
  `describe()`는 개수(`count`), 평균(`mean`), 표준편차(`std`),
  최솟값(`min`), 중앙값(`50%`), 최댓값(`max`) 등을 **한 번에** 보여준다냥!
  데이터를 처음 받으면 가장 먼저 실행해보면 좋은 함수다냥.
</Callout>

```python
import seaborn as sns
import matplotlib.pyplot as plt

sns.set_theme(style="whitegrid")
plt.rcParams["font.family"] = "Malgun Gothic"

sns.histplot(data=df, x="거래금액", bins=5)
plt.title("아파트 거래금액 분포")
plt.xlabel("거래금액(만원)")
plt.ylabel("건수")
plt.show()
```

<Callout type="tip">
  `bins`은 가격 구간을 몇 개로 나눌지 정하는 옵션이다냥. `bins=5`면
  가장 낮은 가격부터 가장 높은 가격까지를 5개 구간으로 나눠서, 각
  구간에 몇 건이 있는지 막대로 보여준다냥!
</Callout>

## 3단계 · 가격대별 건수 세어보기 (7분)

<NyangSpeech>
  마지막으로, 조건 필터링을 활용해서 "저가/중가/고가" 아파트가
  각각 몇 건인지 직접 세어보자냥!
</NyangSpeech>

```python
저가 = df[df["거래금액"] < 70000]
중가 = df[(df["거래금액"] >= 70000) & (df["거래금액"] < 100000)]
고가 = df[df["거래금액"] >= 100000]

print(f"저가(7억 미만): {len(저가)}건")
print(f"중가(7억~10억): {len(중가)}건")
print(f"고가(10억 이상): {len(고가)}건")
```

<StepCard step="핵심" title="len()으로 행 개수 세기">

| 코드 | 하는 일 |
|---|---|
| `df[조건]` | 조건을 만족하는 행만 남긴 새 DataFrame |
| `len(df[조건])` | 그 DataFrame의 **행 개수**(건수) |

</StepCard>

<Callout type="note">
  `len()`은 파이썬 리스트의 길이를 셀 때도 쓰지만, DataFrame에
  쓰면 **행의 개수**를 알려준다냥! 조건 필터링과 함께 쓰면 "몇
  건이나 되는지"를 쉽게 셀 수 있다냥.
</Callout>
