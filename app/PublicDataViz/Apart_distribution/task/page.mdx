<MissionCard number={1} title="기본 통계 확인하기" time="7~8분">

거래금액의 기본 통계를 확인해보자냥! 아래 템플릿에서
**빈칸(`____`)을 채워보자냥.**

```python
import pandas as pd

data = {
    "단지명": ["행복아파트", "은빛아파트", "달빛아파트", "구름아파트", "별빛아파트"],
    "거래금액": [65000, 92000, 128000, 68000, 95000],
}
df = pd.DataFrame(data)

print(df["거래금액"].____())
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 평균, 중앙값 등을 한 번에 보여주는 함수 이름을 넣으면 된다냥. (`describe`)
> - count, mean, min, max 등이 함께 출력되냥?

</MissionCard>

import seaborn as sns

<MissionCard number={3} title="가격대별 건수 세기" time="8~10분">

저가/중가/고가 아파트가 각각 몇 건인지 세어보자냥.

```python
저가 = df[df["거래금액"] < 70000]
고가 = df[df["거래금액"] >= 100000]

print(f"저가(7억 미만): {____(저가)}건")
print(f"고가(10억 이상): {len(고가)}건")
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 행의 개수를 세는 함수 이름을 넣으면 된다냥. (`len`)
> - 저가 2건, 고가 1건으로 나오냥?

<StepCard step="확인" title="len(df[조건])의 순서를 기억하자냥!">

먼저 `df[조건]`으로 원하는 행만 걸러낸 다음, 그 결과를
`len()`으로 감싸서 개수를 센다냥. 순서를 바꾸면 에러가 난다냥!

</StepCard>
