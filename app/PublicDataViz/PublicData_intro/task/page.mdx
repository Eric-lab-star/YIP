<MissionCard number={3} title="데이터 검색해보기" time="8~10분">

이제 검색창에 관심 있는 주제를 검색해보자냥! 아래 활동지를 채우면서
탐험해보자냥.

```text
1. 검색창에 "지하철"을 검색해보세요.
   - 몇 건의 검색 결과가 나왔나요? ____________
   - 그중 눈에 띄는 데이터셋 이름 하나를 적어보세요: ____________

2. 검색창에 "미세먼지"를 검색해보세요.
   - 어떤 기관이 이 데이터를 제공하나요? ____________

3. 내가 관심 있는 주제 하나를 직접 검색해보세요 (예: 우리 동네, 반려동물, 축구 등).
   - 검색어: ____________
   - 찾은 데이터셋 이름: ____________
   - 이 데이터로 무엇을 알아낼 수 있을까요? ____________
```

> **확인해보자냥**
> - 데이터셋을 하나 클릭해서 "미리보기"나 "상세설명"까지 살펴봤냥?
> - 그 데이터가 "파일 데이터"인지 "오픈API"인지 확인했냥? (상세 페이지에
>   "다운로드" 버튼이 있으면 파일, "활용신청" 버튼이 있으면 API라냥!)

<StepCard step="관찰" title="파일 데이터 vs Open API, 구별하는 법">

데이터셋 상세 페이지에서 아래 버튼을 찾아보면 바로 구별할 수 있다냥.

| 보이는 버튼 | 데이터 종류 |
|---|---|
| **다운로드** | 파일 데이터 — 바로 CSV·엑셀을 받을 수 있다냥 |
| **활용신청** | Open API — 인증키를 신청해야 쓸 수 있다냥 |

</StepCard>

</MissionCard>
