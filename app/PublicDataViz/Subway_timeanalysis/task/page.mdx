<MissionCard number={1} title="melt로 세로로 펼치기" time="10~12분">

시간대별로 흩어진 열을 하나로 모아보자냥! 아래 템플릿에서
**빈칸(`____`)을 채워보자냥.**

```python
import pandas as pd

원본 = {
    "역명": ["강남", "역삼"],
    "07-08시_승차": [8200, 3100],
    "08-09시_승차": [15200, 6400],
    "18-19시_승차": [9800, 3900],
}
df = pd.DataFrame(원본)

길게 = pd.____(
    df,
    id_vars=["역명"],
    value_vars=["07-08시_승차", "08-09시_승차", "18-19시_승차"],
    var_name="시간대",
    value_name="승차인원",
)
print(길게)
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 넓은 형태를 긴 형태로 바꾸는 함수 이름을 넣으면 된다냥. (`melt`)
> - 결과가 6행(역 2개 × 시간대 3개)으로 나오냥?

</MissionCard>

<MissionCard number={2} title="시간대별 평균 구하기" time="8~10분">

groupby로 시간대별 평균 승차인원을 구해보자냥.

```python
시간대평균 = 길게.groupby(____)["승차인원"].mean()
print(시간대평균)
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 그룹으로 묶을 기준 열 이름을 넣으면 된다냥. (`"시간대"`)
> - 08-09시 평균이 가장 높게 나오냥?

</MissionCard>

<MissionCard number={3} title="가장 붐비는 시간대 찾기" time="8~10분">

이제 가장 혼잡한 시간대의 이름을 콕 집어보자냥.

```python
가장붐비는시간대 = 시간대평균.____()
print(f"가장 붐비는 시간대: {가장붐비는시간대}")
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 가장 큰 값을 가진 "이름"을 찾는 함수 이름을 넣으면 된다냥. (`idxmax`)
> - "08-09시_승차"가 출력되냥?

<StepCard step="확인" title="max()와 헷갈리지 말자냥!">

`시간대평균.max()`는 숫자(값)를 돌려주지만, `시간대평균.idxmax()`는
그 값을 가진 **시간대 이름**을 돌려준다냥. 둘 다 실행해서 차이를
비교해보자냥!

</StepCard>

</MissionCard>
