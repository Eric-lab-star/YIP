<MissionCard number={1} title="평형대 나누기" time="10~12분">

전용면적을 소형/중형/대형으로 나눠보자냥! 아래 템플릿에서
**빈칸(`____`)을 채워보자냥.**

```python
import pandas as pd

data = {
    "단지명": ["행복아파트", "은빛아파트", "달빛아파트", "구름아파트"],
    "지역": ["강남구", "강남구", "마포구", "마포구"],
    "전용면적": [59.9, 114.8, 59.9, 84.3],
    "거래금액": [92000, 155000, 68000, 78000],
}
df = pd.DataFrame(data)

df["평형대"] = pd.____(
    df["전용면적"],
    bins=[0, 60, 85, 200],
    labels=["소형", "중형", "대형"],
)
print(df)
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 숫자를 구간별로 나누는 함수 이름을 넣으면 된다냥. (`cut`)
> - 59.9는 "소형", 114.8은 "대형"으로 나오냥?

<MissionCard number={3} title="피벗 테이블 만들기" time="8~10분">

지역을 행, 평형대를 열로 하는 표를 만들어보자냥.

```python
표 = pd.pivot_table(
    df,
    values="거래금액",
    index="지역",
    columns=____,
    aggfunc="mean",
    observed=True,
)
print(표)
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 표의 가로(열) 기준이 될 열 이름을 문자열로 넣으면 된다냥. (`"평형대"`)
> - 지역이 행, 평형대가 열로 나온 표가 보이냥?

<StepCard step="확인" title="index=행, columns=열, 헷갈리지 말자냥!">

`index`는 표의 **세로(왼쪽)**에 나열될 기준이고, `columns`는
표의 **가로(위쪽)**에 나열될 기준이다냥.

</StepCard>
