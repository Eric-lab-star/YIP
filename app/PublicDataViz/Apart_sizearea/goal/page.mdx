## 1단계 · 전용면적을 평형대로 나누기 (10분)

<NyangSpeech>
  "59.9㎡", "84.3㎡"처럼 숫자로만 되어있으면 비교하기 번거롭다냥.
  "소형", "중형", "대형"처럼 **구간별 이름**으로 나눠보자냥!
</NyangSpeech>

```python
import pandas as pd

data = {
    "단지명": ["행복아파트", "은빛아파트", "달빛아파트", "구름아파트"],
    "지역": ["강남구", "강남구", "마포구", "마포구"],
    "전용면적": [59.9, 114.8, 59.9, 84.3],
    "거래금액": [92000, 155000, 68000, 78000],
}
df = pd.DataFrame(data)

df["평형대"] = pd.cut(
    df["전용면적"],
    bins=[0, 60, 85, 200],
    labels=["소형", "중형", "대형"],
)
print(df)
```

<Callout type="important">
  `pd.cut()`은 숫자를 **구간(bin)**으로 나눠서 이름표를 붙여준다냥.
  `bins=[0, 60, 85, 200]`은 "0~60, 60~85, 85~200" 세 구간을 뜻하고,
  `labels`로 각 구간의 이름을 정해준다냥!
</Callout>

## 2단계 · 두 가지 기준으로 그룹 묶기 (8분)

<NyangSpeech>

```python
지역평형평균 = df.groupby(["지역", "평형대"], observed=True)["거래금액"].mean()
print(지역평형평균)
```

<Callout type="tip">
  `observed=True`는 `pd.cut()`으로 만든 카테고리 중 **실제로
  데이터에 존재하는 조합만** 보여주는 옵션이다냥. 없으면 존재하지
  않는 조합까지 빈 줄로 나올 수 있다냥.
</Callout>

## 3단계 · pivot_table로 표 정리하기 (7분)

<NyangSpeech>
  groupby 결과는 세로로 길게 나와서 한눈에 비교하기 조금
  불편하다냥. `pivot_table()`을 쓰면, **지역을 행, 평형대를 열로**
  놓은 깔끔한 표를 만들 수 있다냥!
</NyangSpeech>

```python
표 = pd.pivot_table(
    df,
    values="거래금액",
    index="지역",
    columns="평형대",
    aggfunc="mean",
    observed=True,
)
print(표)
```

<StepCard step="핵심" title="pivot_table의 4가지 재료">

| 매개변수 | 뜻 |
|---|---|
| `values` | 계산할 값이 담긴 열 |
| `index` | 표의 세로(행) 기준 |
| `columns` | 표의 가로(열) 기준 |
| `aggfunc` | 어떤 통계를 계산할지("mean", "sum" 등) |

</StepCard>

<Callout type="note">
  `pivot_table()`은 엑셀의 "피벗 테이블"과 똑같은 역할을 한다냥!
  두 기준을 표의 가로/세로에 각각 배치해서, **한눈에 비교하기
  좋은 표**를 만들어준다냥.
</Callout>
