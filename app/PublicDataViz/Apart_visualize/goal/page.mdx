## 1단계 · 피벗 테이블을 히트맵으로 그리기 (10분)

<NyangSpeech>
  숫자로 가득한 표는 한눈에 비교하기 어렵다냥! **히트맵(heatmap)**은
  숫자 크기에 따라 색깔을 다르게 칠해줘서, 어디가 높고 낮은지 한눈에
  보여준다냥.
</NyangSpeech>

```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

plt.rcParams["font.family"] = "Malgun Gothic"

data = {
    "단지명": ["행복", "은빛", "달빛", "구름", "별빛", "하늘"],
    "지역": ["강남구", "강남구", "마포구", "마포구", "종로구", "종로구"],
    "평형대": ["소형", "대형", "소형", "중형", "소형", "중형"],
    "전용면적": [59.9, 114.8, 59.9, 84.3, 59.9, 84.3],
    "거래금액": [92000, 155000, 68000, 78000, 60000, 71000],
}
df = pd.DataFrame(data)

표 = pd.pivot_table(
    df, values="거래금액", index="지역", columns="평형대",
    aggfunc="mean", observed=True,
)

sns.heatmap(표, annot=True, fmt=".0f", cmap="YlOrRd")
plt.title("지역×평형대 평균 거래금액")
plt.show()
```

<Callout type="important">
  `annot=True`는 칸마다 **실제 숫자**를 함께 써준다냥. `cmap`은
  색깔 팔레트를 정하는 옵션인데, `"YlOrRd"`는 노랑에서 빨강으로
  갈수록 값이 커진다는 뜻이다냥. 진한 빨강일수록 가격이 높다는
  걸 색으로 바로 알 수 있다냥!
</Callout>

```python
import plotly.express as px

fig = px.scatter(
    df, x="전용면적", y="거래금액", color="지역",
    hover_data=["단지명"],
    title="전용면적과 거래금액의 관계",
)
fig.show()
```

<Callout type="tip">
  점들이 오른쪽 위로 올라가는 모양이면, 면적이 넓을수록 가격도
  비싸지는 **양의 상관관계**가 있다는 뜻이다냥! `color="지역"`을
  더하면, 지역마다 점 색깔도 다르게 나온다냥.
</Callout>

## 3단계 · 결론 정리하기 (6분)

<NyangSpeech>
  프로젝트 1에서처럼, 오늘도 분석 결과를 한 문장으로 정리하는
  습관을 잊지 말자냥!
</NyangSpeech>

```python
가장비싼조합 = 표.stack().idxmax()
print(f"결론: {가장비싼조합[0]} {가장비싼조합[1]} 아파트가 가장 비싸다.")
```

<StepCard step="핵심" title="stack()으로 표를 다시 세로로">

`pivot_table()`로 만든 표는 지역이 행, 평형대가 열인 **넓은
형태**다냥. `stack()`을 쓰면 다시 세로로 긴 형태가 되어서,
`idxmax()`로 "가장 비싼 지역-평형 조합"을 한 번에 찾을 수 있다냥!

</StepCard>

<Callout type="note">
  `stack()`은 프로젝트 1에서 배운 `melt()`와 비슷한 역할을 한다냥.
  둘 다 "넓은 표를 세로로 길게 만든다"는 목적은 같지만, `stack()`은
  피벗 테이블처럼 이미 표 형태인 데이터에 자주 쓰인다냥.
</Callout>
