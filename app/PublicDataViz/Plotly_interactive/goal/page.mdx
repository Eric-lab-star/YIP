## 1단계 · plotly로 막대 그래프 그리기 (10분)

<NyangSpeech>
  plotly는 보통 `plotly.express`를 `px`라는 이름으로 줄여서
  불러온다냥. 사용법은 seaborn과 비슷하다냥!
</NyangSpeech>

```python
import plotly.express as px
import pandas as pd

data = {
    "구": ["중구", "강남구", "종로구", "마포구"],
    "미세먼지": [30, 42, 25, 38],
}
df = pd.DataFrame(data)

fig = px.bar(df, x="구", y="미세먼지", title="구별 미세먼지 농도")
fig.show()
```

<Callout type="important">
  `fig.show()`로 그래프를 열면, matplotlib과 달리 **마우스를
  올렸을 때 정확한 값이 말풍선으로 뜨고**, 마우스 휠로 확대/축소도
  할 수 있다냥! 이게 바로 인터랙티브(interactive) 그래프다냥.
</Callout>

## 3단계 · hover_data로 정보 추가하기 (7분)

<NyangSpeech>
  마우스를 올렸을 때, 기본으로 보이는 값 말고 **다른 열의 정보도
  함께** 보여주고 싶을 땐 `hover_data`를 쓴다냥!
</NyangSpeech>

```python
data3 = {
    "구": ["중구", "강남구", "종로구", "마포구"],
    "미세먼지": [30, 42, 25, 38],
    "초미세먼지": [15, 21, 12, 18],
}
df3 = pd.DataFrame(data3)

fig3 = px.bar(
    df3, x="구", y="미세먼지",
    hover_data=["초미세먼지"],
    title="구별 미세먼지 농도",
)
fig3.show()
```

<StepCard step="핵심" title="hover_data는 리스트로 넣는다냥!">

| 코드 | 하는 일 |
|---|---|
| `hover_data=["초미세먼지"]` | 마우스를 올렸을 때 초미세먼지 값도 함께 보여줌 |
| `hover_data=["초미세먼지", "습도"]` | 여러 열을 콤마로 나열하면 모두 함께 보여줌 |

</StepCard>

<Callout type="note">
  공공데이터는 열이 많은 경우가 흔한데, `hover_data`를 잘 활용하면
  그래프를 복잡하게 만들지 않으면서도 **필요한 정보를 마우스
  한 번으로** 확인할 수 있다냥!
</Callout>
