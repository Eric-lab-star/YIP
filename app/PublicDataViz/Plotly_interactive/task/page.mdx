<MissionCard number={1} title="인터랙티브 막대 그래프 그리기" time="10~12분">

구별 미세먼지 데이터를 plotly 막대 그래프로 그려보자냥! 아래
템플릿에서 **빈칸(`____`)을 채워보자냥.**

```python
import plotly.express as px
import pandas as pd

data = {
    "구": ["중구", "강남구", "종로구", "마포구"],
    "미세먼지": [30, 42, 25, 38],
}
df = pd.DataFrame(data)

fig = px.____(df, x="구", y="미세먼지", title="구별 미세먼지 농도")
fig.show()
```

<MissionCard number={3} title="hover_data로 정보 추가하기" time="8~10분">

data3 = {

}
df3 = pd.DataFrame(data3)

fig3 = px.bar(
    df3, x="구", y="미세먼지",
