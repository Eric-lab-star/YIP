## 1단계 · 지역별 평균 비교하기 (8분)

<NyangSpeech>
  기초 과정에서 배운 groupby와 barplot 기억나냥? 여러 지역을
  비교할 때 딱 좋은 조합이다냥!
</NyangSpeech>

```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

sns.set_theme(style="whitegrid")
plt.rcParams["font.family"] = "Malgun Gothic"

data = {
    "지역": ["중구", "중구", "강남구", "강남구", "마포구", "마포구"],
    "미세먼지": [30, 34, 42, 38, 25, 29],
}
df = pd.DataFrame(data)

지역평균 = df.groupby("지역")["미세먼지"].mean().reset_index()
sns.barplot(data=지역평균, x="지역", y="미세먼지")
plt.title("지역별 평균 미세먼지")
plt.show()
```

<Callout type="important">
  평균만 보면 "강남구가 제일 심하다"는 것까지는 알 수 있지만,
  **"매일 비슷하게 심한지, 어떤 날만 유독 심한지"**는 알 수
  없다냥. 그래서 분포를 함께 봐야 한다냥!
</Callout>

```python
sns.boxplot(data=df, x="지역", y="미세먼지")
plt.title("지역별 미세먼지 분포")
plt.show()
```

<StepCard step="핵심" title="상자그림 읽는 법">

| 부분 | 의미 |
|---|---|
| 상자 가운데 선 | 중앙값(데이터를 순서대로 세웠을 때 가운데 값) |
| 상자의 위/아래 끝 | 데이터의 중간 50%가 몰린 범위 |
| 상자 밖 점 | 유난히 크거나 작은 값(이상치일 수 있음) |

</StepCard>

<Callout type="note">
  상자가 **길게 늘어져 있으면** 그 지역은 날마다 값이 들쭉날쭉하다는
  뜻이고, 상자가 **짧으면** 값이 비교적 일정하다는 뜻이다냥!
</Callout>

## 3단계 · 기준치를 넘는 지역 찾기 (7분)

<NyangSpeech>
  마지막으로, 조건 필터링을 다시 활용해서 "평균이 기준치를 넘는
  지역"만 콕 집어보자냥!
</NyangSpeech>

```python
지역평균 = df.groupby("지역")["미세먼지"].mean().reset_index()

기준치 = 35
위험지역 = 지역평균[지역평균["미세먼지"] > 기준치]
print(위험지역)
```

<Callout type="tip">
  기초 과정에서 배운 `df[조건]` 필터링을, groupby로 요약한 결과에도
  **똑같이** 쓸 수 있다냥! 새로운 걸 배우는 게 아니라, 배운 걸
  조합하는 것이 프로젝트 과정의 핵심이다냥.
</Callout>
