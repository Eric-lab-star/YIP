
<MissionCard number={2} title="마커 하나 찍어보기" time="8~10분">

서울시청 위치에 마커를 찍어보자냥.

```python
folium.Marker(
    location=[37.5665, 126.9780],
    popup=____,
    tooltip="클릭해보세요!",
).add_to(m)

m.save("map.html")
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 클릭했을 때 보일 설명을 문자열로 넣으면 된다냥. (`"서울시청"`)
> - 지도에서 마커를 클릭하면 설명이 뜨냥?

<Callout type="important">
  마커를 만든 뒤 `.add_to(m)`을 빠뜨리면, 마커가 지도에 나타나지
  않는다냥! 꼭 붙여주자냥.
</Callout>

</MissionCard>

<MissionCard number={3} title="반복문으로 여러 마커 찍기" time="10~12분">

미세먼지 측정소 3곳에 마커를 한 번에 찍어보자냥.

```python
import pandas as pd

data = {
    "측정소": ["중구", "강남구", "종로구"],
    "위도": [37.5636, 37.4979, 37.5735],
    "경도": [126.9975, 127.0276, 126.9788],
    "미세먼지": [30, 42, 25],
}
df = pd.DataFrame(data)

for i, row in df.____():
    folium.Marker(
        location=[row["위도"], row["경도"]],
        popup=f"{row['측정소']} (미세먼지 {row['미세먼지']})",
    ).add_to(m)

m.save("map.html")
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 DataFrame을 한 행씩 꺼내는 함수 이름을 넣으면 된다냥. (`iterrows`)
> - 미션 2의 서울시청까지 더해서 마커가 4개 찍히냥? (같은 m에 계속 덧붙는다냥)

<StepCard step="관찰" title="같은 지도 m에 계속 마커 추가하기">

`m`은 미션 1에서 만든 지도 그대로다냥! 새 지도를 또 만드는 게
아니라, 같은 `m`에 마커를 계속 `.add_to(m)`으로 덧붙이는 것이다냥.

</StepCard>

</MissionCard>
