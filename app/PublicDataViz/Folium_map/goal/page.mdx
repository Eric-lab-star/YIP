## 오늘의 학습 목표

<Callout type="goal">
  - `folium.Map()`으로 기본 지도를 만들 수 있다.
  - `folium.Marker()`로 지도에 위치 표시를 찍을 수 있다.
  - 여러 개의 마커를 반복문으로 한 번에 찍을 수 있다.
</Callout>

## 1단계 · 지도 만들기 (8분)

<NyangSpeech>
  folium 지도를 만들려면, 지도의 **중심 위치**와 **확대 정도**를
  정해줘야 한다냥. 위치는 위도(latitude), 경도(longitude) 숫자
  쌍으로 표현한다냥.
</NyangSpeech>

```python
import folium

# 서울시청 근처를 중심으로 지도 만들기
m = folium.Map(location=[37.5665, 126.9780], zoom_start=12)
m.save("map.html")
```

<Callout type="important">
  `location=[위도, 경도]`는 지도의 **중심점**을 정한다냥.
  `zoom_start`는 처음 지도가 열릴 때의 확대 정도로, **숫자가
  클수록 더 확대**된다냥. `m.save("map.html")`로 저장하면 웹
  브라우저에서 지도를 열어볼 수 있다냥!
</Callout>

## 2단계 · 마커 찍기 (10분)

<NyangSpeech>
  지도를 만들었으니, 이제 특정 위치에 **핀(마커)**을 꽂아보자냥!
</NyangSpeech>

<CompareBubble
  left={{

    color: 'blue',
    items: [
      '지도의 바탕을 만듦',
      'location과 zoom_start로 중심/확대 설정',
    ],
  }}
  right={{
    label: 'folium.Marker()',
    color: 'purple',
    items: [
      '지도 위 특정 위치에 핀을 꽂음',
      'popup으로 클릭 시 보일 설명을 넣음',
    ],
  }}
/>

```python
folium.Marker(
    location=[37.5665, 126.9780],
    popup="서울시청",
    tooltip="클릭해보세요!",
).add_to(m)

m.save("map.html")
```

<Callout type="tip">
  `popup`은 마커를 **클릭했을 때** 뜨는 설명이고, `tooltip`은
  마우스를 **올렸을 때** 미리 보이는 짧은 안내문이다냥. 마지막에
  꼭 `.add_to(m)`을 붙여서, 만든 마커를 지도 `m`에 붙여줘야 한다냥!
</Callout>

## 3단계 · 여러 마커 한 번에 찍기 (7분)

<NyangSpeech>
  미세먼지 측정소가 10개, 100개라면 하나하나 마커 코드를 쓰긴
  힘들다냥! 이럴 땐 **반복문**으로 한 번에 찍으면 된다냥.
</NyangSpeech>

```python
import pandas as pd

data = {
    "측정소": ["중구", "강남구", "종로구"],
    "위도": [37.5636, 37.4979, 37.5735],
    "경도": [126.9975, 127.0276, 126.9788],
    "미세먼지": [30, 42, 25],
}
df = pd.DataFrame(data)

for i, row in df.iterrows():
    folium.Marker(
        location=[row["위도"], row["경도"]],
        popup=f"{row['측정소']} (미세먼지 {row['미세먼지']})",
    ).add_to(m)

m.save("map.html")
```

<StepCard step="핵심" title="df.iterrows()로 한 행씩 꺼내기">

`for i, row in df.iterrows():`는 DataFrame을 **한 행씩** 순서대로
꺼내주는 반복문이다냥. `row["열이름"]`으로 그 행의 값을 꺼낼 수
있다냥!

</StepCard>

<Callout type="note">
  `f"{row['측정소']} (미세먼지 {row['미세먼지']})"`처럼 f-string을
  쓰면, 문자열 안에 변수 값을 쉽게 끼워넣을 수 있다냥!
</Callout>
