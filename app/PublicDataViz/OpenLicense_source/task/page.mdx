# 라이선스 실습 — 출처 표시 문장 써보기

<NyangSpeech>
  안녕, 코딩냥이다냥! 지금부터 약 20~25분 동안, 실제 데이터셋의 라이선스를
  확인하고 출처 표시 문장을 직접 써보는 연습을 할 거다냥. 빈칸(`____`)을

<MissionCard number={1} title="데이터셋 라이선스 확인하기" time="8~10분">

공공데이터포털에 로그인해서, "지하철 승하차" 또는 "미세먼지"로 검색한 뒤
데이터셋 하나를 클릭해보자냥. 상세 페이지에서 라이선스 정보를 찾아보자냥.

```text
1. 검색한 데이터셋 이름: ____________
2. 제공 기관: ____________
3. 공공누리 유형 (제몇 유형인가요?): ____________
4. 상업적 이용이 가능한가요? (예/아니오): ____________
```

> **확인해보자냥**
> - 데이터셋 상세 페이지에서 "이용허락범위" 또는 라이선스 마크를 찾았냥?
> - 제1유형이 맞다면, "상업적 이용 가능"이라는 뜻이라는 걸 기억해두자냥!

<Callout type="tip">
  라이선스 마크를 못 찾겠다면, 데이터셋 페이지 아래쪽이나 "저작권정책"
  링크를 살펴보자냥. 대부분의 공공데이터포털 데이터는 화면 어딘가에 유형이
  표시되어 있다냥.
</Callout>

</MissionCard>

<MissionCard number={2} title="출처 표시 문장 완성하기" time="10~12분">

이제 미션 1에서 확인한 정보로, 직접 출처 표시 문장을 완성해보자냥! 아래
빈칸(`____`)을 채워보자냥.

```text
본 자료는 ____(제공 기관)____에서 개방한
「____(데이터셋 이름)____」 데이터를
공공누리 ____(유형)____에 따라 이용하였습니다.
(출처: 공공데이터포털)
```

> **확인해보자냥 (빈칸 힌트)**
> - 미션 1에서 적어둔 제공 기관, 데이터셋 이름, 유형을 그대로 가져와서 채우면 된다냥!
> - 완성한 문장을 소리 내어 읽어보자냥. 어색한 곳은 없냥?

프로젝트(지하철·미세먼지·아파트·상가·인구 통계·캡스톤)에서 계속 사용할
거다냥. 오늘 확실히 익혀두면 나중에 훨씬 편하다냥!

</StepCard>

</MissionCard>
