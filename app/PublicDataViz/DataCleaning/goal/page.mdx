## 오늘의 학습 목표

<Callout type="goal">
  - `isna()`로 빈 값(결측치)이 어디에 있는지 찾을 수 있다.
  - `dropna()`와 `fillna()`로 빈 값을 처리할 수 있다.
  - `drop_duplicates()`로 중복된 행을 제거할 수 있다.
</Callout>

## 1단계 · 빈 값 찾아내기 (10분)

<NyangSpeech>
  공공데이터를 받아보면, 측정 장비 고장이나 입력 누락으로 값이
  비어있는 경우가 흔하다냥. pandas에서 빈 값은 `NaN`(Not a Number)
  으로 표시된다냥.
</NyangSpeech>

```python
import pandas as pd
import numpy as np

data = {
    "측정소": ["중구", "강남구", "종로구", "마포구"],
    "미세먼지": [30, np.nan, 25, np.nan],
}
df = pd.DataFrame(data)

print(df.isna())
print(df["미세먼지"].isna().sum())
```

```text
   측정소   미세먼지
0  False  False
1  False   True
2  False  False
3  False   True
2
```

<Callout type="important">
  `isna()`는 각 칸이 빈 값이면 `True`, 아니면 `False`를 돌려준다냥.
  여기에 `.sum()`을 붙이면 `True`(빈 값)가 몇 개인지 셀 수 있다냥!
  (True는 1, False는 0으로 계산되기 때문이다냥.)
</Callout>

## 2단계 · 빈 값 처리하기 (10분)

<NyangSpeech>
  빈 값을 발견했다면, **버릴지** 아니면 **다른 값으로 채울지**
  결정해야 한다냥!
</NyangSpeech>

<CompareBubble
  left={{
    emoji: '🗑️',

    items: [
      '빈 값이 있는 행을 통째로 삭제',
      '데이터가 충분히 많을 때 적합',
    ],
  }}
  right={{
    emoji: '🩹',
    label: 'fillna() — 채우기',
    color: 'purple',
    items: [
      '빈 값을 원하는 값으로 대체',
      '평균값, 0, "정보없음" 등으로 채움',
    ],
  }}
/>

```python
# 빈 값이 있는 행을 통째로 삭제
정리된_df = df.dropna()
print(정리된_df)

# 빈 값을 평균으로 채우기
평균값 = df["미세먼지"].mean()
채워진_df = df.fillna({"미세먼지": 평균값})
print(채워진_df)
```

<Callout type="tip">
  어떤 방법이 정답이라고 정해져 있진 않다냥! 빈 값이 적으면
  `dropna()`로 버려도 되지만, 데이터가 귀하거나 빈 값이 많다면
  `fillna()`로 평균이나 0 등을 채우는 게 낫다냥.
</Callout>

## 3단계 · 중복된 행 제거하기 (7분)

<NyangSpeech>
  같은 데이터를 두 번 내려받아 합치다 보면, **완전히 똑같은 행**이
  중복으로 들어가는 경우가 있다냥. 이럴 땐 `drop_duplicates()`를
  쓴다냥!
</NyangSpeech>

```python
data = {
    "측정소": ["중구", "강남구", "중구"],
    "미세먼지": [30, 42, 30],
}
df2 = pd.DataFrame(data)

중복확인 = df2.duplicated()
print(중복확인)

중복제거 = df2.drop_duplicates()
print(중복제거)
```

<StepCard step="핵심" title="duplicated vs drop_duplicates">

| 코드 | 하는 일 |
|---|---|
| `df.duplicated()` | 각 행이 이전에 나온 행과 **완전히 같은지** True/False로 표시 |
| `df.drop_duplicates()` | 중복된 행을 **처음 것만 남기고** 나머지를 제거 |

</StepCard>

<Callout type="note">
  `drop_duplicates()`도 `dropna()`와 마찬가지로, 원본 `df2`는 그대로
  두고 **정리된 새 결과**를 돌려준다냥. 원본을 바꾸고 싶다면
  `df2 = df2.drop_duplicates()`처럼 다시 담아줘야 한다냥!
</Callout>
