<MissionCard number={1} title="빈 값 개수 세어보기" time="10~12분">

미세먼지 측정 데이터에서, 빈 값이 몇 개인지 세어보자냥! 아래
템플릿에서 **빈칸(`____`)을 채워보자냥.**

```python
import pandas as pd
import numpy as np

data = {
    "측정소": ["중구", "강남구", "종로구", "마포구"],
    "미세먼지": [30, np.nan, 25, np.nan],
}
df = pd.DataFrame(data)

# 미세먼지 열의 빈 값 개수를 세어보세요
빈값개수 = df["미세먼지"].____().sum()
print(빈값개수)
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 빈 값을 True/False로 표시하는 함수 이름을 넣으면 된다냥. (`isna`)
> - 결과가 2로 나오냥?

</MissionCard>

---

<MissionCard number={2} title="빈 값을 평균으로 채우기" time="8~10분">

이번엔 빈 값을 버리지 않고, 평균값으로 채워보자냥.

```python
평균값 = df["미세먼지"].mean()
채워진_df = df.____({"미세먼지": 평균값})
print(채워진_df)
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 빈 값을 다른 값으로 채우는 함수 이름을 넣으면 된다냥. (`fillna`)
> - NaN이었던 자리에 평균값(27.5)이 채워지냥?

<Callout type="important">
  `df.fillna(...)`는 원본 `df`를 바꾸지 않고 **새로운 결과**를
  돌려준다냥! 원본까지 바꾸고 싶다면 `df = df.fillna(...)`처럼 다시
  담아줘야 한다냥.
</Callout>

</MissionCard>

<MissionCard number={3} title="중복된 행 제거하기" time="8~10분">

이번엔 중복으로 들어간 측정소 데이터를 정리해보자냥.

```python
data2 = {
    "측정소": ["중구", "강남구", "중구"],
    "미세먼지": [30, 42, 30],
}
df2 = pd.DataFrame(data2)

정리됨 = df2.____()
print(정리됨)
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 중복된 행을 제거하는 함수 이름을 넣으면 된다냥. (`drop_duplicates`)
> - 결과에 행이 3개가 아니라 2개만 남냥?

<StepCard step="관찰" title="완전히 같은 행만 중복으로 인식">

`drop_duplicates()`는 **모든 열의 값이 전부 같은** 행만 중복으로
본다냥. 측정소는 같아도 미세먼지 값이 다르면 중복으로 취급하지
않는다냥!

</StepCard>

</MissionCard>
