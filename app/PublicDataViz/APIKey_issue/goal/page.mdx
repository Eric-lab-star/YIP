## 1단계 · 인증키가 뭐고 왜 필요하냥? (5분)

<NyangSpeech>
  질문 하나 할게냥! 도서관에서 책을 빌리려면 뭐가 필요할까냥? 바로 **회원증**
  이다냥. 회원증이 있어야 "이 사람이 진짜 우리 도서관 회원이구나" 하고
  확인할 수 있다냥. Open API도 똑같다냥!
</NyangSpeech>

Open API는 아무나 무제한으로 요청할 수 있게 열어두면, 서버에 너무 많은
요청이 몰려서 정작 필요한 사람이 못 쓰게 될 수 있다냥. 그래서 공공데이터
포털은 **인증키(API Key)**라는 회원증 같은 열쇠를 나눠준다냥. 이 열쇠를
요청에 함께 보내야, "정식으로 등록된 사용자구나" 하고 데이터를 내어준다냥.

<Callout type="important">
  **인증키**는 나만의 비밀번호 같은 거다냥! 다른 사람에게 함부로 알려주면 안
  되고, 코드를 인터넷(예: 깃허브)에 올릴 때도 인증키가 그대로 보이지 않게
  조심해야 한다냥. 이건 나중 시간에 더 자세히 다뤄볼 거다냥.
</Callout>

## 2단계 · 인증키, 어떻게 받냥? (10분)

<NyangSpeech>

</NyangSpeech>

<StepCard step="핵심" title="인증키 발급 네 단계">

1. **로그인** — 1차시에 만든 공공데이터포털 계정으로 로그인한다냥.
2. **데이터셋 찾기** — 쓰고 싶은 Open API 데이터셋을 검색한다냥. (상세
   페이지에 **활용신청** 버튼이 있으면 API라는 뜻이었지냥?)
3. **활용신청** — 버튼을 누르고, 사용 목적(예: "교육 목적, 데이터 분석
   학습") 등 간단한 정보를 입력한다냥.
4. **승인 확인** — 대부분 자동으로 즉시 승인된다냥! 마이페이지 →
   "개발계정" 또는 "오픈API"에서 발급된 인증키를 확인할 수 있다냥.

</StepCard>

## 3단계 · 인증키는 어떻게 생겼냥? (5분)

<NyangSpeech>
  발급받은 인증키를 보면 조금 낯설게 생겼을 거다냥. 걱정 말라냥, 원래 그런
  모습이다냥!
</NyangSpeech>

인증키는 이렇게 영문자와 숫자가 섞인 64자리 긴 문자열이다냥.

```text
81e63f94...(생략)...ffa9a4000
```

<Callout type="note">
  마이페이지 → Open API → **인증키 발급현황**에서 확인할 수 있다냥.
  "일반"이라고 적힌 키 하나만 나오는데, 그걸 **그대로** 코드에 쓰면
  된다냥!
</Callout>

<Callout type="tip">
  **Decoding 키를 찾고 있다면?** 인터넷의 옛 자료를 보면 "일반
  인증키(Decoding)와 (Encoding) 두 가지가 있으니 Decoding을 쓰라"는
  설명이 많다냥. 예전 인증키에는 `+`, `/`, `=` 같은 기호가 섞여 있어서,
  주소에 넣으려면 `%2B`처럼 바꿔 쓴 버전(Encoding)이 따로 필요했기
  때문이다냥.

  지금 발급되는 키는 영문자와 숫자뿐이라 바꿀 게 없다냥. 그래서 두
  형태가 같아지고, 포털도 하나만 보여준다냥!

  혹시 `%`가 섞인 옛 형식 키를 받았다면 이렇게 풀어서 쓰면 된다냥.

  ```python
  from urllib.parse import unquote
  키 = unquote("b3lk9F8s%2FpQ...")
  ```
</Callout>

## 4단계 · 인증키, 안전하게 보관하는 법 (5분)

<NyangSpeech>
  인증키는 "나만의 비밀번호"라고 했지냥? 그래서 안전하게 보관하는 습관도
  같이 익혀보자냥.
</NyangSpeech>

<Callout type="tip">
  **인증키 보관 팁**

  - 인증키를 메모장이나 개인 노트에 따로 적어두자냥. (수업 시간마다 다시
    찾지 않아도 되게!)
  - 코드 파일에 인증키를 직접 적어 쓰더라도, **그 파일을 다른 사람과
    공유하거나 인터넷에 올릴 때는 인증키를 지우고 공유**하자냥.
  - 만약 인증키가 유출된 것 같으면, 마이페이지에서 **재발급**을 받을 수
    있다냥.
</Callout>
