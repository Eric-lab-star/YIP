<MissionCard number={1} title="미세먼지 정보 API 찾기" time="5분">

공공데이터포털 검색창에 아래처럼 검색해서, 우리가 앞으로 쓸 미세먼지 관련

```text
한국환경공단_에어코리아_대기오염정보
```

> **확인해보자냥**
> - 검색 결과에서 "OpenAPI" 라벨이 붙은 데이터셋을 찾았냥?
> - 상세 페이지에 **활용신청** 버튼이 보이냥?

<Callout type="tip">
  검색 결과가 너무 많다면, 검색창 아래 "오픈API" 필터를 눌러서 좁혀보면
  찾기 쉽다냥!
</Callout>

</MissionCard>

<MissionCard number={2} title="활용신청 하기" time="7~10분">

**활용신청** 버튼을 눌러서 신청서를 작성해보자냥.

```text
1. 활용목적 선택: 학습/연구 (또는 비슷한 항목)
2. 상세 목적 작성 예시:
   "공공데이터를 활용한 파이썬 데이터 분석 교육 실습용으로 사용합니다."
3. 시스템 유형: 일반 (개인 개발/학습용)
```

> **확인해보자냥**
> - 신청서를 제출하고 "신청 완료" 또는 "승인 완료" 메시지를 확인했냥?
> - 자동 승인인 경우, 신청 즉시 마이페이지에서 인증키를 볼 수 있다냥!

<StepCard step="확인" title="승인이 안 될 때는?">

가끔 승인까지 몇 분~몇 시간 걸리는 API도 있다냥. 만약 오늘 승인이 안
된다면, 걱정하지 말고 다음 시간에 계속 진행하면 된다냥. 선생님이 준비한
예비 인증키로 실습을 이어갈 수도 있다냥!

</StepCard>

</MissionCard>

---

<MissionCard number={3} title="인증키 확인하고 안전하게 적어두기" time="8~10분">

마이페이지의 "개발계정" 또는 "오픈API" 메뉴로 들어가서, 발급된 인증키를
확인해보자냥.

```text
1. 일반 인증키(Decoding): ____________
2. 일반 인증키(Encoding): ____________
3. 오늘 날짜: ____________
```

> **확인해보자냥**
> - 두 가지 형태의 인증키를 모두 찾았냥?
> - 인증키를 나만 볼 수 있는 안전한 곳(개인 메모장 등)에 옮겨 적었냥?

<Callout type="important">
  **인증키는 절대 다른 사람과 공유하거나, 인터넷 게시판·단체 채팅방에
  붙여넣지 말자냥!** 오늘 발급받은 이 키를 다음 시간부터 계속 사용할
  거다냥.
</Callout>

</MissionCard>
