<MissionCard number={1} title="시간대별 평균 막대 그래프 그리기" time="10~12분">

시간대평균을 seaborn 막대 그래프로 그려보자냥! 아래 템플릿에서
**빈칸(`____`)을 채워보자냥.**

```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

plt.rcParams["font.family"] = "Malgun Gothic"

길게 = pd.DataFrame({
    "역명": ["강남", "강남", "역삼", "역삼"],
    "시간대": ["07-08시", "08-09시", "07-08시", "08-09시"],
    "승차인원": [8200, 15200, 3100, 6400],
})

시간대평균 = 길게.groupby("시간대")["승차인원"].mean().____()
sns.barplot(data=시간대평균, x="시간대", y="승차인원")
plt.show()
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 groupby 결과의 인덱스를 다시 평범한 열로 되돌리는 함수 이름을 넣으면 된다냥. (`reset_index`)
> - 08-09시 막대가 더 높게 나오냥?

<MissionCard number={2} title="역별 변화 선 그래프 그리기" time="10~12분">

이번엔 plotly로 역별 시간대 변화를 비교해보자냥.

```python
import plotly.express as px

fig = px.line(
    길게, x="시간대", y="승차인원", color=____,
    title="역별 시간대 승차인원 변화",
)
fig.show()
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 역마다 다른 색 선으로 구분해줄 열 이름을 문자열로 넣으면 된다냥. (`"역명"`)
> - 강남과 역삼이 서로 다른 색 선으로 나오냥?
