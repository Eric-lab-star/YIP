## 1단계 · 시간대별 평균 막대 그래프 (8분)

<NyangSpeech>
  지난 시간에 구한 시간대평균을, seaborn 막대 그래프로 그려보자냥!
</NyangSpeech>

```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

sns.set_theme(style="whitegrid")
plt.rcParams["font.family"] = "Malgun Gothic"

길게 = pd.DataFrame({
    "역명": ["강남", "강남", "역삼", "역삼"],
    "시간대": ["07-08시", "08-09시", "07-08시", "08-09시"],
    "승차인원": [8200, 15200, 3100, 6400],
})

시간대평균 = 길게.groupby("시간대")["승차인원"].mean().reset_index()

sns.barplot(data=시간대평균, x="시간대", y="승차인원")
plt.title("시간대별 평균 승차인원")
plt.show()
```

<Callout type="important">
  `groupby(...).mean()`의 결과는 "시간대"가 **인덱스**로 들어간
  상태다냥. `reset_index()`를 붙이면, 인덱스를 다시 **평범한
  열**로 되돌려줘서 `sns.barplot(data=..., x="시간대", ...)`처럼
  열 이름으로 바로 쓸 수 있게 된다냥!
</Callout>

```python
import plotly.express as px

fig = px.line(
    길게, x="시간대", y="승차인원", color="역명",
    title="역별 시간대 승차인원 변화",
)
fig.show()
```

<Callout type="tip">
  `color="역명"`을 추가하면, 역마다 **다른 색깔의 선**으로 자동
  구분해서 그려준다냥! 범례(legend)를 클릭하면 특정 역의 선만
  숨기거나 보이게 할 수도 있다냥.

## 3단계 · 그래프로 결론 내리기 (7분)

<NyangSpeech>
  그래프를 그렸다면, 이제 **"그래서 무엇을 알게 됐나?"**를 한 문장으로
  정리하는 습관을 들이면 좋다냥!
</NyangSpeech>

```python
가장붐비는시간대 = 길게.groupby("시간대")["승차인원"].mean().idxmax()
print(f"결론: {가장붐비는시간대}에 승차인원이 가장 많다.")
print("→ 이 시간대에 배차 간격을 좁히면 혼잡도가 줄어들 것으로 예상된다.")
```

<StepCard step="핵심" title="분석 → 시각화 → 결론, 이 순서를 기억하자냥!">

| 단계 | 지난 시간 / 오늘 |
|---|---|
| 분석 | melt, groupby, idxmax로 숫자 계산 (지난 시간) |
| 시각화 | seaborn, plotly로 그래프 그리기 (오늘) |
| 결론 | 그래프를 보고 한 문장으로 의미 요약 (오늘) |

</StepCard>
