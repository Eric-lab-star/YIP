<MissionCard number={1} title="구별 미세먼지 평균 구하기" time="10~12분">

미세먼지 측정소 데이터에서, 구별 평균 미세먼지를 구해보자냥! 아래
템플릿에서 **빈칸(`____`)을 채워보자냥.**

```python
import pandas as pd

data = {
    "구": ["중구", "중구", "강남구", "강남구", "마포구"],
    "측정소": ["중구1", "중구2", "강남1", "강남2", "마포1"],
    "미세먼지": [30, 34, 42, 38, 25],
}
df = pd.DataFrame(data)

# 구별로 묶어서 미세먼지 평균을 구해보세요
구별평균 = df.groupby(____)["미세먼지"].mean()
print(구별평균)
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 그룹으로 묶을 기준 열 이름을 문자열로 넣으면 된다냥. (`"구"`)
> - 중구, 강남구, 마포구 세 그룹의 평균이 나오냥?

</MissionCard>

<MissionCard number={2} title="평균과 최댓값 함께 보기" time="8~10분">

이번엔 평균뿐 아니라 최댓값도 함께 구해보자냥.

```python
요약 = df.groupby("구")["미세먼지"].agg([____, "max"])
print(요약)
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 평균을 뜻하는 통계 함수 이름을 문자열로 넣으면 된다냥. (`"mean"`)
> - 강남구의 max 값이 42로 나오냥?

<StepCard step="확인" title="agg에는 리스트로 여러 개!">

`agg(["mean", "max"])`처럼 대괄호 안에 원하는 통계 이름을 콤마로
나열하면, 그 통계들을 한 번에 계산해준다냥.

</StepCard>

</MissionCard>

<MissionCard number={3} title="구별 측정소 개수 세기" time="8~10분">

이번엔 각 구에 측정소가 몇 개씩 있는지 세어보자냥.

```python
구별개수 = df[____].value_counts()

```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 개수를 세고 싶은 열 이름을 문자열로 넣으면 된다냥. (`"구"`)
> - 중구와 강남구가 각각 2, 마포구가 1로 나오냥?
