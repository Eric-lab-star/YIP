## 1단계 · 상가 마커 찍기 (8분)

<NyangSpeech>
  기초 과정에서 배운 `iterrows()`와 `Marker`를 다시 써보자냥!
</NyangSpeech>

```python
import folium
import pandas as pd

data = {
    "상호명": ["코딩냥카페", "행복분식", "은빛치킨"],
    "업종": ["카페", "분식", "치킨"],
    "위도": [37.4979, 37.5636, 37.5172],
    "경도": [127.0276, 126.9975, 127.0473],
}
df = pd.DataFrame(data)

m = folium.Map(location=[37.55, 127.0], zoom_start=12)

for i, row in df.iterrows():
    folium.Marker(
        location=[row["위도"], row["경도"]],
        popup=row["상호명"],
    ).add_to(m)

m.save("cafe_map.html")
```

<Callout type="important">
  기초 과정에서 배운 패턴 그대로다냥! `location`은 지도의 중심,
  `zoom_start`는 확대 정도, `for` 반복문으로 각 행마다 마커를
  찍는다냥. 배운 것을 그대로 재사용하는 게 프로젝트 과정의
  매력이다냥.
</Callout>

```python
색상표 = {"카페": "blue", "치킨": "red", "분식": "green"}

m = folium.Map(location=[37.55, 127.0], zoom_start=12)  # 지도를 새로 만든다냥

for i, row in df.iterrows():
    folium.Marker(
        location=[row["위도"], row["경도"]],
        popup=row["상호명"],
        icon=folium.Icon(color=색상표.get(row["업종"], "gray")),
    ).add_to(m)

m.save("store_color_map.html")
```

<Callout type="tip">
  `색상표.get(row["업종"], "gray")`는 딕셔너리에서 값을 찾되,
  **없으면 기본값**("gray")을 쓰라는 뜻이다냥. 혹시 색상표에 없는
  새로운 업종이 나와도 에러 없이 회색으로 표시된다냥!
</Callout>

## 3단계 · MarkerCluster로 마커 묶기 (8분)

<NyangSpeech>
  실제 상가 데이터는 마커가 수백, 수천 개가 될 수도 있다냥! 그러면
  지도가 마커로 뒤덮여서 오히려 보기 힘들어진다냥. 이럴 때
  `MarkerCluster`를 쓰면, 가까운 마커끼리 숫자로 묶어서 보여준다냥.
</NyangSpeech>

```python
from folium.plugins import MarkerCluster

m2 = folium.Map(location=[37.55, 127.0], zoom_start=12)
클러스터 = MarkerCluster().add_to(m2)

for i, row in df.iterrows():
    folium.Marker(
        location=[row["위도"], row["경도"]],
        popup=row["상호명"],
    ).add_to(클러스터)

m2.save("cafe_cluster_map.html")
```

<StepCard step="핵심" title="Marker를 m이 아닌 클러스터에 붙이기">

| 코드 | 하는 일 |
|---|---|
| `MarkerCluster().add_to(m2)` | 지도 `m2`에 클러스터 기능을 추가 |
| `folium.Marker(...).add_to(클러스터)` | 마커를 지도가 아니라 **클러스터에** 붙임 |

</StepCard>

<Callout type="note">
  지도를 확대하면 클러스터가 자동으로 풀리면서 개별 마커가
  나타난다냥! 마커가 많은 데이터를 다룰 때 아주 유용한 기능이다냥.
</Callout>
