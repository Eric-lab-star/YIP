<MissionCard number={1} title="상가 마커 찍기" time="8~10분">

상가 데이터를 지도에 마커로 찍어보자냥! 아래 템플릿에서
**빈칸(`____`)을 채워보자냥.**

```python
import folium
import pandas as pd

data = {
    "상호명": ["코딩냥카페", "행복분식", "은빛치킨"],
    "업종": ["카페", "분식", "치킨"],
    "위도": [37.4979, 37.5636, 37.5172],
    "경도": [127.0276, 126.9975, 127.0473],
}
df = pd.DataFrame(data)

m = folium.Map(location=[37.55, 127.0], zoom_start=12)

for i, row in df.____():
    folium.Marker(
        location=[row["위도"], row["경도"]],
        popup=row["상호명"],
    ).add_to(m)

m.save("cafe_map.html")
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 DataFrame을 한 행씩 꺼내는 함수 이름을 넣으면 된다냥. (`iterrows`)
> - 상가 3곳에 마커가 찍히냥?

</MissionCard>

<MissionCard number={2} title="업종별 아이콘 색 입히기" time="8~10분">

업종에 따라 마커 색을 다르게 지정해보자냥.

```python
색상표 = {"카페": "blue", "치킨": "red", "분식": "green"}

m = folium.Map(location=[37.55, 127.0], zoom_start=12)  # 지도를 새로 만든다냥

for i, row in df.iterrows():
    folium.Marker(
        location=[row["위도"], row["경도"]],
        icon=folium.Icon(color=색상표.____(row["업종"], "gray")),
    ).add_to(m)

m.save("store_color_map.html")
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 딕셔너리에서 값을 찾되 없으면 기본값을 쓰는 함수 이름을 넣으면 된다냥. (`get`)
> - 지도를 **새로 만들지 않으면** 미션 1의 마커에 덧붙어서 6개가 겹친다냥!
> - `store_color_map.html`을 열면 카페는 파란색, 분식은 초록색, 치킨은 빨간색으로 나오냥?

</MissionCard>

<MissionCard number={3} title="MarkerCluster로 묶기" time="8~10분">

마커를 클러스터로 묶어서 표시해보자냥.

```python
from folium.plugins import MarkerCluster

m2 = folium.Map(location=[37.55, 127.0], zoom_start=12)
클러스터 = MarkerCluster().____(m2)

for i, row in df.iterrows():
    folium.Marker(
        location=[row["위도"], row["경도"]],
    ).add_to(클러스터)

m2.save("cafe_cluster_map.html")
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 클러스터를 지도에 붙이는 함수 이름을 넣으면 된다냥. (`add_to`)
> - 지도를 축소하면 마커가 숫자로 묶여서 보이냥?

<StepCard step="확인" title="마커는 지도가 아니라 클러스터에!">

이번 미션에서는 `folium.Marker(...).add_to(클러스터)`처럼, 지도
`m2`가 아니라 `클러스터`에 마커를 붙인다냥. 이 차이를 꼭
기억하자냥!

</StepCard>

</MissionCard>
