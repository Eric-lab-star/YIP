## 오늘의 학습 목표

<Callout type="goal">
  - `plt.plot()`으로 선 그래프를 그릴 수 있다.
  - `plt.bar()`로 막대 그래프를 그릴 수 있다.
  - 그래프에서 한글이 깨지지 않게 폰트를 설정할 수 있다.

## 1단계 · 선 그래프 그리기 (10분)

<NyangSpeech>
  시간에 따라 변하는 데이터, 예를 들어 요일별 지하철 승차인원처럼
  **변화의 흐름**을 보고 싶을 땐 선 그래프가 딱이다냥!
</NyangSpeech>

```python
import matplotlib.pyplot as plt

요일 = ["월", "화", "수", "목", "금"]
승차인원 = [12000, 11500, 13000, 12800, 15200]

plt.plot(요일, 승차인원)
plt.title("요일별 지하철 승차인원")
plt.xlabel("요일")
plt.ylabel("승차인원")
plt.show()
```

<Callout type="important">
  `plt.plot(x, y)`에서 첫 번째 리스트는 **가로축(x축)**, 두 번째
  리스트는 **세로축(y축)** 값이다냥. 두 리스트의 **길이가 같아야**
  각 점이 짝을 맞춰 이어진다냥!
</Callout>

## 2단계 · 막대 그래프 그리기 (10분)

<NyangSpeech>
  변화의 흐름이 아니라, **항목끼리 크기를 비교**하고 싶을 땐 막대
  그래프가 더 좋다냥. 예를 들어 구별 미세먼지를 비교할 때처럼
  말이다냥!
</NyangSpeech>

```python
구 = ["중구", "강남구", "종로구", "마포구"]
미세먼지 = [30, 42, 25, 38]

plt.bar(구, 미세먼지)
plt.title("구별 미세먼지 농도")
plt.xlabel("구")
plt.ylabel("미세먼지(㎍/㎥)")
plt.show()
```

<Callout type="tip">
  `plt.plot()`과 `plt.bar()`는 사용법이 거의 똑같다냥! x축 리스트와
  y축 리스트만 바꿔 넣으면, 나머지 `title`, `xlabel`, `ylabel`,
  `show()`는 그대로 쓸 수 있다냥.
</Callout>

## 3단계 · 한글 깨짐 방지하기 (7분)

<NyangSpeech>
  matplotlib은 원래 한글 폰트를 기본으로 지원하지 않아서, 그냥
  실행하면 한글이 네모(□)로 깨져 보일 수 있다냥! 코드 맨 앞에 폰트
  설정을 딱 한 줄 추가하면 해결된다냥.
</NyangSpeech>

```python
import matplotlib.pyplot as plt

# 한글 폰트 설정 (Windows는 맑은 고딕, Mac은 AppleGothic)
plt.rcParams["font.family"] = "Malgun Gothic"
plt.rcParams["axes.unicode_minus"] = False  # 마이너스 기호 깨짐 방지
```

<StepCard step="핵심" title="한글 폰트, 이것만 기억하자냥!">

| 운영체제 | 폰트 이름 |
|---|---|
| Windows | `"Malgun Gothic"` (맑은 고딕) |
| macOS | `"AppleGothic"` |

</StepCard>

<Callout type="note">
  `axes.unicode_minus = False`도 함께 설정해줘야 한다냥! 한글
  폰트로 바꾸면 마이너스(`-`) 기호가 깨지는 경우가 있는데, 이
  옵션이 그걸 막아준다냥.
</Callout>
