<MissionCard number={1} title="한글 폰트 설정하기" time="5~7분">

그래프를 그리기 전에, 한글이 깨지지 않도록 폰트부터 설정해보자냥!
아래 템플릿에서 **빈칸(`____`)을 채워보자냥.**

```python
import matplotlib.pyplot as plt

plt.rcParams["font.family"] = ____  # 윈도우 기준
plt.rcParams["axes.unicode_minus"] = False
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 윈도우용 한글 폰트 이름을 문자열로 넣으면 된다냥. (`"Malgun Gothic"`)
> - Mac을 쓰고 있다면 `"AppleGothic"`으로 바꿔서 넣어도 좋다냥.

</MissionCard>

<MissionCard number={2} title="요일별 승차인원 선 그래프 그리기" time="10~12분">

요일별 지하철 승차인원 변화를 선 그래프로 그려보자냥.

```python
요일 = ["월", "화", "수", "목", "금"]
승차인원 = [12000, 11500, 13000, 12800, 15200]

plt.____(요일, 승차인원)
plt.title("요일별 지하철 승차인원")
plt.xlabel("요일")
plt.ylabel("승차인원")
plt.show()
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 선 그래프를 그리는 함수 이름을 넣으면 된다냥. (`plot`)
> - 금요일에 승차인원이 가장 높게 올라가는 그래프가 보이냥?

</MissionCard>

<MissionCard number={3} title="구별 미세먼지 막대 그래프 그리기" time="8~10분">

이번엔 구별 미세먼지를 막대 그래프로 비교해보자냥.

```python
구 = ["중구", "강남구", "종로구", "마포구"]
미세먼지 = [30, 42, 25, 38]

plt.____(구, 미세먼지)
plt.title("구별 미세먼지 농도")
plt.xlabel("구")
plt.ylabel("미세먼지(㎍/㎥)")
plt.show()
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 막대 그래프를 그리는 함수 이름을 넣으면 된다냥. (`bar`)
> - 강남구 막대가 가장 높게 나오냥?

<StepCard step="관찰" title="plot과 bar, 사용법은 거의 똑같다냥!">

x축 리스트와 y축 리스트만 넣으면, `title`, `xlabel`, `ylabel`,
`show()`는 두 그래프에서 똑같이 사용할 수 있다냥.

</StepCard>

</MissionCard>
