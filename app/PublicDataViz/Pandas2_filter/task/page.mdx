<MissionCard number={1} title="조건으로 역 걸러내기" time="10~12분">

지하철역 데이터에서, 승차인원이 많은 역만 걸러보자냥! 아래 템플릿에서
**빈칸(`____`)을 채워보자냥.**

```python
import pandas as pd

data = {
    "역명": ["강남", "역삼", "선릉", "삼성"],
    "승차인원": [15230, 9820, 11400, 13500],
}
df = pd.DataFrame(data)

# 승차인원이 12000보다 많은 역만 걸러보세요
붐비는역 = df[df["승차인원"] > ____]
print(붐비는역)
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 기준이 되는 숫자를 넣으면 된다냥. (`12000`)
> - 강남과 삼성만 결과에 나오냥?

</MissionCard>

---

<MissionCard number={2} title="두 조건 함께 걸기" time="8~10분">

이번엔 조건 두 개를 동시에 걸어보자냥!

```python
# 승차인원이 10000 이상 14000 이하인 역만 걸러보세요
중간역 = df[____]
print(중간역)
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 두 조건을 `&`(그리고)로 묶은 전체 조건을 넣으면 된다냥.
>   예: `(df["승차인원"] >= 10000) & (df["승차인원"] <= 14000)`
> - 선릉과 삼성만 결과에 나오냥?

<Callout type="important">
  괄호를 빠뜨리면 에러가 난다냥! `(조건1) & (조건2)`처럼 각 조건을 꼭
  괄호로 감싸주자냥.
</Callout>

</MissionCard>

<MissionCard number={3} title="승차인원 순서로 줄 세우기" time="8~10분">

이제 전체 데이터를 승차인원 순서로 정렬해보자냥.

```python
# 승차인원이 많은 순서(내림차순)로 정렬해보세요
정렬결과 = df.sort_values("승차인원", ascending=____)
print(정렬결과)
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 True 또는 False가 들어간다냥. 큰 값부터 보고 싶으니 오름차순이 아니라는 뜻으로 넣어야 한다냥. (`False`)
> - 강남이 맨 위에 나오냥?

<StepCard step="관찰" title="정렬 후에도 원래 데이터는 그대로!">

`sort_values()`는 정렬된 **새로운 결과**를 돌려줄 뿐, 원래 `df`는 바뀌지
않는다냥. `print(df)`를 다시 실행해보면 원래 순서 그대로인 걸 확인할 수
있다냥!

</StepCard>

</MissionCard>
