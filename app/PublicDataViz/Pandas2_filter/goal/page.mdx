## 1단계 · 조건으로 데이터 걸러내기 (10분)

<NyangSpeech>
  질문 하나 할게냥! "미세먼지가 30보다 심한 측정소만 보고 싶다"고
  하면, 어떻게 할까냥? 바로 **조건 필터링**을 쓰면 된다냥!
</NyangSpeech>

```python
import pandas as pd

data = {
    "측정소": ["중구", "강남구", "종로구", "마포구"],
    "미세먼지": [30, 42, 25, 55],
}
df = pd.DataFrame(data)

심한곳 = df[df["미세먼지"] > 30]
print(심한곳)
```

```text
   측정소  미세먼지
1  강남구    42
3  마포구    55
```

<Callout type="important">
  `df["미세먼지"] > 30`은 각 행이 조건을 만족하는지 `True`/`False`로
  알려주는 **Series**를 만든다냥. 이걸 `df[...]` 안에 넣으면, `True`인
  행만 쏙쏙 골라내는 거다냥!
</Callout>

## 2단계 · 여러 조건 한꺼번에 (10분)

<NyangSpeech>
  조건을 두 개 이상 동시에 쓰고 싶을 때도 있다냥. 이럴 땐 `&`(그리고)와
  `|`(또는)를 쓴다냥!
</NyangSpeech>

<CompareBubble
  left={{
    emoji: '➕',
    label: '& (그리고, AND)',
    color: 'blue',
    items: [
      '두 조건을 모두 만족해야 함',
      '예: 미세먼지가 30 초과 AND 45 이하',
    ],
  }}
  right={{
    emoji: '↔️',
    label: '| (또는, OR)',
    color: 'purple',
    items: [
      '둘 중 하나만 만족해도 됨',
      '예: 측정소가 중구 OR 마포구',
    ],
  }}
/>

```python
# 미세먼지가 30 초과 45 이하인 곳
중간 = df[(df["미세먼지"] > 30) & (df["미세먼지"] <= 45)]
print(중간)

# 측정소가 중구 또는 마포구인 곳
특정지역 = df[(df["측정소"] == "중구") | (df["측정소"] == "마포구")]
print(특정지역)
```

<Callout type="tip">
  조건을 `&`나 `|`로 묶을 때는, **각 조건을 꼭 괄호로 감싸야 한다냥!**
  `df["미세먼지"] > 30 & ...`처럼 괄호 없이 쓰면 에러가 나기 쉽다냥.
</Callout>

## 3단계 · 순서대로 줄 세우기 (8분)

<NyangSpeech>
  이번엔 데이터를 순서대로 정렬해보자냥! `sort_values()`를 쓰면 된다냥.
</NyangSpeech>

```python
# 미세먼지가 낮은 순서대로 정렬
오름차순 = df.sort_values("미세먼지")
print(오름차순)

# 미세먼지가 높은 순서대로 정렬 (내림차순)
내림차순 = df.sort_values("미세먼지", ascending=False)
print(내림차순)
```

<StepCard step="핵심" title="sort_values, 이것만 기억하자냥!">

| 코드 | 하는 일 |
|---|---|
| `df.sort_values("열이름")` | 오름차순(작은 값 → 큰 값) 정렬 |
| `df.sort_values("열이름", ascending=False)` | 내림차순(큰 값 → 작은 값) 정렬 |

</StepCard>

<Callout type="note">
  `ascending`은 "오름차순"이라는 뜻의 영어다냥. `ascending=False`라고
  쓰면 "오름차순이 아니다" → 즉 "내림차순"이 된다냥!
</Callout>
