## 1단계 · 추이 그래프 넣기 (7분)

<NyangSpeech>
  기초 과정 마지막 시간에 배운 streamlit, 기억나냥? `st.line_chart()`로
  추이 그래프를 앱에 넣어보자냥!
</NyangSpeech>

```python
import streamlit as st
import pandas as pd

st.title("우리 동네 미세먼지 대시보드")

data = {
    "날짜": pd.to_datetime(["2025-01-01", "2025-01-02", "2025-01-03"]),
    "지역": ["강남구", "강남구", "강남구"],
    "미세먼지": [30, 42, 38],
}
df = pd.DataFrame(data)

st.line_chart(df, x="날짜", y="미세먼지")
```

<Callout type="important">
  `st.line_chart()`는 `st.bar_chart()`와 사용법이 똑같다냥! DataFrame과
  x, y 열 이름만 넣으면, 별도의 matplotlib 코드 없이 바로 추이
  그래프가 나타난다냥.
</Callout>

```python
전체지역 = df["지역"].unique()
선택지역 = st.selectbox("지역을 선택하세요", 전체지역)

# 고른 지역만 남긴다냥 — 이게 "필터링"이다냥!
선택된_df = df[df["지역"] == 선택지역]

st.write(f"선택한 지역: {선택지역}")
st.line_chart(선택된_df, x="날짜", y="미세먼지")
```

<Callout type="tip">
  목록을 손으로 적지 않고 `df["지역"].unique()`로 데이터에서 직접
  뽑는 게 요령이다냥. 그러면 지역이 늘어나도 코드를 고칠 필요가
  없다냥. 그리고 **고른 값으로 실제 데이터를 걸러내야** 대시보드가
  진짜로 동작한다냥 — 화면에 출력만 하면 아무것도 바뀌지 않는다냥!
</Callout>

## 3단계 · 기준치 슬라이더 넣기 (8분)

<NyangSpeech>
  지난 시간에 "기준치를 넘는 지역"을 코드로 직접 정했었지냥? 오늘은
  그 기준치를, **사용자가 슬라이더로 직접 조절**하게 만들어보자냥!
</NyangSpeech>

```python
기준치 = st.slider("위험 기준치", min_value=0, max_value=100, value=35)

st.write(f"기준치: {기준치} 이상이면 위험 지역으로 표시합니다.")

if df["미세먼지"].mean() > 기준치:
    st.write("⚠️ 이 지역은 기준치를 넘었습니다!")
else:
    st.write("✅ 이 지역은 기준치 이내입니다.")
```

<StepCard step="핵심" title="st.slider()의 4가지 재료">

| 매개변수 | 뜻 |
|---|---|
| `"위험 기준치"` | 슬라이더 위에 표시될 안내 문구 |
| `min_value` | 슬라이더가 가질 수 있는 최솟값 |
| `max_value` | 슬라이더가 가질 수 있는 최댓값 |
| `value` | 처음 화면에 보일 기본값 |

</StepCard>

<Callout type="note">
  `st.slider()`가 돌려주는 값도 `st.selectbox()`처럼, 사용자가
  움직일 때마다 **실시간으로 바뀐다**냥! 이 값을 `if`문 조건으로
  쓰면, 슬라이더를 움직일 때마다 위험 여부 메시지가 바로 바뀐다냥.
</Callout>
