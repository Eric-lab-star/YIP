<MissionCard number={1} title="추이 그래프 넣기" time="7~8분">

앱 제목을 달고, 미세먼지 추이 그래프를 넣어보자냥! 아래 템플릿에서
**빈칸(`____`)을 채워보자냥.**

```python
import streamlit as st
import pandas as pd

st.title("우리 동네 미세먼지 대시보드")

data = {
    "날짜": pd.to_datetime(["2025-01-01", "2025-01-02", "2025-01-03"]),
    "미세먼지": [30, 42, 38],
}
df = pd.DataFrame(data)

st.____(df, x="날짜", y="미세먼지")
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 추이(선) 그래프를 그리는 함수 이름을 넣으면 된다냥. (`line_chart`)
> - 날짜순으로 오르내리는 선이 보이냥?

</MissionCard>

<MissionCard number={2} title="지역 선택 필터 넣기" time="8~10분">

사용자가 지역을 고를 수 있게 만들어보자냥.

```python
전체지역 = ["강남구", "중구", "마포구"]
선택지역 = st.____("지역을 선택하세요", 전체지역)

선택된_df = df[df["지역"] == ____]      # 고른 지역만 남기기
st.write(f"선택한 지역: {선택지역}")
st.dataframe(선택된_df)
```

> **확인해보자냥 (빈칸 힌트)**
> - 첫 `____`에는 목록에서 하나를 고르는 함수 이름을 넣으면 된다냥. (`selectbox`)
> - 둘째 `____`에는 방금 고른 값이 담긴 변수를 넣으면 된다냥. (`선택지역`)
> - 다른 지역을 고르면 **표의 내용까지** 바뀌냥? 문장만 바뀌면 필터링이 안 된 거다냥!

</MissionCard>

<MissionCard number={3} title="기준치 슬라이더 넣기" time="10~12분">

사용자가 기준치를 직접 조절할 수 있게 만들어보자냥.

```python
기준치 = st.____("위험 기준치", min_value=0, max_value=100, value=35)

if df["미세먼지"].mean() > 기준치:
    st.write("⚠️ 이 지역은 기준치를 넘었습니다!")
else:
    st.write("✅ 이 지역은 기준치 이내입니다.")
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 숫자를 직접 조절하는 슬라이더 함수 이름을 넣으면 된다냥. (`slider`)
> - 슬라이더를 낮추면 경고 메시지로 바뀌냥?

<StepCard step="관찰" title="슬라이더 값이 조건문을 바꾼다냥!">

`기준치`는 슬라이더를 움직일 때마다 값이 바뀌는 변수다냥. 그
값이 `if`문의 조건으로 쓰이기 때문에, 슬라이더를 움직이면 화면의
메시지도 실시간으로 바뀐다냥!

</StepCard>
