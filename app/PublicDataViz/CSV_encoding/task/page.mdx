<MissionCard number={2} title="CSV 읽고 인코딩 문제 해결하기" time="10~12분">

이제 내려받은 파일을 pandas로 읽어보자냥! 아래 템플릿에서
**빈칸(`____`)을 직접 채워보자냥.**

```python
import pandas as pd

# 1) 먼저 기본값(UTF-8)으로 읽어보세요
df = pd.read_csv("여기에 파일 이름 입력.csv")
print(df.head())
```

> **확인해보자냥**
> - 한글 열 이름(역명, 승차인원 등)이 잘 보이냥, 아니면 깨져 보이냥?

한글이 깨져 보인다면, 아래처럼 인코딩 옵션을 추가해보자냥.

```python
# 2) 한글이 깨진다면 encoding 옵션을 추가해서 다시 읽어보세요
df = pd.read_csv("여기에 파일 이름 입력.csv", encoding=____)
print(df.head())
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 개념 강의에서 배운 한국 공공기관 CSV에 자주 쓰이는 인코딩을 따옴표로 감싸서 넣으면 된다냥. (`"cp949"`)
> - 이번엔 한글이 잘 보이냥?

<Callout type="important">
  **`UnicodeDecodeError`가 뜬다면?** 인코딩이 맞지 않다는 신호다냥!
  `encoding="cp949"`를 시도해보고, 그래도 안 되면 `encoding="euc-kr"`을
  시도해보자냥.
</Callout>

</MissionCard>

<MissionCard number={3} title="불러온 데이터 살펴보기" time="8~10분">

파일을 잘 읽었다면, DataFrame의 기본 정보를 확인해보자냥.

```python
print("행과 열의 개수:", df.shape)
print("열 이름:", df.columns.tolist())
print(df.head(3))
```

> **확인해보자냥**
> - 몇 행, 몇 열인지 확인했냥?
> - 열 이름들을 보고, 어떤 정보가 담겨 있는지 짐작할 수 있냥?

<StepCard step="관찰" title="shape과 columns, 이것만 기억하자냥!">

| 코드 | 하는 일 |
|---|---|
| `df.shape` | (행 개수, 열 개수)를 튜플로 보여줌 |
| `df.columns` | 열 이름들을 보여줌 |
| `df.head(n)` | 위에서부터 n개 행만 미리보기 |

</StepCard>
