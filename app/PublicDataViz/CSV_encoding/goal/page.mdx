## 1단계 · CSV 파일이 뭐냥? (5분)

<NyangSpeech>
  CSV는 **Comma-Separated Values**의 줄임말이다냥. 이름 그대로, 쉼표(,)로
  값을 구분해서 적어놓은 아주 단순한 표 형식의 파일이다냥!
</NyangSpeech>

```text
역명,승차인원,하차인원
강남,15230,14800
역삼,9820,9500
```

이렇게 생긴 파일을 엑셀로 열면 표처럼 보이지만, 사실은 그냥 **글자로만
이루어진 텍스트 파일**이다냥. 공공데이터포털의 파일 데이터 대부분이 이
CSV 형식으로 제공된다냥.

<Callout type="important">
  CSV는 엑셀 파일(`.xlsx`)보다 훨씬 가볍고 다루기 쉬워서, 데이터 분석에서
  가장 많이 쓰이는 형식이다냥!
</Callout>

## 2단계 · pandas로 CSV 읽기 (8분)

<NyangSpeech>
  이제 이 CSV 파일을 파이썬으로 읽어보자냥! **pandas**라는 라이브러리를
  쓰면 CSV를 표(DataFrame) 형태로 순식간에 불러올 수 있다냥. pandas는
  다음 시간부터 본격적으로 배울 거고, 오늘은 `read_csv()`만 먼저
  맛보기로 써보자냥.
</NyangSpeech>

```python
import pandas as pd

df = pd.read_csv("subway.csv")
print(df)
```

<Callout type="note">
  `pd.read_csv()` 딱 한 줄이면, CSV 파일 전체가 표 형태로 변신한다냥! 이
  표를 **DataFrame(데이터프레임)**이라고 부른다냥.
</Callout>

## 3단계 · 한글이 깨져요! 인코딩이 뭐냥? (12분)

<NyangSpeech>
  자, 그런데 방금 코드를 그대로 실행했는데 한글이 `?좑깖?ㅼ쨮` 처럼
  이상하게 나온다면? 당황하지 말라냥! 이건 **인코딩(encoding)** 문제다냥.
</NyangSpeech>

컴퓨터는 글자를 숫자로 바꿔서 저장한다냥. 이때 "어떤 규칙으로 숫자로
바꿀지" 정하는 게 바로 **인코딩**이다냥. 문제는, 이 규칙이 여러 가지라는
거다냥!

      '공공데이터포털 CSV 파일에 아직도 많이 남아있음',
      'UTF-8로 읽으면 한글이 깨짐',

  }}
/>

이 두 규칙이 서로 다르다 보니, **CP949로 저장된 파일을 UTF-8인 줄 알고
읽으면** 한글이 깨져 보이는 거다냥. 해결법은 간단하다냥 — `read_csv()`에
`encoding` 옵션을 정확히 알려주면 된다냥!

```python
import pandas as pd

# UTF-8로 읽었는데 한글이 깨진다면, cp949로 다시 시도해보자
df = pd.read_csv("subway.csv", encoding="cp949")
print(df)
```

<StepCard step="문제 해결" title="한글이 깨질 때, 이 순서로 시도해보자냥!">

1. 아무 옵션 없이 `pd.read_csv("파일명")`으로 읽어본다냥. (기본값은 UTF-8)
2. 한글이 깨지면 `encoding="cp949"`를 추가해서 다시 읽어본다냥.
3. 그래도 안 되면 `encoding="euc-kr"`을 시도해본다냥. (cp949와 거의 비슷하다냥)

</StepCard>

<Callout type="tip">
  공공데이터포털에서 내려받은 한국 정부/공공기관 CSV 파일은 **cp949일 확률이
  꽤 높다냥**. 한글이 깨지면 제일 먼저 `encoding="cp949"`부터 시도해보자냥!
</Callout>
