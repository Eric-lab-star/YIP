<MissionCard number={1} title="날짜를 datetime으로 바꾸기" time="8~10분">

문자열 날짜를 진짜 날짜 타입으로 바꿔보자냥! 아래 템플릿에서
**빈칸(`____`)을 채워보자냥.**

```python
import pandas as pd

data = {
    "날짜": ["2025-01-03", "2025-01-01", "2025-01-02"],
    "미세먼지": [45, 30, 38],
}
df = pd.DataFrame(data)

df["날짜"] = pd.____(df["날짜"])
print(df["날짜"].dtype)
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 문자열을 날짜 타입으로 바꾸는 함수 이름을 넣으면 된다냥. (`to_datetime`)
> - dtype이 datetime64로 바뀌냥?

<MissionCard number={3} title="추이 선 그래프 그리기" time="10~12분">

정렬한 데이터로 미세먼지 추이를 그려보자냥.

```python

plt.rcParams["font.family"] = "Malgun Gothic"

plt.____(정렬됨["날짜"], 정렬됨["미세먼지"])

```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 선 그래프를 그리는 함수 이름을 넣으면 된다냥. (`plot`)
