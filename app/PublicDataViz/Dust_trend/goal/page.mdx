## 2단계 · 날짜를 진짜 날짜로 바꾸기 (10분)

<NyangSpeech>
  CSV에서 날짜를 읽으면, 파이썬은 그걸 그냥 **문자열**로 취급한다냥.
  "2025-01-15"라는 문자열은 크기 비교나 정렬이 이상하게 될 수
  있어서, `datetime` 타입으로 바꿔줘야 한다냥!
</NyangSpeech>

```python
import pandas as pd

data = {
    "날짜": ["2025-01-03", "2025-01-01", "2025-01-02"],
    "미세먼지": [45, 30, 38],
}
df = pd.DataFrame(data)

print(df["날짜"].dtype)  # object (문자열)

df["날짜"] = pd.to_datetime(df["날짜"])
print(df["날짜"].dtype)  # datetime64
```

<Callout type="important">
  `pd.to_datetime()`은 문자열을 진짜 **날짜/시간 타입**으로
  바꿔준다냥. 이렇게 바꾸고 나면, 날짜순 정렬이나 "이번 달만
  보기" 같은 작업이 훨씬 쉬워진다냥!
</Callout>

## 3단계 · 날짜순 정렬하고 추이 그리기 (10분)

<NyangSpeech>
  날짜 타입으로 바꿨다면, `sort_values()`로 날짜순 정렬을 하고
  선 그래프로 추이를 그려보자냥.
</NyangSpeche>

```python
정렬됨 = df.sort_values("날짜")
print(정렬됨)

import matplotlib.pyplot as plt
plt.rcParams["font.family"] = "Malgun Gothic"

plt.plot(정렬됨["날짜"], 정렬됨["미세먼지"])
plt.title("날짜별 미세먼지 추이")
plt.xlabel("날짜")
plt.ylabel("미세먼지(㎍/㎥)")
plt.show()
```

<StepCard step="핵심" title="날짜 데이터, 이 순서로 다루자냥!">

| 순서 | 코드 |
|---|---|
| 1. 날짜 타입 변환 | `df["날짜"] = pd.to_datetime(df["날짜"])` |
| 2. 날짜순 정렬 | `df.sort_values("날짜")` |
| 3. 추이 그리기 | `plt.plot(날짜, 값)` |

</StepCard>

<Callout type="tip">
  선 그래프는 x축이 **순서대로 늘어서 있을 때** 의미가 있다냥.
  날짜 데이터는 정렬을 꼭 먼저 해줘야, 선이 오락가락하지 않고
  깔끔한 추이를 보여준다냥!
</Callout>
