<NyangSpeech>

<Callout type="note">
  **이번 프로젝트 데이터 출처**

  - 제공처: 서울열린데이터광장 (data.seoul.go.kr) — "지하철 호선별 역별 시간대별 승하차 인원" (예시)
  - 라이선스: 공공누리 제1유형 (출처 표시 시 자유 이용 가능)
  - 이 수업에서는 실제 파일 대신, **같은 구조를 가진 작은 예시 데이터**로 연습한다냥.
</Callout>

```python
import pandas as pd

# 실제로 내려받으면 이런 모습의 원본 데이터를 만나게 된다냥
원본 = {
    "사용월": ["202501", "202501", "202501", "202501"],
    "호선명": ["2호선", "2호선", "3호선", "3호선"],
    "역명": ["강남", "역삼", "충무로", "동대입구"],
    "승차총승객수": [452300, 298100, 187600, -1],   # -1은 이상치(오류값)다냥
    "하차총승객수": [447800, 301200, None, 96200],  # None은 결측치다냥
}
df = pd.DataFrame(원본)
print(df)
```

<Callout type="important">
  실제 공공데이터는 지금까지 연습한 깔끔한 예시와 달리, **열 이름이
  길고**, **결측치나 이상한 값(예: 음수)**이 섞여 있는 경우가
  흔하다냥. 오늘은 이걸 정리하는 실전 연습을 해보는 거다냥!
</Callout>

<Callout type="tip">
  `rename(columns={...})`은 **기존 이름: 새 이름** 형태로 딕셔너리를
  넣으면 된다냥. `df[[...]]`으로 먼저 필요한 열만 고른 뒤 이름을
  바꾸면, 코드 순서가 자연스럽다냥!

## 3단계 · 결측치와 이상치 점검하기 (8분)

<NyangSpeech>
  기초 과정에서 배운 데이터 클리닝 실력을 여기서 발휘할 차례다냥!
  결측치는 `isna()`로, 이상치(음수 같은 말이 안 되는 값)는 조건
  필터링으로 찾아보자냥.
</NyangSpeech>

```python
# 결측치 확인
print(정리.isna().sum())

# 이상치 확인: 승차 인원이 음수인 행 찾기
이상치 = 정리[정리["승차"] < 0]
print(이상치)

# 결측치는 0으로, 이상치는 통째로 제거
정리["하차"] = 정리["하차"].fillna(0)
정리 = 정리[정리["승차"] >= 0]
print(정리)
```

<StepCard step="핵심" title="정리 순서, 이렇게 기억하자냥!">

| 순서 | 하는 일 |
|---|---|
| 1. 열 고르기 | 필요한 열만 남기고 이름 정리 |
| 2. 결측치 확인 | `isna().sum()`으로 빈 값 개수 파악 |
| 3. 이상치 확인 | 조건 필터링으로 말이 안 되는 값 찾기 |
| 4. 처리하기 | `fillna()` 또는 조건으로 제거 |

</StepCard>

<Callout type="note">
  이상치를 무조건 지우는 게 정답은 아니다냥! 실제 프로젝트에서는
  "왜 음수가 나왔을까?"를 먼저 생각해보는 게 좋다냥. 여기서는
  명백한 오류값이라 판단해서 제거했다냥.
</Callout>
