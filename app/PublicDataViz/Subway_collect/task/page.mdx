<MissionCard number={1} title="필요한 열만 골라 이름 정리하기" time="10~12분">

원본 데이터에서 필요한 열만 고르고, 이름을 정리해보자냥! 아래
템플릿에서 **빈칸(`____`)을 채워보자냥.**

```python
import pandas as pd

원본 = {
    "사용월": ["202501", "202501", "202501"],
    "호선명": ["2호선", "3호선", "3호선"],
    "역명": ["강남", "충무로", "동대입구"],
    "승차총승객수": [452300, 187600, 132400],
    "하차총승객수": [447800, 190100, 129700],
}
df = pd.DataFrame(원본)

정리 = df[["호선명", "역명", "승차총승객수", "하차총승객수"]].rename(
    columns={"승차총승객수": ____, "하차총승객수": "하차"}
)
print(정리)
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 "승차총승객수"를 바꿀 새 이름을 문자열로 넣으면 된다냥. (`"승차"`)
> - 결과 표의 열 이름이 "승차", "하차"로 짧아지냥?

```python
    "하차": [14800, 9500, np.nan],

print(빈값)
print(이상치)
```

> **확인해보자냥 (빈칸 힌트)**

<MissionCard number={3} title="결측치·이상치 처리하기" time="8~10분">

찾아낸 문제를 실제로 고쳐보자냥.

```python
df2["하차"] = df2["하차"].fillna(____)
df2 = df2[df2["승차"] >= ____]
print(df2)
```

> **확인해보자냥 (빈칸 힌트)**
> - 첫 번째 `____` 자리에는 빈 값을 채울 숫자를 넣으면 된다냥. (`0`)
> - 두 번째 `____` 자리에는 승차 인원의 최소 허용값을 넣으면 된다냥. (`0`)
> - 역삼역이 결과에서 사라지고, 2개 행만 남냥?

<StepCard step="관찰" title="처리 순서가 결과를 바꾼다냥!">

`fillna()`를 먼저 하고 `df2[df2["승차"] >= 0]`으로 걸러내면, 하차
열의 빈 값은 채워지고 승차 열의 이상치만 제거된다냥. 순서를 바꿔서
해봐도 결과가 같은지 직접 확인해보자냥!
