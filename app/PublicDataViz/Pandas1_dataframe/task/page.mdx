<MissionCard number={1} title="딕셔너리로 DataFrame 만들기" time="10~12분">

지난 시간에 내려받은 지하철 데이터를 흉내 내서, 미세먼지 측정소 데이터를
직접 만들어보자냥! 아래 템플릿에서 **빈칸(`____`)을 채워보자냥.**

```python
import pandas as pd

data = {
    "측정소": ["중구", "강남구", "종로구"],
    "미세먼지": [30, 42, 25],
    ____: [15, 21, 12],  # 열 이름을 "초미세먼지"로 지어보세요
}

df = pd.DataFrame(data)
print(df)
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 열 이름을 문자열로 넣으면 된다냥. (`"초미세먼지"`)
> - 3행 3열의 표가 잘 출력되냥?

</MissionCard>

<MissionCard number={2} title="열 꺼내보기" time="8~10분">

만든 표에서 원하는 열을 꺼내보자냥.

```python
# 미세먼지 열만 꺼내보세요
미세먼지_열 = df[____]
print(미세먼지_열)
print(type(미세먼지_열))

# 측정소와 미세먼지, 두 열을 함께 꺼내보세요
두열 = df[["측정소", ____]]
print(두열)
```

> **확인해보자냥 (빈칸 힌트)**
> - 첫 번째 `____`에는 열 이름을 문자열로 넣는다냥. (`"미세먼지"`)
> - 두 번째 `____`에는 함께 꺼내고 싶은 다른 열 이름을 넣는다냥. (`"미세먼지"`)
> - `type(미세먼지_열)`을 출력하면 `Series`라고 나오냥?

<StepCard step="확인" title="대괄호 한 번 vs 두 번">

`df["열"]`은 대괄호가 **한 번**이라 Series가 나오고, `df[["열1", "열2"]]`는
대괄호가 **두 번**(리스트를 넣음)이라 DataFrame이 나온다냥! 헷갈리기 쉬우니
꼭 기억해두자냥.

</StepCard>

</MissionCard>

<MissionCard number={3} title="행 꺼내보기" time="8~10분">

이번엔 특정 측정소의 데이터를 행 단위로 꺼내보자냥.

```python
# 첫 번째 측정소(중구) 데이터를 통째로 꺼내보세요
첫번째 = df.iloc[____]
print(첫번째)

# 세 번째 측정소(종로구) 데이터도 꺼내보세요
세번째 = df.iloc[____]
print(세번째)
```

> **확인해보자냥 (빈칸 힌트)**
> - `.iloc[]`의 번호는 0부터 시작한다냥! 첫 번째는 `0`, 세 번째는 `2`다냥.
> - 각 측정소의 모든 열 값이 한 번에 출력되냥?

</MissionCard>
