## 2단계 · 딕셔너리로 DataFrame 만들기 (10분)

<NyangSpeech>
  CSV 파일이 없어도, 파이썬 딕셔너리만으로 직접 DataFrame을 만들 수
  있다냥! 실습할 때 예시 데이터를 빨리 만들고 싶을 때 아주 유용하다냥.
</NyangSpeech>

```python
import pandas as pd

data = {
    "역명": ["강남", "역삼", "선릉"],
    "승차인원": [15230, 9820, 11400],
    "하차인원": [14800, 9500, 11100],
}

df = pd.DataFrame(data)
print(df)
```

```text
   역명   승차인원   하차인원
0  강남   15230   14800
1  역삼    9820    9500
2  선릉   11400   11100
```

<Callout type="note">
  딕셔너리의 **키(key)**는 열 이름이 되고, **값(value)의 리스트**는 그
  열의 데이터가 된다냥. 맨 왼쪽에 자동으로 붙는 `0, 1, 2`는 **인덱스
  (index)**라고 부르는 행 번호다냥.
</Callout>

## 3단계 · 열(Column) 접근하기 (8분)

<NyangSpeech>
  이제 표에서 원하는 열만 쏙 꺼내보자냥! 대괄호 안에 열 이름을 적으면
  된다냥.
</NyangSpeech>

```python
승차 = df["승차인원"]
print(승차)
print(type(승차))
```

```text
0    15230
1     9820
2    11400
Name: 승차인원, dtype: int64
<class 'pandas.core.series.Series'>
```

<Callout type="important">
  `df["열이름"]`으로 꺼낸 결과는 **Series**다냥! 방금 배운 대로, DataFrame의
  열 하나가 바로 Series라는 걸 코드로 직접 확인한 거다냥.
</Callout>

열을 **여러 개** 꺼내고 싶다면, 대괄호를 두 번 겹쳐서 리스트로 넣으면 된다냥.

```python
일부 = df[["역명", "승차인원"]]
print(일부)
print(type(일부))  # 이번엔 DataFrame!
```

## 4단계 · 행(Row) 접근하기 (7분)

<NyangSpeech>
  이번엔 반대로, 특정 **행(줄)**을 꺼내보자냥! `.iloc`을 쓰면 번호로 행을
  꺼낼 수 있다냥.
</NyangSpeech>

<StepCard step="핵심" title="행에 접근하는 두 가지 방법">

| 코드 | 하는 일 |
|---|---|
| `df.iloc[0]` | **위치 번호**로 첫 번째 행을 꺼냄 (0부터 시작) |
| `df.loc[0]` | **인덱스 값**으로 행을 꺼냄 (보통 iloc과 같지만, 인덱스를 바꾸면 달라질 수 있음) |

</StepCard>

```python
첫줄 = df.iloc[0]
print(첫줄)
```

```text
역명         강남
승차인원    15230
하차인원    14800
Name: 0, dtype: object
```

<Callout type="tip">
  헷갈린다면 당분간은 `.iloc`만 써도 충분하다냥! "숫자로 몇 번째 줄인지
  꺼낸다"고 기억하면 된다냥.
</Callout>
