<MissionCard number={1} title="앱 제목과 표 보여주기" time="8~10분">

앱의 제목을 달고, 미세먼지 데이터를 표로 보여주자냥! 아래
템플릿에서 **빈칸(`____`)을 채워보자냥.**

```python
import streamlit as st
import pandas as pd

st.____("우리 동네 미세먼지 앱")

data = {
    "구": ["중구", "강남구", "종로구", "마포구"],
    "미세먼지": [30, 42, 25, 38],
}
df = pd.DataFrame(data)

st.dataframe(df)
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 앱의 제목을 크게 보여주는 함수 이름을 넣으면 된다냥. (`title`)
> - 터미널에서 `streamlit run app.py`를 입력했을 때 브라우저가 자동으로 열리냥?

<MissionCard number={3} title="선택창으로 필터링하기" time="10~12분">

사용자가 구를 골라서, 그 구의 미세먼지만 볼 수 있게 만들어보자냥.

```python
선택한구 = st.____("구를 선택하세요", df["구"])

필터된_df = df[df["구"] == 선택한구]
st.write(f"{선택한구}의 미세먼지: {필터된_df['미세먼지'].values[0]}")
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 목록에서 하나를 고를 수 있는 선택창을 만드는 함수 이름을 넣으면 된다냥. (`selectbox`)
> - 다른 구를 선택할 때마다 아래 문장이 바뀌냥?

<StepCard step="확인" title="화면이 자동으로 업데이트된다냥!">

streamlit은 사용자가 선택창을 바꿀 때마다 **코드 전체를 다시
실행**해서 화면을 새로 그린다냥. 그래서 별도의 새로고침 버튼 없이도
바로바로 반영되는 것이다냥!

</StepCard>
