<MissionCard number={2} title="API 요청 보내기" time="10~12분">

이제 3차시에 발급받은 인증키로 진짜 요청을 보내보자냥! 아래 템플릿에서
**빈칸(`____`)을 직접 채워보자냥.**

```python
import requests

url = "http://apis.data.go.kr/B552584/ArpltnInforInqireSvc/getCtprvnRltmMesureDnsty"

params = {
    "serviceKey": ____,  # 3차시에 발급받은 인증키를 그대로 넣어보세요
    "returnType": "json",
    "numOfRows": 10,
    "pageNo": 1,
    "sidoName": "서울",
    "ver": "1.0",
}

response = requests.get(url, params=params)
print("상태 코드:", response.status_code)
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 문자열로 된 본인의 인증키를 따옴표로 감싸서 넣으면 된다냥.
>   예: `"serviceKey": "여기에 나만의 인증키"`
> - 상태 코드가 **200**으로 출력되냥?

<Callout type="important">
  **상태 코드가 200이 아니라면?** 개념 강의 4단계에서 배운 흔한 원인들을
  하나씩 확인해보자냥 — 인증키 오타, 앞뒤 공백, 승인 대기 중
  등이다냥.
</Callout>

</MissionCard>

<MissionCard number={3} title="원하는 데이터 꺼내기" time="10~13분">

요청이 성공했다면, 이제 JSON 응답에서 우리가 원하는 값만 쏙쏙 꺼내보자냥!
아래 템플릿에서 **빈칸(`____`)을 채워보자냥.**

```python
data = response.json()
items = data["response"]["body"][____]  # 실제 데이터가 담긴 부분을 넣어보세요

for item in items:
    station = item["stationName"]
    pm10 = item["pm10Value"]
    print(f"{station} 측정소 - 미세먼지(PM10): {pm10}")
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 개념 강의에서 배운, 실제 데이터 리스트가 들어있는 키를 넣으면 된다냥. (`"items"`)
> - 서울 각 지역의 측정소 이름과 미세먼지 수치가 잘 출력되냥?

<StepCard step="관찰" title="측정소마다 값이 다른 이유">

같은 서울이라도 측정소마다 미세먼지 수치가 다르게 나온다냥! 도로 근처인지,
공원 근처인지에 따라 공기질이 다르기 때문이다냥. 이런 차이를 비교하는 게
