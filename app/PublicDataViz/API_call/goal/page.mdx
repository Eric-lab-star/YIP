<Callout type="goal">

## 1단계 · API 호출, 어떻게 하냥? (5분)

<NyangSpeech>
  API를 부르는 건 사실 식당에서 주문하는 것과 비슷하다냥! "이 주소로,
  이런 조건으로 데이터를 주세요"라고 부탁하면, API가 데이터를 돌려주는
  거다냥.
</NyangSpeech>

파이썬에서는 `requests`라는 라이브러리로 이 "부탁"을 보낸다냥. 필요한 건
딱 두 가지다냥.

<StepCard step="핵심" title="API 호출에 필요한 두 가지">

1. **주소(URL)** — 어떤 API에게 물어볼지 (예: 에어코리아 미세먼지 API 주소)
2. **파라미터(params)** — 인증키, 원하는 지역, 몇 건을 받을지 같은 세부 조건

</StepCard>

```text
pip install requests
```

<Callout type="note">
  `requests`는 파이썬에 기본으로 들어있지 않아서 설치가 필요하다냥. 이미
  설치되어 있다면 그냥 넘어가도 된다냥!
</Callout>

## 2단계 · 코드로 요청 보내기 (10분)

<NyangSpeech>
  이제 실제 코드를 살펴보자냥! 우리가 3차시에 인증키를 발급받았던 **에어코리아
  대기오염정보** API를 불러볼 거다냥.
</NyangSpeech>

```python
import requests

url = "http://apis.data.go.kr/B552584/ArpltnInforInqireSvc/getCtprvnRltmMesureDnsty"

params = {
    "serviceKey": "여기에 본인의 인증키 입력",  # 발급받은 그대로
    "returnType": "json",   # 결과를 JSON 형식으로 받겠다는 뜻
    "numOfRows": 10,        # 몇 개의 측정소 데이터를 받을지
    "pageNo": 1,
    "sidoName": "서울",      # 조회하고 싶은 시도 이름
    "ver": "1.0",
}

response = requests.get(url, params=params)
print("상태 코드:", response.status_code)
print(response.text[:300])  # 응답 앞부분만 미리 보기
```

<Callout type="important">
  `status_code`가 **200**이면 성공이라는 뜻이다냥! 200이 아니라면, 아래에서
  배울 문제 해결법을 참고해서 원인을 찾아보자냥.
</Callout>

## 3단계 · JSON 응답, 이렇게 생겼다냥 (10분)

<NyangSpeech>
  공공데이터포털의 API는 대부분 비슷한 모양의 JSON을 돌려준다냥. 딱
  구조만 알아두면, 다른 API를 만나도 당황하지 않는다냥!
</NyangSpeech>

```json
{
  "response": {
    "header": {
      "resultCode": "00",
      "resultMsg": "NORMAL_CODE"
    },
    "body": {
      "totalCount": 25,
      "items": [
        {
          "stationName": "중구",
          "dataTime": "2024-01-01 12:00",
          "pm10Value": "30",
          "pm25Value": "15"
        }
      ],
      "numOfRows": 10,
      "pageNo": 1
    }
  }
}
```

<StepCard step="핵심" title="JSON 구조, 이렇게 읽는다냥!">

| 키 | 뜻 |
|---|---|
| `response.header.resultCode` | 요청이 성공했는지 (`"00"`이면 성공) |
| `response.body.totalCount` | 전체 측정소 개수 |
| `response.body.items` | 실제 데이터가 들어있는 **리스트** |
| `items[0]["pm10Value"]` | 첫 번째 측정소의 미세먼지(PM10) 값 |

</StepCard>

파이썬에서는 `response.json()`으로 이 JSON을 딕셔너리로 바꿔서 다룰 수 있다냥.

```python
data = response.json()
items = data["response"]["body"]["items"]

for item in items:
    print(item["stationName"], "미세먼지(PM10):", item["pm10Value"])
```

<Callout type="tip">
  `pm10Value`처럼 숫자로 보이는 값도 사실 **문자열("30")**로 온다냥! 나중에
  계산이 필요하면 `int(item["pm10Value"])`처럼 숫자로 바꿔줘야 한다냥.
</Callout>
