## 1단계 · 상가 정보 데이터 출처 확인하기 (5분)

<Callout type="note">
  **이번 프로젝트 데이터 출처**

  - 제공처: 소상공인시장진흥공단 상가(상권)정보 (data.go.kr) (예시)
  - 라이선스: 공공누리 제1유형 (출처 표시 시 자유 이용 가능)
  - 이 수업에서는 실제 파일 대신, **같은 구조를 가진 작은 예시 데이터**로 연습한다냥.
</Callout>

```python
import pandas as pd
import numpy as np

data = {
    "상호명": ["코딩냥카페", "행복분식", "냥이베이커리", "은빛치킨", "달빛카페"],
    "업종": ["카페", "분식", "제과", "치킨", "카페"],
    "위도": [37.4979, 37.5636, np.nan, 37.5172, 37.5665],
    "경도": [127.0276, 126.9975, 126.9784, 127.0473, np.nan],
}
df = pd.DataFrame(data)
print(df)
```

<Callout type="important">
  상가 정보는 보통 **수십만 개** 행이 넘는 큰 데이터다냥! 그중
  우리가 관심 있는 업종만, 그리고 지도에 찍을 수 있는(좌표가 있는)
  데이터만 골라내는 게 첫 단계다냥.
</Callout>

카페만 = df[df["업종"] == "카페"]

<Callout type="tip">
  `==`은 "같다"는 뜻의 비교 연산자다냥. `df["업종"] == "카페"`는
  업종이 정확히 "카페"인 행만 `True`로 표시한 Series를 만들고,
  `df[...]`에 넣으면 그 행들만 골라진다냥!
</Callout>

## 3단계 · 위도·경도 결측치 제거하기 (9분)

<NyangSpeech>
  다음 시간에 folium으로 지도에 마커를 찍을 건데, **좌표가 없으면
  지도에 찍을 수가 없다냥!** 위도나 경도가 빈 값인 행을 미리
  제거해두자냥.
</NyangSpeech>

```python
지도용 = 카페만.dropna(subset=["위도", "경도"])
print(지도용)
print(f"원래 {len(카페만)}건 → 좌표 있는 {len(지도용)}건만 남음")
```

<StepCard step="핵심" title="dropna의 subset 옵션">

| 코드 | 하는 일 |
|---|---|
| `df.dropna()` | **어느 열이든** 빈 값이 있으면 그 행을 지움 |
| `df.dropna(subset=["위도", "경도"])` | **지정한 열**에 빈 값이 있을 때만 그 행을 지움 |

</StepCard>

<Callout type="note">
  `subset`을 지정하지 않으면, 상관없는 다른 열(예: 상호명)에 빈
  값이 있어도 행이 지워질 수 있다냥. 지도 시각화처럼 **특정 열이
  꼭 필요한 경우**엔 `subset`을 지정하는 게 안전하다냥!
</Callout>
