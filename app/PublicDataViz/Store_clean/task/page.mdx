<MissionCard number={1} title="원하는 업종만 골라내기" time="8~10분">

전체 상가 데이터에서 "카페"만 골라보자냥! 아래 템플릿에서
**빈칸(`____`)을 채워보자냥.**

```python
import pandas as pd
import numpy as np

data = {
    "상호명": ["코딩냥카페", "행복분식", "냥이베이커리", "은빛치킨", "달빛카페"],
    "업종": ["카페", "분식", "제과", "치킨", "카페"],
    "위도": [37.4979, 37.5636, np.nan, 37.5172, 37.5665],
    "경도": [127.0276, 126.9975, 126.9784, 127.0473, np.nan],
}
df = pd.DataFrame(data)

카페만 = df[df["업종"] == ____]
print(카페만)
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 찾고 싶은 업종 이름을 문자열로 넣으면 된다냥. (`"카페"`)
> - "코딩냥카페"와 "달빛카페" 2곳만 남냥?

</MissionCard>

<MissionCard number={2} title="좌표 결측치 확인하기" time="7~8분">

카페 데이터 중 좌표가 빠진 곳이 있는지 확인해보자냥.

```python
빈좌표 = 카페만[카페만.____().any(axis=1)]
print(빈좌표)
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 빈 값을 True/False로 표시하는 함수 이름을 넣으면 된다냥. (`isna`)
> - "달빛카페"가 경도 결측치로 걸리냥?

</MissionCard>

<MissionCard number={3} title="좌표 결측치 제거하기" time="8~10분">

지도에 찍을 수 있도록 좌표가 있는 데이터만 남겨보자냥.

```python
지도용 = 카페만.dropna(subset=____)
print(f"원래 {len(카페만)}건 → {len(지도용)}건만 남음")
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 확인할 열들을 리스트로 넣으면 된다냥. (`["위도", "경도"]`)
> - 2건에서 1건으로 줄어드냥?

<StepCard step="확인" title="subset을 빼먹으면 어떻게 될까냥?">

`dropna()`에서 `subset`을 빼먹으면, 상호명 같은 다른 열에 빈
값이 있어도 행이 지워질 수 있다냥. 지도용 데이터를 만들 땐 꼭
필요한 열만 `subset`으로 지정하는 습관을 들이자냥!

</StepCard>
