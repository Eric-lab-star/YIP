## 2단계 · 히트맵 그리기 (10분)

<NyangSpeech>
  히트맵은 `folium.plugins`의 `HeatMap`을 쓴다냥. 마커처럼
  하나씩 반복문을 돌 필요 없이, **좌표 목록을 통째로** 넘기면
  된다냥!
</NyangSpeech>

```python
import folium
from folium.plugins import HeatMap
import pandas as pd

data = {
    "상호명": ["코딩냥카페", "달빛카페", "은빛카페", "행복분식", "구름치킨"],
    "위도": [37.4979, 37.4985, 37.4970, 37.4990, 37.5636],
    "경도": [127.0276, 127.0280, 127.0265, 127.0290, 126.9975],
}
df = pd.DataFrame(data)

m = folium.Map(location=[37.52, 127.01], zoom_start=13)

좌표목록 = df[["위도", "경도"]].values.tolist()
HeatMap(좌표목록).add_to(m)

m.save("heatmap.html")
```

<Callout type="important">
  `df[["위도", "경도"]].values.tolist()`는 DataFrame의 위도, 경도
  두 열을 **[[위도, 경도], [위도, 경도], ...]** 형태의 파이썬
  리스트로 바꿔준다냥. `HeatMap()`은 바로 이 형태의 좌표 목록을
  입력으로 받는다냥!
</Callout>

## 3단계 · 결론 정리하기 (8분)

<NyangSpeech>
  마지막으로, value_counts()를 활용해서 "어느 동네에 상가가 가장
  많은지" 숫자로도 확인하고 결론을 내려보자냥!
</NyangSpeech>

```python
data2 = {
    "동": ["역삼동", "역삼동", "역삼동", "역삼동", "성수동"],
    "상호명": ["코딩냥카페", "달빛카페", "은빛카페", "행복분식", "구름치킨"],
}
df2 = pd.DataFrame(data2)

동별개수 = df2["동"].value_counts()
print(동별개수)

가장많은동 = 동별개수.idxmax()
print(f"결론: {가장많은동}에 상가가 가장 많이 몰려있다.")
```

<StepCard step="핵심" title="히트맵과 숫자, 둘 다 보여주기">

| 방법 | 장점 |
|---|---|
| 히트맵 | 지도 위에서 시각적으로 밀집도를 직관적으로 파악 |
| `value_counts()` | 정확한 숫자로 "몇 곳인지" 확인 가능 |

</StepCard>

<Callout type="note">
  그림(히트맵)과 숫자(value_counts)를 **함께** 보여주면, 발표할
  때 훨씬 설득력이 있다냥! 그림만 있으면 정확한 근거가 부족하고,
  숫자만 있으면 감이 잘 안 오기 때문이다냥.
</Callout>
