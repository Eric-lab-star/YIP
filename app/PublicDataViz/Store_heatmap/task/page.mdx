<MissionCard number={1} title="좌표 목록 만들기" time="7~8분">

DataFrame에서 위도, 경도만 뽑아 좌표 목록을 만들어보자냥! 아래
템플릿에서 **빈칸(`____`)을 채워보자냥.**

```python
import pandas as pd

data = {
    "상호명": ["코딩냥카페", "달빛카페", "은빛카페"],
    "위도": [37.4979, 37.4985, 37.4970],
    "경도": [127.0276, 127.0280, 127.0265],
}
df = pd.DataFrame(data)

좌표목록 = df[["위도", "경도"]].____.tolist()
print(좌표목록)
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 DataFrame을 순수 숫자 배열로 바꾸는 속성 이름을 넣으면 된다냥. (`values`)
> - [[37.4979, 127.0276], ...] 형태로 나오냥?

<MissionCard number={3} title="동별 상가 개수로 결론 정리하기" time="8~10분">

어느 동에 상가가 가장 많은지 숫자로 확인해보자냥.

```python
# 미션 1의 상가 3곳이 어느 동에 있는지 붙여준다냥
data2 = {
    "상호명": ["코딩냥카페", "달빛카페", "은빛카페"],
    "동": ["역삼동", "역삼동", "성수동"],
}
df2 = pd.DataFrame(data2)

동별개수 = df2["동"].value_counts()
가장많은동 = 동별개수.____()
print(f"결론: {가장많은동}에 상가가 가장 많이 몰려있다.")
```

> **확인해보자냥 (빈칸 힌트)**
> - `____` 자리에는 가장 큰 값을 가진 이름을 찾는 함수 이름을 넣으면 된다냥. (`idxmax`)
> - "역삼동"이 출력되냥?
